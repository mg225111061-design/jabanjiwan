여기서부터는 '숫자만 다루던 세계'에서 '글자도 다루는 세계'로 넘어간다.
지금까지는 3, −5, 7/2 같은 정해진 수만 계산했다. 그런데 "어떤 수인지 아직 모른다",
"여러 수를 한꺼번에 말하고 싶다" 같은 상황이 생긴다. 그때 숫자 대신 글자를 쓴다.
글자는 무섭지 않다. 그냥 '아직 정해지지 않은 수가 들어갈 빈칸'에 이름을 붙인 것이다.


■ 문자(변수)의 뜻 — 모르는 수를 글자로, 식 세우기
 〈왜 배우나〉 "사탕 한 개에 300원, x개 사면 얼마?"처럼 '개수가 아직 안 정해진' 상황을
   한 줄로 적으려면 글자가 필요하다. 모든 방정식·함수의 출발점이다.
 〈개념〉 글자(문자)는 '어떤 수가 들어갈 빈칸'에 붙인 이름이다. 보통 x, y, a, b를 쓴다.
   이렇게 값이 변할 수 있는 글자를 변수(變數, 변하는 수)라고 부른다.

   빈칸 그림:
     사탕 1개 = 300원
     사탕 [   ]개 = 300 × [   ] 원
     이 [   ] 자리에 글자 x를 넣으면 →  300 × x 원

   문자를 쓸 때 약속(이걸 지키면 식이 깔끔해진다):
     (1) 곱셈 기호 ×는 생략한다.   3 × x → 3x
     (2) 숫자를 글자 앞에 쓴다.     x × 3 → 3x  (3x라 쓰지 x3이라 안 쓴다)
     (3) 1은 생략한다.             1 × x → x ,   −1 × x → −x
     (4) 나눗셈 ÷는 분수로 바꾼다.  x ÷ 5 → x/5
     (5) 같은 글자의 곱은 거듭제곱으로.  x × x → x²

   ASCII로 '식 세우기'의 흐름:
     [말]  ──번역──▶  [식]
     "x보다 3 큰 수"          x + 3
     "x의 2배"               2x
     "x를 5로 나눈 몫"        x/5
     "한 개 700원짜리 a개 값"  700a

 〈예제〉
  예제1. 한 자루에 500원인 연필 a자루의 값을 식으로?
    풀이: (한 자루 값)×(자루 수) = 500 × a. ×는 생략 → 500a (원).
    왜: '한 개 값 곱하기 개수'가 전체 값이라서.
  예제2. 가로 x cm, 세로 4 cm인 직사각형의 넓이를 식으로?
    풀이: 넓이 = 가로 × 세로 = x × 4. 숫자를 앞에 → 4x (cm²).
    왜: 약속 (2)에 따라 숫자 4를 글자 x 앞에 쓴다.
  예제3. "어떤 수 x의 3배보다 2 작은 수"를 식으로?
    풀이: 3배 → 3x, 그보다 2 작은 → 3x − 2.
    왜: "~보다 □ 작은"은 그 수에서 □를 빼는 것.
 〈연습문제〉
  기초 1. 4 × x 를 약속대로 간단히
       2. x × x × x 를 간단히
       3. y ÷ 7 을 간단히
       4. 1 × a 를 간단히
       5. (−1) × b 를 간단히
  기본 6. "x보다 5 큰 수"를 식으로
       7. "한 개 200원짜리 사탕 n개의 값"을 식으로
       8. "x를 2로 나눈 몫에 3을 더한 수"를 식으로
  유형 9. 가로 a cm, 세로 b cm 직사각형의 넓이를 식으로
       10. 펜 한 자루 800원, 공책 한 권 1200원. 펜 x자루와 공책 y권을 산 값을 식으로
 〈해설〉
  1. ×생략 → 4x. (숫자가 이미 앞이라 그대로.)
  2. 같은 글자 3번 곱 → x³. 흔한 실수: 3x로 쓰면 안 된다(3x는 x+x+x, 곱이 아니다).
  3. ÷는 분수로 → y/7.
  4. 1은 생략 → a.
  5. −1도 1을 생략 → −b.
  6. "큰"은 더하기 → x + 5.
  7. (한 개 값)×(개수)=200 × n → 200n.
  8. x를 2로 나눈 몫 x/2, 거기에 3 더하기 → x/2 + 3.
  9. 가로×세로 = a × b → ab (cm²).
  10. 펜값 800x, 공책값 1200y, 합 → 800x + 1200y (원).
 〈정답〉 1) 4x  2) x³  3) y/7  4) a  5) −b  6) x+5  7) 200n  8) x/2 + 3  9) ab  10) 800x + 1200y
 〈위로 잇기〉 문자로 식 세우기는 방정식(01c), 함수, F카드의 '대수' 전체로 자란다.


■ 식의 값 (대입)
 〈왜 배우나〉 식을 세웠으면 "x가 실제로 5라면 답은 얼마?"를 알아야 쓸모가 있다.
   글자 자리에 수를 넣어 답을 구하는 것이 '식의 값'이다.
 〈개념〉 대입(代入)이란 글자 자리에 수를 '대신 넣는다'는 뜻이다.
   식의 값이란 대입해서 계산한 결과다.

   대입 그림 (x = 4를 넣을 때):
     3x + 1
       │
       └─ x 자리에 4를 넣는다
     3 × 4 + 1 = 12 + 1 = 13

   ★중요 1: 생략됐던 ×를 되살려라.★  3x 는 3 × x 다. x=4면 3×4=12.
   ★중요 2: 음수를 넣을 때는 괄호로 감싸라.★  x²에 x=−2 → (−2)² = 4 (−4 아님).
   괄호를 안 쓰면 −2² = −4로 잘못 읽기 쉽다. (−2)²는 (−2)×(−2)=+4.

 〈예제〉
  예제1. x = 3일 때 2x + 5 의 값?
    풀이: 2 × 3 + 5 = 6 + 5 = 11.
    왜: 2x는 2×x이므로 먼저 곱하고(6) 더한다(곱셈을 덧셈보다 먼저).
  예제2. x = −2일 때 x² 의 값?
    풀이: (−2)² = (−2) × (−2) = 4.
    왜: 음수는 괄호로 감싸야 부호를 바르게 곱한다. 음수×음수=양수.
  예제3. a = 2, b = 5일 때 3a + b 의 값?
    풀이: 3 × 2 + 5 = 6 + 5 = 11.
    왜: 글자마다 해당 수를 넣고, 곱셈 먼저.
 〈연습문제〉
  기초 1. x=2일 때 x + 7
       2. x=5일 때 4x
       3. x=3일 때 2x − 1
       4. x=10일 때 x/2
       5. a=6, b=1일 때 a + b
  기본 6. x=−3일 때 2x + 4
       7. x=−1일 때 x²
       8. x=4일 때 x² − x
  유형 9. x=2, y=3일 때 5x − 2y
       10. 직사각형 넓이 식 4x에서 x=7일 때 넓이(cm²)
 〈해설〉
  1. 2 + 7 = 9.
  2. 4 × 5 = 20.
  3. 2 × 3 − 1 = 6 − 1 = 5.
  4. 10 ÷ 2 = 5.
  5. 6 + 1 = 7.
  6. 2 × (−3) + 4 = −6 + 4 = −2. 흔한 실수: 음수 대입 시 괄호 빼먹기.
  7. (−1)² = (−1)×(−1) = 1.
  8. 4² − 4 = 16 − 4 = 12.
  9. 5 × 2 − 2 × 3 = 10 − 6 = 4.
  10. 4 × 7 = 28 cm².
 〈정답〉 1) 9  2) 20  3) 5  4) 5  5) 7  6) −2  7) 1  8) 12  9) 4  10) 28
 〈위로 잇기〉 대입은 함수의 'x를 넣으면 y가 나온다', 좌표 찍기로 곧장 이어진다.


■ 동류항 정리·일차식 계산
 〈왜 배우나〉 3x + 2x는 5x로 합칠 수 있다. 식을 짧게 정리해야 계산이 쉽고
   방정식도 풀 수 있다. 식 정리의 가장 기본 기술이다.
 〈개념〉 항(項)이란 +나 − 기호로 나뉜 한 덩어리다.   3x + 2x − 5 에는 항이 3개 (3x, 2x, −5).
   항에서 글자 앞에 곱해진 수를 계수(係數)라 한다.  3x의 계수는 3.
   글자 없이 수만 있는 항을 상수항(常數項)이라 한다.  −5가 상수항.

   동류항(同類項)이란 '글자 부분이 똑같은 항'끼리다.
     3x 와 2x → 동류항 (둘 다 x)
     3x 와 5  → 동류항 아님 (한쪽은 x, 한쪽은 글자 없음)
     x  와 x² → 동류항 아님 (x와 x²는 다르다)

   동류항 합치기 = 계수끼리만 더하거나 뺀다. 글자는 그대로 둔다.
     ┌ 3x + 2x = (3+2)x = 5x      ← 계수 3과 2를 더함
     └ 7x − 4x = (7−4)x = 3x

   일차식이란 글자의 차수가 1인 식(x는 있지만 x², x³은 없는 식). 예: 2x + 3.

 〈예제〉
  예제1. 5x + 3x 를 정리?
    풀이: 동류항. 계수만 더한다 → (5+3)x = 8x.
    왜: x가 5개와 3개를 합치면 x가 8개라서.
  예제2. 7x + 2 − 4x + 5 를 정리?
    풀이: x끼리: 7x − 4x = 3x. 수끼리: 2 + 5 = 7. → 3x + 7.
    왜: 동류항끼리만 모은다. x항과 상수항은 못 합친다.
  예제3. 2(x + 3) + x 를 정리?
    풀이: 먼저 괄호 풀기 2(x+3)=2x+6. 그다음 +x. → 2x + 6 + x = 3x + 6.
    왜: 괄호 앞 2를 안의 모든 항에 곱한다(분배법칙, 다음 소주제).
 〈연습문제〉
  기초 1. 2x + 6x
       2. 9x − 5x
       3. 4a + a
       4. 3x + 5 + 2x
       5. 8y − 3y + 2
  기본 6. 6x + 4 − 2x − 1
       7. 5a − 2 − 3a + 7
       8. x + 2x + 3x
  유형 9. 3(x + 2) + 4x
       10. 2x + 5 + 3(x − 1)
 〈해설〉
  1. (2+6)x = 8x.
  2. (9−5)x = 4x.
  3. a는 1a → (4+1)a = 5a. 흔한 실수: a를 0으로 세지 말 것, 계수는 1이다.
  4. x끼리 3x+2x=5x, 상수 5 → 5x + 5.
  5. y끼리 8y−3y=5y, 상수 +2 → 5y + 2.
  6. x끼리 6x−2x=4x, 상수 4−1=3 → 4x + 3.
  7. a끼리 5a−3a=2a, 상수 −2+7=5 → 2a + 5.
  8. (1+2+3)x = 6x.
  9. 3(x+2)=3x+6, +4x → 3x+4x+6 = 7x + 6.
  10. 3(x−1)=3x−3, 더하면 2x+5+3x−3 = 5x + 2.
 〈정답〉 1) 8x  2) 4x  3) 5a  4) 5x+5  5) 5y+2  6) 4x+3  7) 2a+5  8) 6x  9) 7x+6  10) 5x+2
 〈위로 잇기〉 동류항 정리는 방정식 풀이(이항·정리)와 다항식 계산의 필수 도구다.


■ 분배법칙과 전개 (a(b+c)=ab+ac)
 〈왜 배우나〉 괄호가 있는 식을 풀어 써야 동류항도 정리하고 방정식도 풀 수 있다.
   괄호를 푸는 규칙이 분배법칙이다.
 〈개념〉 분배법칙: 괄호 앞의 수(또는 글자)를 괄호 안의 '모든 항에 빠짐없이' 곱한다.
       a(b + c) = a×b + a×c = ab + ac
   '전개'란 괄호를 풀어서 곱이 없는 형태로 펼치는 것이다.

   화살표 그림 (모든 항에 가야 한다):
        ┌──────┐
        │   ┌──┼──┐
       3 ( x + 2 )
        └──┘
       3×x + 3×2 = 3x + 6

   ★부호 주의★: 괄호 앞이 − 이면 안의 부호가 전부 바뀐다.
       −(x − 4) = −x + 4    ( −1을 모든 항에 곱한 것 )
       −2(x + 3) = −2x − 6

 〈예제〉
  예제1. 4(x + 5) 를 전개?
    풀이: 4×x + 4×5 = 4x + 20.
    왜: 괄호 안 두 항 모두에 4를 곱해야 해서.
  예제2. −3(2x − 1) 를 전개?
    풀이: −3×2x + (−3)×(−1) = −6x + 3.
    왜: 두 번째 항 −1에 −3을 곱하면 +3 (음수×음수=양수).
  예제3. 2(x + 3) + 3(x − 1) 을 전개하고 정리?
    풀이: 2x+6 + 3x−3 = (2x+3x) + (6−3) = 5x + 3.
    왜: 각 괄호를 전개한 뒤 동류항끼리 모은다.
 〈연습문제〉
  기초 1. 2(x + 4)
       2. 5(a − 3)
       3. 3(2x + 1)
       4. −(x + 6)
       5. −4(x − 2)
  기본 6. 2(x + 1) + 3x
       7. 3(x − 2) − x
       8. −2(x − 5) + 4
  유형 9. 4(x + 2) + 2(x − 3)
       10. 5(x − 1) − 2(x + 4)
 〈해설〉
  1. 2x + 8.
  2. 5a − 15.
  3. 3×2x + 3×1 = 6x + 3.
  4. −x − 6 (−1을 둘 다에 곱). 흔한 실수: −(x+6)을 −x+6으로 잘못 쓰기.
  5. −4×x + (−4)×(−2) = −4x + 8.
  6. 2x+2 + 3x = 5x + 2.
  7. 3x−6 − x = 2x − 6.
  8. −2x+10 + 4 = −2x + 14.
  9. 4x+8 + 2x−6 = 6x + 2.
  10. 5x−5 − 2x−8 = 3x − 13. 흔한 실수: −2(x+4)에서 +4에 −2 곱해 −8인데 부호 빠뜨림.
 〈정답〉 1) 2x+8  2) 5a−15  3) 6x+3  4) −x−6  5) −4x+8  6) 5x+2  7) 2x−6  8) −2x+14  9) 6x+2  10) 3x−13
 〈위로 잇기〉 분배법칙은 곱셈공식, 다항식 곱셈, 방정식의 괄호 풀기로 이어진다.


■ 곱셈공식 기초 ((a+b)²=a²+2ab+b², (a+b)(a−b)=a²−b²)
 〈왜 배우나〉 (x+3)²처럼 괄호끼리의 곱을 매번 일일이 풀면 느리다. 자주 나오는 모양은
   공식으로 외워 두면 빠르고 실수도 준다.
 〈개념〉 먼저 '괄호 둘의 곱'은 모든 항을 짝지어 곱한다(분배법칙 두 번).
       (a + b)(c + d) = ac + ad + bc + bd
   여기서 특별한 두 모양이 곱셈공식이다.

   공식1 (합의 제곱):
       (a + b)² = a² + 2ab + b²
     넓이 그림 (한 변 a+b인 정사각형을 네 조각으로):
       ┌─────┬───┐
       │ a²  │ab │
       ├─────┼───┤
       │ ab  │b² │
       └─────┴───┘
       a² + ab + ab + b² = a² + 2ab + b²   (가운데 ab가 두 개 → 2ab)

   공식2 (차의 제곱):  (a − b)² = a² − 2ab + b²   (가운데 부호만 −)

   공식3 (합·차의 곱):  (a + b)(a − b) = a² − b²   (가운데 항이 사라진다)
     확인: a² − ab + ab − b² = a² − b².

 〈예제〉
  예제1. (x + 3)² 을 전개?
    풀이: 공식1, a=x, b=3 → x² + 2·x·3 + 3² = x² + 6x + 9.
    왜: 2ab 자리에 2×x×3=6x, b² 자리에 9.
  예제2. (x − 5)² 을 전개?
    풀이: 공식2, a=x, b=5 → x² − 2·x·5 + 5² = x² − 10x + 25.
    왜: 차의 제곱은 가운데가 −. 끝 b²은 (−5)²=25로 항상 +.
  예제3. (x + 4)(x − 4) 를 전개?
    풀이: 공식3, a=x, b=4 → x² − 4² = x² − 16.
    왜: 합·차의 곱은 가운데가 지워지고 제곱의 차만 남는다.
 〈연습문제〉
  기초 1. (x + 1)²
       2. (x + 2)²
       3. (x − 1)²
       4. (x + 5)(x − 5)
       5. (x − 3)²
  기본 6. (x + 6)²
       7. (x − 2)(x + 2)
       8. (2x + 1)²
  유형 9. (x + 3)² − 9
       10. (x + 2)(x − 2) + (x − 1)²
 〈해설〉
  1. x² + 2x + 1.
  2. x² + 4x + 4.
  3. x² − 2x + 1.
  4. x² − 25.
  5. x² − 6x + 9.
  6. x² + 12x + 36.
  7. 합·차의 곱 → x² − 4.
  8. a=2x, b=1: (2x)² + 2·2x·1 + 1² = 4x² + 4x + 1. 흔한 실수: (2x)²를 2x²로 쓰기(맞게는 4x²).
  9. (x²+6x+9) − 9 = x² + 6x.
  10. (x²−4) + (x²−2x+1) = 2x² − 2x − 3.
 〈정답〉 1) x²+2x+1  2) x²+4x+4  3) x²−2x+1  4) x²−25  5) x²−6x+9  6) x²+12x+36
        7) x²−4  8) 4x²+4x+1  9) x²+6x  10) 2x²−2x−3
 〈위로 잇기〉 곱셈공식은 인수분해(거꾸로), 이차방정식·이차함수의 핵심 도구가 된다.


■ 인수분해 기초 (공통인수, 곱셈공식 거꾸로)
 〈왜 배우나〉 전개가 '괄호를 푸는 것'이라면 인수분해는 그 반대 — '곱의 형태로 묶는 것'이다.
   이차방정식을 풀 때 이 묶기가 결정적이다.
 〈개념〉 인수(因數)란 '곱해서 그 식을 만드는 조각'이다.  6 = 2 × 3에서 2와 3이 인수.
   인수분해란 식을 인수들의 곱으로 다시 쓰는 것이다.

   전개 ──▶  3(x+2) = 3x + 6
   인수분해 ◀──  3x + 6 = 3(x+2)
   (같은 식을 서로 반대 방향으로 본 것이다.)

   방법1: 공통인수로 묶기. 모든 항에 똑같이 들어 있는 것을 밖으로 뺀다.
       3x + 6 = 3·x + 3·2 = 3(x + 2)        ← 공통인수 3
       x² + x = x·x + x·1 = x(x + 1)        ← 공통인수 x

   방법2: 곱셈공식을 거꾸로.
       a² + 2ab + b² = (a + b)²
       a² − 2ab + b² = (a − b)²
       a² − b²       = (a + b)(a − b)        ← '제곱의 차'를 보면 떠올려라

 〈예제〉
  예제1. 2x + 8 을 인수분해?
    풀이: 두 항 모두 2로 나뉜다(2x=2·x, 8=2·4). 공통인수 2 → 2(x + 4).
    왜: 2를 묶어 내면 안에 x+4가 남는다. 검산: 2(x+4)=2x+8 맞다.
  예제2. x² − 9 를 인수분해?
    풀이: 9=3²이므로 x² − 3² = 제곱의 차 → (x + 3)(x − 3).
    왜: 공식3을 거꾸로. 검산: (x+3)(x−3)=x²−9 맞다.
  예제3. x² + 6x + 9 를 인수분해?
    풀이: 끝이 9=3², 가운데 6x=2·x·3 → 합의 제곱 → (x + 3)².
    왜: a²+2ab+b² 꼴. 검산: (x+3)²=x²+6x+9 맞다.
 〈연습문제〉
  기초 1. 3x + 9
       2. 5x − 10
       3. x² + x
       4. 2x² + 4x
       5. 6a + 6b
  기본 6. x² − 4
       7. x² − 25
       8. x² + 4x + 4
  유형 9. x² − 10x + 25
       10. 4x² − 1
 〈해설〉
  1. 공통 3 → 3(x + 3). 검산 3x+9. 맞다.
  2. 공통 5 → 5(x − 2). 검산 5x−10.
  3. 공통 x → x(x + 1). 검산 x²+x.
  4. 공통 2x → 2x(x + 2). 검산 2x²+4x. 흔한 실수: 2만 빼고 x를 놓침.
  5. 공통 6 → 6(a + b).
  6. 제곱의 차(4=2²) → (x + 2)(x − 2).
  7. (x + 5)(x − 5).
  8. 9 대신 4=2², 4x=2·x·2 → (x + 2)².
  9. 25=5², 10x=2·x·5, 가운데 − → (x − 5)².
  10. 4x²=(2x)², 1=1² → (2x + 1)(2x − 1). 검산 4x²−1.
 〈정답〉 1) 3(x+3)  2) 5(x−2)  3) x(x+1)  4) 2x(x+2)  5) 6(a+b)  6) (x+2)(x−2)
        7) (x+5)(x−5)  8) (x+2)²  9) (x−5)²  10) (2x+1)(2x−1)
 〈위로 잇기〉 인수분해는 이차방정식 풀이(=곱이 0이면 한쪽이 0), 분수식 약분으로 자란다.


■ 지수법칙 (aᵐ·aⁿ=aᵐ⁺ⁿ, (aᵐ)ⁿ=aᵐⁿ, aᵐ/aⁿ)
 〈왜 배우나〉 x²·x³ 같은 거듭제곱의 곱을 빠르게 계산해야 한다. 큰 수·작은 수,
   다항식 계산, 과학의 단위까지 거듭제곱이 깔려 있다.
 〈개념〉 거듭제곱: a를 여러 번 곱한 것. aⁿ에서 a를 밑, n을 지수라 한다.
       a³ = a × a × a   (a를 3번 곱함)

   법칙1 (곱셈, 지수끼리 더하기):  aᵐ · aⁿ = aᵐ⁺ⁿ
     이유 그림:
       a² · a³ = (a·a)·(a·a·a) = a·a·a·a·a = a⁵   (2개 + 3개 = 5개)

   법칙2 (거듭제곱의 거듭제곱, 지수끼리 곱하기):  (aᵐ)ⁿ = aᵐⁿ
       (a²)³ = a²·a²·a² = a^(2+2+2) = a⁶   (2 × 3 = 6)

   법칙3 (나눗셈, 지수끼리 빼기, m > n일 때):  aᵐ / aⁿ = aᵐ⁻ⁿ
       a⁵ / a² = (a·a·a·a·a)/(a·a) = a·a·a = a³   (5 − 2 = 3)

   ★주의★: 밑이 같을 때만 더하거나 뺀다. a²·b³는 더 못 합친다(밑이 다름).
   또 a²·a³ ≠ a⁶. 지수는 더하는 것(2+3=5)이지 곱하는 게 아니다.

 〈예제〉
  예제1. x² · x⁴ = ?
    풀이: 밑이 같으니 지수를 더한다 → x^(2+4) = x⁶.
    왜: x가 2개와 4개, 합쳐 6개를 곱하니까.
  예제2. (x³)² = ?
    풀이: 지수를 곱한다 → x^(3×2) = x⁶.
    왜: x³을 2번 곱하면 x³·x³=x⁶, 즉 3×2.
  예제3. x⁷ / x³ = ?
    풀이: 지수를 뺀다 → x^(7−3) = x⁴.
    왜: 위 7개에서 아래 3개를 약분해 없애면 4개 남는다.
 〈연습문제〉
  기초 1. a³ · a²
       2. x · x⁴       (x는 x¹)
       3. (a²)³
       4. y⁵ / y²
       5. 2² · 2³       (수로 계산: 답을 수로)
  기본 6. x³ · x³ · x
       7. (x⁴)²
       8. a⁶ / a
  유형 9. x² · x³ / x   (위는 곱, 그다음 나눔)
       10. (2x²)³        (계수도 거듭제곱)
 〈해설〉
  1. 3+2 → a⁵.
  2. x¹·x⁴ → x^(1+4) = x⁵. 흔한 실수: x를 x⁰로 보지 말 것, x는 x¹이다.
  3. 2×3 → a⁶.
  4. 5−2 → y³.
  5. 지수 더하기 2+3=5 → 2⁵ = 32. (검산: 4×8=32.)
  6. 3+3+1 → x⁷.
  7. 4×2 → x⁸.
  8. a는 a¹: 6−1 → a⁵.
  9. 먼저 x²·x³=x⁵, 그다음 x⁵/x¹ = x⁴.
  10. (2x²)³ = 2³·(x²)³ = 8·x⁶ = 8x⁶. 흔한 실수: 계수 2를 그냥 두기(2³=8로 올려야 함).
 〈정답〉 1) a⁵  2) x⁵  3) a⁶  4) y³  5) 32  6) x⁷  7) x⁸  8) a⁵  9) x⁴  10) 8x⁶
 〈위로 잇기〉 지수법칙은 다항식·지수함수, 매우 큰/작은 수의 표기(과학적 기수법)로 이어진다.


■ 비와 비율
 〈왜 배우나〉 "남학생 대 여학생 = 2 대 3"처럼 두 양을 견주어 말할 때 비를 쓴다.
   요리 재료 비율, 지도 축척, 농도까지 전부 비의 언어다.
 〈개념〉 비(比)란 두 수를 ':'로 견준 것.  2 : 3 은 "2 대 3"이라 읽는다.
   a : b 에서 b를 기준으로 a가 얼마인지를 분수로 나타낸 것이 비의 값(비율)이다.
       a : b 의 비의 값 = a/b

   그림 (2 : 3 을 칸으로):
       앞 ■■        (2칸)
       뒤 ■■■       (3칸)
       비의 값 = 2/3 (뒤 3칸을 기준으로 앞은 그 2/3)

   ★같은 비★: 앞뒤에 같은 수를 곱하거나 나눠도 비는 변하지 않는다.
       2 : 3 = 4 : 6 = 6 : 9        (앞뒤에 똑같이 ×2, ×3)
       이걸 이용해 비를 가장 작은 정수로 줄인 것을 '가장 간단한 비'라 한다.
       10 : 15 = (÷5) = 2 : 3

 〈예제〉
  예제1. 6 : 8 을 가장 간단한 비로?
    풀이: 6과 8의 공통인수 2로 나눈다 → (6÷2) : (8÷2) = 3 : 4.
    왜: 앞뒤를 같은 수로 나눠도 비는 그대로. 더 줄일 공통인수 없음.
  예제2. 비 3 : 4 의 비의 값?
    풀이: 앞/뒤 = 3/4.
    왜: 비의 값은 '뒤를 기준으로 한 앞의 분수'.
  예제3. 0.5 : 2 를 간단한 정수비로?
    풀이: 소수를 없애려 앞뒤에 ×2 → 1 : 4.
    왜: 같은 수를 곱해도 비는 안 변한다. 정수로 만들면 보기 쉽다.
 〈연습문제〉
  기초 1. 4 : 6 을 간단히
       2. 10 : 5 를 간단히
       3. 9 : 12 를 간단히
       4. 비 1 : 2 의 비의 값
       5. 비 5 : 1 의 비의 값
  기본 6. 8 : 20 을 간단히
       7. 0.3 : 0.6 을 정수비로
       8. 비 7 : 14 의 값(분수로, 약분)
  유형 9. 사과 12개 대 배 18개의 비를 간단히
       10. 가로:세로 = 6:4인 직사각형, 가장 간단한 비로
 〈해설〉
  1. ÷2 → 2 : 3.
  2. ÷5 → 2 : 1.
  3. ÷3 → 3 : 4.
  4. 1/2.
  5. 5/1 = 5.
  6. ÷4 → 2 : 5.
  7. ×10으로 정수화 → 3 : 6, 다시 ÷3 → 1 : 2.
  8. 7/14 = 1/2 (÷7).
  9. 12 : 18, ÷6 → 2 : 3. 흔한 실수: ÷2만 하고 6:9에서 멈추기(더 줄여 2:3).
  10. 6 : 4, ÷2 → 3 : 2.
 〈정답〉 1) 2:3  2) 2:1  3) 3:4  4) 1/2  5) 5  6) 2:5  7) 1:2  8) 1/2  9) 2:3  10) 3:2
 〈위로 잇기〉 비는 비례식·비례배분, 일차함수의 기울기, 닮음비로 자란다.


■ 백분율(퍼센트)
 〈왜 배우나〉 할인 30%, 시험 정답률 80%, 소금물 농도 5%. 일상의 '비율'은 거의
   백분율로 말한다. 읽고 계산할 줄 알아야 한다.
 〈개념〉 백분율(百分率)이란 전체를 100으로 봤을 때의 비율이다. 기호는 % (퍼센트).
       비율(분수·소수)  ──×100──▶  백분율(%)
       백분율(%)        ──÷100──▶  비율(소수)

   변환 그림:
       0.3  ──×100──▶  30%
       30%  ──÷100──▶  0.3
       1/4 = 0.25  ──×100──▶  25%

   핵심 공식 (이 세 줄이면 거의 다 푼다):
       비율 = (부분) / (전체)
       백분율(%) = (부분/전체) × 100
       부분 = 전체 × (백분율/100)

   ★주의★ "전체의 몇 %"를 구할 때 '전체'가 무엇인지 먼저 정하라.
   예: 1000원의 20%는 1000 × 20/100 = 200원.

 〈예제〉
  예제1. 0.45 를 백분율로?
    풀이: ×100 → 45%.
    왜: 백분율은 비율에 100을 곱한 것.
  예제2. 25명 중 5명이 안경. 안경 쓴 비율은 몇 %?
    풀이: 부분/전체 = 5/25 = 0.2, ×100 → 20%.
    왜: 전체 25를 기준으로 부분 5의 비율을 100배 한다.
  예제3. 2000원짜리의 30%는 얼마?
    풀이: 2000 × 30/100 = 2000 × 0.3 = 600원.
    왜: '부분 = 전체 × (백분율/100)' 공식.
 〈연습문제〉
  기초 1. 0.7 을 %로
       2. 60% 를 소수로
       3. 1/2 을 %로
       4. 0.05 를 %로
       5. 25% 를 소수로
  기본 6. 50명 중 10명은 몇 %?
       7. 800원의 25%는 얼마?
       8. 200의 40%는 얼마?
  유형 9. 정가 5000원에서 20% 할인하면 할인액과 낼 돈은?
       10. 어떤 반 40명 중 60%가 남학생. 남학생 수는?
 〈해설〉
  1. 0.7×100 = 70%.
  2. 60÷100 = 0.6.
  3. 1/2=0.5, ×100 → 50%.
  4. 0.05×100 = 5%.
  5. 25÷100 = 0.25.
  6. 10/50=0.2 → 20%.
  7. 800×25/100 = 800×0.25 = 200원.
  8. 200×40/100 = 200×0.4 = 80.
  9. 할인액 5000×20/100=1000원, 낼 돈 5000−1000=4000원. 흔한 실수: 할인액만 답하고 낼 돈을 안 구함.
  10. 40×60/100 = 40×0.6 = 24명.
 〈정답〉 1) 70%  2) 0.6  3) 50%  4) 5%  5) 0.25  6) 20%  7) 200원  8) 80  9) 할인 1000원, 낼 돈 4000원  10) 24명
 〈위로 잇기〉 백분율은 농도·이자 문제, 통계의 상대도수, 확률(백분율 표현)로 이어진다.


■ 비례식과 비례배분
 〈왜 배우나〉 "3개에 1500원이면 7개는?"처럼 비가 같음을 이용해 모르는 값을 구할 때
   비례식을 쓴다. 비례배분은 전체를 정해진 비로 나눠 주는 기술이다.
 〈개념〉 비례식이란 두 비가 같음을 등호로 쓴 것이다.   a : b = c : d
   읽기: 안쪽 둘(b, c)을 '내항', 바깥 둘(a, d)을 '외항'이라 한다.

       a : b = c : d
       └외       외┘
           └내 내┘

   ★비례식의 성질★: 내항의 곱 = 외항의 곱.   b × c = a × d
       그림으로 외우기 (가위표 ✕ 모양으로 곱한다):
         a : b
            ✕
         c : d   →  b·c = a·d

   이 성질로 모르는 항 x를 구한다. 예: 2 : 3 = x : 9 → 외항·내항 곱 같게:
       2 × 9 = 3 × x → 18 = 3x → x = 6.

   비례배분이란 전체를 정해진 비로 나누는 것이다.  전체 ÷ (비의 합) × (각 몫)
       예: 1000원을 2 : 3으로 → 비의 합 5. 한 칸 = 1000÷5 = 200.
           앞 = 200×2 = 400원, 뒤 = 200×3 = 600원. (합 1000 확인.)

 〈예제〉
  예제1. 4 : 5 = 8 : x 에서 x?
    풀이: 외항곱=내항곱 → 4·x = 5·8 → 4x = 40 → x = 10.
    왜: 비례식은 안쪽 곱과 바깥 곱이 같다는 성질을 쓴다. 검산: 4:5=8:10 맞다.
  예제2. 사탕 3개가 600원. 같은 사탕 5개는?
    풀이: 3 : 600 = 5 : x → 3x = 600·5 = 3000 → x = 1000원.
    왜: 개수와 값의 비가 일정하므로 비례식.
  예제3. 1200원을 1 : 2로 나누면?
    풀이: 비의 합 1+2=3, 한 칸=1200÷3=400. 앞=400×1=400, 뒤=400×2=800.
    왜: 비례배분. 검산: 400+800=1200 맞다.
 〈연습문제〉
  기초 1. 2 : 3 = 4 : x
       2. 1 : 4 = x : 12
       3. 5 : 2 = x : 6
       4. 3 : x = 6 : 8
       5. x : 5 = 4 : 10
  기본 6. 연필 2자루 300원, 5자루는? (2 : 300 = 5 : x)
       7. 900원을 1 : 2로 비례배분
       8. 1500원을 2 : 3으로 비례배분
  유형 9. 사탕 24개를 형과 동생이 5 : 3으로 나누면 각각 몇 개?
       10. 지도에서 2 cm가 실제 100 m. 실제 350 m는 지도에서 몇 cm? (2 : 100 = x : 350)
 〈해설〉
  1. 2x = 3·4 = 12 → x = 6.
  2. 1·12 = 4·x → 12 = 4x → x = 3.
  3. 5·6 = 2·x → 30 = 2x → x = 15.
  4. 3·8 = 6·x → 24 = 6x → x = 4.
  5. 10·x = 5·4 → 10x = 20 → x = 2.
  6. 2x = 300·5 = 1500 → x = 750원.
  7. 합 3, 한 칸 900÷3=300. 앞 300×1=300, 뒤 300×2=600. (300+600=900.)
  8. 합 5, 한 칸 1500÷5=300. 앞 300×2=600, 뒤 300×3=900. (600+900=1500.)
  9. 합 8, 한 칸 24÷8=3. 형 3×5=15개, 동생 3×3=9개. (15+9=24.) 흔한 실수: 비의 합으로 안 나누고 그냥 5,3을 답함.
