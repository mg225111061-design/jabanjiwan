Tier4 — 다리: 도장에서 익힌 '한 수'를 미해결 난제에 직접 휘두르기
================================================================

지금까지 너는 도장에서 다섯 가지 발명 동작을 손에 익혔다.

   ┌─ 도장에서 익힌 다섯 동작(연장통) ─────────────────────────┐
   │ ① 접기(folding)        : 반복·무한 사슬을 한 수로 눌러 담기 │
   │                          (Tier0 곱셈·지수, Tier1 가우스합·망원합)│
   │ ② 뒤집기(reversing)    : 줄을 거꾸로 짝지어 대칭을 만들기   │
   │                          (Tier1 가우스합, Tier2 복소평면)   │
   │ ③ 불변량 만들기        : 변하는 양을 조합해 안 변하는 지문 뽑기│
   │                          (Tier1 얽힘수, Tier3 오일러지표·매듭)│
   │ ④ 차원 늘리기          : 막힌 평면을 한 축 더해 우회로로 풀기│
   │                          (Tier2 복소평면 √−1, 적분의 넓이)  │
   │ ⑤ 불가능 증명          : '절대 안 됨'을 불변량으로 박제하기  │
   │                          (Tier3 패리티 논증·불가능성 증명)  │
   └──────────────────────────────────────────────────────────────┘

Tier4는 새 과제를 주지 않는다. 대신 **이 다섯 동작이 미해결 난제 속에서
어떻게 괴물처럼 부풀어 오르는지**를 보여 준다. 난제는 네가 도장에서 푼 문제와
*같은 동작*을 요구한다 — 다만 크기가 인류 전체가 아직 못 넘은 만큼 크다.

세 난제를 고른다. 각 난제마다 (1) 한 줄 현상 (2) 어느 동작의 조합인지
(3) 문서 C로 넘기는 다리 (4) [도장 동작 → 난제의 벽] 대응표 한 컷.

읽는 법: "아, 내가 가우스합에서 한 짝짓기가 #8에서는 이렇게 커지는구나"를
느끼면 된다. 그 느낌이 다리다. 건너가서 직접 도구를 설계하는 건 문서 C에서다.

다리 1 — 난제 #8  나비에-스토크스 (매끄러운 흐름의 존재)   [축: 물리]
================================================================

(1) 한 줄 현상
   수도꼭지를 살살 틀면 물줄기가 유리막대처럼 매끈하다(층류). 세게 틀면 갑자기
   하얗게 부서진다(난류). 매끈하게 출발한 흐름이 영원히 매끈한지, 아니면 어느
   점에서 속도가 무한대로 치솟아(폭발, blow-up) 방정식이 의미를 잃는지 — 3차원에서
   아무도 증명하지 못한다.

(2) 이 난제는 도장의 어느 동작들의 조합인가
   **#8 나비에-스토크스 = Tier1 '접기'(가우스/망원합) + Tier3 '불변량 만들기'(오일러
   지표)를 비선형 스케일에 휘두르기.**

   한마디로: **"무한히 작아지는 소용돌이 사슬을 한 수로 접고, 폭발 직전에도 안 변하는
   양을 뽑아라."**

   풀어 보면 —

   · 접기(①) 의 괴물 버전:
     가우스합에서 너는 1+2+…+n 이라는 *유한한* 반복 덧셈을 n(n+1)/2 라는 한 수로
     접었다. #8에서 접어야 할 것은 *무한한* 사슬이다. 큰 소용돌이가 자식 소용돌이를,
     자식이 손자를 낳으며 스케일이 끝없이 작아진다(에너지 캐스케이드).

        가우스합(도장):  1 + 2 + 3 + … + n        → 한 수 n(n+1)/2   (유한, 끝이 있음)
        #8(난제)     :  큰소용돌이 → /2 → /4 → /8 → … → 0?  → 한 수 ⟦스케일가교⟧#8[u](t)?  (무한 사슬)

     망원합(telescoping)에서 익힌 "가운데 항이 줄줄이 상쇄돼 양 끝만 남는다"가 여기서
     필요하다 — 스케일마다 흩어진 에너지를 한 적분으로 눌러 담는 것. 다만 항이 무한히
     많고, 비선형이라 깔끔히 상쇄되지 않는다. 거기서 도장의 접기가 비명을 지른다.

   · 불변량 만들기(③) 의 괴물 버전:
     오일러지표에서 너는 "찌그러뜨려도 안 변하는 양 χ=V−E+F"를 뽑았다. #8이 원하는
     건 "흐름이 폭발로 치닫는 동안에도 *유한하면 폭발 없음을 보장하는* 양"이다.
     즉 폭발이라는 격변 앞에서도 통제되는 한 개의 수 — 일종의 '폭발 불변량'.
     문서 C는 이걸 가칭 ⟦스케일가교⟧#8로 부른다.

        오일러지표(도장):  도형을 늘여도   χ 안 변함        → 위상의 지문
        #8(난제)       :  흐름이 폭발해도  ⟦스케일가교⟧#8[u](t)<∞ 유지?  → 폭발을 막는 지문

   왜 인류가 막혔나(정직): 비선형항 (u·∇)u 가 스케일을 *무한히* 잇는다. 접으려는
   가중치 Φ(k)를 어떻게 골라도, 비선형이 그 가중치를 빠져나가 더 작은 스케일로 새는
   양을 제어하는 부등식이 *자기 자신을 닫지 못한다*. 도장의 접기는 사슬이 유한할 때만
   완벽했다. 무한 비선형 사슬에서는 접기와 불변량 만들기를 동시에 휘둘러야 하는데,
   그 두 손을 한 식 안에서 맞물리는 법을 여기서부터 인류가 모른다.

(3) 이제 네 차례 → 문서 C로
   → **파일 `27_C_난제_물리_08-14.md` 의 「◆ 난제 #8」, 그 안 「4) 〈도구 설계 의뢰〉」**
   로 건너가라. 거기서 너는 스케일가교 연산자 ⟦스케일가교⟧#8 를 직접 설계하고, 가중치 Φ(k)를
   어떻게 골라야 비선형 누수를 막는지 5대 검문소로 채점하게 된다. 도장에서 접기와
   불변량 만들기를 따로 익혔으니, 이제 둘을 *한 손으로* 휘두를 차례다.

(4) [도장 동작 → 난제의 벽] 대응표

   ┌─────────────────────────────┬──────────────────────────────────────────┐
   │ 네가 도장에서 쓴 동작        │ #8에서 그게 부딪치는 벽                     │
   ├─────────────────────────────┼──────────────────────────────────────────┤
   │ ① 접기(가우스합)            │ 무한히 작아지는 소용돌이 사슬을 한 적분으로 │
   │   유한 반복 → 한 수          │ 접기 — 사슬이 무한·비선형이라 안 닫힘       │
   ├─────────────────────────────┼──────────────────────────────────────────┤
   │ ① 접기(망원합)              │ 스케일마다 흩어진 에너지의 상쇄 — 비선형이  │

다리 2 — 난제 #2  P 대 NP (확인은 빠른데 찾기는 느린가)   [축: 수학]
================================================================

(1) 한 줄 현상
   스도쿠 답이 맞는지 *확인*하는 건 1분이면 되는데, 빈 칸에서 답을 *찾는* 건 훨씬
   오래 걸린다. 세상엔 '확인은 빠른데 찾기는 본질적으로 느린' 문제가 정말 따로
   있나(P≠NP), 아니면 우리가 좋은 방법을 못 찾았을 뿐 늘 빠르게 할 수 있나(P=NP)?

(2) 이 난제는 도장의 어느 동작들의 조합인가
   **#2 P vs NP = Tier3 '불가능성 증명'(패리티/불변량으로 안 됨 증명)을 계산 단계 수에
   휘두르기.**

   한마디로: **"어떤 불변량이 '빠른 알고리즘이 절대 없음'을 박제하나?"**

   풀어 보면 —

   · 불가능 증명(⑤) 의 괴물 버전:
     도장에서 너는 '안 됨'을 불변량으로 박제하는 법을 봤다. 전형적인 한 수가 *패리티
     (parity, 홀짝)* 다. 예를 들어 "체스판 양 끝 칸을 뗀 판을 도미노로 빈틈없이 덮을 수
     있나?"는 — 칸을 흑백으로 칠하면 떼어낸 두 칸이 *같은 색*이라 흑·백 개수가 어긋난다.
     도미노 하나는 늘 흑1·백1을 덮으니, 색 개수 차이라는 **불변량**이 0이 아니면 *어떤
     배치로도* 못 덮는다. "한 번도 시도 안 한 배치까지 전부 포함해 불가능"을 한 수로
     박제한 것 — 이게 불가능 증명의 핵심이다.

        도미노(도장):  흑 개수 − 백 개수 = 불변량 ≠ 0  ⇒ 어떤 배치로도 덮기 불가능
        #2(난제)   :  SAT의 '본질 난도' = 불변량 ?     ⇒ 어떤 알고리즘으로도 다항 불가능?

   · #2가 원하는 것:
     P≠NP를 증명하려면 "SAT 같은 문제는 *아직 발명 안 된 것까지 포함해, 모든 가능한
     알고리즘으로도* 다항 시간에 못 푼다"를 보여야 한다. 도미노에서 '모든 배치'를
     한꺼번에 막은 그 패리티처럼, '모든 알고리즘'을 한꺼번에 막는 *불변량 같은 자(尺)*가
     필요하다. 문서 C는 이걸 가칭 ⟦난도⟧#2로 부른다.

        모든 알고리즘:  [분할정복][동적계획][탐욕][아직 안 나온 미래기법 ???]
                        └── 이 전부를 한 번에 "SAT엔 안 통함" 막을 불변량 = ⟦난도⟧#2 ──┘

   왜 인류가 막혔나(정직): 도미노의 패리티는 문제 구조에 *딱 맞는* 불변량이었기에
   통했다. #2에는 그런 자(尺)를 막는 두 겹의 장벽이 있다. (가) **상대화 장벽** — 튜링
   기계에 신탁(oracle)을 달면 P=NP인 세계도 P≠NP인 세계도 만들 수 있어, 신탁에 무심한
   불변량은 결판을 못 낸다(도미노 패리티는 신탁에 무심한 쪽이라 이 길로는 막힌다).
   (나) **자연적 증명 장벽** — '회로가 복잡하다'를 보이는 자연스러운 방법이 오히려
   암호의 존재 가정과 충돌한다. 그래서 ⟦난도⟧#2는 "기법에 *민감한*(신탁을 달면 흔들리는 게
   아니라 진짜 계산 구조를 들여다보는)" 불변량이어야 하는데, 그런 양을 인류가 아직
   한 번도 손에 못 쥐었다. 여기서부터 인류가 모른다.

(3) 이제 네 차례 → 문서 C로
   → **파일 `26_C_난제_수학_01-07.md` 의 「◆ 난제 #2 P 대 NP」, 그 안 「4) 〈도구 설계
   의뢰〉」** 로 건너가라. 거기서 너는 본질난도 연산자 ⟦난도⟧#2 를 직접 벼리고, 그것이 두
   장벽(상대화·자연적 증명)을 어떻게 동시에 우회해야 하는지 5대 검문소로 채점한다.
   도장에서 패리티로 '안 됨'을 박제했으니, 이제 *계산 단계 수* 위에서 그 칼을 휘두를
   차례다.

(4) [도장 동작 → 난제의 벽] 대응표

   ┌─────────────────────────────┬──────────────────────────────────────────┐
   │ 네가 도장에서 쓴 동작        │ #2에서 그게 부딪치는 벽                     │
   ├─────────────────────────────┼──────────────────────────────────────────┤
   │ ⑤ 불가능 증명(패리티)       │ '모든 알고리즘으로도 다항 불가능'을 박제 — │
   │   '모든 배치 불가능' 박제    │ 신탁에 무심하면 상대화 장벽에 막힘          │
   ├─────────────────────────────┼──────────────────────────────────────────┤
   │ ③ 불변량 만들기             │ 기법에 안 흔들리는 '본질 난도' 불변량 ⟦난도⟧#2 —  │
   │   문제에 딱 맞는 지문        │ 자연적 증명 장벽이 그런 자(尺)를 암호와 충돌시킴│
   ├─────────────────────────────┼──────────────────────────────────────────┤
   │ ⑤ 불가능 증명의 '계산기'    │ '모든 알고리즘 위의 최소 단계 수'를 유한 절차로│
   │   유한 규칙으로 안 됨 보이기 │ 계산하는 길 — 미래 기법까지 포함이라 계산 불가│
   └─────────────────────────────┴──────────────────────────────────────────┘

다리 3 — 난제 #30  위상 절연체와 벌크-경계 대응   [축: 양자]
================================================================

(1) 한 줄 현상
   어떤 물질은 속(벌크)은 전기가 안 통하는 절연체인데 표면(경계)에서만 전류가 잘
   흐르고, 그 표면 전류는 불순물에도 끊기지 않는다(보호됨). 속의 보이지 않는 "꼬임"이
   표면 전류를 강제하는 것 같다. 무엇이 이 속/표면 갈림을 정하나 — 어떤 위상수가?

(2) 이 난제는 도장의 어느 동작들의 조합인가
   **#30 위상절연체 = Tier1·Tier3 '불변량 만들기'(오일러지표 → 천 수)를 양자 파동의
   위상에 휘두르기.**

   한마디로: **"속/표면을 가르는 정수 불변량(천 수, Chern number)을 어떻게 세나?"**

   풀어 보면 —

   · 불변량 만들기(③) 의 직계 후손:
     오일러지표에서 너는 도형을 점·선·면으로 쪼개 χ=V−E+F 라는 *정수*를 뽑았다. 늘이고
     구부려도 안 변하는 위상의 지문. #30은 *바로 그 동작*을 양자 상태에 쓴다. 도형 대신
     "양자 파동을 운동량 공간에서 한 바퀴 돌릴 때 따라붙는 위상(베리 위상)"을, 그 휘어짐
     (베리 곡률 F)을 운동량 공간 전체에서 다 모으면 — **반드시 정수**가 떨어진다. 그게
     천 수 C 다.

        오일러지표(도장):  도형의 휘어짐(쪼갬)을 다 모음 → 정수 χ = V−E+F  (위상 지문)
        #30(난제)     :  파동의 휘어짐(베리곡률 F)을 다 모음 → 정수 C = (1/2π)∮ F  (위상 지문)

     χ가 "구멍 g개면 2−2g"였듯, C도 매끄럽게는 절대 못 바꾸는 정수라 작은 교란에
     끄떡없다. 도장에서 익힌 "변하는 양(곡률·쪼갬)을 다 모으면 안 변하는 정수가 튀어
     나온다"가 그대로 자란 것이다.

   · 불변량이 *물리를 강제*한다(벌크-경계 대응):
     여기서 한 발 더 나간다. 속의 정수 C가 표면 전류 채널의 *개수*를 정확히 정한다.

        (표면을 가로지르는 보호된 전류 채널 수)  =  ΔC  (양쪽 벌크 천 수의 차)

     속의 위상 지문이 표면에 끊을 수 없는 전류를 강제로 만든다 — 불변량이 단순한
     '꼬리표'가 아니라 자연을 부리는 명령이 된다.

   왜 인류가 막혔나(정직): 천 수의 정의 C=(1/2π)∮_BZ F 는 *주기적인* 운동량 공간(브릴루앙
   영역, BZ)을 돌며 적분한다. 그런데 (가) 무질서·비주기 물질에는 BZ가 없어 ∮_BZ 자체가
   정의 안 되고, (나) 전자끼리 강하게 상호작용하면(강상관) 단일 입자 밴드가 없어 C를
   어떻게 정의할지조차 흔들린다. 문서 C는 이를 우회하려 운동량 적분 대신 *실공간 좌표*
   로 천 수를 다시 쓰는 가칭 ⟦실공간천수⟧#30를 제안한다 — 오일러지표의 정신(휘어짐을 다
   모아 정수 뽑기)을 주기성 없는 땅으로 옮기는 일. 비상호작용 무질서까지는 작동하지만,
   강상관 다체계로의 일반화는 여기서부터 인류가 모른다.

(3) 이제 네 차례 → 문서 C로
   → **파일 `29_C_난제_양자_23-30.md` 의 「◆ 난제 #30」, 그 안 「4) 〈도구 설계 의뢰〉」**
   로 건너가라. 거기서 너는 실공간 천 수 연산자 ⟦실공간천수⟧#30 를 직접 설계하고, 그것이 주기성 없는
   계에서도 정수를 뱉으며 표면 채널 수를 보장하는지 5대 검문소로 채점한다. 도장에서
   오일러지표로 '휘어짐을 정수로 박제'했으니, 이제 *양자 파동의 위상* 위에서 그 칼을
   휘두를 차례다.

세 다리를 다 건넜다. 너는 이제 안다 — 미해결 난제는 *낯선 괴물*이 아니라,
도장에서 익힌 동작이 인류가 아직 못 넘은 크기로 부푼 모습이다. #8은 접기와
불변량 만들기, #2는 불가능 증명, #30은 불변량 만들기. 도구는 너에게 이미 있다.

졸업장 대신, 떠나기 전에 **5대 검문소를 다시 한 번** 손에 쥐어 준다. 도장에서는
이걸로 *네가 발명한 답*을 채점했다. 이제부터는 *미해결 난제 앞에서 네가 새로
벼리는 도구*를 같은 다섯 칸으로 채점하라. 외치지 말고, 차분히, 한 칸씩.

   ┌─ 졸업생을 위한 5대 검문소 (이제 미해결 난제 앞에서) ──────────┐
   │ ① 환원 : 네 새 도구를, 이미 풀린 작은 경우에 넣으면 알려진     │
   │          답을 정확히 재현하나? (못 하면 도구가 아니라 착각)    │
   │ ② 정의 : 입력·출력·규칙에 모호함이 0인가? 막히면 어디서        │
   │          막히는지를 *정확히 짚어* 정직히 적어라.               │
   │ ③ 무모순: 이미 증명된 정리와 충돌하지 않나? 충돌하면 둘 중      │
   │          하나가 틀렸다 — 대개 새 도구 쪽이다.                  │
   │ ④ 표적 : 정확히 *어느 벽*을 노리나? 벽을 한 문장으로 못 쓰면   │
   │          아직 표적이 흐린 것이다.                              │
   │ ⑤ 정직 : 왜 아직 아무도 못 만들었나? 막히는 검문소를 찾아      │
   │          "여기서부터 인류가 모른다"로 선언하라. 권위로 때우지  │
   │          말 것. 막힘을 정직히 적는 것이 졸업생의 자격이다.     │
   └────────────────────────────────────────────────────────────────┘

이 다섯 칸은 도장의 졸업 시험이자, 난제의 입학 시험이다. 같은 자(尺)다.
네가 도장에서 가우스합·오일러지표·패리티를 채점하던 그 자로, 이제 ⟦스케일가교⟧#8·⟦난도⟧#2 같은
*아직 세상에 없는 도구*를 채점한다. 답이 안 나와도 좋다 — 검문소가 어디서
막히는지를 정직히 짚는 순간, 너는 이미 최전선에 서 있는 것이다.
