# [문서 B+] · 38 재명명 탐지기 · 다루는 항목: 재명명 vs 진짜 도구·크랭크 함정·자가 진단·정직 점수·거짓 폭주
# ← 짝: 발명 도장(검문소 채점)  |  → 다음: 문서 C 각 난제의 '정직 판정'
# 진행: [x] 재명명정의 [x] 자가진단 [x] 크랭크경고 [x] 대조예시 [x] 정직점수0/1 [x] 거짓폭주갤러리

================================================================
이 문서의 자리
================================================================
발명 도장(32~36)에서 너는 도구를 직접 만들어 봤다. 근본벽 문서(37)는 그
도구들이 어느 '벽'을 향하는지 보여 준다. 그런데 도구를 만들다 보면 누구나
한 번은 빠지는 함정이 있다. 진짜 도구를 만든 게 아니라, **모르는 것에 새
이름표만 붙이고는 "풀었다"고 착각**하는 함정이다.

이 짧은 함정의 이름이 '재명명(renaming)'이다. 이 문서는 네 발명이 진짜
도구인지, 아니면 이름표 바꾸기인지를 스스로 가려내는 '탐지기'다.

검문소(①환원 ②정의 ③무모순 ④표적 ⑤정직)를 기억하는가? 도장에서 네 발명을
이 5개로 채점했다. 이 탐지기는 바로 그 채점을 실전에서 휘두르는 법이다. 즉
**도장의 검문소 채점 = 재명명 탐지기의 실전 적용**이다. 같은 칼을, 이번엔
'자기 자신의 흥분'을 향해 쓴다.

================================================================
(1) 재명명(renaming)이란 무엇인가
================================================================
재명명 = **모르는 것에 이름표만 붙이고, 새 계산은 0인 것.**

쉬운 비유부터. 어떤 친구가 "나는 우주의 모든 비밀을 푸는 기계를 만들었다"고
말한다. 보여 달라니, 상자에 '비밀 푸는 기계'라고 적힌 종이를 붙여 놨을 뿐
안은 비어 있다. 이름은 거창한데 기계는 아무 일도 안 한다. 이게 재명명이다.

수학에서도 똑같은 일이 일어난다. 구체 예를 보자.

──────────────────────────────────────────────
구체 예: 리만 가설(Riemann Hypothesis)의 가칭 도구 ⟦정렬⟧#1
──────────────────────────────────────────────
리만 가설은 거칠게 말하면 "제타 함수(ζ, zeta function)의 어떤 특별한
영점(零點, zero) ρ들이 전부 한 직선 — 실수부(Re, real part)가 정확히 ½인
세로줄 — 위에 놓인다"는 주장이다. 여기서 ρ(로 rho)는 'ζ가 0이 되는 점'을
뜻한다. (ρ는 밀도에도 쓰는 글자지만, 여기서는 오직 '영점'이다. 못박는다.)

누군가 이런 '도구'를 발명했다고 하자.

    ⟦정렬⟧#1  :=  S = Σ (Re ρ − ½)²
                       ρ
    (모든 특별한 영점 ρ에 대해, 그 실수부에서 ½을 뺀 값을 제곱해 다 더한다)

그리고 이렇게 주장한다. "S = 0 이면 모든 영점이 ½ 줄 위에 있다는 뜻이다.
그러니 S = 0 임을 보이면 리만 가설은 참이다! 나는 도구를 만들었다!"

기호를 한 글자씩 해부하자.
    Σ  : '다 더해라'(합). 아래의 ρ를 바꿔 가며 전부 더한다.
    Re ρ : 영점 ρ의 실수부(왼쪽–오른쪽 위치).
    − ½ : ½ 줄에서 얼마나 벗어났나.
    (  )² : 제곱. 벗어남을 부호 없이 0 이상으로.
    S  : 벗어남들의 제곱 합. 모두 ½ 위면 각 항이 0 → S = 0.

논리 자체는 맞다. 모든 ρ가 ½ 위 ⟺ S = 0. **그런데 이건 도구가 아니라
가설의 재진술(restatement)이다.** 왜? S를 실제로 **계산하려면 영점 ρ들을
먼저 알아야** 하는데, 그 영점들의 위치야말로 리만 가설이 묻는 바로 그
'모르는 것'이기 때문이다. 모르는 것을 알아야 계산이 되는 도구 = 새 계산 0.

ASCII로 그 공허함을 보자.

    [묻는 것] 영점 ρ가 ½ 줄 위에 있나? ──┐
                                          │  (같은 모름이 빙빙 돈다)
    [도구 S] S=0 이면 ½ 줄 위.  ──────────┤
    [S 계산하려면?] ρ를 알아야 함. ────────┘
                    └─ 그런데 ρ를 아는 게 바로 [묻는 것]!

    원이 닫혀 버린다. 한 칸도 전진하지 못했다.

정직하게 말하자. ⟦정렬⟧#1은 **발상 정리용**으로는 쓸모가 있다("벗어남의
총합"이라는 그림을 준다). 하지만 **증명 도구는 아니다.** 모르는 양으로만
정의돼 있어, 넣을 수 있는 새 값이 없다.

[메커니즘 — 왜 새 계산이 0인가, 한 문단]
진짜 도구는 '내가 이미 아는 입력'을 받아 '몰랐던 출력'을 토해 낸다. 가우스
합 n(n+1)/2는 아는 n을 넣어 모르던 합을 즉시 뱉는다(T1-1). 입력→출력 사이에
실제 화살표가 있다. 그런데 S는 입력 자리에 ρ가 와야 하는데, ρ는 출력에서야
알 수 있는 값이다. 입력과 출력이 같은 모름을 가리키니 화살표가 자기 자신으로
돌아온다. 화살표가 한 바퀴 돌아 제자리면 이동 거리는 0 — 그래서 새 계산이
0이다. 이름표 S는 '영점들이 ½ 위에 있다'는 문장을 그저 한 글자로 줄여 쓴
약어일 뿐, 그 문장을 한 톨도 더 참으로 만들지 못한다.

================================================================
(2) 진짜 도구 vs 재명명 — 자가 진단 체크리스트
================================================================
새 기호·새 도구를 만들 때마다, 흥분이 식기 전에 이 5칸을 통과시켜라. 하나라도
'아니오'면 멈추고 다시 봐라.

  □ 내 기호를 빼고 문제를 다시 읽으면, 문제가 조금이라도 쉬워졌나?
      → 기호를 지웠더니 문제가 그대로면, 그 기호는 아무 일도 안 한 것이다.
        쉬워진 게 없으면 재명명이다.

  □ 내 기호는 새 계산을 하나, 아니면 모르는 것에 이름만 붙였나?
      → '아는 값을 넣어 모르던 값이 나오는' 단계가 실제로 있는지 봐라.
        없으면 약어일 뿐 도구가 아니다.

  □ 작은 경우에서 내 도구로 실제로 답이 나오나?
      → 가장 작은 예에 직접 넣어 손으로 검산하라(환원 검사). 가우스 합을
        n=3에 넣어 6이 나오듯(T1-1), 네 도구도 작은 데서 답을 토해야 한다.

  □ 내 도구가 메우는 '벽'을 한 문장으로 말할 수 있나?
      → "이 도구는 ○○라는 벽을 넘는다"가 안 써지면 표적이 없는 것이고,
        표적 없는 도구는 재명명이다(근본벽 문서 37의 '벽'과 맞춰 보라).

  □ '거의 풀었다'는 흥분이 드나? → ★위험 신호★
      → 진짜 도구는 '아직 멀지만 딱 한 칸 나아갔다'는 차분한 느낌을 준다.
        '거의 다 풀었다'는 짜릿함은 보통 ④표적이나 ①환원을 건너뛴 신호다.
        흥분할수록 검산을 더 해라.

이 5칸은 검문소(①환원 ②정의 ③무모순 ④표적 ⑤정직)와 한 몸이다. 셋째 칸이
①환원, 넷째 칸이 ④표적, 다섯째 칸이 ⑤정직이다. 도장에서 남의 문제를
채점하던 자를, 이제 네 손목에 댄다.

================================================================
(3) 크랭크 함정 경고
================================================================
'크랭크(crank)'란, 검문소 없이 흥분만으로 "내가 리만/페르마를 풀었다"고
믿어 버리는 사람을 가리키는 오래된 말이다. 비웃자는 게 아니다. 누구나
한 번은 그 문턱에 선다. 중요한 건 패턴을 아는 것이다.

아마추어가 '리만/페르마를 풀었다'고 착각하는 경우는, 살펴보면 거의 항상
다음 셋 중 하나(또는 겹침)다.

    (가) 정의 누락  : 핵심 기호의 뜻이 모호하다(검문소 ②정의 실패).
                      "이 함수"가 정확히 무엇인지 끝까지 안 적혀 있다.
    (나) 재명명     : 모르는 것에 이름표만 붙였다(이 문서의 (1)). 새 계산 0.
    (다) 작은 경우 미검산 : 가장 작은 예에 넣어 본 적이 없다(검문소 ①환원
                      실패). 손으로 한 번만 돌려 봤어도 무너졌을 식이다.

야심(ambition)은 연료다. 큰 문제를 향한 불이 없으면 애초에 도구를 만들 일도
없다. 그 불을 끄라는 게 아니다. 다만 **검문소 없는 흥분은 함정**이다. 불은
나를 산 위로 밀어 올리지만, 검문소가 없으면 그 불이 나를 절벽으로도 똑같이
밀어 버린다.

핵심 한 줄: **진짜 발명가는 자기 발명을 가장 가혹하게 의심하는 사람이다.**
남이 의심해 주기 전에 내가 먼저 (가)(나)(다)로 내 도구를 두들겨 본다.
두들겨도 안 깨지면, 그때 비로소 한 칸 나아간 것이다. 불은 살리되, 자기기만은
차단한다. 차분히, 메커니즘으로.

================================================================
(4) 재명명 vs 진짜 도구 — 대조 예시
================================================================
한쪽은 이름표만 바꾼 것, 한쪽은 단계 수를 실제로 줄이거나 모르던 값을 실제로
토해 낸 것이다. 차이는 '새 계산이 있는가'다.

──────────────────────────────────────────────
대조 1 — 합 구하기
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구           |
  +-------------------------+-------------------------+
  | "1..n의 합을 Sum(n)이라  | 가우스 합 n(n+1)/2       |
  |  부르자."                | (T1-1)                  |
  |                         |                         |
  | Sum(n)을 계산하려면      | n=100 넣으면 5050이      |
  | 여전히 1+2+…+n을 다      | 곱셈 하나로 즉시 나옴.   |
  | 더해야 함.              |                         |
  |                         |                         |
  | 단계 수: O(n) 그대로.   | 단계 수: O(n) → O(1).   |
  | 새 계산 = 0.            | 새 계산 = 있음.         |
  +-------------------------+-------------------------+
  판정: 왼쪽은 '합'을 'Sum'으로 글자만 바꿨다. 오른쪽은 짝짓기 대칭으로
        단계 수를 실제로 줄였다(검문소 ④표적 통과).

──────────────────────────────────────────────
대조 2 — 리만 가설
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구(부분 전진)|
  +-------------------------+-------------------------+
  | ⟦정렬⟧#1: S=Σ(Reρ−½)²   | "임계선 위에 영점이      |
  | "S=0이면 풀린다."        |  무한히 많다"는 증명     |
  |                         |  (실제 수학사의 한 칸).  |
  | S를 계산하려면 ρ를       |                         |
  | 알아야 함 = 묻는 그것.  | 아는 도구(해석학)로     |
  |                         | 몰랐던 사실 하나를      |
  | 새 계산 = 0.            | 실제로 토해 냄.         |
  | 느낌: "거의 풀었다!"    | 느낌: "아직 멀지만      |
  |  → ★위험 신호★          |  한 칸 나아갔다."       |
  +-------------------------+-------------------------+
  판정: 왼쪽은 가설의 재진술(새 계산 0). 오른쪽은 가설 전체는 아니어도
        '몰랐던 출력'을 실제로 만든다. 흥분의 온도가 정반대인 점에 주목.

──────────────────────────────────────────────
대조 3 — 모양의 지문
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구           |
  +-------------------------+-------------------------+
  | "도넛의 구멍 수를        | 오일러 지표 χ=V−E+F     |
  |  hole(X)라 부르자."      | (T3-1)                  |
  |                         |                         |
  | hole(도넛)=1 이라 쓰지만 | 정육면체에 넣으면        |
  | hole을 어떻게 세는지     | 8−12+6=2 가 손으로      |
  | 절차가 없음.            | 검산됨. 구멍 g개면      |
  |                         | χ=2−2g 로 모르던        |
  | 새 계산 = 0.            | 값이 나옴.              |
  +-------------------------+-------------------------+
  판정: 왼쪽은 '구멍 수'에 이름만 줬다. 오른쪽은 세는 절차(V,E,F)를 줘서
        실제로 손으로 셀 수 있다(검문소 ①환원 통과).

세 쌍 모두 갈림길은 같다. **"아는 값을 넣어 모르던 값이 나오는가."** 나오면
진짜, 안 나오면 재명명이다.

================================================================
(5) 정직 점수 0/1 판정식 — 숫자 한 개로 못박기
================================================================
앞의 (1)~(4)는 말로 가렸다. 이제 같은 판단을 **숫자 한 개**로 못박자. 재명명이냐
진짜 도구냐를 두고 말씨름하지 않도록, [정직 점수]를 0 또는 1로 딱 떨어뜨린다.

──────────────────────────────────────────────
판정식 (중2 말로)
──────────────────────────────────────────────
네가 만든 도구를 f(입력) → 출력 으로 적어 보자. f(에프, function = 함수, 즉
'입력을 넣으면 출력을 뱉는 기계')라고 읽는다. 그리고 이렇게 물어라.

  ★ "그 출력 값을 실제로 얻으려면 해야 하는 계산(산수·논리 연산)이,
     이미 가진 도구들의 사슬로 한 칸도 안 건너뛰고 끝까지 적히는가?" ★

여기서 '사슬(chain = 연결 고리)'은 '내가 이미 아는 도구를 차례로 잇댄 줄'이다.
한 칸 = 한 번의 실제 계산. '건너뛴다'는 건 그 칸에 '아직 모르는 값'이 슬쩍
들어앉아 있다는 뜻이다.

    · 끝까지 적힌다(빈칸 0개) ─────────→ [정직 점수 = 1]  (진짜 부분 도구)
    · 중간에 "흐름을 다 풀어야 비로소 답을 안다"처럼,
      미지(未知, unknown = 모르는 값)의 것이 자기 자신을
      붙잡는 자기참조(self-reference) 고리가 있다 ──→ [정직 점수 = 0]  (재명명 파산)

쉽게: 계산 줄을 끝까지 적었는데 빈칸이 하나도 없으면 1점. 적다 보니 "이 칸을
채우려면 사실 답을 이미 알고 있어야 하네?" 하는 순간 0점이다. 그 순간 도구는
자기 꼬리를 문 것이다.

──────────────────────────────────────────────
자기참조 고리 — 한 컷 (점수 0의 정체)
──────────────────────────────────────────────
출력을 알려면 입력을 알아야 하고, 입력을 알려면 다시 출력을 알아야 한다.
화살표가 바깥으로 못 나가고 뱅글뱅글 제자리만 돈다.

        ┌──────────────────────────────────┐
        │                                  │
        ▼                                  │
   [출력을 알려면]                          │
        │  ↑ 채우려면                       │
        ▼                                  │
   [입력을 알아야 함]                       │
        │  ↑ 채우려면                       │
        ▼                                  │
   [그 입력이 곧 출력] ───────"뱅글"────────┘

   바깥으로 나가는 화살표가 0개. 새 값이 한 톨도 안 들어온다 → 정직 점수 0.

이건 (1)의 ⟦정렬⟧#1에서 본 '닫힌 원'과 똑같은 그림이다. S를 계산하려면 ρ를
알아야 하고, ρ는 묻는 그것이라 다시 S로 돌아온다. 원이 닫히는 순간 = 점수 0.

──────────────────────────────────────────────
점수가 0이면? — '자기참조를 끊는 규칙'을 반드시 빈칸으로 남겨라
──────────────────────────────────────────────
점수 0은 사형 선고가 아니다. **"여기서부터 인류가(또는 내가) 모른다"**를
정직하게 적는 빈칸이다. 그 빈칸의 이름은 [자기참조를 끊는 규칙]이다.

중2 비유: **"내 꼬리를 문 뱀(우로보로스)을 어디서 자를까?"** 뱀이 제 꼬리를
물고 있으면 머리도 꼬리도 시작이 없다. 어딘가 한 군데를 '싹둑' 잘라야 줄이
펴지고, 그제야 한쪽 끝(아는 값)에서 다른 끝(모르던 값)으로 계산이 흐른다.

실제로 수학·물리에는 이런 '고리 절단기(loop cutter)'가 있다. 빈칸에 이런 걸
후보로 적어 두는 게 정직이다.

    · 쿠프만 연산자(Koopman operator)로 비선형을 선형으로 펴기
      → 빙빙 도는 비선형 흐름을, 무한 차원이지만 '곧은' 선형 세계로 옮겨
        고리를 한 번에 펴 버린다(꼬인 줄을 곧게 다림질).
    · 재규격화(renormalization)로 스케일(scale = 크기 눈금) 고리 끊기
      → "작은 걸 보려면 큰 걸 알아야 하고 큰 걸 보려면 작은 걸…"의 무한 고리를,
        눈금을 한 칸씩 옮겨 가며 잘라 유한하게 만든다(돋보기 배율 사슬 끊기).

이 후보들이 정답이라는 게 아니다. **빈칸을 빈칸이라 적는 것**이 핵심이다.
'끊는 규칙' 칸을 비워 두면 점수는 정직하게 0으로 남고, 누군가 그 칸을 진짜로
채우는 날 0이 1로 바뀐다. 빈칸을 몰래 메운 척하는 게 바로 재명명이다.

──────────────────────────────────────────────
이 점수는 문서 C의 [정직 판정]에서 실제로 쓰인다
──────────────────────────────────────────────
문서 C는 30난제 하나하나에 이 탐지기를 들이댄다. 그때 내리는 [정직 판정]이
바로 이 0/1 점수의 실전 적용이다. 어떤 난제의 한 도구가 '빈칸 0'이면 그
도구에 정직 점수 1, '자기참조 고리'가 남으면 정직 점수 0을 붙이고 [끊는 규칙]
칸을 빈칸으로 표시한다. 즉 (5)의 판정식 = 문서 C [정직 판정]의 계산기다.

================================================================
(6) 거짓 폭주 갤러리 — 규칙을 뒤집을 때 조용히 망가지는 도구들
================================================================
재명명은 "처음부터 텅 빈" 가짜다. 그런데 더 무서운 가짜가 있다. **멀쩡해
보이는 진짜 도구가, '규칙을 뒤집는 순간' 속에서 조용히 망가지는** 경우다.
겉은 작동하는데 안에서 보존(保存, conservation = 지켜져야 할 양이 그대로
유지됨)이 깨져, 도구가 천천히 거짓말을 하기 시작한다. 이걸 '거짓 폭주(false
blow-up)'라 부르자. 세 장면을 ASCII로 건다.

──────────────────────────────────────────────
(가) 유한 절단의 에너지 누수 — 닫혀야 할 고리가 살짝 벌어진다
──────────────────────────────────────────────
무한히 긴 급수(級數, series = 항을 끝없이 더하는 합)를, 컴퓨터가 다루려고
유한히 잘라 쓴다(체비쇼프 절단, Chebyshev truncation = 체비쇼프 함수들로
편 무한합을 앞쪽 몇 항만 남기고 자르기). 그러면 '에너지'처럼 지켜져야 할
보존량의 등고선(等高線, contour = 같은 값을 잇는 닫힌 곡선)이 딱 안 닫히고
미세하게 벌어진다. 그 틈으로 에너지가 새고, 장기 시뮬레이션에서 시스템이
없던 에너지를 무한히 창조하며 폭발한다.

    [무한 급수 — 보존 OK]        [유한 절단 — 보존 깨짐]

        .-----------.               .-----------.
       /             \             /             \
      |   닫힌 고리   |           |   살짝 벌어진 ←─ 여기로
      |   (에너지     |           |   고리        |   에너지가
       \  새지 않음) /             \  (E 새어 감) /    줄줄 샌다
        '-----------'               '----- ‖ ----'
                                          벌어진 틈

    한 바퀴 돌면 제자리(E 그대로)      한 바퀴 돌 때마다 E가 조금씩 늘어
                                       → 1만 바퀴 후 E가 폭발(blow-up)

  왜 '거짓 폭주'인가(중2): 도구(절단된 급수)는 한두 바퀴 돌려 보면 멀쩡해
  보인다. 그런데 틈이 매 바퀴 '조금씩' 새서, 오래 돌리면 거짓이 쌓여 터진다.
  멀쩡한 얼굴로 속에서 보존을 깨고 천천히 거짓말을 하는 것이다.
  위험한 검문소: ③무모순(잘라도 보존 법칙과 안 어긋나야 하는데 어긋남).

──────────────────────────────────────────────
(나) 발산 급수를 억지로 더하기 — 부분합이 ±로 널뛴다
──────────────────────────────────────────────
발산(發散, divergent = 더할수록 한 값에 모이지 않고 흩어짐) 급수를 "그래도
합이 있겠지" 하며 억지로 더하면, 부분합(앞에서부터 몇 항까지의 합)이 한
값에 가라앉질 못하고 ±로 펄쩍펄쩍 널뛴다. 예: 1−1+1−1+… 의 부분합.

   부분합 값
    +1 ┤●     ●     ●     ●        ← 홀수 항까지: +1
       │ \   / \   / \   / \
     0 ┤  \ /   \ /   \ /   \      (가운데 어디에도 안 멈춤)
       │   \   / \   / \   /
    −1 ┤    ●     ●     ●          ← 짝수 항까지: 0
       └──┬──┬──┬──┬──┬──┬── 항 개수 →
          1  2  3  4  5  6

  왜 '거짓 폭주'인가(중2): "합 = 어떤 한 수"라고 부르는 순간, 도구는 정해진
  답이 있는 척한다. 그런데 부분합은 영영 한 곳에 안 앉는다. 답이 없는데
  있다고 우기는 = 조용한 거짓말. 위험한 검문소: ⑤정직(없는 수렴값을 있다고
  적으면 정직 점수 0 — (5)의 자기기만과 한 핏줄).

──────────────────────────────────────────────
(다) 나비효과 — 작은 오차가 비선형에서 지수로 불어난다
──────────────────────────────────────────────
비선형(非線形, nonlinear = 입력을 2배 해도 출력이 2배가 아닌, 서로 엉켜
증폭되는 관계)에서는 처음의 아주 작은 오차(error = 참값과의 차이)가 한 발짝
갈 때마다 곱절로 불어난다. 더하기(+)가 아니라 곱하기(×)로 커지니, 곧 지수
(指數, exponential = 곱절의 곱절로 폭증)로 치솟는다.

   오차 크기
    큰 ┤                              ╱← 여기서 폭주
       │                           ╱
       │                        ╱
       │                    ╱
       │               ╱
       │          ╱
   작은┤_____╱            ← 처음엔 거의 안 보일 만큼 작음(점 하나 차이)
       └──┬───┬───┬───┬───┬───┬── 시간 →
          처음              나중

  왜 '거짓 폭주'인가(중2): 처음 한두 칸은 오차가 점만 해서 도구가 정확해
  보인다. 그런데 비선형이 그 점을 매 칸 곱절로 키워, 나중엔 답이 통째로
  거짓이 된다. 멀쩡한 얼굴로 시작해 속에서 오차를 키우는 거짓 폭주다.
  위험한 검문소: ③무모순(같은 입력이 칸마다 딴 답을 내면 일관성이 깨짐).

세 장면의 공통 교훈: **"한두 번 돌려 멀쩡함 ≠ 끝까지 정직함."** 도구는 짧게
보면 멀쩡한데, 규칙을 뒤집어(무한→유한, 수렴→발산, 선형→비선형) 오래
돌리면 속에서 보존이 깨져 거짓이 쌓인다. 그래서 ③무모순·⑤정직 검문소는
'한 번'이 아니라 '오래 돌려도'까지 통과해야 한다.

  탐지기의 실전 적용이다. 특히 골드 예시 T1-1(가우스 합)·T3-1(오일러 지표)의

  그 [정직 판정]의 실제 계산기가 (5)의 정직 점수 0/1 판정식이다(빈칸 0 → 1,
  자기참조 고리 → 0, '끊는 규칙' 칸은 빈칸으로). 도구가 (6)처럼 오래 돌릴 때

못한 도구는 버리는 게 아니라 '발상 정리용'으로 따로 둔다 — 그것도 쓸모는
있되, 증명 도구라 부르지 않을 뿐이다.
