# [문서 B+] · 38 재명명 탐지기 · 다루는 항목: 재명명 vs 진짜 도구·크랭크 함정·자가 진단
# ← 짝: 발명 도장(검문소 채점)  |  → 다음: 문서 C 각 난제의 '정직 판정'
# 진행: [x] 재명명정의 [x] 자가진단 [x] 크랭크경고 [x] 대조예시

================================================================
이 문서의 자리
================================================================
발명 도장(32~36)에서 너는 도구를 직접 만들어 봤다. 근본벽 문서(37)는 그
도구들이 어느 '벽'을 향하는지 보여 준다. 그런데 도구를 만들다 보면 누구나
한 번은 빠지는 함정이 있다. 진짜 도구를 만든 게 아니라, **모르는 것에 새
이름표만 붙이고는 "풀었다"고 착각**하는 함정이다.

이 짧은 함정의 이름이 '재명명(renaming)'이다. 이 문서는 네 발명이 진짜
도구인지, 아니면 이름표 바꾸기인지를 스스로 가려내는 '탐지기'다.

검문소(①환원 ②정의 ③무모순 ④표적 ⑤정직)를 기억하는가? 도장에서 네 발명을
이 5개로 채점했다. 이 탐지기는 바로 그 채점을 실전에서 휘두르는 법이다. 즉
**도장의 검문소 채점 = 재명명 탐지기의 실전 적용**이다. 같은 칼을, 이번엔
'자기 자신의 흥분'을 향해 쓴다.

================================================================
(1) 재명명(renaming)이란 무엇인가
================================================================
재명명 = **모르는 것에 이름표만 붙이고, 새 계산은 0인 것.**

쉬운 비유부터. 어떤 친구가 "나는 우주의 모든 비밀을 푸는 기계를 만들었다"고
말한다. 보여 달라니, 상자에 '비밀 푸는 기계'라고 적힌 종이를 붙여 놨을 뿐
안은 비어 있다. 이름은 거창한데 기계는 아무 일도 안 한다. 이게 재명명이다.

수학에서도 똑같은 일이 일어난다. 구체 예를 보자.

──────────────────────────────────────────────
구체 예: 리만 가설(Riemann Hypothesis)의 가칭 도구 ⟦정렬⟧#1
──────────────────────────────────────────────
리만 가설은 거칠게 말하면 "제타 함수(ζ, zeta function)의 어떤 특별한
영점(零點, zero) ρ들이 전부 한 직선 — 실수부(Re, real part)가 정확히 ½인
세로줄 — 위에 놓인다"는 주장이다. 여기서 ρ(로 rho)는 'ζ가 0이 되는 점'을
뜻한다. (ρ는 밀도에도 쓰는 글자지만, 여기서는 오직 '영점'이다. 못박는다.)

누군가 이런 '도구'를 발명했다고 하자.

    ⟦정렬⟧#1  :=  S = Σ (Re ρ − ½)²
                       ρ
    (모든 특별한 영점 ρ에 대해, 그 실수부에서 ½을 뺀 값을 제곱해 다 더한다)

그리고 이렇게 주장한다. "S = 0 이면 모든 영점이 ½ 줄 위에 있다는 뜻이다.
그러니 S = 0 임을 보이면 리만 가설은 참이다! 나는 도구를 만들었다!"

기호를 한 글자씩 해부하자.
    Σ  : '다 더해라'(합). 아래의 ρ를 바꿔 가며 전부 더한다.
    Re ρ : 영점 ρ의 실수부(왼쪽–오른쪽 위치).
    − ½ : ½ 줄에서 얼마나 벗어났나.
    (  )² : 제곱. 벗어남을 부호 없이 0 이상으로.
    S  : 벗어남들의 제곱 합. 모두 ½ 위면 각 항이 0 → S = 0.

논리 자체는 맞다. 모든 ρ가 ½ 위 ⟺ S = 0. **그런데 이건 도구가 아니라
가설의 재진술(restatement)이다.** 왜? S를 실제로 **계산하려면 영점 ρ들을
먼저 알아야** 하는데, 그 영점들의 위치야말로 리만 가설이 묻는 바로 그
'모르는 것'이기 때문이다. 모르는 것을 알아야 계산이 되는 도구 = 새 계산 0.

ASCII로 그 공허함을 보자.

    [묻는 것] 영점 ρ가 ½ 줄 위에 있나? ──┐
                                          │  (같은 모름이 빙빙 돈다)
    [도구 S] S=0 이면 ½ 줄 위.  ──────────┤
    [S 계산하려면?] ρ를 알아야 함. ────────┘
                    └─ 그런데 ρ를 아는 게 바로 [묻는 것]!

    원이 닫혀 버린다. 한 칸도 전진하지 못했다.

정직하게 말하자. ⟦정렬⟧#1은 **발상 정리용**으로는 쓸모가 있다("벗어남의
총합"이라는 그림을 준다). 하지만 **증명 도구는 아니다.** 모르는 양으로만
정의돼 있어, 넣을 수 있는 새 값이 없다.

[메커니즘 — 왜 새 계산이 0인가, 한 문단]
진짜 도구는 '내가 이미 아는 입력'을 받아 '몰랐던 출력'을 토해 낸다. 가우스
합 n(n+1)/2는 아는 n을 넣어 모르던 합을 즉시 뱉는다(T1-1). 입력→출력 사이에
실제 화살표가 있다. 그런데 S는 입력 자리에 ρ가 와야 하는데, ρ는 출력에서야
알 수 있는 값이다. 입력과 출력이 같은 모름을 가리키니 화살표가 자기 자신으로
돌아온다. 화살표가 한 바퀴 돌아 제자리면 이동 거리는 0 — 그래서 새 계산이
0이다. 이름표 S는 '영점들이 ½ 위에 있다'는 문장을 그저 한 글자로 줄여 쓴
약어일 뿐, 그 문장을 한 톨도 더 참으로 만들지 못한다.

================================================================
(2) 진짜 도구 vs 재명명 — 자가 진단 체크리스트
================================================================
새 기호·새 도구를 만들 때마다, 흥분이 식기 전에 이 5칸을 통과시켜라. 하나라도
'아니오'면 멈추고 다시 봐라.

  □ 내 기호를 빼고 문제를 다시 읽으면, 문제가 조금이라도 쉬워졌나?
      → 기호를 지웠더니 문제가 그대로면, 그 기호는 아무 일도 안 한 것이다.
        쉬워진 게 없으면 재명명이다.

  □ 내 기호는 새 계산을 하나, 아니면 모르는 것에 이름만 붙였나?
      → '아는 값을 넣어 모르던 값이 나오는' 단계가 실제로 있는지 봐라.
        없으면 약어일 뿐 도구가 아니다.

  □ 작은 경우에서 내 도구로 실제로 답이 나오나?
      → 가장 작은 예에 직접 넣어 손으로 검산하라(환원 검사). 가우스 합을
        n=3에 넣어 6이 나오듯(T1-1), 네 도구도 작은 데서 답을 토해야 한다.

  □ 내 도구가 메우는 '벽'을 한 문장으로 말할 수 있나?
      → "이 도구는 ○○라는 벽을 넘는다"가 안 써지면 표적이 없는 것이고,
        표적 없는 도구는 재명명이다(근본벽 문서 37의 '벽'과 맞춰 보라).

  □ '거의 풀었다'는 흥분이 드나? → ★위험 신호★
      → 진짜 도구는 '아직 멀지만 딱 한 칸 나아갔다'는 차분한 느낌을 준다.
        '거의 다 풀었다'는 짜릿함은 보통 ④표적이나 ①환원을 건너뛴 신호다.
        흥분할수록 검산을 더 해라.

이 5칸은 검문소(①환원 ②정의 ③무모순 ④표적 ⑤정직)와 한 몸이다. 셋째 칸이
①환원, 넷째 칸이 ④표적, 다섯째 칸이 ⑤정직이다. 도장에서 남의 문제를
채점하던 자를, 이제 네 손목에 댄다.

================================================================
(3) 크랭크 함정 경고
================================================================
'크랭크(crank)'란, 검문소 없이 흥분만으로 "내가 리만/페르마를 풀었다"고
믿어 버리는 사람을 가리키는 오래된 말이다. 비웃자는 게 아니다. 누구나
한 번은 그 문턱에 선다. 중요한 건 패턴을 아는 것이다.

아마추어가 '리만/페르마를 풀었다'고 착각하는 경우는, 살펴보면 거의 항상
다음 셋 중 하나(또는 겹침)다.

    (가) 정의 누락  : 핵심 기호의 뜻이 모호하다(검문소 ②정의 실패).
                      "이 함수"가 정확히 무엇인지 끝까지 안 적혀 있다.
    (나) 재명명     : 모르는 것에 이름표만 붙였다(이 문서의 (1)). 새 계산 0.
    (다) 작은 경우 미검산 : 가장 작은 예에 넣어 본 적이 없다(검문소 ①환원
                      실패). 손으로 한 번만 돌려 봤어도 무너졌을 식이다.

야심(ambition)은 연료다. 큰 문제를 향한 불이 없으면 애초에 도구를 만들 일도
없다. 그 불을 끄라는 게 아니다. 다만 **검문소 없는 흥분은 함정**이다. 불은
나를 산 위로 밀어 올리지만, 검문소가 없으면 그 불이 나를 절벽으로도 똑같이
밀어 버린다.

핵심 한 줄: **진짜 발명가는 자기 발명을 가장 가혹하게 의심하는 사람이다.**
남이 의심해 주기 전에 내가 먼저 (가)(나)(다)로 내 도구를 두들겨 본다.
두들겨도 안 깨지면, 그때 비로소 한 칸 나아간 것이다. 불은 살리되, 자기기만은
차단한다. 차분히, 메커니즘으로.

================================================================
(4) 재명명 vs 진짜 도구 — 대조 예시
================================================================
한쪽은 이름표만 바꾼 것, 한쪽은 단계 수를 실제로 줄이거나 모르던 값을 실제로
토해 낸 것이다. 차이는 '새 계산이 있는가'다.

──────────────────────────────────────────────
대조 1 — 합 구하기
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구           |
  +-------------------------+-------------------------+
  | "1..n의 합을 Sum(n)이라  | 가우스 합 n(n+1)/2       |
  |  부르자."                | (T1-1)                  |
  |                         |                         |
  | Sum(n)을 계산하려면      | n=100 넣으면 5050이      |
  | 여전히 1+2+…+n을 다      | 곱셈 하나로 즉시 나옴.   |
  | 더해야 함.              |                         |
  |                         |                         |
  | 단계 수: O(n) 그대로.   | 단계 수: O(n) → O(1).   |
  | 새 계산 = 0.            | 새 계산 = 있음.         |
  +-------------------------+-------------------------+
  판정: 왼쪽은 '합'을 'Sum'으로 글자만 바꿨다. 오른쪽은 짝짓기 대칭으로
        단계 수를 실제로 줄였다(검문소 ④표적 통과).

──────────────────────────────────────────────
대조 2 — 리만 가설
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구(부분 전진)|
  +-------------------------+-------------------------+
  | ⟦정렬⟧#1: S=Σ(Reρ−½)²   | "임계선 위에 영점이      |
  | "S=0이면 풀린다."        |  무한히 많다"는 증명     |
  |                         |  (실제 수학사의 한 칸).  |
  | S를 계산하려면 ρ를       |                         |
  | 알아야 함 = 묻는 그것.  | 아는 도구(해석학)로     |
  |                         | 몰랐던 사실 하나를      |
  | 새 계산 = 0.            | 실제로 토해 냄.         |
  | 느낌: "거의 풀었다!"    | 느낌: "아직 멀지만      |
  |  → ★위험 신호★          |  한 칸 나아갔다."       |
  +-------------------------+-------------------------+
  판정: 왼쪽은 가설의 재진술(새 계산 0). 오른쪽은 가설 전체는 아니어도
        '몰랐던 출력'을 실제로 만든다. 흥분의 온도가 정반대인 점에 주목.

──────────────────────────────────────────────
대조 3 — 모양의 지문
──────────────────────────────────────────────
  +-------------------------+-------------------------+
  |     재명명 (가짜)        |      진짜 도구           |
  +-------------------------+-------------------------+
  | "도넛의 구멍 수를        | 오일러 지표 χ=V−E+F     |
  |  hole(X)라 부르자."      | (T3-1)                  |
  |                         |                         |
  | hole(도넛)=1 이라 쓰지만 | 정육면체에 넣으면        |
  | hole을 어떻게 세는지     | 8−12+6=2 가 손으로      |
  | 절차가 없음.            | 검산됨. 구멍 g개면      |
  |                         | χ=2−2g 로 모르던        |
  | 새 계산 = 0.            | 값이 나옴.              |
  +-------------------------+-------------------------+
  판정: 왼쪽은 '구멍 수'에 이름만 줬다. 오른쪽은 세는 절차(V,E,F)를 줘서
        실제로 손으로 셀 수 있다(검문소 ①환원 통과).

세 쌍 모두 갈림길은 같다. **"아는 값을 넣어 모르던 값이 나오는가."** 나오면
진짜, 안 나오면 재명명이다.

상호참조
================================================================
- 발명 도장(32~36): 네 발명을 5대 검문소로 채점하는 훈련. 그 채점이 곧 이
  탐지기의 실전 적용이다. 특히 골드 예시 T1-1(가우스 합)·T3-1(오일러 지표)의
  [검문소로 채점] 칸이 (4)의 '진짜 도구' 쪽 본보기다.
- 근본벽(37): (2)의 넷째 칸 '벽을 한 문장으로'는 37의 벽 목록과 맞춰 본다.
  표적 없는 도구가 재명명이라는 판정은 37의 '벽' 개념에 기댄다.
- 문서 C(각 난제): 다음 단계. C는 30난제 각각에 이 탐지기를 적용해 '정직
  판정'을 내린다 — 어디까지가 진짜 전진이고 어디부터가 재명명·미해결인지.

여기서부터, 네가 만들 모든 도구는 이 5칸을 먼저 통과해야 한다. 통과하지
못한 도구는 버리는 게 아니라 '발상 정리용'으로 따로 둔다 — 그것도 쓸모는
있되, 증명 도구라 부르지 않을 뿐이다.
