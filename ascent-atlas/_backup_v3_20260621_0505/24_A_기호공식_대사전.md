## 이음새 — 직전(파일 23, 지구20)에서 넘어온 것

지구20을 닫으며 우리는 이런 의문을 안고 왔다: "지금까지 우리가 벼린 30개 지구의 도구들이 저마다 자기 기호를 들고 나왔다. 어떤 기호는 분야마다 뜻이 다르고(σ는 표준편차이기도 응력이기도 하다), 어떤 공식은 한 줄인데 그 안에 다섯 개의 도구가 겹쳐 있다. 이 기호들을 한 곳에 모아, 중2가 읽어도 헷갈리지 않게 다시 못박을 수 없을까?"

이 파일이 그 못이다. 여기서는 새 도구를 만들지 않는다. 대신 지금까지 등장한 모든 기호를 한 곳에 세워두고, 골드 예시 ⟨∂⟩처럼 **읽는 법 → 뜻(분야별 전부) → 다른 기호와 구분 → 예시**로 해부한다. 그다음 30난제의 대표 공식을 골드 예시 ⟨나비에-스토크스⟩처럼 **원문 → 한 글자씩 → 통째 의미(중2 언어) → 뭘 하나 → 어느 난제 닿나 → 어디서 부서지나**로 해부한다.

읽는 법: 이 파일은 사전이다. 처음부터 끝까지 읽어도 되고, 다른 파일을 읽다가 모르는 기호가 나오면 여기로 와서 찾아도 된다.

# [1부] 기호 대사전

각 기호는 이렇게 적는다:
- **읽는 법**: 입으로 어떻게 소리 내나.
- **뜻**: 무엇을 말하나(분야마다 다르면 전부 나열).
- **구분**: 닮은 다른 기호와 어떻게 다른가.
- **예시**: 실제로 쓰인 한 줄.

---

## 1-A. 연산 기호

### ⟨ + ⟩ 더하기
- **읽는 법**: "플러스", "더하기".
- **뜻**:
  - 산수·대수: 두 수를 합친다. 3 + 4 = 7.
  - 부호: 양수 표시. +5는 "양의 5".
  - 집합·벡터공간: ⊕(직합)의 줄임으로 쓰이기도 하나, 보통은 같은 종류끼리의 덧셈.
  - 전기: 양극(+극).
- **구분**: ± (플러스마이너스, 둘 다)와 다르다. ⊕ (동그라미 안 플러스, 직합·배타적논리합)와 다르다.
- **예시**: 2 + 2 = 4. 벡터에서 (1,0) + (0,1) = (1,1).

### ⟨ − ⟩ 빼기
- **읽는 법**: "마이너스", "빼기".
- **뜻**:
  - 산수: 두 수의 차. 7 − 4 = 3.
  - 부호: 음수 표시. −5는 "음의 5".
  - 방향: 반대 방향(벡터 −v는 v의 정반대 화살표).
- **구분**: 빼기 −는 두 수 사이에, 부호 −는 한 수 앞에 붙는다. 7−4(빼기) vs −4(음수).
- **예시**: 10 − 3 = 7. −v 는 v를 거꾸로 뒤집은 화살표.

### ⟨ × ⟩ 곱하기
- **읽는 법**: "곱하기", "타임스".
- **뜻**:
  - 산수: 두 수를 곱한다. 3 × 4 = 12.
  - 벡터: a × b 는 외적(cross product) — 두 화살표에 동시에 수직인 새 화살표(3차원 전용). 1-K 참조.
  - 집합: A × B 는 데카르트 곱(순서쌍 전부의 모음). {1,2} × {a} = {(1,a),(2,a)}.
- **구분**: 가운뎃점 · (스칼라 곱·내적)과 다르다. ⊗ (텐서곱)과 다르다. 수끼리는 × 또는 ·, 벡터끼리 ×는 외적이라 결과가 또 벡터다.
- **예시**: 5 × 6 = 30. (1,0,0) × (0,1,0) = (0,0,1).

### ⟨ ÷ ⟩ 나누기
- **읽는 법**: "나누기", "디바이드".
- **뜻**: 산수: 똑같이 나눈다. 12 ÷ 4 = 3.
- **구분**: / (슬래시)나 분수 막대 ─ 와 같은 뜻. d/dx의 슬래시는 나누기가 아니라 미분 기호(1-C ⟨d/dx⟩ 참조)이니 헷갈리면 안 된다.
- **예시**: 20 ÷ 5 = 4.

### ⟨ = ⟩ 같다
- **읽는 법**: "이퀄", "같다".
- **뜻**: 왼쪽과 오른쪽이 같은 값·같은 대상이다. x = 3.
- **구분**: ≠(같지 않다), ≈(거의 같다), ≡(항등·정의·합동), := (정의로 같게 둔다)와 구별. ⇔(논리적 동치, 1-B)와도 다르다 — =는 값이, ⇔는 명제가 같다.
- **예시**: 2 + 2 = 4.

### ⟨ ≠ ⟩ 같지 않다
- **읽는 법**: "같지 않다", "낫 이퀄".
- **뜻**: 왼쪽과 오른쪽이 다르다.
- **구분**: = 위에 빗금이 그어진 것. ≢(합동 아님)과 다르다.
- **예시**: 3 ≠ 5.

### ⟨ ≤ ⟩ 작거나 같다 / ⟨ ≥ ⟩ 크거나 같다
- **읽는 법**: "작거나 같다", "이하" / "크거나 같다", "이상".
- **뜻**: ≤는 왼쪽이 오른쪽보다 작거나 같다. ≥는 크거나 같다.
- **구분**: < (순수히 작다)·> (순수히 크다)는 같은 경우를 뺀다. ≤는 같아도 된다. ≪(훨씬 작다)·≫(훨씬 크다)와도 다르다.
- **예시**: x ≤ 5 는 x가 5거나 5보다 작다. 길이 ‖ψ‖ ≥ 0 은 길이가 0이거나 양수.

### ⟨ ± ⟩ 플러스마이너스
- **읽는 법**: "플러스마이너스".
- **뜻**:
  - 두 값을 한꺼번에: a ± b 는 "a+b 와 a−b 둘 다". 근의 공식 x = (−b ± √D)/2a 처럼 답이 둘.
  - 오차: 5 ± 0.1 은 "5인데 0.1만큼 틀릴 수 있다".
- **구분**: + 하나, − 하나가 아니라 둘을 동시에 뜻한다. ∓(마이너스플러스, 부호 순서 반대)와 짝.
- **예시**: √4 = ±2 (제곱해서 4가 되는 수는 2와 −2).

### ⟨ ∝ ⟩ 비례한다
- **읽는 법**: "비례한다", "프로포셔널 투".
- **뜻**: 한쪽이 커지면 다른 쪽도 같은 배율로 커진다. y ∝ x 는 "y는 x에 비례" = y = (상수)×x.
- **구분**: = 와 다르다. ∝는 "배율(상수)은 모르지만 비례한다"만 말한다. ∼(어림수로 같다)와도 다르다.
- **예시**: 중력 F ∝ 1/r² (거리 제곱에 반비례). 원둘레 ∝ 반지름.

## 1-B. 논리·집합 기호

### ⟨ ∈ ⟩ 원소이다
- **읽는 법**: "원소이다", "에 속한다", "벌롱스 투".
- **뜻**: 왼쪽 대상이 오른쪽 집합 안에 들어 있다. x ∈ A 는 "x는 A의 원소".
- **구분**: ∉(원소 아니다)와 반대. ⊂(부분집합, 집합이 집합 안에)와 다르다 — ∈는 "낱개가 모임 안에", ⊂는 "모임이 모임 안에".
- **예시**: 3 ∈ ℕ (3은 자연수). |ψ⟩ ∈ ℋ (상태는 힐베르트 공간의 원소).

### ⟨ ∉ ⟩ 원소가 아니다
- **읽는 법**: "원소가 아니다".
- **뜻**: 왼쪽이 오른쪽 집합 안에 없다.
- **구분**: ∈ 에 빗금. ⊄(부분집합 아님)와 다르다.
- **예시**: −1 ∉ ℕ (음수는 자연수 아님).

### ⟨ ⊂ ⟩ 부분집합이다 / ⟨ ⊆ ⟩ 부분집합이거나 같다
- **읽는 법**: "부분집합이다", "포함된다" / "부분집합이거나 같다".
- **뜻**: A ⊂ B 는 "A의 모든 원소가 B에도 있다". ⊆는 같아도 됨을 분명히 한 것.
- **구분**: ∈(낱개)와 다르다. ⊃(거꾸로, B가 A를 포함)와 방향 반대. ⊊(진부분집합, 같지는 않음)와도 구별.
- **예시**: ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ (수 체계의 사다리).

### ⟨ ∪ ⟩ 합집합 / ⟨ ∩ ⟩ 교집합
- **읽는 법**: "합집합", "유니온" / "교집합", "인터섹션".
- **뜻**: A ∪ B 는 둘 중 하나라도 속한 것 전부. A ∩ B 는 둘 다에 속한 것만.
- **구분**: ∪는 컵 모양(담아 합침), ∩은 뚜껑 모양(겹치는 부분만). ∨(논리합)·∧(논리곱)과 모양이 닮았지만 ∪/∩은 집합, ∨/∧은 참거짓.
- **예시**: {1,2} ∪ {2,3} = {1,2,3}. {1,2} ∩ {2,3} = {2}.

### ⟨ ∅ ⟩ 공집합
- **읽는 법**: "공집합", "엠티 셋".
- **뜻**: 원소가 하나도 없는 집합 { }.
- **구분**: 숫자 0과 다르다(0은 수, ∅은 빈 모임). {∅}와도 다르다 — {∅}는 "빈 모임을 원소로 가진 모임"이라 원소가 1개다.
- **예시**: A ∩ B = ∅ 은 "A와 B는 겹치는 게 없다".

### ⟨ ∀ ⟩ 모든 / ⟨ ∃ ⟩ 어떤이 존재한다
- **읽는 법**: "모든", "포 올" / "존재한다", "데어 이그지스츠".
- **뜻**: ∀x 는 "모든 x에 대해". ∃x 는 "적어도 하나의 x가 있어서".
- **구분**: ∀는 A를 뒤집은 모양(All), ∃는 E를 뒤집은 모양(Exists). ∃!는 "정확히 하나만 존재".
- **예시**: ∀x∈ℝ, x² ≥ 0 ("모든 실수는 제곱하면 0 이상"). ∃x, x² = 2 ("제곱해서 2 되는 수가 있다").

### ⟨ ¬ ⟩ 부정 / ⟨ ∧ ⟩ 그리고 / ⟨ ∨ ⟩ 또는
- **읽는 법**: "낫", "부정" / "앤드", "그리고" / "오어", "또는".
- **뜻**: ¬P 는 "P가 아니다". P ∧ Q 는 "P 그리고 Q 둘 다 참". P ∨ Q 는 "P 또는 Q 적어도 하나 참".
- **구분**: ∧/∨은 참거짓(명제), ∩/∪은 집합. ∨는 "둘 다 참이어도 참"이라 일상의 배타적 "또는"과 다르다.
- **예시**: ¬(비 온다) = "비 안 온다". (해 뜸) ∧ (바람 붐).

### ⟨ ⇒ ⟩ 함의 / ⟨ ⇔ ⟩ 동치
- **읽는 법**: "이면", "임플라이즈" / "필요충분", "동치", "이프 앤드 온리 이프".
- **뜻**: P ⇒ Q 는 "P가 참이면 Q도 참". P ⇔ Q 는 "P와 Q가 동시에 참이거나 동시에 거짓"(서로 갈음 가능).
- **구분**: → (단순 화살표·사상·극한)과 다르다. ⇒는 논리, →는 "어디로 간다/대응". = 와도 다르다 — =는 값, ⇔는 명제의 참거짓이 같다.
- **예시**: (x = 2) ⇒ (x² = 4). (Av=λv, v≠0) ⇔ det(A−λI)=0.

### ⟨ ∴ ⟩ 그러므로 / ⟨ ∵ ⟩ 왜냐하면
- **읽는 법**: "그러므로", "데어포어" / "왜냐하면", "비코즈".
- **뜻**: ∴는 결론을 끌어낼 때, ∵는 이유를 댈 때.
- **구분**: 점 세 개의 방향이 반대. ∴는 위가 1점·아래 2점(결론이 위에서 내려옴), ∵는 위 2점·아래 1점.
- **예시**: x² = 4, x > 0 ∴ x = 2.

### ⟨ | ⟩ 세로막대 (중의성 큰 기호 — 맥락마다 뜻 다름)
- **읽는 법**: 맥락에 따라 "절댓값", "such that(그런)", "given(조건부)", "나눈다", "켓/브라 사이".
- **뜻**:
  - 절댓값·크기: |x| 는 x의 크기(부호 떼기). |−3| = 3.
  - 집합 정의: { x | P(x) } 는 "P를 만족하는 x들의 모임". 여기 |는 "such that(그런 것 중)".
  - 조건부확률: P(A | B) 는 "B가 일어났을 때 A의 확률". 여기 |는 "given(주어졌을 때)".
  - 나눔: a | b 는 "a가 b를 나눈다(b는 a의 배수)". 2 | 6 (2는 6을 나눔).
  - 양자: ⟨ψ|φ⟩의 가운데 막대는 브라와 켓을 잇는 자리(내적). |ψ⟩의 막대는 켓의 왼쪽 테두리.
- **구분**: 위 다섯 뜻은 모양이 같으니 반드시 맥락으로 못박는다. 절댓값은 한 쌍 |⋅|, 집합·확률은 중괄호·확률 안, 나눔은 두 수 사이.
- **예시**: |−5| = 5. {n | n은 짝수}. P(비 | 구름).

## 1-C. 해석학(미적분) 기호

### ⟨ Σ ⟩ 시그마(합)
- **읽는 법**: "시그마", "합", "섬(sum)".
- **뜻**: 여러 항을 차례로 다 더하라. 아래에 시작, 위에 끝, 옆에 더할 식.
- **구분**: 대문자 Σ(합)과 소문자 σ(표준편차·응력 등, 1-M)는 완전히 다른 일을 한다. ∏(곱)와 짝 — Σ는 더하기, ∏는 곱하기.
- **예시**: Σ_{n=1}^{3} n = 1+2+3 = 6. ζ(s)=Σ n^{−s}는 1/1ˢ + 1/2ˢ + …를 다 더하라는 뜻(2부 #1).

### ⟨ ∏ ⟩ 파이(곱)
- **읽는 법**: "파이(대문자)", "곱", "프로덕트".
- **뜻**: 여러 항을 차례로 다 곱하라.
- **구분**: 대문자 ∏(곱)과 소문자 π(원주율 3.14…)는 다르다. Σ(더하기)와 짝.
- **예시**: ∏_{n=1}^{3} n = 1×2×3 = 6. 오일러 곱 ∏(1−p^{−s})^{−1}은 소수 p마다의 인수를 다 곱하라(2부 #1).

### ⟨ ∫ ⟩ 적분 / ⟨ ∮ ⟩ 선적분(닫힌) / ⟨ ∬ ⟩ 이중적분 / ⟨ ∭ ⟩ 삼중적분
- **읽는 법**: "인테그랄", "적분" / "닫힌 선적분", "컨투어 인테그랄" / "이중적분" / "삼중적분".
- **뜻**: ∫는 잘게 쪼갠 조각을 무한히 더해 넓이·합계를 구한다(더하기 Σ의 연속판). ∮는 한 바퀴 도는 닫힌 길을 따라 더한다. ∬·∭는 넓이·부피 위에서 더한다.
- **구분**: ∫는 길쭉한 S(sum의 옛 글자). 동그라미 붙은 ∮은 "한 바퀴 닫힌 길". Σ(띄엄띄엄 더하기)와 ∫(연속 더하기)는 사촌.
- **예시**: ∫₀¹ x dx = 1/2 (0부터 1까지 x의 넓이). ∮ 자기장·dl = 전류(앙페르 법칙).

### ⟨ ∂ ⟩ 편미분 (★골드 예시 — 중의성 기호★)
- **읽는 법**: "파셜", "라운드 디", "둥근 d".
- **뜻** (분야별 전부):
  - 미적분: **편미분(partial derivative)**. 여러 변수 중 하나만 살짝 바꿀 때의 변화율. ∂f/∂x 는 "y·z는 고정하고 x만 움직였을 때 f의 변화율".
  - 위상수학·기하: **경계(boundary)**. ∂A 는 영역 A의 테두리. ∂(공)= 공의 껍질(구면).
  - 호몰로지: **경계 연산자**. ∂는 사슬을 그 테두리로 보내는 연산자. ∂²=0 ("테두리의 테두리는 없다").
- **구분 (전미분 d 와의 차이)**:
  - 전미분 d: 변수가 하나뿐이거나, 모든 변수를 동시에 다 따질 때. df/dx.
  - 편미분 ∂: 여러 변수 중 **나머지를 고정하고 하나만** 따질 때. ∂f/∂x.
  - 같은 둥근 d라도 위치로 안다: 분수꼴(∂f/∂x)이면 편미분, 영역 앞(∂A)이면 경계.
- **예시**:
  - f(x,y)=x²y 일 때 ∂f/∂x = 2xy (y는 상수 취급), ∂f/∂y = x².
  - 정사각형의 ∂는 네 변(테두리).
  - 나비에-스토크스의 ∂u/∂t (2부 #8)는 "한 점에 가만히 서서 본 속도의 시간 변화율".

### ⟨ ∇ ⟩ 나블라 / ⟨ ∇· ⟩ 발산 / ⟨ ∇× ⟩ 회전 / ⟨ ∇² ⟩ 라플라시안
- **읽는 법**: "나블라", "델", "그래디언트" / "다이버전스", "발산" / "컬", "회전" / "라플라시안", "델 제곱".
- **뜻**:
  - ∇f (그래디언트): 스칼라장 f가 가장 빨리 커지는 방향+기울기를 가리키는 화살표. "오르막 화살표".
  - ∇·v (발산): 한 점에서 화살표장이 얼마나 솟아나오나(샘) 혹은 빨려드나(싱크). 양수면 솟음, 음수면 빨림, 0이면 보존.
  - ∇×v (회전): 한 점에서 화살표장이 얼마나 빙빙 도나. 작은 바람개비가 도는 정도.
  - ∇²f (라플라시안): ∇·(∇f). f가 이웃 평균보다 얼마나 높은지/낮은지. 열·파동·확산의 심장.
- **구분**: ∇ 혼자(화살표 결과)·∇·(점, 스칼라 결과)·∇×(가위표, 벡터 결과)·∇²(제곱, 스칼라 결과)는 모두 다른 연산자다. □(달랑베르시안, 1-C 아래)와 ∇²(라플라시안)는 시간을 넣느냐로 갈린다.
- **예시**: ∇·u = 0 (2부 #8, 물이 안 압축됨). ∇²φ = 0 (라플라스 방정식, 정전기).

### ⟨ □ ⟩ 달랑베르시안 (박스 연산자)
- **읽는 법**: "박스", "달랑베르시안", "큐벡(quabla)".
- **뜻**: 시공간의 라플라시안. □ = ∇² − (1/c²)∂²/∂t². 공간으로 퍼지는 것과 시간으로 흐르는 것을 한꺼번에 본 파동 연산자.
- **구분**: ∇²(공간만)와 다르다. □는 시간 축을 음의 부호로 끼워 넣어 빛의 속도 c가 들어간다(1-G ⟨c⟩).
- **예시**: □φ = 0 은 파동 방정식(빛·중력파가 c로 퍼짐).

### ⟨ lim ⟩ 극한 / ⟨ → ⟩ 화살표 / ⟨ ∞ ⟩ 무한대
- **읽는 법**: "리미트", "극한" / "화살표", "로 간다", "사상" / "무한대", "인피니티".
- **뜻**:
  - lim: 변수가 어떤 값에 한없이 다가갈 때 식이 다가가는 값.
  - → : "어디로 다가간다/보낸다". x→0 ("x가 0으로"). 또는 함수 f: A→B ("A를 B로 보내는 사상").
  - ∞ : 끝없이 큼. 수가 아니라 "한없이 커지는 상태".
- **구분**: → (단순 화살표)는 극한·사상, ⇒(이중 화살표)는 논리적 함의(1-B). ∞는 진짜 수가 아니라 "한계를 넘어선다"는 표지.
- **예시**: lim_{x→0} (sin x)/x = 1. n→∞ ("n이 한없이 커질 때").

### ⟨ δ ⟩ 델타(소문자) / ⟨ Δ ⟩ 델타(대문자) — 중의성 기호
- **읽는 법**: "델타(소문자)" / "델타(대문자)".
- **뜻**:
  - δ (소문자):
    - 아주 작은 변화·변분: δx 는 "x의 미세한 흔들림". 변분법의 δS(작용의 변분).
    - 디랙 델타: δ(x) 는 "한 점에만 무한히 뾰족한 봉우리, 전체 넓이는 1"인 가짜 함수.
    - 크로네커 델타: δ_{ij} 는 i=j면 1, 아니면 0.
  - Δ (대문자):
    - 유한한 차이: Δx = x₂ − x₁ ("x의 큰 변화량").
    - 라플라시안의 다른 표기: Δ = ∇²(특히 기하·해석에서).
    - 판별식: 이차식의 Δ = b²−4ac.
    - 삼각형(기하).
- **구분**: 소문자 δ는 "무한히 작은 변화/봉우리/점함수", 대문자 Δ는 "유한한 차이/라플라시안/판별식". d(미분)와 δ(변분)도 다르다 — d는 변수를 따라, δ는 경로 자체를 흔든다.
- **예시**: Δx = 5 − 3 = 2 (변화량). δ(x−a) (a에 박힌 점 봉우리). δ_{ij}(대각만 1인 표).

### ⟨ ′ ⟩ 프라임
- **읽는 법**: "프라임", "프라임(도함수)".
- **뜻**: f′(x) 는 f의 도함수(미분). 또는 x′처럼 "다른 것·새 변수" 표시.
- **구분**: f′(미분)와 f*(켤레·쌍대)·f†(에르미트 켤레, 1-D)는 다르다. 분(′)·초(″) 단위와도 모양이 같으니 맥락으로.
- **예시**: (x²)′ = 2x.

### ⟨ d/dx ⟩ 전미분 (도함수 연산자)
- **읽는 법**: "디 디엑스", "x에 대한 미분".
- **뜻**: 변수 x가 살짝 바뀔 때 식이 얼마나 바뀌나(변화율). 분자 d는 "아주 작은 변화", 분모 dx는 "x의 아주 작은 변화".
- **구분**: 전미분 d/dx(변수 하나, 혹은 전부 동시에) vs 편미분 ∂/∂x(여럿 중 하나만). 슬래시는 진짜 나눗셈이 아니라 "변화율"이라는 한 덩어리 기호.
- **예시**: d(x³)/dx = 3x². β(g)=μ dg/dμ (2부 #9, 결합세기가 척도에 따라 흐르는 속도).

## 1-C+. 삼각함수·각·항등식 기호 (해석/함수 묶음)

여기 나오는 각은 모두 **θ(세타)=각도**다(1-M θ 참조). 시간이나 매개변수를 뜻하는 **t와 헷갈리면 안 된다** — t는 시간/매개변수, θ는 각. 삼각함수는 "단위원(반지름 1짜리 원) 위에서 각 θ만큼 돈 점"의 좌표를 읽는 기계다. 자세한 카드 그림은 **→ F04+ 삼각함수 카드(파일02) 참조**.

```
        세로 높이 = sin θ
        |
   . ----+ (점)
  /:     :
 / :     : <- 단위원 (반지름 1)
θ  :     :
+--+-----+----   가로 = cos θ
원점
```

### ⟨ sin θ ⟩ 사인
- **읽는 법**: "사인 세타".
- **뜻**: 단위원에서 각 θ만큼 돈 점의 **세로 높이**(y좌표). 직각삼각형에선 (높이)/(빗변). 값은 항상 −1 ~ 1 사이를 출렁인다.
- **구분**: cos(가로)와 짝이다. sin은 θ=0에서 0(점이 가로축에 붙어 높이 0). 변수 s나 표준편차 σ와 무관.
- **ASCII 비유**: 그네를 옆에서 볼 때의 "땅에서 뜬 높이". 한 바퀴 돌면 0↑+1↓0↓−1↑0.
- **예시**: sin 0 = 0, sin(π/2) = 1 (꼭대기). (sin x)′ = cos x (라디안일 때).

### ⟨ cos θ ⟩ 코사인
- **읽는 법**: "코사인 세타".
- **뜻**: 같은 점의 **가로**(x좌표). 직각삼각형에선 (밑변)/(빗변). 값은 −1 ~ 1.
- **구분**: sin보다 위상이 π/2(90°) **앞선다** — cos θ = sin(θ + π/2). θ=0에서 cos는 1(점이 오른쪽 끝, 가로 최대), sin은 0.
- **ASCII 비유**: 같은 그네를 위에서 내려다볼 때의 "앞뒤 거리". sin과 cos는 90° 어긋난 한 쌍의 출렁임.
- **예시**: cos 0 = 1, cos(π/2) = 0.

### ⟨ tan θ ⟩ 탄젠트
- **읽는 법**: "탄젠트 세타", "탄 세타".
- **뜻**: tan θ = sin θ / cos θ = 그 점까지 그은 직선의 **기울기**(세로÷가로). 비탈의 가파른 정도.
- **구분**: cos θ = 0이 되는 곳(θ=π/2, 90°)에서 분모가 0이라 ∞로 **발산**한다(1-C ∞). sin·cos는 −1~1에 갇히지만 tan은 끝없이 커진다.
- **ASCII 비유**: 언덕의 "경사도". 거의 수직에 가까울수록 기울기가 하늘로 치솟는다.
- **예시**: tan 0 = 0, tan(π/4) = 1 (45°는 기울기 1).

### ⟨ sec θ · csc θ · cot θ ⟩ 역수 3형제
- **읽는 법**: "시컨트" / "코시컨트" / "코탄젠트".
- **뜻**: 셋 다 위 세 개를 뒤집은 것. sec θ = 1/cos θ, csc θ = 1/sin θ, cot θ = cos θ / sin θ = 1/tan θ.
- **구분**: sec는 cos의 역수(이름이 엇갈림 주의 — se**c**는 **cos** 짝), csc는 sin의 역수, cot은 tan의 역수. 분모가 0인 곳에서 발산.
- **ASCII 비유**: 원래 함수가 "납작"하면 역수는 "치솟고", 원래가 치솟으면 역수는 0으로 가라앉는다(시소).
- **예시**: sec 0 = 1/cos 0 = 1. cot(π/4) = 1.

### ⟨ arcsin · arccos · arctan ⟩ 역삼각함수
- **읽는 법**: "아크사인" / "아크코사인" / "아크탄젠트". (sin⁻¹·cos⁻¹·tan⁻¹로도 씀.)
- **뜻**: 거꾸로 가는 기계. **값을 주면 그 값을 만드는 각 θ를 돌려준다**. arcsin(1) = π/2 ("높이 1을 만드는 각은 90°").
- **구분**: 윗첨자 −1은 "역함수"이지 "역수(1/sin)"가 아니다 — sin⁻¹θ ≠ 1/sin θ(그건 csc). **치역(돌려주는 각의 범위) 주의**: 한 값에 각이 여럿이라(한 바퀴마다 반복) 대표 구간 하나만 돌려준다.
- **ASCII 비유**: sin이 "각→높이" 자판기라면 arcsin은 "높이를 넣으면 각이 나오는" 거꾸로 자판기.
- **예시**: arctan(1) = π/4. arcsin(0) = 0.

### ⟨ rad ⟩ 라디안 (각의 단위)
- **읽는 법**: "라디안", "래드".
- **뜻**: 각을 **호의 길이로 재는** 단위. 반지름 1인 원에서, 호의 길이가 그대로 각이다. 반지름만큼의 호가 딱 1 rad(≈57.3°).
- **구분**: 도(°)와 다른 잣대. 한 바퀴 = 2π rad = 360°. 도는 "한 바퀴를 360으로 쪼갠 사람 약속", 라디안은 "원 자체의 길이로 잰 잣대".
- **왜 라디안인가**: 미분이 라디안에서만 깔끔하다 — (sin x)′ = cos x는 x가 라디안일 때만 성립한다(도로 재면 자질구레한 상수가 붙는다).
- **ASCII 비유**: 360°는 "피자를 360조각으로 약속해서 센 것", 라디안은 "피자 둘레의 끈 길이로 잰 것".
- **예시**: 90° = π/2 rad. 180° = π rad. 1 rad ≈ 57.3°.

### ⟨ cos²θ + sin²θ = 1 ⟩ 피타고라스 항등식
- **읽는 법**: "코사인 제곱 세타 더하기 사인 제곱 세타는 1".
- **한 글자씩**:
  - cos²θ : 가로(cos θ)를 제곱한 것 = (가로)².
  - + : 더하기(1-A).
  - sin²θ : 세로(sin θ)를 제곱한 것 = (세로)².
  - = 1 : 그 합이 항상 정확히 1.
- **통째 의미**: 단위원 위 점의 (가로)² + (세로)² = (반지름)² = 1² = 1. 이건 **단위원에 적용한 피타고라스 정리**다. 각 θ가 무엇이든 항상 성립하는 "항등식".
- **ASCII 비유**: 직각삼각형의 두 변(가로 cos, 세로 sin)을 제곱해 더하면 빗변(반지름=1)의 제곱이 된다.
- **예시**: θ=π/2일 때 cos²= 0, sin²= 1, 합 = 1. θ=0일 때 1 + 0 = 1.

### ⟨ sin(a+b) = sin a cos b + cos a sin b ⟩ 덧셈정리
- **읽는 법**: "사인 에이 플러스 비는, 사인 에이 코사인 비 더하기 코사인 에이 사인 비".
- **한 글자씩**:
  - sin(a+b) : 두 각 a, b를 **합한** 각의 사인.
  - sin a cos b : 첫 각의 세로 × 둘째 각의 가로.
  - + : 더하기.
  - cos a sin b : 첫 각의 가로 × 둘째 각의 세로.
- **통째 의미**: 두 각을 더한 뒤의 높이(sin)는, 각각의 높이·가로를 섞어 만든다. 큰 각을 작은 각들로 쪼개 계산하게 해준다.
- **ASCII 비유**: 그네를 두 번 밀어(a만큼, 그다음 b만큼) 도달한 높이를, 각각 한 번씩 민 결과를 버무려 알아내는 공식.
- **예시**: sin(90°+0°) = sin 90° cos 0° + cos 90° sin 0° = 1·1 + 0·0 = 1.

### ⟨ e^(iθ) = cos θ + i·sin θ ⟩ 오일러 공식
- **읽는 법**: "이 의 아이 세타 제곱은 코사인 세타 더하기 아이 사인 세타".
- **한 글자씩**:
  - e : 자연상수 2.718…(1-E e). "성장"의 기계.
  - i : 허수단위, i²=−1(1-E i). "90° 돌리기"의 기계.
  - θ : 각(1-M θ). 시간 t 아님.
  - e^(iθ) : e를 (i 곱하기 θ)제곱 — 복소평면에서 **각 θ만큼 회전**한 단위 화살표.
  - cos θ + i·sin θ : 그 화살표의 가로(cos)와 세로(sin)를 실수부·허수부로 적은 것.
- **통째 의미**: **회전(삼각함수)과 성장(지수함수)이 허수 i 하나로 같은 것이 된다.** e^(iθ)는 "한 바퀴 도는 점"이고, 그 가로·세로가 바로 cos·sin이다. 지수의 세계와 삼각의 세계를 잇는 다리.
- **ASCII 비유**: 보통 e^x는 "쭉 뻗는 성장", 그런데 지수에 i를 끼우면 뻗는 대신 **빙글빙글 돈다**. 직선 성장을 90° 꺾어 원운동으로 바꾸는 것이 i다.
- **예시**: θ = π를 넣으면 e^(iπ) = cos π + i sin π = −1 + 0 = −1, 즉 **e^(iπ) + 1 = 0** (오일러 항등식 — e, i, π, 1, 0이 한 줄에).

## 1-D. 선형대수·양자 기호

### ⟨ ⊗ ⟩ 텐서곱 / ⟨ ⊕ ⟩ 직합
- **읽는 법**: "텐서 프로덕트", "크로네커 곱" / "다이렉트 섬", "직합".
- **뜻**:
  - ⊗ (텐서곱): 두 공간을 "곱해" 훨씬 큰 공간을 만든다. 두 입자의 상태 |a⟩⊗|b⟩는 둘을 한꺼번에 적은 합동 상태. 차원이 더해지지 않고 **곱해진다**(2차원⊗2차원=4차원).
  - ⊕ (직합): 두 공간을 "나란히 붙여" 더한다. 차원이 **더해진다**(2차원⊕3차원=5차원).
- **구분**: ⊗는 차원을 곱(얽힘의 무대), ⊕는 차원을 더함(따로 붙임). 이 곱셈 vs 덧셈 차이가 양자 얽힘(2부 #24,#27)의 핵심.
- **예시**: |↑⟩⊗|↓⟩ (첫 입자 위, 둘째 아래). ℝ² ⊕ ℝ³ = ℝ⁵.

### ⟨ † ⟩ 단검(에르미트 켤레) / ⟨ ᵀ ⟩ 전치
- **읽는 법**: "대거", "단검", "에르미트 켤레", "어드조인트" / "트랜스포즈", "전치".
- **뜻**:
  - † : 행과 열을 뒤집고(전치) + 각 수를 켤레복소수로 바꾼다(허수부 부호 뒤집기). 양자에서 켓 |ψ⟩의 †는 브라 ⟨ψ|.
  - ᵀ : 행과 열만 뒤집는다(켤레는 안 함). 실수 행렬에선 † = ᵀ.
- **구분**: †(전치+켤레)는 복소수 세계, ᵀ(전치만)는 실수면 충분. A†=A인 행렬이 에르미트 행렬(관측량, 고유값이 실수).
- **예시**: 행렬 A의 (i,j)성분이 a+bi면 A†의 (j,i)성분은 a−bi. a†(생성연산자, 입자 하나 더함).

### ⟨ det ⟩ 행렬식 / ⟨ tr ⟩ 대각합
- **읽는 법**: "디터미넌트", "행렬식" / "트레이스", "대각합".
- **뜻**:
  - det A: 그 변환이 부피를 몇 배로 키우나(부호는 뒤집힘 여부). det=0이면 부피를 0으로 찌부러뜨림(역행렬 없음).
  - tr A: 대각선 성분의 합. 고유값들의 합과 같다.
- **구분**: det는 고유값들의 **곱**, tr는 고유값들의 **합**. 둘 다 변환의 "지문"이지만 곱 vs 합으로 다르다.
- **예시**: det(A−λI)=0 (특성방정식, 고유값 찾기). tr(ρ)=1 (밀도행렬의 확률 총합, 2부 #23).

### ⟨ ⟨·|·⟩ ⟩ 내적(브라켓) / ⟨ |ψ⟩ ⟩ 켓 / ⟨ ⟨ψ| ⟩ 브라
- **읽는 법**: "브라켓", "인너 프로덕트" / "켓 프사이" / "브라 프사이".
- **뜻**:
  - |ψ⟩ (켓): 양자 상태를 담은 화살표(열벡터). ψ(프사이)는 상태 이름, 1-M 참조.
  - ⟨ψ| (브라): 켓의 짝(행벡터, 에르미트 켤레). ⟨ψ| = (|ψ⟩)†.
  - ⟨φ|ψ⟩ (브라켓·내적): 두 상태가 얼마나 닮았나(겹침). 같은 방향이면 1, 수직이면 0. 그 절댓값 제곱이 확률.
- **구분**: ⟨·|·⟩(내적, 스칼라 결과)와 |ψ⟩⟨φ|(외적, 연산자 결과)는 막대 순서로 갈린다. 안쪽으로 모이면 내적, 바깥으로 펼치면 연산자(사영 등).
- **예시**: ⟨ψ|ψ⟩ = ‖ψ‖² = 1 (자기 자신과의 겹침 = 길이 제곱 = 1, 2부 #5).

### ⟨ ‖·‖ ⟩ 노름(크기) / ⟨ · ⟩ 내적·스칼라곱 / ⟨ × ⟩ 외적(벡터)
- **읽는 법**: "노름", "크기" / "닷", "내적", "스칼라곱" / "크로스", "외적".
- **뜻**:
  - ‖v‖ : 벡터·상태의 길이(크기). 절댓값 |·|의 다차원판.
  - a·b : 두 화살표의 내적 = ‖a‖‖b‖cosθ. 한 수(스칼라)가 나온다. "얼마나 같은 방향인가".
  - a×b : 두 화살표의 외적 = 둘에 수직인 새 화살표. 벡터가 나온다(3차원 전용). "얼마나 다른 방향인가 + 그 수직 방향".
- **구분**: ‖·‖는 길이(쌍 막대), |·|는 수의 절댓값(홑 막대). a·b(스칼라)와 a×b(벡터)는 결과 종류가 다르다.
- **예시**: ‖(3,4)‖ = 5. (1,0)·(0,1) = 0 (수직). (1,0,0)×(0,1,0)=(0,0,1).

## 1-E. 수 체계 기호

### ⟨ ℕ ℤ ℚ ℝ ℂ ⟩ 수의 사다리
- **읽는 법**: "자연수 집합 N" / "정수 집합 Z" / "유리수 집합 Q" / "실수 집합 R" / "복소수 집합 C".
- **뜻**:
  - ℕ : 자연수 {1,2,3,…}(셈하는 수). 가운데 두 줄 N.
  - ℤ : 정수 {…,−1,0,1,…}(독일어 Zahlen에서 Z).
  - ℚ : 유리수(분수로 적히는 수, Quotient의 Q).
  - ℝ : 실수(수직선의 모든 점, Real의 R).
  - ℂ : 복소수(a+bi 꼴, Complex의 C).
- **구분**: 보통 글자(N,Z,…)와 달리 두 줄짜리 굵은 글꼴은 "수의 집합 전체"를 뜻한다. 사다리 ℕ⊂ℤ⊂ℚ⊂ℝ⊂ℂ.
- **예시**: s ∈ ℂ (리만 제타의 입력은 복소수, 2부 #1). x ∈ ℝ.

### ⟨ i ⟩ 허수단위 / ⟨ e ⟩ 자연상수
- **읽는 법**: "아이", "허수단위" / "이", "자연상수", "오일러 수".
- **뜻**:
  - i : 제곱하면 −1이 되는 수. i² = −1. 수직선 밖(위쪽)으로 나가는 방향.
  - e : 2.71828…. 끝없이 이어지는 자연의 성장 상수. eˣ는 미분해도 자기 자신.
- **구분**: i(허수단위)와 변수 i(합의 첨자, Σ_{i=1}…)는 모양이 같으니 맥락으로. e(상수 2.718)와 변수 e(전자 전하 등)도 맥락으로. 오일러 항등식 e^{iπ}+1=0이 둘을 묶는다.
- **예시**: e^{iθ} = cosθ + i sinθ (오일러 공식). |ψ⟩의 위상 e^{iφ}.

### ⟨ ℜ ⟩ 실수부 / ⟨ ℑ ⟩ 허수부
- **읽는 법**: "리얼 파트", "실수부" / "이매지너리 파트", "허수부".
- **뜻**: 복소수 z = a+bi 에서 ℜ(z)=a (실수부), ℑ(z)=b (허수부).
- **구분**: 집합 ℝ·ℂ(두 줄 글꼴)와 다르게 ℜ·ℑ은 옛날식 장식 글꼴로 "부분을 뽑아낸다". Re(z)·Im(z)로도 쓴다.
- **예시**: 리만 가설 Re(s) = ½ ("자명하지 않은 영점은 모두 실수부가 ½", 2부 #1).

## 1-F. 물리 상수·장 기호

### ⟨ ℏ ⟩ 플랑크 상수(환산) / ⟨ c ⟩ 빛의 속도 / ⟨ G ⟩ 중력상수 / ⟨ k_B ⟩ 볼츠만 상수
- **읽는 법**: "에이치 바", "디랙 상수" / "씨", "빛의 속도" / "지", "중력상수" / "케이 비", "볼츠만 상수".
- **뜻**:
  - ℏ : 양자 세계의 최소 알갱이 크기(작용의 단위). h/2π. 양자 현상의 모든 곳에 등장.
  - c : 빛의 속도(약 3×10⁸ m/s). 우주의 속도 상한.
  - G : 중력의 세기 상수(아주 작음). 질량끼리 끄는 힘의 비례상수.
  - k_B : 온도와 에너지를 잇는 환율. "온도 1도가 에너지로 얼마인가".
- **구분**: ℏ(가로줄 그은 h)와 보통 h(플랑크 상수 본체, h=2πℏ)는 2π배 다르다. c(빛속도 상수)와 변수 c도 맥락으로.
- **예시**: G_μν = 8πG/c⁴ · T_μν (아인슈타인 방정식, 2부 #10). E = k_B T (열에너지 눈금).

### ⟨ g_μν ⟩ 계량 / ⟨ Γ^λ_μν ⟩ 크리스토펠 기호 / ⟨ R^ρ_σμν ⟩ 리만 곡률
- **읽는 법**: "메트릭 지 뮤 누", "계량 텐서" / "크리스토펠 람다 뮤 누" / "리만 텐서 로 시그마 뮤 누".
- **뜻**:
  - g_μν : 휜 공간에서 거리·각도를 재는 자. 아래첨자 μ,ν(뮤,누)는 방향 번호. "두 방향 사이 길이를 어떻게 재나".
  - Γ^λ_μν : 휜 공간에서 "곧게 간다"가 어떻게 휘는지 알려주는 보정값(접속). 직선이 어떻게 굽나.
  - R^ρ_σμν : 공간이 실제로 얼마나 휘었나(곡률). 0이면 평평, 아니면 휨.
- **구분**: 위/아래 첨자(ρ,σ,μ,ν)는 텐서의 방향 번호이지 거듭제곱이 아니다. g(계량)·Γ(접속)·R(곡률)은 휜 공간의 세 층(자→직선의 휨→공간의 휨).
- **예시**: 측지선 방정식에 Γ가, 아인슈타인 방정식 G_μν에 g와 R이 들어간다(2부 #10,#11).

## 1-M. 그리스 문자 대사전 (중의성 박멸)

각 문자: **읽는 법 → 분야별 뜻 전부 → 맥락 못박기**.

### α (알파)
- 읽는 법: "알파". 뜻: 각도, 미세구조상수(α≈1/137, 전자기 세기), 흡수계수, 가속도(드물게), 첫째 것. 맥락: 양자전기역학에서 α=결합세기, 기하에선 각.

### β (베타)
- 읽는 법: "베타". 뜻: 각도, 베타 함수 β(g)(결합세기가 척도 따라 흐르는 속도, 2부 #9), 속도/빛속도 비(β=v/c, 상대론), 둘째 것. 맥락: 재규격화군에서 β=흐름 속도.

### γ (감마)
- 읽는 법: "감마". 뜻: 각도, 로런츠 인자 γ=1/√(1−β²)(상대론), 감마선, 감마행렬 γ^μ(디랙), 오일러-마스케로니 상수 γ≈0.577. 맥락: 상대론에선 시간 늘어남 인자, 입자물리에선 행렬.

### δ (소문자 델타) — 1-C에서 해부함
- 미세변화/변분, 디랙 델타 δ(x), 크로네커 δ_{ij}.

### ε (엡실론)
- 읽는 법: "엡실론". 뜻: 아주 작은 양(ε>0, "얼마든 작게"), 유전율 ε(전기 통하는 정도, 2부 #22), 변형률(strain), 레비-치비타 기호 ε_{ijk}(부호 가리는 표). 맥락: 극한 정의에선 작은 수, 전자기에선 유전율.

### ζ (제타)
- 읽는 법: "제타". 뜻: 리만 제타 함수 ζ(s)(2부 #1), 감쇠비(진동). 맥락: 해석적 정수론에선 제타 함수.

### η (에타)
- 읽는 법: "에타". 뜻: 점성계수 η(끈적임), 효율, 민코프스키 계량 η_μν(평평한 시공간의 자). 맥락: 유체에선 점성, 상대론에선 평평한 계량.

### θ (세타)
- 읽는 법: "세타". 뜻: 각도(가장 흔함), 위상각, 세타각(QCD), 온도(드물게 Θ로). 맥락: 거의 항상 각.

### ι (이오타)
- 읽는 법: "이오타". 뜻: 아주 작은 양(드물게), 단위벡터, 포함사상 ι. 거의 안 쓰임(i와 닮아 기피).

### κ (카파)
- 읽는 법: "카파". 뜻: 곡률(curvature), 열전도율, 압축률, 아인슈타인 상수 κ=8πG/c⁴. 맥락: 기하에선 곡률, 열에선 전도율.

### λ (람다) — 중의성 큰 기호
- 읽는 법: "람다". 뜻:
  - **고유값**: Av=λv 의 λ(배율, 1-D 참조).
  - **파장**: λ=빛·파동의 한 마루에서 다음 마루까지 거리.
  - **라그랑주 승수**: 제약조건 아래 최적화할 때 끼우는 미지수 λ.
  - 붕괴율(방사능), 우주상수 Λ(대문자, 2부 #13).
- 맥락: 행렬·연산자 옆이면 고유값, 빛·파동이면 파장, 제약최적화면 라그랑주 승수. 반드시 못박는다.

### μ (뮤) — 중의성 큰 기호
- 읽는 법: "뮤". 뜻:
  - **평균**(통계): 분포의 한가운데 값 μ.
  - **투자율**(전자기): 자기 통하는 정도 μ(2부 #22).
  - **지표(index)**: 텐서 첨자 μ=0,1,2,3(시공간 방향, g_μν).
  - 화학퍼텐셜 μ, 마찰계수 μ, 환산질량 μ, 척도(재규격화의 μ, 2부 #9).
- 맥락: 통계면 평균, 자기면 투자율, 텐서 첨자면 방향 번호. 못박기 필수.

### ν (누)
- 읽는 법: "누". 뜻: 진동수(빛의 떨림 횟수), 동점성계수 ν(2부 #8, 끈적임을 밀도로 나눈 것), 중성미자 ν, 텐서 첨자 ν. 맥락: 유체에선 동점성, 빛이면 진동수.

### ξ (크사이)
- 읽는 법: "크사이", "크시". 뜻: 상관길이 ξ(2부 #12, 질서가 이어지는 거리), 임의 변수, 위치 변수. 맥락: 상전이에선 상관길이.

### π (파이)
- 읽는 법: "파이(소문자)". 뜻: 원주율 3.14159…, 소수(prime, p와 함께), 운동량 켤레변수 π, 사영연산자(드물게 P). 맥락: 거의 원주율. 대문자 ∏(곱)과 다름(1-C).

### ρ (로) — 중의성 큰 기호
- 읽는 법: "로". 뜻:
  - **밀도**(물리): 질량밀도·전하밀도 ρ(2부 #8,#10).
  - **밀도행렬**(양자): ρ=상태의 확률 섞임을 담은 행렬(2부 #23, tr ρ=1).
  - 저항률, 상관계수(통계), 곡률반지름.
- 맥락: 유체·중력이면 질량/전하 밀도, 양자 열린계면 밀도행렬. 못박기 필수.

### σ (시그마, 소문자) — 중의성 가장 큰 기호
- 읽는 법: "시그마(소문자)". 뜻:
  - **표준편차**(통계): 분포가 평균에서 얼마나 퍼졌나 σ.
  - **파울리 행렬**(양자): σ_x,σ_y,σ_z(스핀 1/2의 회전, 2부 #5,#23).
  - **응력**(고체역학): σ=단위넓이당 힘(2부 #21).
  - **전도도**(전자기): σ=전기 얼마나 잘 통하나.
  - 단면적(입자충돌), 표면장력.
- 맥락: 통계면 표준편차, 스핀이면 파울리, 재료면 응력, 전기면 전도도. 대문자 Σ(합, 1-C)와 절대 혼동 금지. 못박기 필수.

### τ (타우)
- 읽는 법: "타우". 뜻: 시간상수·고유시간(상대론), 비틀림(torsion), 토크, 전단응력, 타우 입자. 맥락: 상대론에선 고유시간, 재료에선 전단응력.

### υ (윕실론)
- 읽는 법: "윕실론". 뜻: 거의 안 쓰임(u·v와 닮아 기피). 드물게 속도·입자 이름.

### φ (파이/피) — 중의성 주의
- 읽는 법: "파이", "피". 뜻: 위상각 φ, 퍼텐셜 φ(전기·중력), 스칼라장 φ(2부 #9), 황금비 φ≈1.618, 각도. 맥락: 장이론에선 스칼라장, 전자기에선 퍼텐셜.

### χ (카이)
- 읽는 법: "카이". 뜻: 감수율 χ(외부장에 얼마나 반응하나), 오일러 지표 χ(위상수학), 카이제곱 χ²(통계), 파동함수(드물게). 맥락: 위상수학에선 오일러 지표.

### ψ (프사이)
- 읽는 법: "프사이", "사이". 뜻: 파동함수 ψ(양자 상태, 2부 #5,#24), 흐름함수(유체). 맥락: 양자면 파동함수, 2차원 유체면 흐름함수.

### ω (오메가, 소문자)
- 읽는 법: "오메가(소문자)". 뜻: 각진동수 ω=2πν(빙빙 도는 빠르기), 각속도, 미분형식, 단위근. 맥락: 진동·파동이면 각진동수.

# [2부] 난제 공식 대사전

각 공식은 골드 예시 ⟨나비에-스토크스⟩처럼:
- **원문**: 공식 그대로.
- **한 글자씩**: 모든 기호 해부(1부 참조 연결).
- **통째 의미**: 중2 언어로 한 덩어리 뜻.
- **뭘 하나**: 이 식이 실제로 하는 일.
- **어느 난제**: 닿는 난제 번호.
- **어디서 부서지나**: "여기서부터 인류가 모른다".

## #1 리만 가설 — 제타 함수와 오일러 곱

**원문**: ζ(s) = Σ_{n=1}^∞ n^{−s} = ∏_{p 소수} (1 − p^{−s})^{−1}, 그리고 자명하지 않은 영점은 Re(s) = ½.

**한 글자씩**:
- ζ : 제타 함수(1-M ζ). 복소수 s를 받아 복소수를 내놓는 기계.
- s : 입력. 복소수 s∈ℂ(1-E ℂ). s = σ + it 꼴(여기 σ는 실수부, t는 허수부 — 표준편차 아님, 1-M σ 주의).
- Σ_{n=1}^∞ : n을 1부터 무한까지 다 더하라(1-C Σ, ∞).
- n^{−s} : n의 −s제곱 = 1/nˢ.
- ∏_{p 소수} : 모든 소수 p마다의 인수를 다 곱하라(1-C ∏).
- (1 − p^{−s})^{−1} : 소수 하나당 인수 1/(1−1/pˢ).
- Re(s) = ½ : s의 실수부가 정확히 ½(1-E ℜ).

**통째 의미**: 왼쪽은 "모든 수를 한 번씩 더한 합"이고, 오른쪽은 "모든 소수를 한 번씩 곱한 곱"이다. 오일러는 이 둘이 같다는 걸 발견했다 — 더하기 세계(모든 수)와 곱하기 세계(소수)가 같은 함수의 두 얼굴이다. 그래서 ζ를 들여다보면 소수의 비밀이 보인다. 리만 가설은 "이 함수가 0이 되는 특별한 점들이 모두 한 줄(실수부 ½) 위에 정확히 늘어서 있다"는 주장이다.

**뭘 하나**: 소수가 수직선 위에 얼마나 고르게 흩어졌는지를 ζ의 영점 위치로 번역한다. 영점이 모두 Re(s)=½ 위에 있으면, 소수의 분포 오차가 가능한 한 작다는 뜻이다.

**어느 난제**: #1(리만 가설). 도구: 지구01 고유값(영점), 해석접속.

**어디서 부서지나**: 영점이 ½ 줄 근처에 무수히 많다는 것까지는 계산으로 확인됐다. 하지만 "**모든** 영점이 빠짐없이 그 줄 위"임은 증명되지 않았다. 더하기와 곱하기를 잇는 ζ의 깊은 대칭이 왜 영점을 한 줄에 묶는지 — 여기서부터 인류가 모른다.

## #2 P vs NP — SAT와 다항 환원

**원문**: P = NP ? (모든 NP 문제가 다항시간 알고리즘을 가지는가). SAT ∈ NP-complete, A ≤_p SAT.

**한 글자씩**:
- P : 답을 **빨리(다항시간) 푸는** 문제들의 모임.
- NP : 답이 주어지면 **빨리 검산하는** 문제들의 모임.
- = : 두 모임이 같은가(1-A =).
- ? : 미해결 물음표.
- SAT : 논리식이 참이 되게 만들 수 있나(만족가능성) 문제.
- ∈ : 원소이다(1-B). SAT는 NP-완전 부류에 속한다.
- ≤_p : 다항 환원("A를 SAT로 빠르게 바꿔 풀 수 있다"). 아래첨자 p는 polynomial(다항).

**통째 의미**: "검산은 쉬운데 푸는 건 정말 어려운 문제가 있을까?"를 묻는다. SAT는 그 어려운 문제들의 대장(NP-완전)이다. A ≤_p SAT는 "어떤 NP 문제든 SAT 모양으로 빠르게 바꿀 수 있다"는 뜻 — SAT 하나만 빨리 풀면 전부 빨리 풀린다.

**뭘 하나**: 세상의 수많은 어려운 문제(일정 짜기, 암호 깨기)를 단 하나 SAT로 묶어, "이 하나가 쉬운가"로 전부의 운명을 건다.

**어느 난제**: #2(P vs NP). 도구: 환원, 복잡도.

**어디서 부서지나**: P≠NP일 거라고 다들 믿지만, "빨리 푸는 길이 **절대** 없다"를 증명하려면 모든 가능한 알고리즘을 한꺼번에 막아야 한다. 그런 전면적 하한을 세우는 도구가 없다 — 여기서부터 인류가 모른다.

---

## #3 푸앵카레/기하화 계열 — 곡률과 호몰로지·호모토피

**원문**: π₁(M) = 0 ⇒ M ≅ Sⁿ ? (단순연결이면 구인가). 호몰로지 H_n(M), 리치 흐름 ∂g/∂t = −2 Ric(g).

**한 글자씩**:
- π₁(M) : M의 기본군(고리를 줄여보는 군). 1-M의 π와 다른 쓰임(첨자 1).
- = 0 : 모든 고리가 한 점으로 줄어든다(구멍 없음).
- ⇒ : 이면(1-B).
- M ≅ Sⁿ : M이 n차원 구와 위상적으로 같다(≅는 "동형").
- H_n(M) : n번째 호몰로지 군(n차원 구멍의 개수 세기).
- ∂g/∂t : 계량 g(1-F)의 시간 변화율(∂는 편미분, 1-C).
- Ric(g) : 리치 곡률(공간이 휜 정도의 평균).

**통째 의미**: "고무공처럼 구멍 없이 매끈한 3차원 덩어리는 결국 구(공 껍질)뿐인가?"를 묻는다. 호몰로지는 구멍을 세고, 리치 흐름은 울퉁불퉁한 공간을 열 퍼지듯 매끈하게 펴서 모양의 정체를 드러낸다.

**뭘 하나**: 곡률을 시간에 따라 흘려보내 복잡한 모양을 표준형으로 펴낸다(기하화).

**어느 난제**: #3(푸앵카레는 해결됨, 기하화·고차원은 진행 중). 도구: 호몰로지, 리치 흐름.

**어디서 부서지나**: 리치 흐름은 펴는 도중 한 점이 무한히 뾰족해지는 특이점을 만든다. 페렐만은 그 특이점을 잘라 잇는 수술로 3차원을 해결했다. 하지만 더 높은 차원·일반 상황에서 특이점을 항상 다룰 수 있는지 — 여기서부터 인류가 모른다.

## #4 일반 비선형 PDE — 특성곡선과 약해

**원문**: F(x, u, Du, D²u) = 0; 약해: ∫ u ∂φ = −∫ (∂u) φ (∀ 시험함수 φ).

**한 글자씩**:
- F(...) = 0 : 미지함수 u와 그 도함수들이 만족할 방정식.
- Du, D²u : u의 1차·2차 도함수 모음(∇·∇² 일반화, 1-C).
- 약해(weak solution) : 직접 미분이 안 돼도 적분으로 만족시키는 해.
- ∫ : 적분(1-C). φ : 시험함수(아무 매끈한 함수).
- ∂φ : φ의 미분(1-C ∂). 미분을 u에서 φ로 떠넘긴 것.
- ∀ : 모든(1-B).

**통째 의미**: 어떤 방정식의 해 u가 너무 거칠어서 직접 미분이 안 될 때, "u에 매끈한 짝 φ를 곱해 적분하면 식을 만족한다"로 뜻을 바꾼다(미분을 φ로 떠넘김). 그러면 거친 해도 받아들일 수 있다.

**뭘 하나**: 충격파처럼 꺾인 해도 다룰 수 있게 "해"의 정의를 넓힌다.

**어느 난제**: #4(일반 비선형 PDE 정칙성). 도구: 지구06 소보레프 공간, 약해.

**어디서 부서지나**: 약해는 존재하지만 여럿일 수 있고(유일성 깨짐), 그중 진짜 물리적인 하나를 고르는 보편 기준이 없다. 거친 약해가 언제 매끈해지는지(정칙성)도 방정식마다 다르다 — 여기서부터 인류가 모른다.

## #5 양자측정 — 파동함수·사영·규격화

**원문**: |ψ⟩, ‖ψ⟩‖ = 1; 측정 후 |ψ⟩ → P|ψ⟩/‖P|ψ⟩‖, 확률 = ⟨ψ|P|ψ⟩.

**한 글자씩**:
- |ψ⟩ : 양자 상태 켓(1-D, 1-M ψ).
- ‖·‖ = 1 : 길이가 1(1-D ‖·‖). 확률 총합이 1이라는 약속.
- → : 측정으로 상태가 바뀐다(1-C →, 사상).
- P : 사영연산자(측정이 골라내는 방향으로 납작 누름). P²=P.
- ⟨ψ|P|ψ⟩ : 그 방향으로의 겹침 = 그 결과가 나올 확률(1-D 브라켓).

**통째 의미**: 양자 상태는 길이 1인 화살표다. 측정하면 화살표가 갑자기 측정장치가 고른 방향으로 툭 꺾이고(사영), 그 방향과 원래 화살표가 얼마나 겹쳤었나가 그 결과가 나올 확률이다.

**뭘 하나**: 측정 결과의 확률과 측정 뒤 상태를 계산한다(보른 규칙 + 붕괴 공준).

**어느 난제**: #5(양자측정), #28(측정문제). 도구: 지구01 고유값, 사영.

**어디서 부서지나**: 화살표가 **왜** 한 방향으로 툭 꺾이는지, 그 꺾임이 진짜 일어나는 일인지 아니면 우리 무지인지 — 슈뢰딩거 방정식엔 붕괴가 없다. 측정의 "툭"은 손으로 덧붙인 규칙이다. 여기서부터 인류가 모른다(#28로 이어짐).

## #6 이산 미분기하 — Δ·Σ·이산 기본정리

**원문**: Σ_{e∈∂F} f(e) = Σ_{e∈F} (Δf)(e) (이산 스토크스), Δf = f(끝) − f(시작).

**한 글자씩**:
- Σ : 합(1-C). e : 변(edge), F : 면(face).
- ∂F : 면 F의 경계(테두리 변들, 1-C ∂의 경계 뜻).
- Δf : 이산 차이(이웃 값의 차, 1-C Δ).
- f(끝)−f(시작) : 양 끝 값의 차.

**통째 의미**: 매끈한 세상의 "테두리에서 잰 합 = 안쪽의 변화를 다 더한 합"(스토크스 정리)을, 점·선·면으로 짠 격자 위에서 그대로 베낀다. 미적분 없이 더하기·빼기만으로 곡률·발산을 다룬다.

**뭘 하나**: 컴퓨터가 다룰 수 있게 곡면·장을 격자로 쪼개고, 연속 미적분 법칙을 이산판으로 옮긴다.

**어느 난제**: #6(이산 미분기하의 연속 극한). 도구: 지구06 미분기하, 이산화.

**어디서 부서지나**: 격자를 잘게 할 때 이산 답이 진짜 연속 답으로 수렴하는지는 격자 모양에 민감하다. 곡률 같은 양은 격자에 따라 안 맞을 수 있다 — 보편적 수렴 보장이 없다. 여기서부터 인류가 모른다.

## #7 에르고딕 이론 — 시간평균=공간평균·리아푸노프

**원문**: lim_{T→∞} (1/T)∫₀ᵀ f(φ_t x) dt = ∫_X f dμ; 리아푸노프 지수 λ = lim (1/t) ln‖δx(t)‖.

**한 글자씩**:
- lim_{T→∞} : T가 무한으로(1-C lim,∞).
- (1/T)∫₀ᵀ ... dt : 시간 0부터 T까지의 평균(시간평균).
- φ_t x : 시간 t 뒤 x의 위치(흐름).
- ∫_X f dμ : 공간 X 전체에 걸친 평균(공간평균). μ는 불변측도(1-M μ — 여기선 측도, 평균 아님).
- λ : 리아푸노프 지수(1-M λ — 여기선 흩어짐 속도). δx : 처음의 미세한 차이(1-C δ).
- ln : 자연로그.

**통째 의미**: "한 알갱이를 아주 오래 따라다니며 잰 평균"이 "한순간 공간 전체를 훑어 잰 평균"과 같아진다는 것(에르고딕). 리아푸노프 지수 λ는 처음 살짝 어긋난 두 길이 얼마나 빨리 벌어지나(>0이면 카오스).

**뭘 하나**: 복잡한 운동을 일일이 안 풀고 "오래 보면 결국 골고루 퍼진다"로 평균을 잡는다.

**어느 난제**: #7(에르고딕성·혼합 증명). 도구: 불변측도, 리아푸노프.

**어디서 부서지나**: 구체적 물리계(예: 단단한 공 여럿)가 진짜 에르고딕인지 증명하기가 극악하다. KAM 정리는 일부 길이 영원히 안 섞임을 보였다 — 어디가 섞이고 어디가 안 섞이는지 일반 답이 없다. 여기서부터 인류가 모른다.

## #8 나비에-스토크스 (★골드 예시 깊이★)

**원문**: ∂u/∂t + (u·∇)u = −∇p/ρ + ν∇²u + f, ∇·u = 0.

**한 글자씩**:
- ∂u/∂t : 한 점에 가만히 서서 본 속도 u의 시간 변화율(1-C ∂, 편미분 — 경계 아님).
- u : 속도장(각 점에서 물이 어느 쪽으로 얼마나 빠른지, 화살표).
- (u·∇)u : 물이 자기 속도장을 타고 흐르며 생기는 변화(이류항). u·∇은 "흐르는 방향으로의 변화율"(1-D ·, 1-C ∇). 이게 **비선형**(u가 두 번 곱해짐).
- −∇p/ρ : 압력 p의 기울기가 미는 힘. ∇p는 압력이 가장 빨리 커지는 방향(1-C ∇), ρ는 밀도(1-M ρ — 질량밀도). 음수라 높은 압력에서 낮은 쪽으로 민다.
- ν∇²u : 점성에 의한 퍼짐(끈적임이 속도차를 매끈하게). ν는 동점성(1-M ν), ∇²는 라플라시안(이웃 평균과의 차, 1-C).
- f : 바깥에서 주는 힘(중력 등).
- ∇·u = 0 : 발산이 0(1-C ∇·) — 물이 한 점에서 솟거나 사라지지 않음(비압축).

**통째 의미**: 물 한 방울에 작용하는 뉴턴 F=ma를 흐름 전체에 쓴 것이다. 왼쪽은 물방울의 가속도(가만히 본 변화 + 흐름 타고 가며 본 변화), 오른쪽은 그 물방울에 가해지는 힘(압력차로 밀림 + 끈적임으로 매끈해짐 + 바깥 힘). 마지막 줄은 "물은 짓눌려 줄지 않는다".

**뭘 하나**: 물·공기의 모든 흐름(잔잔한 강부터 난류까지)을 한 방정식으로 적는다.

**어느 난제**: #8(매끄러운 해의 존재). 도구: 지구19 NS 방정식, 지구08 비선형성, 지구06 소보레프 공간.

**어디서 부서지나**: 비선형항 (u·∇)u가 에너지를 큰 소용돌이 → 작은 소용돌이로 계단처럼 몰아넣는다.

```
   큰 소용돌이 ▇▇▇▇  →  ▇▇  →  ▇  →  ▪ ... → ?
   (무한히 작아지며 속도 기울기가 ∞로 폭발?)
```

약해(레이 해)는 3차원에서 존재하지만, 그게 영원히 **매끈하고 유일**한지는 증명이 무너진다. 비선형이 스케일을 무한히 잇기 때문이다. 여기서부터 인류가 모른다.

## #9 양자장론 — 루프 적분과 베타 함수

**원문**: ∫ d⁴k/(2π)⁴ · 1/(k²−m²) (발산), β(g) = μ dg/dμ.

**한 글자씩**:
- ∫ d⁴k : 4차원 운동량 k 전체에 걸친 적분(1-C ∫). 루프(고리) 안의 모든 운동량을 더함.
- (2π)⁴ : 규격화 인수(π는 원주율, 1-M π).
- 1/(k²−m²) : 전파인자(입자가 한 점에서 다른 점으로 갈 확률폭). m은 질량.
- β(g) : 베타 함수(1-M β). 결합세기 g가 척도에 따라 흐르는 속도.
- μ : 척도(재규격화 기준 에너지, 1-M μ — 여기선 척도, 평균/투자율 아님).
- dg/dμ : g가 μ에 따라 변하는 율(1-C d/dx).

**통째 의미**: 입자들이 가상으로 잠깐 생겼다 사라지는 고리(루프)를 다 더하면 적분이 무한대로 발산한다. 이 무한을 "어떤 에너지 척도 μ에서 보느냐"로 흡수하면, 결합세기 g가 척도에 따라 흐른다(β 함수가 그 흐름 속도).

**뭘 하나**: 무한대를 척도 의존으로 재정의해 유한한 예측을 뽑는다(재규격화). 강한 핵력이 가까이선 약해짐(점근자유)을 설명.

**어느 난제**: #9(양-밀스 질량간극, 재규격화의 수학적 엄밀화). 도구: 루프 적분, 재규격화군.

**어디서 부서지나**: 재규격화는 물리적으로 기막히게 맞지만, 4차원 양-밀스 이론을 수학적으로 빈틈없이 정의하고 "질량간극(가장 가벼운 입자도 무게가 있음)"을 증명하는 일은 안 됐다. 무한을 다루는 손버릇을 엄밀한 수학으로 못 올렸다 — 여기서부터 인류가 모른다.

## #10 일반상대성 — 아인슈타인 방정식

**원문**: G_μν = 8πG/c⁴ · T_μν, 플랑크 길이 ℓ_P = √(ℏG/c³).

**한 글자씩**:
- G_μν : 아인슈타인 텐서(공간이 휜 정도, 1-F의 곡률에서 만듦). 첨자 μ,ν는 시공간 방향(1-M μ,ν — 여기선 지표).
- 8πG/c⁴ : 비례상수. G는 중력상수, c는 빛속도(1-F), π는 원주율.
- T_μν : 에너지-운동량 텐서(어디에 에너지·물질이 얼마나 있나).
- ℓ_P : 플랑크 길이(공간이 양자적으로 출렁이는 최소 길이). ℏ(1-F), G, c로 만듦.

**통째 의미**: "물질이 공간에게 어떻게 휘라고 말하고, 휜 공간이 물질에게 어떻게 움직이라 말한다." 왼쪽(휨)과 오른쪽(에너지)이 같다 — 에너지가 있는 곳에서 시공간이 휜다. 그 휨이 중력이다.

**뭘 하나**: 행성 궤도, 빛의 휨, 블랙홀, 우주 팽창을 다 설명한다.

**어느 난제**: #10(양자중력), #11(수치상대론). 도구: 지구의 기하·곡률.

**어디서 부서지나**: 블랙홀 중심·빅뱅에서 곡률이 무한대로 발산한다(특이점). 그 작은 척도(플랑크 길이)에선 양자 출렁임이 시공간 자체를 흔드는데, 아인슈타인 방정식엔 양자가 없다. 중력을 양자화하면 재규격화가 안 된다(#9와 충돌) — 여기서부터 인류가 모른다.

## #11 수치상대론 — 중력파 파형

**원문**: h(t) = A(t) cos(φ(t)), 미분방정식 ∂_t² g = (G_μν 분해).

**한 글자씩**:
- h(t) : 중력파의 변형률(시공간이 늘었다 줄었다 하는 미세한 비율).
- A(t) : 진폭(파동의 키). φ(t) : 위상(파동의 시각, 1-M φ).
- cos : 코사인(출렁임).
- ∂_t² g : 계량 g의 시간 2차 편미분(1-C ∂, 1-F g). 아인슈타인 방정식을 시간 전진형으로 쪼갠 것.

**통째 의미**: 두 블랙홀이 빙빙 돌다 합쳐질 때 시공간이 떨려 나오는 파동의 모양 h(t)를, 컴퓨터로 아인슈타인 방정식을 시간 따라 풀어 예측한다. 이 파형을 검출기 데이터와 맞춰 사건을 읽는다.

**뭘 하나**: 손으로 못 푸는 아인슈타인 방정식을 격자에서 수치로 풀어 중력파 사전 파형을 만든다.

**어느 난제**: #11(수치상대론 안정성). 도구: 지구11 수치해석, 격자.

**어디서 부서지나**: 시공간을 격자로 쪼개 시간 전진시키면 작은 오차가 지수로 커져 계산이 폭발한다(좌표 선택·구속조건 위반). 어떤 격자·게이지가 항상 안정적인지 보편 답이 없다 — 여기서부터 인류가 모른다.

## #12 상전이·임계현상 — 자유에너지와 상관길이

**원문**: F = −k_B T ln Z, ξ ∝ |T−T_c|^{−ν}, 질서변수 m = ⟨φ⟩.

**한 글자씩**:
- F : 자유에너지(계가 쓸 수 있는 에너지). k_B(1-F 볼츠만), T(온도), ln Z(분배함수의 로그, Z는 모든 상태의 무게합, 1-M Ω 연관).
- ξ : 상관길이(1-M ξ) — 한 곳의 질서가 얼마나 멀리까지 이어지나.
- ∝ : 비례(1-A). |T−T_c| : 임계온도 T_c와의 거리(절댓값, 1-B |).
- ^{−ν} : 임계지수 ν(여기선 지수 이름, 1-M ν).
- m = ⟨φ⟩ : 질서변수 = 장 φ의 평균(자석의 정렬도). ⟨·⟩은 평균(1-D 브라켓의 기댓값 뜻).

**통째 의미**: 물이 끓고 자석이 자성을 잃는 "상이 바뀌는 순간(임계점)"에서, 질서가 이어지는 거리 ξ가 무한으로 치솟는다. 그때 물질은 모든 크기의 요동을 동시에 갖는다. 임계지수 ν는 그 치솟는 속도이며, 재료가 달라도 같은 값이 나온다(보편성).

**뭘 하나**: 끓는점·자성 소실 같은 급변을 한 틀로 설명하고, 재료 무관한 보편 지수를 예측한다.

**어느 난제**: #12(임계지수의 엄밀 도출). 도구: 지구12 재규격화군, 상관함수.

**어디서 부서지나**: 3차원에서 임계지수 ν 등을 수학적으로 엄밀히 도출하는 일은 거의 안 됐다(2차원·평균장만 풀림). 모든 척도가 한꺼번에 얽히는 임계점을 다룰 완전한 도구가 없다 — 여기서부터 인류가 모른다.

## #13 암흑물질·암흑에너지 — 회전곡선과 ΛCDM

**원문**: v(r) = √(GM(r)/r), Ω_Λ + Ω_m = 1; MOND: a = √(a₀ g_N).

**한 글자씩**:
- v(r) : 반지름 r에서의 회전 속도. G(중력상수), M(r)(반지름 안 질량).
- √ : 제곱근.
- Ω_Λ, Ω_m : 암흑에너지·물질의 밀도 비율(1-M Ω — 여기선 밀도변수). Λ는 우주상수(1-M Λ).
- a₀ : MOND의 기준 가속도(아주 작음). g_N : 뉴턴 예측 가속도.

**통째 의미**: 은하 바깥별의 회전 속도 v(r)는 보이는 물질만으론 너무 빠르다. 안 보이는 질량(암흑물질)을 넣으면 맞는다. 우주 전체로 보면 보이는 물질은 일부, 나머지는 암흑물질+암흑에너지(Λ)다. MOND는 "중력 법칙 자체를 약한 곳에서 고치자"는 대안.

**뭘 하나**: 은하 회전, 우주 팽창 가속을 설명한다(암흑 성분 또는 수정중력).

**어느 난제**: #13(암흑물질·암흑에너지 정체). 도구: 지구13 중력·우주론.

**어디서 부서지나**: ΛCDM은 큰 척도를 잘 맞추지만 암흑물질 입자를 실험으로 못 잡았고, 우주상수 Λ의 값이 이론 예측보다 10¹²⁰배 작은 이유를 모른다(우주상수 문제). MOND는 작은 척도를 맞추나 우주론적 큰 척도에서 깨진다. 둘 다 완전하지 않다 — 여기서부터 인류가 모른다.

## #14 우주 거대구조 — 상관함수와 비가우스성

**원문**: ξ(r) = ⟨δ(x)δ(x+r)⟩, P(k) = 푸리에[ξ], f_NL(비가우스성).

**한 글자씩**:
- ξ(r) : 두 점 상관함수(1-M ξ) — 거리 r 떨어진 두 곳의 밀도요동이 함께 출렁이는 정도.
- δ(x) : 밀도요동(평균 대비 더하거나 덜한 비율, 1-C δ의 미세변화 뜻).
- ⟨·⟩ : 평균(앙상블 기댓값).
- P(k) : 파워 스펙트럼(파수 k별 요동 세기). 푸리에 변환된 ξ.
- f_NL : 비가우스성 크기(요동이 순수 종 모양에서 얼마나 벗어났나).

**통째 의미**: 우주의 은하들은 무작위가 아니라 거미줄처럼 얽혀 있다. 상관함수 ξ는 "두 점이 얼마나 같이 뭉치나", P(k)는 "어느 크기의 덩어리가 얼마나 많나"를 잰다. f_NL은 초기 요동이 완벽한 종 모양(가우스)에서 벗어난 정도로, 초기 우주(인플레이션)의 흔적이다.

**뭘 하나**: 은하 지도를 통계로 압축해 초기 우주의 씨앗 요동을 역추적한다.

**어느 난제**: #14(초기조건·인플레이션 검증). 도구: 지구14 상관함수, 푸리에.

## #15 자기유체역학(MHD) — 자기 레이놀즈 수

**원문**: ∂B/∂t = ∇×(u×B) + η∇²B, Rm = UL/η.

**한 글자씩**:
- ∂B/∂t : 자기장 B의 시간 변화율(1-C ∂).
- ∇×(u×B) : 흐름이 자기장을 끌고 가며 휘감는 항(1-C ∇×, 1-D × 외적).
- η∇²B : 자기 확산(저항으로 자기장이 새어 퍼짐). η는 자기 확산계수(1-M η — 여기선 확산, 점성 아님), ∇²(1-C).
- Rm = UL/η : 자기 레이놀즈 수(끌고감 vs 새어나감의 비). U는 속도, L은 크기.

**통째 의미**: 별·은하의 플라스마는 흐르면서 자기장을 같이 끌고 다닌다. 자기장은 흐름에 얼어붙어(동결) 끌려가거나, 저항으로 천천히 새어 퍼진다. Rm이 크면 자기장이 흐름에 단단히 매여 다닌다(태양·은하). Rm이 작으면 흩어진다.

**뭘 하나**: 태양 흑점, 은하 자기장, 다이나모(천체가 스스로 자기장을 키움)를 설명한다.

**어느 난제**: #15(MHD 난류·다이나모). 도구: 지구15 MHD, 지구08 비선형성.

**어디서 부서지나**: Rm이 클 때(현실의 천체) MHD는 난류가 되고, 자기장이 어떻게 스스로 증폭·유지되는지(다이나모 문제)는 #8 난류와 같은 비선형 벽에 막힌다. 자기 재결합(자기선이 끊고 다시 이어짐)의 속도도 이론값보다 훨씬 빠른데 이유를 모른다 — 여기서부터 인류가 모른다.

## #16 플라스마 운동론 — 자이로운동 방정식과 수송계수

**원문**: ∂f/∂t + v·∇f + (q/m)(E+v×B)·∇_v f = C[f], D = ⟨(Δx)²⟩/2Δt.

**한 글자씩**:
- f : 분포함수(어느 속도·위치에 입자가 얼마나 있나).
- ∂f/∂t : f의 시간 변화율(1-C ∂).
- v·∇f : 위치 따라 흐르며 생기는 변화(1-D ·, 1-C ∇).
- (q/m)(E+v×B)·∇_v f : 전기장 E·자기장 B의 로런츠 힘이 속도공간에서 미는 항. q(전하), m(질량), ∇_v(속도에 대한 기울기).
- C[f] : 충돌항(입자끼리 부딪혀 분포를 섞음).
- D : 확산계수(얼마나 빨리 퍼지나). ⟨(Δx)²⟩(평균제곱이동, 1-C Δ).

**통째 의미**: 핵융합로·우주의 플라스마는 입자가 너무 많아 하나씩 못 푼다. 대신 "속도·위치별 입자 분포 f"가 어떻게 변하는지 따라간다. 입자는 자기장을 나선(자이로)으로 돌며 흐르고, 충돌로 섞인다. 수송계수 D는 열·입자가 새어나가는 속도다.

**뭘 하나**: 핵융합 플라스마의 가둠(열이 얼마나 새는가)을 예측한다.

**어느 난제**: #16(플라스마 난류 수송). 도구: 지구16 운동론, 통계.

**어디서 부서지나**: 자이로운동 난류에서 수송계수 D를 첫 원리로 예측하는 일은 비선형 난류라 안 된다. 가둠 성능을 실험 없이 못 맞춘다 — #8 난류 벽의 친척이다. 여기서부터 인류가 모른다.

## #17 복잡망 — 쿠라모토 모형과 그래프 라플라시안

**원문**: dθ_i/dt = ω_i + (K/N)Σ_j sin(θ_j−θ_i), L = D − A.

**한 글자씩**:
- θ_i : i번째 진동자의 위상(시각, 1-M θ).
- dθ_i/dt : 그 위상의 변화 속도(1-C d/dx).
- ω_i : i번째의 고유 진동수(혼자일 때 빠르기, 1-M ω).
- K : 결합세기(서로 얼마나 끌어당기나). N : 진동자 수.
- Σ_j sin(θ_j−θ_i) : 다른 진동자들과의 위상차를 다 더해 끌어당김(1-C Σ).
- L = D − A : 그래프 라플라시안. D는 차수행렬(각 점에 몇 줄 연결), A는 인접행렬(누가 누구와 연결).

**통째 의미**: 반딧불이들이 처음엔 제각각 깜빡이다 점점 같이 깜빡이게 되는 현상(동기화)을 적은 식이다. 각자 고유 박자 ω가 있지만, 이웃과 위상차만큼 서로 당겨 K가 충분히 크면 한꺼번에 맞춰진다. 그래프 라플라시안 L은 망의 연결 구조가 동기화·확산을 어떻게 돕는지 담는다.

**뭘 하나**: 전력망·신경·심장 세포의 동기화와 연쇄실패(한 곳 고장이 퍼짐)를 모형화한다.

**어느 난제**: #17(복잡망 동기화·연쇄실패 예측). 도구: 지구17 그래프 라플라시안.

**어디서 부서지나**: 큰 비선형 망에서 동기화가 언제 일어나고 연쇄실패가 어디까지 번지는지, 망 구조만 보고 미리 예측하는 일반 이론이 없다. 망 구조와 동역학이 얽혀 풀기 어렵다 — 여기서부터 인류가 모른다.

## #18 기후·결합 PDE — 부분격자 파라미터화

**원문**: ∂_t Φ = N(Φ) + 𝒫(작은 척도), 결합 (대기⊗해양).

**한 글자씩**:
- Φ : 기후 상태 전체(온도·바람·해류 등의 묶음, 1-M Φ).
- ∂_t Φ : 그 시간 변화율(1-C ∂).
- N(Φ) : 비선형 동역학(나비에-스토크스 등 #8을 품음).
- 𝒫(작은 척도) : 격자보다 작은 현상(구름·소용돌이)을 평균으로 근사한 항(파라미터화).
- ⊗ : 대기와 해양 모형을 결합(1-D ⊗).

**통째 의미**: 기후는 대기·해양·얼음이 얽힌 거대한 흐름이다. 컴퓨터 격자보다 작은 구름·소용돌이는 일일이 못 푸니, 그 평균 효과를 손으로 끼운다(파라미터화 𝒫). 대기와 해양을 ⊗로 묶어 같이 돌린다.

**뭘 하나**: 100년 뒤 기후를 예측하고 불확실성을 가늠한다.

**어느 난제**: #18(기후 예측 불확실성). 도구: 지구18 결합 PDE, 지구08 비선형성.

**어디서 부서지나**: 파라미터화 𝒫는 작은 척도의 진짜 물리를 근사한 손때라, 모형마다 다르고 예측 불확실성의 큰 원천이다. 작은 구름이 큰 기후에 미치는 영향(구름 되먹임)을 첫 원리로 못 잡는다 — #8 난류 벽이 여기에도 있다. 여기서부터 인류가 모른다.

## #19 로봇·제어 — 자코비안과 의사역행렬

**원문**: ẋ = J q̇, q̇ = J⁺ ẋ, J⁺ = Jᵀ(JJᵀ)^{−1}.

**한 글자씩**:
- ẋ : 손끝 속도(위의 점은 시간미분, ẋ = dx/dt).
- J : 자코비안(관절 움직임이 손끝 움직임으로 어떻게 바뀌나, 변환행렬).
- q̇ : 관절 속도.
- J⁺ : 의사역행렬(무어-펜로즈). J가 정사각이 아닐 때의 "가장 그럴듯한 역".
- Jᵀ : J의 전치(1-D ᵀ).
- (JJᵀ)^{−1} : 역행렬.

**통째 의미**: 로봇 팔의 관절을 어떻게 돌리면 손끝이 원하는 곳으로 가나? 자코비안 J가 "관절 → 손끝" 변환이다. 거꾸로 손끝을 정하고 관절을 구하려면 J를 뒤집어야 하는데, 관절이 손끝 자유도보다 많으면(여유자유도) 정확한 역이 없다. 의사역행렬 J⁺가 "에너지를 가장 덜 쓰는 답"을 고른다.

**뭘 하나**: 여유자유도 로봇·연속체 로봇의 움직임을 계산한다.

**어느 난제**: #19(무한자유도 제어). 도구: 지구19 선형대수, 의사역행렬.

**어디서 부서지나**: J가 특이점(JJᵀ의 det→0, 1-D det)에 닿으면 J⁺가 폭발한다(작은 손끝 움직임에 관절이 무한히 빨라짐). 무한자유도(부드러운 로봇·연속체)에선 J가 무한차원 연산자라 J⁺를 안정적으로 정의·계산하는 일반법이 없다 — 여기서부터 인류가 모른다.

## #20 다체제어 — 그래프 라플라시안 합의

**원문**: ẋ = −L x, L = D − A, 합의 ⇔ rank(L) = N−1.

**한 글자씩**:
- ẋ : 에이전트 상태의 변화 속도(점은 시간미분).
- −L x : 라플라시안이 이끄는 끌림(이웃 평균 쪽으로).
- L = D − A : 그래프 라플라시안(#17과 동일). D 차수행렬, A 인접행렬.
- rank(L) = N−1 : L의 계수(독립 행 수)가 N−1(연결 그래프 조건).
- ⇔ : 필요충분(1-B).

**통째 의미**: 드론 떼·로봇 무리가 통신만으로 한 값(대형·속도)에 합의하게 만든다. 각자 이웃과의 차이만큼 끌려가면(−Lx) 결국 모두 같아진다. 그래프가 연결돼 있으면(rank L = N−1) 반드시 합의에 도달한다.

**뭘 하나**: 중앙 지휘 없이 분산된 다체가 스스로 합의·편대를 이룬다.

**어느 난제**: #20(다체제어 강건성). 도구: 지구20 그래프 라플라시안.

**어디서 부서지나**: 통신이 끊기거나 늦거나(시간지연), 일부가 적대적으로 거짓 보고할 때 합의가 깨진다. 비선형·시변·적대 상황에서 합의를 보장하는 일반 조건이 없다 — 여기서부터 인류가 모른다.

## #21 파괴역학 — 응력장과 응력확대계수

**원문**: σ_ij(r,θ) = K/√(2πr) · f_ij(θ), K = σ√(πa).

**한 글자씩**:
- σ_ij : 응력 텐서(1-M σ — 여기선 응력, 표준편차/파울리 아님). 첨자 i,j는 면·방향.
- r, θ : 균열 끝에서의 거리·각도(1-M θ).
- K : 응력확대계수(균열 끝에 응력이 얼마나 몰리나).
- √(2πr) : 거리 제곱근(r→0이면 응력 발산).
- f_ij(θ) : 각도별 분포 모양.
- a : 균열 길이. σ : 멀리서 가한 응력.

**통째 의미**: 금 간 재료를 당기면, 균열 끝에 응력이 확 몰린다. 균열 끝(r→0)에서 응력은 1/√r로 무한히 치솟는다. 그 치솟는 세기를 한 수 K로 압축한다. K가 재료의 한계(파괴인성)를 넘으면 균열이 확 자라 부서진다.

**뭘 하나**: 다리·비행기·압력용기가 균열에서 언제 부서질지 예측한다.

**어느 난제**: #21(동적 파괴·균열 경로 예측). 도구: 지구21 응력 텐서, 특이점.

**어디서 부서지나**: 균열이 빠르게 자라며 갈라지고 휘는 동적 파괴, 그리고 균열이 다음에 어디로 갈지(경로 선택)는 미시 결함·재료 무질서가 좌우해 첫 원리 예측이 안 된다. 균열 끝의 응력 무한대 자체가 모형의 이상화라 진짜 끝에선 다른 물리가 필요하다 — 여기서부터 인류가 모른다.

## #22 메타물질·역문제 — 유전율·투과율 텐서

**원문**: D = εE, B = μH; 역문제: 측정 → (ε,μ) 복원.

**한 글자씩**:
- D, E : 전기 변위·전기장. ε : 유전율 텐서(1-M ε — 여기선 유전율). 방향마다 다른 반응이라 텐서.
- B, H : 자속밀도·자기장. μ : 투과율 텐서(1-M μ — 여기선 투과율, 평균 아님).

**통째 의미**: 물질이 빛에 어떻게 반응하나는 ε(전기 반응)·μ(자기 반응)로 정한다. 이 둘을 자유롭게 설계하면(메타물질) 빛을 휘게 해 투명망토·완벽렌즈를 만든다. 역문제는 거꾸로, 바깥 측정만으로 안쪽 물성 분포를 알아내기(의료영상·지질탐사).

**뭘 하나**: 빛·전자기파를 마음대로 다루는 물질을 설계하고, 측정으로 내부를 영상화한다.

**어느 난제**: #22(역문제의 유일·안정 복원). 도구: 지구22 텐서, 역문제.

**어디서 부서지나**: 역문제는 부적정(ill-posed) — 다른 내부 구조가 같은 바깥 측정을 줄 수 있어 답이 유일하지 않고, 측정 잡음이 답을 크게 흔든다(불안정). 안정적·유일 복원의 일반 조건이 없다 — 여기서부터 인류가 모른다.

## #23 열린 양자계 — 밀도행렬과 린드블라드 방정식

**원문**: dρ/dt = −(i/ℏ)[H,ρ] + Σ_k (L_k ρ L_k† − ½{L_k†L_k, ρ}).

**한 글자씩**:
- ρ : 밀도행렬(1-M ρ — 여기선 밀도행렬, 질량밀도 아님). 상태의 확률 섞임을 담음. tr ρ = 1(1-D tr).
- dρ/dt : ρ의 시간 변화율.
- (i/ℏ) : 허수단위 i(1-E)·플랑크 상수 ℏ(1-F).
- [H,ρ] : 교환자 Hρ−ρH. H는 해밀토니안(에너지). 닫힌계의 떨림.
- L_k : 린드블라드 연산자(환경이 계를 흔드는 통로). L_k†(에르미트 켤레, 1-D †).
- {A,B} : 반교환자 AB+BA.
- Σ_k : 모든 통로 더함(1-C Σ).

**통째 의미**: 양자계가 완전히 고립되지 않고 환경과 닿으면, 깨끗한 |ψ⟩ 대신 확률이 섞인 ρ로 적어야 한다. 첫 항은 평소의 양자 떨림(닫힌계), 둘째 항은 환경이 결맞음을 갉아먹는 디코히어런스다. 밀도행렬의 비대각 성분(결맞음)이 둘째 항으로 사라진다.

**뭘 하나**: 양자컴퓨터 큐비트가 환경 때문에 정보를 잃는 과정을 모형화한다.

**어느 난제**: #23(비마르코프 열린계), #28(측정문제). 도구: 지구23 밀도행렬, 린드블라드.

**어디서 부서지나**: 린드블라드 방정식은 환경이 과거를 "기억 못 한다(마르코프)"고 가정한다. 실제 환경은 기억이 있어(비마르코프, #29) 이 식이 깨진다. 강한 결합·구조화된 환경의 일반 동역학을 풀 방법이 없다 — 여기서부터 인류가 모른다.

## #24 강상관 전자계 — 허바드 모형과 부호 문제

**원문**: H = −t Σ_⟨i,j⟩,σ (c†_iσ c_jσ + h.c.) + U Σ_i n_i↑ n_i↓.

**한 글자씩**:
- H : 해밀토니안(계의 전체 에너지 규칙).
- t : 깡충뛰기 세기(전자가 이웃 자리로 건너뛰는 정도). 1-M τ의 시간상수 아님.
- Σ_⟨i,j⟩,σ : 이웃 자리쌍 ⟨i,j⟩와 스핀 σ에 대해 합(1-C Σ; σ는 스핀, 1-M σ).
- c†_iσ, c_jσ : 생성·소멸 연산자(전자를 자리에 넣고 뺌). †(1-D).
- h.c. : 에르미트 켤레(앞 항의 짝, 거꾸로 깡충).
- U : 같은 자리 반발(전자 둘이 한 자리 싫어함).
- n_i↑ n_i↓ : i자리의 위·아래 스핀 전자 수.

**통째 의미**: 격자 위 전자들이 두 욕구로 다툰다 — 이웃으로 건너뛰어 퍼지고 싶음(t)과 한 자리에 둘이 못 모임(U). 이 줄다리기가 자성·초전도·절연체를 만든다. 가장 간단한데도 풀기 가장 어려운 모형이다.

**뭘 하나**: 고온초전도·모트 절연체 같은 강상관 물질의 정체를 모형화한다.

**어느 난제**: #24(강상관계·고온초전도). 도구: 지구24 다체 양자, 격자.

**어디서 부서지나**: 전자가 페르미온이라 다체 파동함수의 부호가 +,−로 마구 바뀐다. 몬테카를로로 합을 잴 때 +와 −가 거의 상쇄돼 신호가 잡음에 묻힌다(부호 문제). 이 부호 문제는 일반적으로 NP-난해(#2와 연결)라 알려진 우회로가 없다 — 여기서부터 인류가 모른다.

## #25 양자 카오스 — 준위 간격과 랜덤 행렬

**원문**: P(s) ≈ (π/2) s e^{−πs²/4} (GOE 위그너), s = (E_{n+1}−E_n)/⟨ΔE⟩.

**한 글자씩**:
- P(s) : 이웃 에너지 준위 간격 s의 확률분포.
- s : 규격화된 간격(평균 간격으로 나눔).
- E_{n+1}−E_n : 이웃 에너지 준위 차.
- ⟨ΔE⟩ : 평균 간격(1-C Δ, 1-D ⟨·⟩).
- (π/2) s e^{−πs²/4} : 위그너 추측 분포(π 원주율, e 자연상수, 1-E).
- GOE/GUE : 가우스 직교/유니타리 앙상블(랜덤 행렬의 두 종류).

**통째 의미**: 양자계의 에너지 준위들이 얼마나 떨어져 있나를 본다. 규칙적(적분가능)이면 준위가 무관해 가까이 몰릴 수 있다. 그런데 고전적으로 카오스인 계는 준위가 서로를 밀어내(준위 반발) 가까이 안 온다. 이 반발 모양 P(s)가 무작위로 만든 큰 행렬(랜덤 행렬, GOE/GUE)의 고유값 간격과 똑같다.

**뭘 하나**: 양자계가 카오스인지 아닌지를 에너지 준위 통계로 진단한다(랜덤 행렬과 비교).

**어느 난제**: #25(양자 카오스·고유상태). 도구: 지구25 고유값(랜덤 행렬), 통계. 흥미롭게 #1 제타 영점 간격도 GUE를 따른다.

**어디서 부서지나**: "고전 카오스 ⇒ 양자 준위가 랜덤 행렬 통계를 따른다"(BGS 추측)는 수치로 강력히 맞지만 일반 증명이 없다. 왜 무작위 행렬이 결정론적 카오스계의 통계를 정확히 맞추는지 깊은 이유를 모른다 — 여기서부터 인류가 모른다.

## #26 격자 QCD — 경로적분과 색가둠

**원문**: ⟨O⟩ = (1/Z)∫ 𝒟U O[U] e^{−S[U]}, ⟨W(C)⟩ ∼ e^{−σ·면적} (가둠).

**한 글자씩**:
- ⟨O⟩ : 관측량 O의 평균(1-D ⟨·⟩).
- Z : 분배함수(전체 무게합, 규격화).
- ∫ 𝒟U : 모든 글루온 장 배열 U에 대한 경로적분(1-C ∫; 𝒟U는 무한차원 적분).
- O[U] : 그 배열에서의 관측량 값.
- e^{−S[U]} : 작용 S의 지수 무게(작용 작을수록 큰 무게).
- W(C) : 윌슨 고리(닫힌 경로 C를 따라 색전하를 한 바퀴).
- σ·면적 : 끈장력 σ(1-M σ — 여기선 끈장력) × 고리가 두른 면적.

**통째 의미**: 쿼크를 묶는 강한 핵력을 시공간 격자 위에서 컴퓨터로 푼다. 모든 글루온 장 배열을 무게 e^{−S}로 더해 평균을 낸다. 윌슨 고리 ⟨W(C)⟩가 면적에 따라 지수로 줄면(면적 법칙), 색전하를 떼어놓을수록 에너지가 끝없이 커진다는 뜻 — 쿼크가 영원히 갇힌다(색가둠).

**뭘 하나**: 양성자 질량·쿼크 가둠을 첫 원리에서 수치로 계산한다.

**어느 난제**: #26(색가둠의 해석적 증명, #9 질량간극). 도구: 지구26 경로적분, 격자.

**어디서 부서지나**: 격자 QCD는 수치로 가둠을 보여주지만, "왜 가두는가"를 연속극한에서 해석적으로 증명하는 일(양-밀스 질량간극, #9)은 안 됐다. 유한 격자에서 연속·무한부피로 가는 극한의 엄밀한 통제가 미완이다 — 여기서부터 인류가 모른다.

## #27 위상 물질 — 얽힘 엔트로피와 TQFT

**원문**: S = α L − γ, γ = ln 𝒟 (위상 얽힘 엔트로피).

**한 글자씩**:
- S : 얽힘 엔트로피(한 영역과 나머지가 얼마나 얽혔나, 1-M Ω의 엔트로피 친척).
- α L : 경계 길이 L에 비례하는 항(면적 법칙, α는 계수).
- γ : 위상 항(1-M γ — 여기선 위상 얽힘 엔트로피, 상수). 빼기로 들어감.
- 𝒟 : 전체 양자차원(위상질서의 지문). ln(자연로그).
- TQFT : 위상 양자장론(거리 안 따지고 구멍·매듭만 보는 이론).

**통째 의미**: 보통 물질은 영역을 둘로 나눌 때 얽힘이 경계 길이 L에 비례한다(αL). 그런데 위상질서가 있는 물질은 거기서 일정한 양 γ를 **뺀다**. 이 γ는 길이·모양과 무관한 상수로, 그 물질이 숨긴 위상적 질서(어떤 준입자가 사는지)를 드러낸다.

**뭘 하나**: 거리로 안 보이는 숨은 질서(위상질서)를 얽힘의 상수항 γ로 잡아낸다(위상 양자컴퓨팅의 기반).

**어느 난제**: #27(위상질서 분류·비가환 애니온). 도구: 지구27 얽힘, TQFT.

**어디서 부서지나**: 2차원 위상질서는 TQFT로 꽤 분류됐지만, 3차원 이상·상호작용하는 페르미온계의 완전한 분류는 미완이다. γ를 실험에서 깨끗이 재는 것도 어렵다 — 여기서부터 인류가 모른다.

## #28 측정 문제 — 디코히어런스 대 객관붕괴

**원문**: |ψ⟩ = Σ_n c_n |n⟩ → ρ = Σ_n |c_n|² |n⟩⟨n| (디코히어런스); GRW: 자발적 국소화.

**한 글자씩**:
- |ψ⟩ = Σ c_n|n⟩ : 여러 결과의 중첩(1-D 켓, 1-C Σ). c_n은 각 결과의 진폭.
- → : 측정·환경 접촉으로 바뀜(1-C →).
- ρ = Σ |c_n|² |n⟩⟨n| : 비대각이 사라진 밀도행렬(1-M ρ; |n⟩⟨n|은 외적·사영, 1-D).
- |c_n|² : 그 결과의 확률(보른 규칙).
- GRW : 객관붕괴 모형(파동함수가 가끔 저절로 한 점으로 쪼그라듦).

**통째 의미**: 측정 전 양자계는 여러 결과를 동시에 품는다(중첩). 환경과 닿으면 비대각(결맞음)이 사라져 마치 "이미 하나로 정해진 것들의 확률 섞임"처럼 보인다(디코히어런스). 하지만 디코히어런스는 "섞인 것처럼 보이게"만 할 뿐, 실제로 **하나가** 일어나게 하지는 않는다. GRW 같은 객관붕괴는 진짜 붕괴를 물리법칙에 끼워 넣는다.

**뭘 하나**: 왜 우리가 중첩이 아닌 한 결과만 보는지를 설명하려 한다.

**어느 난제**: #28(측정문제). 도구: 지구23 디코히어런스, 지구28 해석.

**어디서 부서지나**: 디코히어런스는 "왜 하나만 일어나나(결과의 유일성)"와 "왜 그 확률인가"를 끝까지 설명 못 한다(여전히 모든 가지가 ρ 안에 있음). 객관붕괴는 실험으로 확정 안 됐다. 측정의 "툭"이 실재인지 무지인지 — #5에서 시작된 이 물음에 인류가 답을 모른다.

## #29 비마르코프 동역학 — 기억핵

**원문**: dρ/dt = ∫₀ᵗ K(t−s) ρ(s) ds, 비마르코프성 𝒩 = ∫_{dt‖>0} dt ‖.

**한 글자씩**:
- dρ/dt : 밀도행렬의 변화율(1-M ρ).
- ∫₀ᵗ ... ds : 0부터 현재 t까지 과거를 다 더함(1-C ∫). 과거가 현재에 영향.
- K(t−s) : 기억핵(과거 시각 s가 현재 t에 미치는 무게). t−s는 얼마나 옛날인가.
- 𝒩 : 비마르코프성 측도(기억의 강도). 정보가 환경에서 계로 되돌아오는 구간만 더함.

**통째 의미**: #23 린드블라드는 환경이 기억 못 한다고 봤다. 실제 환경은 기억이 있어, 현재의 변화가 과거 전부에 매인다(기억핵 K로 가중). 정보가 계에서 환경으로 샜다가 일부 되돌아오기도 한다(되흐름). 𝒩는 그 되흐름의 총량이다.

**뭘 하나**: 구조화된 환경(광자 결정, 생체 분자)에 닿은 양자계의 기억 있는 동역학을 다룬다.

**어느 난제**: #29(비마르코프 열린계 이론). 도구: 지구29 기억핵, 적분미분방정식.

**어디서 부서지나**: 기억핵 K(t)를 첫 원리로 구하려면 환경 전체를 풀어야 하는데(무한 자유도) 일반적으로 못 푼다. 비마르코프성의 보편적 정의·측도조차 여러 갈래로 갈린다 — 여기서부터 인류가 모른다.

## #30 홀로그래피 — 천 수와 벌크-경계 대응

**원문**: C = (1/2π)∫_BZ F (천 수), Z_bulk[φ₀] = Z_CFT[φ₀] (AdS/CFT).

**한 글자씩**:
- C : 천 수(Chern number, 정수). 띠의 위상적 감김 수.
- (1/2π)∫_BZ F : 브릴루앙 영역 BZ 위에서 베리 곡률 F를 적분(1-C ∫). 2π로 나눠 정수가 됨.
- F : 베리 곡률(파동함수가 매개변수공간에서 비틀린 정도, 1-C ∇× 친척).
- Z_bulk, Z_CFT : 벌크(휜 시공간 안쪽) 분배함수 = 경계(한 차원 낮은 면) 분배함수.
- φ₀ : 경계 조건.

**통째 의미**: 두 가지 깊은 대응을 담는다. (1) 물질의 띠가 매개변수공간에서 몇 바퀴 감겼나(천 수 C)가 정수로 양자화돼, 가장자리 전류가 그 정수만큼 흐른다(양자홀 효과). (2) 홀로그래피(AdS/CFT): 휜 시공간 안쪽(벌크)의 중력 이론이 그 경계면(한 차원 낮은) 위의 중력 없는 양자장론과 완전히 같은 정보를 담는다 — 3차원이 2차원 면에 적힌 것처럼.

**뭘 하나**: 위상절연체의 끝 전류를 정수 C로 예측하고, 풀기 어려운 중력 문제를 한 차원 낮은 장론으로 번역한다.

**어느 난제**: #30(홀로그래피·양자중력). 도구: 지구30 천 수·베리 위상, 벌크-경계.

**어디서 부서지나**: AdS/CFT는 특수한 휜 시공간(음의 곡률, AdS)에서 강력한 증거가 있지만, **수학적 증명**은 없고 우리 우주 같은 일반(평평·양의 곡률) 시공간으로 어떻게 확장되는지 모른다. 경계의 어떤 정보가 안쪽 시공간을 짓는지(창발) — 여기서부터 인류가 모른다.

## 이음새 — 다음(파일 25, 각성서)으로

여기까지 우리는 모든 기호를 한 곳에 못박고(1부), 30난제의 대표 공식을 한 글자씩 해부했다(2부). 그런데 사전을 덮으며 한 가지가 또렷해진다: 이 모든 기호와 공식은 **누군가 어떤 벽 앞에서 새로 벼린 도구**였다. Σ는 "무한히 많은 걸 어떻게 더하지?"의 답이었고, ∂는 "여럿 중 하나만 어떻게 흔들지?"의 답이었고, ρ(밀도행렬)는 "깨끗한 |ψ⟩로 못 적는 섞인 상태를 어떻게 담지?"의 답이었다.

그리고 2부의 모든 난제는 같은 자리에서 멈췄다 — "여기서부터 인류가 모른다." 그 멈춘 자리마다 **아직 태어나지 않은 도구**가 있다.

그래서 다음 파일 25 〈각성서〉의 첫 의문은 이것이다: "도구는 대체 어떻게 태어나는가? Σ도 ∂도 ρ도 처음엔 없었다. 벽 앞에서 새 기호 하나가 태어나는 순간, 그 안에서는 정확히 무슨 일이 일어나는가 — 그리고 우리는 그 순간을 의도적으로 만들 수 있는가?"
