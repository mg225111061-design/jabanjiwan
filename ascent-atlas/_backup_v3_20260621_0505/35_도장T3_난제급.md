이 단의 정신: "불변량을 뽑아라"
================================================================
Tier2까지는 '벽을 우회로로 넘는' 동작이었다. 이제 한 단계 위.
난제급 도구들은 거의 다 한 가지 마술을 쓴다 — 변하는 것들을 조합해서
'절대 안 변하는 양(불변량 invariant)'을 뽑아낸다. 그리고 그 불변량으로
"이건 저것과 다르다" 또는 "이건 절대 안 된다"를 증명한다.

네 가지를 직접 발명한다:
 T3-1 오일러 지표 — 모양의 지문(이미 골드 예시. 여기선 그대로 다시 휘두른다)
 T3-2 매듭 불변량 — 끈이 정말 묶였는지를 숫자로
 T3-3 엔트로피     — '놀람의 크기'를 숫자로
 T3-4 불가능성 증명 — '안 됨'을 증명하는 칼

기호 약속(이 단 전체):
 χ (그리스 글자 '카이', chi) — 오일러 지표. 모양의 지문 숫자.
 V, E, F — 꼭짓점(Vertex) 수, 모서리(Edge) 수, 면(Face) 수.
 Σ (그리스 대문자 '시그마', sigma) — "전부 더하라(합)"는 명령. ∑(아래 i, 위 n)는 i=1부터 n까지.
 p (피, probability) — 어떤 일이 일어날 확률. 0과 1 사이 숫자.
 log₂ (밑이 2인 로그) — "2를 몇 번 곱해야 이 수가 되나?"를 묻는 자. log₂8 = 3 (2·2·2=8).
 H (에이치) — 엔트로피(entropy), 평균 놀람의 크기.
 √2 (루트 2) — 제곱하면 2가 되는 양수. 1.414…

◆ 도장 과제 [T3-1] — "찌그러뜨려도 안 변하는 '구멍 수'를 세는 도구를 발명하라"   난이도: ★★★
================================================================
[도전]
 공·도넛·찻잔을 고무처럼 늘이고 구부려도(안 찢고) 변하지 않는 '모양의 지문'을
 숫자로 만들 수 있나? 찻잔과 도넛은 손잡이 구멍 하나로 '같은 부류'라는데,
 그걸 어떻게 숫자 하나로 못박나?

[막다른 길]
 길이·각도·넓이는 늘이면 전부 변한다. '변하는 자'로는 '안 변하는 것'을 잴 수 없다.
 자를 들이대면 도넛을 조금만 눌러도 둘레가 바뀐다 — 측정값이 모양마다, 손짓마다 춤춘다.
 측정을 멈추고, 측정값이 어떻게 변하든 그 조합이 안 변하는 — 새 종류의 양(불변량 invariant)이 필요하다.

[발명하라 ✍️]
 지금 책을 덮고 5분 시도하라.
 힌트: 도형을 점(꼭짓점)·선(모서리)·면으로 쪼개 세어 보라.
 쪼개는 방식은 손짓마다 다르지만, '셈들의 어떤 조합'은 늘여도 안 변할지 모른다.
 더했다 뺐다 해 보라. V, E, F 세 수로 만든 식 중 어느 게 항상 같은 값이 나오나?
 네가 찾은 '안 변하는 조합'을 적어라. 그게 네 발명이다.

[정답 도구] — 오일러 지표 χ = V − E + F
 V=꼭짓점 수, E=모서리 수, F=면 수. 모든 볼록 정다면체가 V−E+F = 2.
     정육면체: V=8, E=12, F=6 → 8−12+6 = 2
     사면체  : V=4, E=6,  F=4 → 4−6+4  = 2
 늘이고 구부려도 V−E+F는 안 변한다(위상 불변량 topological invariant).
 모서리 하나를 잘라 면을 둘로 쪼개면 E도 1 늘고 F도 1 늘어 −E+F가 상쇄 → χ 그대로.
 도넛은 χ=0. → 베티 수(Betti number)·호몰로지(homology)의 씨앗.
 ASCII:
     공(구멍0)  χ=2        도넛(구멍1) χ=0        쌍도넛(구멍2) χ=−2
        ___                  _______                _______ _______
       /   \                / _____ \              / ___  V ___  \
      |     |              | |     | |            | |   |   |   | |
      |     |              | |_____| |            | |___|   |___| |
       \___/                \_______/              \_______ _______/
     구멍 g개면  χ = 2 − 2g  (방향 잡힌 곡면 orientable surface)
       g=0 → 2,  g=1 → 0,  g=2 → −2

[검문소로 채점]
 ① 환원: 정육면체 검산(8−12+6=2 ✓). 사면체도(4−6+4=2 ✓). 작은 경우로 직접 세 본다.
 ② 정의: 어떤 쪼갬을 써도 같은 값이 나오나? (정육면체를 대각선으로 더 쪼개도 χ=2 유지?)
 ③ 무모순: 도넛=0, 공=2와 다 맞나? 구멍 g개면 2−2g 공식과 충돌 없나?
 ④ 표적: '늘여도 안 변하는 지문' 벽을 실제로 메웠나? 자(길이)로는 절대 못 한 일을 했나?
 ⑤ 정직: 새 진리를 '발견'한 게 아니라 '구멍 수'라는 본질을 V−E+F라는 산수로 박제(불변량화)한 것이다.

[이 과제가 가르치는 발명 동작]
 "변하는 양들(V, E, F)을 조합하면 안 변하는 불변량(χ)이 튀어나온다."
 → 난제 #3(다양체 분류: 베티 수)·#30(위상절연체 topological insulator: 천 수 Chern number)에서
   휘둘러야 할 바로 그 칼. 거기선 χ가 천 수·베티 수로 진화한다.
 [경고] χ는 '완전한' 지문이 아니다. 같은 χ인데 다른 공간이 존재한다
   (예: 구와, 구에 손잡이 둘+구멍 메운 묘한 곡면이 χ는 같아도 다를 수 있다).
   이 '불완전함' — 한 숫자로는 모양을 다 구별 못 한다는 사실 — 이
   난제 #3(고차원 다양체 분류)을 아직도 미해결로 남긴 자리다.
   여기서부터, 4차원 위로 올라가면, 인류는 모든 모양을 분류하는 완전한 불변량 목록을 모른다.

◆ 도장 과제 [T3-2] — "끈이 정말 묶였는지(풀리는지)를 안 변하는 수로 판정하는 도구를 발명하라"   난이도: ★★★
================================================================
[도전]
 끈을 마구 꼬아 양 끝을 붙여 고리로 만들었다. 이게 진짜 '매듭(knot)'인가,
 아니면 슬슬 풀면 그냥 동그라미(풀린 매듭 unknot)가 되는 가짜인가?
 손으로 풀어 보면 알 것 같지만 — 안 찢고 끝을 안 떼고 — 정말 안 풀린다는 걸 어떻게 증명하나?

[막다른 길]
 "한참 만져도 안 풀리던데?"는 증명이 아니다. 더 영리하게 만지면 풀릴 수도 있다.
 매듭은 무한히 많은 방식으로 같은 모양을 그릴 수 있어서('이렇게 보이지만 사실 같은 매듭'),
 그림만 비교하면 끝이 없다. 만지는 손동작(꼬기·넘기기)은 그림을 바꾼다.
 → 손동작으로 그림이 어떻게 변하든 안 변하는 숫자 — 매듭 불변량(knot invariant) — 이 있어야
   "이 수가 풀린 동그라미의 수와 다르므로, 절대 안 풀린다"고 못박을 수 있다.

[발명하라 ✍️]
 지금 책을 덮고 5분 시도하라.
 힌트: 매듭 그림의 각 '줄 토막'에 색을 칠해 보라(예: 빨강·파랑·초록 3색).
 단, 교차점(한 줄이 다른 줄 위로 지나는 곳)마다 규칙을 정하라 —
 "교차점에서 만나는 세 토막은 전부 같은 색이거나, 전부 다른 색이어야 한다."
 합법적으로 3색을 칠하는 방법이 몇 가지인가? 그 '가짓수'가 손동작에도 안 변하나?
 (또는 더 쉽게: 교차점 개수의 홀짝을 봐도 좋다.)
 네가 만든 '안 변하는 수'를 적어라.

[정답 도구] — 3색칠하기 tricolorability (가장 손쉬운 매듭 불변량)
 규칙: 매듭 그림을 교차점에서 끊긴 '호(arc)' 단위로 나눈다. 3색(빨강 R·파랑 B·초록 G)으로 칠하되,
   각 교차점에서 만나는 세 호가 (전부 같은 색) 또는 (셋 다 다른 색)이어야 '합법'.
   그리고 적어도 두 색을 실제로 써야 '진짜 3색칠'로 인정.
 핵심: 매듭을 합법적으로 3색칠할 수 있나/없나는 손동작(라이데마이스터 이동 Reidemeister move)에
   안 변한다 — 불변량이다!
   · 풀린 동그라미(unknot): 호가 하나뿐 → 두 색을 못 쓴다 → 3색칠 불가능.
   · 삼엽 매듭(trefoil, 가장 단순한 진짜 매듭): 3색칠 가능!
   → 삼엽은 3색칠 되는데 동그라미는 안 된다. 같은 매듭이면 같은 불변량이어야 하는데 다르다.
     ∴ 삼엽은 절대 풀리지 않는다. 증명 끝.
 ASCII (삼엽 매듭 trefoil — 호 3개에 R/B/G):
        R
        |
     ___|___           교차점 ①: R, B, G 만남 → 셋 다 다름 ✓
    /   |   \          교차점 ②: B, G, R 만남 → 셋 다 다름 ✓
   B    X(①)           교차점 ③: G, R, B 만남 → 셋 다 다름 ✓
    \  / \  /
     \/   \/  ← 세 교차점에서 세 호 R,B,G가 돌아가며 만난다
     /\   /\
    /  \ /  \          → 3색 전부 합법으로 칠해짐 → 삼엽은 tricolorable.
   G    X(②)
    \___|___/
        |
     교차점 ③ 에서 G,R,B
   (풀린 동그라미: 호 1개 → 한 색뿐 → 두 색 못 씀 → NOT tricolorable)

 [더 쉬운 친척] 교차수 패리티(parity): 매듭 그림의 교차점 개수의 홀짝.
   주의 — 이건 불변량이 '아니다'(손동작으로 교차점이 2개씩 늘었다 줄었다 함).
   그래서 단순 교차수는 매듭을 구별 못 한다. '진짜 불변량'은 3색칠처럼 손동작을 견뎌야 한다.
   (이 함정 자체가 좋은 교훈: 안 변하는지 반드시 검문해야 불변량이다.)

[검문소로 채점]
 ① 환원: 삼엽 매듭을 직접 3색칠해 본다(위 그림). 동그라미는 못 칠한다. 손으로 확인.
 ② 정의: '합법 3색칠'의 규칙이 모호함 0인가? (교차점마다 '전부 같음 or 전부 다름', 두 색 이상 사용.)
 ③ 무모순: 손동작(꼬기·넘기기 3종) 어느 것에도 3색칠 가능성이 안 변하나? 직접 한 번 꼬아 다시 칠해 본다.
 ④ 표적: '정말 안 풀리나'라는 벽을 메웠나? "삼엽≠동그라미"를 숫자로 증명했나?
 ⑤ 정직: 매듭을 '발견'한 게 아니라, 끈의 꼬임이라는 본질을 손동작에 안 변하는 색칠 가짓수로 박제했다.

[이 과제가 가르치는 발명 동작]
 "손동작으로 그림이 변해도 안 변하는 양을 찾으면, '두 대상이 다르다'를 증명할 수 있다."
 → 난제 #27(양자장론·매듭과 게이지장: 윌슨 고리 Wilson loop, 천-사이먼스 Chern-Simons 이론)에서
   매듭 불변량(존스 다항식 Jones polynomial)이 물리량으로 부활한다. 끈의 꼬임이 입자의 통계가 된다.
 [경고] 3색칠은 '완전한' 불변량이 아니다. 3색칠 결과가 같은데 서로 다른 매듭이 수두룩하다
   (3색칠로는 8자 매듭 figure-8 같은 것을 동그라미와 구별 못 하는 경우가 생긴다).
   더 센 불변량(존스·알렉산더 다항식)도 마찬가지로 '같은 값 다른 매듭'을 남긴다.
   여기서부터 — 모든 매듭을 완벽히 구별하는 단 하나의 계산 가능한 완전 불변량이 있는가 — 는
   인류가 모른다. 이 '불완전함'이 매듭 분류를 아직 열린 문제로 남긴 자리다.

◆ 도장 과제 [T3-3] — "'놀람의 크기'를 숫자로 재는 도구를 발명하라"   난이도: ★★★★
================================================================
[도전]
 공평한 동전을 던져 결과를 들으면 너는 '딱 1개의 예/아니오(1비트)'만큼 놀란다.
 그런데 99% 앞면 나오는 찌그러진 동전은? 거의 앞면일 줄 알았으니 덜 놀란다.
 '놀람의 평균 크기'를 — 확률들만 보고 — 정확히 하나의 숫자로 뽑을 수 있나?
 더 나아가, 이 숫자가 "이 신호를 보내는 데 평균 몇 비트가 필요한가"와 같아야 한다.

[막다른 길]
 그냥 '경우의 수'를 세면? 동전은 2가지, 주사위는 6가지 — 하지만 찌그러진 동전도 '2가지'라
 공평한 동전과 구별이 안 된다. 경우의 수는 확률의 치우침(놀람의 줄어듦)을 못 잡는다.
 확률 p를 그냥 더하면? 항상 1이라 정보가 없다. p를 곱하면? 두 독립 사건을 합칠 때
 확률은 곱해지는데(p·q), 우리는 '정보량은 더해지길' 바란다(1비트 + 1비트 = 2비트).
 → 곱을 합으로 바꾸는 도구가 필요하다. 그게 핵심 벽이다.

[발명하라 ✍️]
 지금 책을 덮고 5분 시도하라.
 힌트1: 한 사건의 '놀람'은 확률 p가 작을수록 커야 한다(드문 일 = 큰 놀람).
   그리고 독립 두 사건을 함께 보면 확률은 p·q로 곱해지는데 놀람은 더해지길 원한다.
   "곱을 합으로 펴는 자"를 Tier2에서 발명했다 — 무엇이었나? (로그!)
 힌트2: 한 사건의 놀람을 log(1/p) = −log p 로 잡아 보라. 밑은 2로(비트 단위).
   그다음 '평균' 놀람 = 각 놀람에 그 확률을 곱해 전부 더하라.
 네가 만든 '평균 놀람 공식'을 적어라.

[정답 도구] — 섀넌 엔트로피 H = −Σ p log₂ p
 한 결과의 '놀람(정보량)' = −log₂ p (밑 2 → 단위는 비트 bit).
   p=1/2 → −log₂(1/2) = 1비트.  p=1/8 → −log₂(1/8) = 3비트(드물수록 큰 놀람).
 평균 놀람 = 각 놀람을 그 확률로 가중하여 전부 더함:
     H = − Σ pᵢ log₂ pᵢ   (Σ는 모든 결과 i에 대해 더하라)
 왜 로그인가: 독립 두 사건 확률 p·q → 놀람 −log(pq) = −log p − log q. 곱이 합으로 펴진다!
   그래서 정보가 '더해진다'. Tier2의 로그(곱→합 접기)가 여기서 정확히 다시 쓰인다.
 ASCII (동전 H를 앞면 확률 p에 따라 그림):
   H(비트)
   1.0 |            _.-‾‾‾-._
       |        .-‾           ‾-.
   0.5 |     .-‾                 ‾-.
       |   .‾                       ‾.
   0.0 |_.‾___________________________‾._____  p(앞면)
       0      0.25     0.5     0.75     1.0
            └ 공평(p=0.5) 에서 최대 H=1비트 ┘
   검산: p=0.5 → H = −(0.5·log₂0.5 + 0.5·log₂0.5) = −(0.5·(−1)+0.5·(−1)) = 1.0 비트 ✓
        p=1.0 → H = −(1·log₂1) = −(1·0) = 0 비트 (확실한 동전 = 놀람 0) ✓
        p=0.99→ H ≈ −(0.99·(−0.0145)+0.01·(−6.64)) ≈ 0.0144+0.0664 ≈ 0.081 비트 (찌그러진 동전 ≪ 1) ✓

[검문소로 채점]
 ① 환원: 공평 동전 H=1, 확실한 동전 H=0, 찌그러진 동전 H<1. 위 검산으로 직접 확인.
 ② 정의: 모든 확률 분포 {pᵢ}에 모호함 0으로 적히나? (p=0 항은 0·log0 = 0으로 약속.)
 ③ 무모순: 독립 두 사건을 합치면 H가 더해지나? (동전 둘 → H=2비트?) 1+1=2 ✓.
   균등 분포일수록 H가 커지고, 한쪽으로 치우칠수록 작아지나? ✓.
 ④ 표적: '놀람의 평균 크기'를 하나의 수로 뽑아 벽을 메웠나? 경우의 수가 못 잡던 '치우침'을 잡나?
 ⑤ 정직: 새 진리가 아니라, '평균 놀람 = 평균 필요 비트 수'라는 본질을 −Σp log p 로 박제했다.
   왜 하필 이 식인가? — 곱을 합으로 펴는(독립이면 더해지는) 성질을 강요하면 로그 말고는 없다.

[이 과제가 가르치는 발명 동작]
 "곱으로 얽힌 양을 로그로 펴서 더하면, 측정 불가능했던 '평균'이 하나의 수로 접힌다."
 → 난제 #23(양자 정보·얽힘 엔트로피 entanglement entropy: 폰 노이만 엔트로피 −Tr ρ log ρ)와
   난제 #14(통계역학·블랙홀 엔트로피)에서 휘둘러야 할 칼.
   거기선 확률 pᵢ가 양자 상태의 밀도행렬(density matrix) ρ의 고윳값으로 진화한다.
 [경고] 엔트로피 H는 '완전한' 지문이 아니다. 전혀 다른 두 확률 분포가 같은 H를 가질 수 있다
   (예: {0.5, 0.5}와 다른 배열의 {0.5, 0.5}는 모양이 달라도 H는 같다; 더 일반으로
   같은 H를 주는 서로 다른 분포가 무수히 많다).
   양자로 가면 더 깊다 — 같은 엔트로피인데 얽힘 구조가 다른 상태가 존재한다.
   여기서부터 — 엔트로피 하나로 양자 얽힘을 완전히 분류할 수 있는가 — 는 인류가 모른다.
   이 '불완전함'이 양자 정보(난제 #23)의 얽힘 분류를 아직 열린 자리로 남겼다.

◆ 도장 과제 [T3-4] — "'이 방법으론 절대 안 된다'를 증명하는 도구를 발명하라"   난이도: ★★★★
================================================================
[도전]
 어떤 일은 "아직 방법을 못 찾았다"가 아니라 "방법이 영원히 없다"이다.
 √2 를 두 정수의 분수 a/b 로 정확히 적는 일, 또는 15퍼즐에서 딱 두 칸만 뒤바꿔 맞추는 일.
 "아무리 해 봐도 안 되더라"가 아니라, '절대 불가능'을 어떻게 증명하나? 시도는 무한히 많은데?

[막다른 길]
 모든 분수 a/b를 하나씩 제곱해 2와 비교? a/b는 무한히 많아 끝이 없다 — 영원히 못 끝낸다.
 15퍼즐의 모든 손놀림 순서를 다 해 봐? 경우의 수가 천문학적이라 역시 무한 비슷.
 '하나씩 다 해 보기(brute force)'는 무한 앞에서 부서진다.
 → 모든 시도가 공유하는 '절대 안 변하는 양(불변량)'을 찾아,
   목표가 그 불변량을 어겨야만 가능함을 보이면 — 단 한 줄로 무한을 닫을 수 있다.

[발명하라 ✍️]
 지금 책을 덮고 5분 시도하라.
 힌트(√2): "√2 = a/b 가 가능하다"고 일단 믿어 보라(귀류법 reductio: 적이 옳다 치고 모순을 끌어내라).
   a/b를 더 못 줄인 기약분수로 두라. 양변 제곱 → a² = 2b². 그럼 a는 짝수, 그럼 b도 짝수…
   '더 못 줄였다'는 약속과 충돌하지 않나? 그 충돌(모순)이 칼이다.
 힌트(15퍼즐): 타일 배열의 '뒤바뀜 횟수(역위 수 inversion)의 홀짝'에 빈칸 위치를 더한 양을 보라.
   한 번 미는 손놀림이 그 홀짝을 바꾸나, 안 바꾸나? 안 변한다면 그게 불변량이다.
 네가 찾은 '불변량'과 '왜 목표가 그걸 어기는지'를 적어라.

[정답 도구 A] — √2 무리수: 귀류법 + 짝홀 불변량
 "√2 = a/b (기약분수, 더 못 줄임)"라 가정.
   양변 제곱:  2 = a²/b²  →  a² = 2b².
   a²이 짝수 → a 짝수 → a = 2k →  (2k)² = 2b² → 4k² = 2b² → b² = 2k² → b도 짝수.
   그런데 a, b 둘 다 짝수면 2로 더 줄일 수 있다 — '기약(더 못 줄임)' 가정과 모순!
   ∴ √2 = a/b 인 정수 a, b는 없다. √2는 무리수(irrational). 무한 시도를 한 줄로 닫음.
   여기서 '불변량'은 a/b의 기약성 — 어떤 분수든 더 줄이면 둘이 같이 짝수일 수 없다는 짝홀 구조.
 ASCII (귀류법의 덫):
     가정: √2 = a/b (기약) ─────────┐
            │ 제곱                  │
            ▼                       │ 모순!
        a² = 2b²                    │ (a,b 둘 다 짝수 →
            │ a 짝 → b 짝            │  기약이 아니었다)
            ▼                       │
       a=2k, b=2m ───[2로 약분 가능]─┘
            → 가정 자체가 거짓. ∴ √2 ≠ 어떤 a/b

[정답 도구 B] — 15퍼즐 패리티(홀짝 불변량)
 15퍼즐: 4×4판, 1~15 타일 + 빈칸 1개. 타일을 밀어 순서를 맞춘다.
   불변량 = (역위 수 inversion 개수의 홀짝) + (빈칸이 아래에서 몇 번째 줄인지의 홀짝), 합쳐서 패리티.
   타일 하나 미는 손놀림 한 번:
     · 좌우로 밀면 → 역위 수 그대로(빈칸과 자리만 교환, 순서 안 바뀜).
     · 위아래로 밀면 → 역위 수가 홀수 개(3개) 바뀌고 빈칸 줄도 1 바뀜 → 합쳐진 패리티는 그대로.
   ∴ 어떤 손놀림에도 패리티(홀짝)는 불변. 풀린 상태의 패리티는 '짝'.
   그런데 두 타일만 딱 맞바꾼 상태는 역위 수가 1(홀) → 패리티 '홀'.
   짝 ≠ 홀 → 어떤 손놀림 순서로도 '두 칸만 바뀐 판'은 절대 못 맞춘다. 증명 끝.
 ASCII:
     [ 1][ 2][ 3][ 4]          [ 1][ 2][ 3][ 4]
     [ 5][ 6][ 7][ 8]          [ 5][ 6][ 7][ 8]
     [ 9][10][11][12]          [ 9][10][11][12]
     [13][14][15][  ]  패리티짝  [13][15][14][  ]  ← 14·15만 바뀜 = 역위 1(홀)

[검문소로 채점]
 ① 환원: √2 — a=2,b=1 로 시작해도 결국 둘 다 짝수로 몰림을 직접 확인. 15퍼즐 — 14·15 스왑이 정말 패리티 홀인지 역위 세 본다.
 ② 정의: '기약분수' '역위 수' '패리티'가 모호함 0으로 정의됐나?
 ③ 무모순: 손놀림 어느 것도(좌우·상하) 패리티를 안 바꾸나? √2 논증에 숨은 가정 오류 없나?
 ④ 표적: '절대 불가능'이라는 벽을 — 무한 시도를 다 안 해 보고 — 한 줄로 닫았나?
 ⑤ 정직: 불가능성은 '발견'이 아니라, 모든 시도가 공유하는 불변량을 찾아 목표가 그걸 어김을 보인 것.

[이 과제가 가르치는 발명 동작]
 "모든 시도가 보존하는 불변량을 찾고, 목표가 그걸 어김을 보이면 — '절대 안 됨'이 증명된다."
 → 난제 #2(P 대 NP: 어떤 문제는 빠른 풀이가 '존재할 수 없는가'를 증명해야 한다)에서
   휘둘러야 할 바로 그 칼. 거기선 불변량이 '회로 복잡도의 하한(lower bound)'으로 진화한다.
   "빠른 알고리즘은 절대 없다"를 증명하려면, 모든 알고리즘이 어길 수 없는 양을 찾아야 한다.
 [경고이자 정직] 불가능성 증명은 '불변량을 찾았을 때만' 작동한다. 불변량을 못 찾으면 무력하다.
   √2·15퍼즐은 딱 맞는 불변량(짝홀)이 있어서 풀렸다.
   하지만 난제 #2(P vs NP)에서는 — "빠른 풀이는 절대 없다"를 증명할 그 불변량을 —
   인류가 아직 못 찾았다. 여기서부터 인류가 모른다.
   같은 복잡도 값을 주는 서로 다른 문제 구조 때문에, 알려진 모든 불변량(증명 기법)이
   장벽(자연화 natural proofs 장벽 등)에 막혀 있다. 이 '불변량의 부재'가 #2를 미해결로 남긴 자리다.
