# ASCENT-ATLAS 〈기초 다지기〉 완료 — 중2 절대 기준의 출발선

이 책의 무조건적 대상은 **중학교 2학년**이다. 기존 사슬은 F00(논리·집합)부터 시작해 그 앞의 기초가 비어 있었다. 그 빈틈을 메우는 〈기초 다지기〉 4부를 README(01)와 F00(02) 사이에 새로 깔았다.

## 추가된 4부 (읽는 순서: 01a → 01b → 01c → 01d → 02 F00)
- **01a 수와 연산** — 수직선·정수(음수)·분수·소수·약수배수·소인수분해·GCD/LCM·거듭제곱·절댓값·연산순서. (예제 30 + 문제 108)
- **01b 문자와 식** — 변수의 뜻·대입·동류항·전개·곱셈공식·인수분해·지수법칙·비와 비율·백분율·비례식. (예제 30 + 문제 100)
- **01c 방정식과 함수** — 방정식·일차방정식·연립·부등식·좌표평면·정비례반비례·일차함수·함수의 뜻·교점·활용. (예제 31 + 문제 104)
- **01d 도형과 측정·기초 통계** — 각·삼각형·둘레넓이·피타고라스·닮음·겉넓이부피·단위차원·평균·경우의 수·확률. (예제 30 + 문제 100)

## 수치
- 새 파일 4개(01a~01d), 약 2,014줄
- 소주제 40개, 예제 약 121개, 연습문제 약 412개 — 전부 검산(오류 0)
- 모든 소주제: 〈왜 배우나〉〈개념+ASCII〉〈예제〉〈연습문제(기초·기본·유형)〉〈해설(흔한 실수 포함)〉〈정답〉〈위로 잇기〉
- README에 "★중2라면 여기서 시작하라★" 안내 추가
- 합본 갱신: 약 41,113줄

## 원칙 준수
- 절대 대상 중2: 모르는 용어 즉시 풀이, ASCII 그림, 앞 개념만으로 설명(앞서가지 않음).
- 기초부터 쌓아올림 → 각 소주제 〈위로 잇기〉가 F카드·지구로 연결(예: 음수·수직선 → F01·F02, 피타고라스 → F09, 함수 → F04).
- 문제 많음, 모든 문제·정답 다시 풀어 검산. 금지어 0, 이모지 0.

이제 중2가 `01a`부터 펴면 — 수직선과 분수에서 출발해, 본 사슬(F00~)과 무기고, 블랙라벨 문제, 30난제 발명 아레나까지 한 줄로 이어진다.
