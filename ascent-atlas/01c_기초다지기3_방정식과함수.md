■ 등식과 방정식의 뜻
 〈왜 배우나〉 "어떤 수에 3을 더했더니 10이 됐다. 그 수는?" 같은 문제를 식으로 적고 답을 찾으려면 등식과 방정식이 필요하다. 모르는 값을 글자로 두고 찾아내는 첫걸음이다.

 〈개념〉 두 식을 등호(=)로 이은 것을 등식이라 한다. 등호 왼쪽을 좌변, 오른쪽을 우변, 둘을 합쳐 양변이라 부른다.
   좌변 = 우변
   (왼쪽)  (오른쪽)
   예: 3 + 4 = 7  → 좌변 3+4, 우변 7. (양쪽 값이 같다.)

   양팔저울을 떠올리자. 등호는 "양쪽 무게가 같다"는 뜻이다.
     좌변 │ 우변
      ●●● │ ●●●     ← 같으면 수평(평형). 이게 등식.
     ─────┴─────
        △ (받침)

   등식 중에서, 아직 모르는 수(미지수)가 들어 있고, 그 미지수에 어떤 값을 넣었을 때만 참(맞는 말)이 되는 등식을 방정식이라 한다.
   - 미지수: 값을 모르는 글자. 보통 x로 쓴다.
   - 예: x + 3 = 10. x가 7일 때만 좌변=우변(10=10)이 된다. 그래서 이건 방정식이고, x=7을 이 방정식의 해(또는 근)라 한다.
   - 해(근): 방정식을 참으로 만드는 미지수의 값.

   비교: 항상 참인 등식도 있다. x + x = 2x 는 x에 무엇을 넣어도 참이다(이런 건 항등식이라 하는데, 지금은 "항상 맞는 등식"으로만 알아두면 된다). 방정식은 "특정 값일 때만" 참이라는 점이 다르다.

   ◇ 좌변에서 우변으로 가는 게 아니라, "양쪽이 같다"가 핵심이다.

 〈예제〉
  예제1. x + 3 = 10 에서 좌변과 우변을 말하고, x=7이 해인지 확인하라.
   풀이: 좌변은 x+3, 우변은 10. (등호 기준 왼쪽·오른쪽이니까.)
   x=7을 좌변에 넣으면 7+3=10. 우변도 10. 좌변=우변이므로 x=7은 해가 맞다.
  예제2. 2x = 6 에서 x=3이 해인지, x=2가 해인지 확인하라.
   풀이: x=3 넣기 → 2×3=6, 우변 6. 같다 → 해 맞음. (참이 되니까.)
   x=2 넣기 → 2×2=4, 우변 6. 4≠6 → 해 아님. (참이 안 되니까.)
  예제3. 다음 중 방정식인 것을 고르라. (가) 5+2=7  (나) x−1=4  (다) 3x
   풀이: (가)는 등식이지만 미지수가 없다 → 그냥 등식(참인 등식). (나)는 미지수 x가 있고 등호가 있다 → 방정식. (다)는 등호가 없다 → 등식조차 아니다(식일 뿐). 답: (나).

 〈연습문제〉
  기초 1. x+5=9 의 좌변과 우변을 각각 말하라.
       2. x−2=3 에서 x=5가 해인지 확인하라.
       3. 4x=12 에서 x=3이 해인지 확인하라.
       4. x+1=8 에서 x=6이 해인지 확인하라.
       5. 다음 중 등식인 것을 모두 고르라. (가) 2+3=5  (나) 7−1  (다) x=4
  기본 6. 다음 중 방정식인 것을 고르라. (가) 6=6  (나) x+2=9  (다) 5x−1
       7. x+4=10 의 해를 1부터 차례로 넣어 찾아라.
       8. 2x−1=5 에서 x=2, x=3 중 해를 골라라.
  유형 9. "어떤 수 x에 4를 더하면 11이다"를 방정식으로 쓰고, x=7이 해인지 보여라.
       10. "어떤 수 x의 2배에서 3을 빼면 7이다"를 방정식으로 써라(풀지는 않는다).

 〈해설〉
  1. 등호 왼쪽이 좌변(x+5), 오른쪽이 우변(9).
  2. x=5 → 5−2=3, 우변 3. 같으니 해 맞음. 흔한 실수: 한쪽만 계산하고 비교를 안 함.
  3. x=3 → 4×3=12, 우변 12. 같으니 해 맞음.
  4. x=6 → 6+1=7, 우변 8. 7≠8 → 해 아님.
  5. 등식은 등호(=)가 있는 것. (가) 있음, (나) 없음, (다) 있음 → (가),(다).
  6. 미지수+등호 둘 다 있어야 방정식. (가)는 미지수 없음, (다)는 등호 없음 → (나).
  7. x=1→5, x=2→6, ... x=6→10. 우변 10과 같아지는 건 x=6.
  8. x=2 → 2×2−1=3(≠5). x=3 → 2×3−1=5(=5). 해는 x=3.
  9. 방정식: x+4=11. x=7 넣기 → 7+4=11, 우변 11. 같으니 해 맞음.
  10. 2배는 2x, 거기서 3을 빼면 2x−3. 그게 7과 같으니 2x−3=7.

 〈정답〉 1)좌변 x+5, 우변 9  2)해 맞음  3)해 맞음  4)해 아님  5)(가),(다)  6)(나)  7)x=6  8)x=3  9)x+4=11, 해 맞음  10)2x−3=7

 〈위로 잇기〉 미지수를 글자로 두고 "참이 되는 값"을 찾는 사고는 F03 '방정식', 나아가 함수와 그래프 전체의 뿌리가 된다.

■ 일차방정식 풀이 (이항, 양변에 같은 연산)
 〈왜 배우나〉 앞에서는 값을 하나씩 넣어 해를 찾았다. 그러나 큰 수가 나오면 그 방법은 느리다. 규칙대로 식을 정리해 x를 단번에 구하는 법이 필요하다.

 〈개념〉 x가 1차(x의 거듭제곱이 없고 x만 있는 것)인 방정식을 일차방정식이라 한다. 예: 2x+3=11. 목표는 "x = (어떤 수)" 꼴로 만드는 것.

   핵심 도구는 두 가지다.
   (1) 양변에 같은 연산: 저울의 양쪽에 똑같이 더하거나 빼거나, 똑같이 곱하거나 나누면 평형은 그대로다.
       좌변=우변 이면, 좌변+5=우변+5 도 참, 좌변÷2=우변÷2 도 참(0으로 나누는 것만 빼고).
   (2) 이항: 한 변에 있는 항을 부호를 바꿔 반대 변으로 옮기는 것. 사실 (1)을 줄여 쓴 것이다.
       x+3=10  ──(양변에서 3을 뺀다)──  x=10−3  → +3이 넘어가며 −3이 됨.
       그래서 "넘어가면 부호가 바뀐다"고 외운다. (덧셈↔뺄셈끼리만! 곱셈은 따로.)

   푸는 순서(가장 안전한 길):
     1) 괄호가 있으면 풀고, 분모가 있으면 양변에 같은 수를 곱해 없앤다.
     2) x가 든 항은 좌변으로, 숫자만 있는 항은 우변으로 이항.
     3) 좌변을 ax 꼴로 정리.
     4) 양변을 a로 나눠 x=□ 완성.
     5) 검산: 구한 x를 원래 식에 넣어 좌변=우변인지 확인.

   그림으로 한 번:
     2x + 3 = 11
        │  (양변에서 3 빼기)
     2x     = 8
        │  (양변을 2로 나누기)
      x     = 4

 〈예제〉
  예제1. x + 7 = 12 를 풀어라.
   풀이: +7을 우변으로 이항 → x = 12 − 7 = 5. (양변에서 7을 빼는 것과 같다.) 검산: 5+7=12 참. x=5.
  예제2. 3x − 4 = 11 을 풀어라.
   풀이: −4 이항 → 3x = 11+4 = 15. 양변 ÷3 → x = 5. 검산: 3×5−4=15−4=11 참. x=5.
  예제3. 2(x+1) = x + 5 를 풀어라.
   풀이: 괄호 풀기 → 2x+2 = x+5. x항을 좌변에, 숫자를 우변에 → 2x−x = 5−2 → x = 3. 검산: 좌변 2(3+1)=8, 우변 3+5=8. 같다. x=3.

 〈연습문제〉
  기초 1. x − 5 = 2     2. x + 8 = 3     3. 4x = 20     4. 2x + 1 = 9     5. 3x − 6 = 9
  기본 6. 5x + 2 = 2x + 11    7. 2(x − 3) = 8    8. 7 − x = 4    9. 4x + 5 = 9x − 10
  유형 10. (x/2) + 1 = 4    11. 3(x+2) − x = 12    12. 0.5x + 1 = 3

 〈해설〉
  1. −5 이항 → x = 2+5 = 7. 흔한 실수: 넘길 때 부호 안 바꿈.
  2. +8 이항 → x = 3−8 = −5.
  3. 양변 ÷4 → x = 5.
  4. +1 이항 → 2x = 8 → ÷2 → x = 4.
  5. −6 이항 → 3x = 15 → ÷3 → x = 5.
  6. 2x를 좌변으로, 2를 우변으로 → 5x−2x = 11−2 → 3x = 9 → x = 3.
  7. 괄호 풀기 → 2x−6 = 8 → 2x = 14 → x = 7.
  8. −x 이항하면 다루기 헷갈리니, 7을 우변으로: −x = 4−7 = −3 → 양변 ×(−1) → x = 3.
  9. 4x를 우변에 모으면 부호가 깔끔: 5+10 = 9x−4x → 15 = 5x → x = 3. (또는 4x−9x = −10−5 → −5x=−15 → x=3.)
  10. 분모 2를 없애려 양변 ×2 → x + 2 = 8 → x = 6. 흔한 실수: 1에도 2를 곱하는 걸 빼먹음(양변 전체에 곱한다).
  11. 괄호 풀기 → 3x+6−x = 12 → 2x+6 = 12 → 2x = 6 → x = 3.
  12. 양변 ×2 → x + 2 = 6 → x = 4. (또는 0.5x = 2 → x = 4.)

 〈정답〉 1)x=7  2)x=−5  3)x=5  4)x=4  5)x=5  6)x=3  7)x=7  8)x=3  9)x=3  10)x=6  11)x=3  12)x=4

 〈위로 잇기〉 "양변에 같은 일을 한다"는 원리는 F03 방정식, 부등식, 그리고 모든 식 변형의 기본 법칙으로 자란다.

■ 연립일차방정식 (가감법 · 대입법)
 〈왜 배우나〉 "사과와 배를 합쳐 5개, 값은 1900원" 같은 문제는 모르는 값이 둘(x, y)이다. 식 하나로는 못 정하고, 식 두 개를 한꺼번에 만족시키는 답을 찾아야 한다.

 〈개념〉 미지수가 둘인 일차방정식 두 개를 묶은 것을 연립일차방정식이라 한다. 두 식을 동시에 참으로 만드는 (x, y) 한 쌍이 해다.
   { x + y = 5
   { x − y = 1
   목표: 미지수를 하나 없애 일차방정식으로 만든 뒤, 앞에서 배운 대로 푼다.

   방법 1 ─ 가감법(더하거나 빼서 한 글자 없애기)
     위 두 식을 변끼리 더하면 y가 사라진다(+y와 −y가 상쇄).
        (x+y) + (x−y) = 5 + 1
         2x          = 6   → x = 3.
     x=3을 첫 식에 넣어 → 3+y=5 → y=2.
     ◇ 없애려는 글자의 계수를 양변에 곱해 같게 맞춘 뒤, 부호가 같으면 빼고 다르면 더한다.

   방법 2 ─ 대입법(한 식을 한 글자=… 로 만들어 넣기)
     첫 식에서 x = 5 − y.
     이걸 둘째 식의 x 자리에 대입 → (5−y) − y = 1 → 5 − 2y = 1 → −2y = −4 → y = 2.
     y=2를 x=5−y에 넣어 → x = 3.

   두 방법 모두 답은 (x, y) = (3, 2). 어느 쪽이든 된다. 계수가 ±1로 깔끔하면 대입법, 계수를 맞추기 좋으면 가감법이 편하다.

   그림(가감법의 느낌):
      x + y = 5
    +)x − y = 1
    ───────────
      2x    = 6     ← y가 지워졌다

 〈예제〉
  예제1. { 2x + y = 7 , x − y = 2 } 를 가감법으로 풀어라.
   풀이: y의 계수가 +1, −1로 부호가 다르다 → 두 식을 더하면 y 소거.
     (2x+y)+(x−y)=7+2 → 3x=9 → x=3. (더해서 y 없앰.)
     x=3을 둘째 식에 → 3−y=2 → y=1. 검산: 2×3+1=7 참, 3−1=2 참. (x,y)=(3,1).
  예제2. { y = 2x − 1 , x + y = 5 } 를 대입법으로 풀어라.
   풀이: 첫 식이 이미 y=… 꼴 → 둘째 식 y에 대입.
     x + (2x−1) = 5 → 3x − 1 = 5 → 3x = 6 → x = 2. (한 글자로 줄임.)
     y = 2×2 − 1 = 3. 검산: 2+3=5 참. (x,y)=(2,3).
  예제3. { 3x + 2y = 12 , x + 2y = 8 } 를 가감법으로 풀어라.
   풀이: y의 계수가 둘 다 +2로 같다 → 빼면 y 소거.
     (3x+2y)−(x+2y)=12−8 → 2x=4 → x=2. (같은 부호라 뺌.)
     x=2를 둘째 식에 → 2+2y=8 → 2y=6 → y=3. 검산: 3×2+2×3=6+6=12 참. (x,y)=(2,3).

 〈연습문제〉
  기초 1. { x + y = 6 , x − y = 2 }   2. { x + y = 10 , x − y = 4 }
       3. { y = x + 1 , x + y = 7 }   4. { 2x + y = 8 , y = 2 }
  기본 5. { 3x + y = 10 , x + y = 6 }   6. { 2x + 3y = 13 , 2x + y = 7 }
       7. { x = 2y , x + y = 9 }   8. { 4x − y = 5 , x + y = 5 }
  유형 9. { 2x + 3y = 12 , x − y = 1 }   10. 사과 x개와 배 y개를 합쳐 5개 샀다. 사과는 배보다 1개 많다. x, y를 구하라.

 〈해설〉
  1. 더하면 2x=8 → x=4, y=6−4=2.
  2. 더하면 2x=14 → x=7, y=10−7=3.
  3. 대입: x+(x+1)=7 → 2x=6 → x=3, y=4.
  4. y=2 대입: 2x+2=8 → 2x=6 → x=3.
  5. 빼면(둘째를 첫째에서) 2x=4 → x=2, y=6−2=4.
  6. 빼면 2y=6 → y=3, 2x+3=7 → 2x=4 → x=2.
  7. 대입: 2y+y=9 → 3y=9 → y=3, x=6.
  8. 더하면 5x=10 → x=2, y=5−2=3.
  9. 둘째 식 ×3 → 3x−3y=3, 첫 식과 더하면 5x=15 → x=3, 3−y=1 → y=2.
  10. 식 세우기: x+y=5, x=y+1. 대입 → (y+1)+y=5 → 2y=4 → y=2, x=3. 흔한 실수: "1개 많다"를 y=x+1로 거꾸로 씀.

 〈정답〉 1)(4,2)  2)(7,3)  3)(3,4)  4)x=3  5)(2,4)  6)(2,3)  7)(6,3)  8)(2,3)  9)(3,2)  10)x=3, y=2

 〈위로 잇기〉 미지수 둘을 동시에 다루는 연립은 F03·F04에서 행렬·연립방정식, 그리고 뒤에 나올 '두 직선의 교점'으로 곧장 이어진다.

■ 일차부등식 (부등호, 음수를 곱하면 부등호가 뒤집힘)
 〈왜 배우나〉 "용돈으로 3000원 이하만 쓸 수 있다", "키가 150cm 이상이면 탑승 가능" 처럼 세상엔 "같다"가 아니라 "크다·작다"인 조건이 많다. 그 범위를 식으로 다루는 게 부등식이다.

 〈개념〉 등호(=) 대신 부등호로 두 식을 이은 것을 부등식이라 한다.
   - a < b : a는 b보다 작다(미만).
   - a > b : a는 b보다 크다(초과).
   - a ≤ b : a는 b보다 작거나 같다(이하).
   - a ≥ b : a는 b보다 크거나 같다(이상).

   부등식을 푸는 법은 방정식과 거의 같다. 양변에 같은 수를 더하거나 빼는 것, 양수를 곱하거나 나누는 것은 부등호 방향을 그대로 둔다.
     예: x + 2 < 5 → 양변에서 2 빼기 → x < 3.

   ★단 하나의 함정★ 양변에 음수를 곱하거나 음수로 나누면 부등호 방향이 뒤집힌다.
     수직선으로 보면 당연하다. 3 < 5 인데, 양변에 −1을 곱하면 −3과 −5다.
        ←─ −5 −4 −3 ... 0 ... 3   5 ─→
       −5는 −3보다 왼쪽 → −3 > −5. 부등호가 뒤집혔다!
     그래서 −x < 3 의 해는 양변 ×(−1) → x > −3 (방향 뒤집힘).

   해는 보통 수직선 위에 표시한다.
     x ≥ 2 :   ●━━━→   (2에 채운 점 ●은 '같음 포함', 오른쪽 전부)
             0  2
     x > 2 :   ○━━━→   (○은 '같음 제외', 2 자신은 안 들어감)
             0  2

 〈예제〉
  예제1. x − 3 < 4 를 풀어라.
   풀이: −3 이항 → x < 4+3 = 7. (더하기는 방향 안 바뀜.) 답: x < 7.
  예제2. 2x + 1 ≥ 9 를 풀어라.
   풀이: −1 이항 → 2x ≥ 8 → 양변 ÷2(양수) → x ≥ 4. (양수로 나눠 방향 그대로.) 답: x ≥ 4.
  예제3. −3x > 12 를 풀어라.
   풀이: 양변 ÷(−3) → x < −4. ★음수로 나눴으니 > 가 < 로 뒤집힌다.★ 답: x < −4.
   확인: x=−5 넣어보면 −3×(−5)=15 > 12 참. x=0 넣으면 0 > 12 거짓 → x는 −4보다 작아야 맞다.

 〈연습문제〉
  기초 1. x + 4 < 10   2. x − 2 > 1   3. 3x ≤ 12   4. x/2 ≥ 3   5. 5x < 20
  기본 6. 2x + 3 ≤ 11   7. 4x − 1 > 7   8. 3x + 2 < x + 8
  유형 9. −x > 5   10. −2x + 1 ≥ 7   11. 5 − 2x ≤ 1   12. 한 권 800원짜리 공책을 x권 사고 1000원을 더 써도 5000원 이하. 최대 몇 권?

 〈해설〉
  1. −4 이항 → x < 6.
  2. +2 이항 → x > 3.
  3. ÷3(양수) → x ≤ 4.
  4. ×2(양수) → x ≥ 6.
  5. ÷5(양수) → x < 4.
  6. −3 이항 → 2x ≤ 8 → ÷2 → x ≤ 4.
  7. +1 이항 → 4x > 8 → ÷4 → x > 2.
  8. x를 좌변으로 → 3x−x < 8−2 → 2x < 6 → x < 3.
  9. ×(−1) → x < −5. ★뒤집힘★ 흔한 실수: 방향 안 바꿈.
  10. −1 이항 → −2x ≥ 6 → ÷(−2) → x ≤ −3. ★뒤집힘★
  11. −5 이항 → −2x ≤ −4 → ÷(−2) → x ≥ 2. ★뒤집힘★
  12. 식: 800x + 1000 ≤ 5000 → 800x ≤ 4000 → x ≤ 5. x는 권수라 자연수 → 최대 5권.

 〈정답〉 1)x<6  2)x>3  3)x≤4  4)x≥6  5)x<4  6)x≤4  7)x>2  8)x<3  9)x<−5  10)x≤−3  11)x≥2  12)5권

 〈위로 잇기〉 부등식과 "음수 곱하면 뒤집힘"은 F03 부등식, 영역(부등식의 그래프), 최댓값·최솟값 문제로 자란다.

■ 좌표평면 (순서쌍 (x, y), 사분면)
 〈왜 배우나〉 지도에서 "가로 3칸, 세로 2칸"으로 위치를 콕 집듯이, 수학에서도 두 수로 평면 위 한 점을 정한다. 그래프를 그리려면 이 위치 표시법이 먼저다.

 〈개념〉 수직선 두 개를 직각으로 겹친 것이 좌표평면이다.
   - 가로 수직선: x축(좌우).  - 세로 수직선: y축(위아래).  - 둘이 만나는 점: 원점 O(0, 0).

   평면 위 한 점은 (x좌표, y좌표) 두 수의 짝으로 나타낸다. 이 짝을 순서쌍이라 하고, 순서가 중요하다. (3, 2)와 (2, 3)은 다른 점이다.
   - x좌표: 원점에서 오른쪽(+)·왼쪽(−)으로 몇 칸.
   - y좌표: 원점에서 위(+)·아래(−)로 몇 칸.

   점 A(3, 2)를 찍는 법: 원점에서 오른쪽으로 3칸, 그다음 위로 2칸.

         y
         3│
         2│      ● A(3,2)
         1│
   ───────O──┬──┬──┬──→ x
        −1│  1  2  3
        −2│

   x축과 y축은 평면을 네 구역으로 나눈다. 이를 사분면이라 하고, 오른쪽 위부터 시계 반대 방향으로 1·2·3·4를 매긴다.

              y
        2사분면 │ 1사분면
        (−,+)   │  (+,+)
      ──────────O──────────→ x
        3사분면 │ 4사분면
        (−,−)   │  (+,−)
              ↓

   - 1사분면: x>0, y>0 (오른쪽 위)
   - 2사분면: x<0, y>0 (왼쪽 위)
   - 3사분면: x<0, y<0 (왼쪽 아래)
   - 4사분면: x>0, y<0 (오른쪽 아래)
   ◇ 축 위의 점(예: (3,0), (0,−2))은 어느 사분면에도 속하지 않는다. 경계선이니까.

 〈예제〉
  예제1. 점 B(−2, 3)은 몇 사분면인가?
   풀이: x=−2<0(왼쪽), y=3>0(위) → 왼쪽 위 → 2사분면.
  예제2. 점 C(4, −1)은 몇 사분면인가?
   풀이: x=4>0(오른쪽), y=−1<0(아래) → 오른쪽 아래 → 4사분면.
  예제3. 점 D(0, 5)는 어디에 있나?
   풀이: x좌표가 0이면 좌우로 안 움직인다 → y축 위. 사분면에 속하지 않는다. (y축 위, 원점에서 위로 5칸.)

 〈연습문제〉
  기초 1. 점 (2, 5)는 몇 사분면?   2. 점 (−3, −4)는 몇 사분면?   3. 점 (1, −6)은 몇 사분면?
       4. 점 (−5, 2)는 몇 사분면?   5. 점 (0, 3)은 어느 축 위?
  기본 6. (3, 2)와 (2, 3)은 같은 점인가?   7. 점 (−4, 0)은 어디에 있나?
       8. x>0, y<0 인 점은 몇 사분면?
  유형 9. 점 (a, b)가 2사분면에 있다. a, b의 부호는?
       10. 점 (−2, 5)를 x축에 대해 뒤집으면(위아래 반사) 좌표는? (힌트: y좌표 부호만 바뀐다.)

 〈해설〉
  1. x>0,y>0 → 1사분면.
  2. x<0,y<0 → 3사분면.
  3. x>0,y<0 → 4사분면.
  4. x<0,y>0 → 2사분면.
  5. x좌표 0 → y축 위.
  6. 순서가 다르면 다른 점 → 같지 않다(아니다).
  7. y좌표 0 → x축 위(원점에서 왼쪽으로 4칸).
  8. 오른쪽 아래 → 4사분면.
  9. 2사분면은 왼쪽 위 → a<0, b>0.
  10. x축 반사는 y부호만 뒤집힘 → (−2, −5).

 〈정답〉 1)1사분면  2)3사분면  3)4사분면  4)2사분면  5)y축  6)아니다  7)x축  8)4사분면  9)a<0, b>0  10)(−2, −5)

 〈위로 잇기〉 좌표평면은 모든 그래프의 바탕이다. F02·F08 좌표·도형, 함수 그래프, 벡터(평면 위 화살표)로 자란다.

■ 정비례 (y = ax)와 반비례 (y = a/x)
 〈왜 배우나〉 "1개 500원짜리 사탕 x개의 값 y", "넓이 12를 가로 x로 채울 때 세로 y" 처럼, 한 양이 변하면 다른 양이 따라 변하는 관계가 많다. 그 변하는 방식 두 가지가 정비례와 반비례다.

 〈개념〉
   정비례: y = ax (a는 0이 아닌 정해진 수, 비례상수). x가 2배·3배가 되면 y도 2배·3배가 된다. "같이 커진다"가 핵심.
     예: y = 2x.  x: 1, 2, 3 → y: 2, 4, 6.  (x가 1 늘 때마다 y는 2씩 는다.)
     그래프는 원점을 지나는 직선이다.
            y
          6│        ● (3,6)
          4│     ●
          2│  ●
       ─────O──┬──┬──┬──→ x
              1  2  3
     a>0면 오른쪽 위로 올라가는 직선, a<0면 오른쪽 아래로 내려가는 직선.

   반비례: y = a/x (a는 0이 아닌 수). x가 2배가 되면 y는 절반(1/2배)이 된다. "한쪽이 커지면 다른 쪽이 작아진다."
     예: y = 6/x.  x: 1, 2, 3, 6 → y: 6, 3, 2, 1.  곱 xy는 항상 6으로 일정하다.
     그래프는 원점을 지나지 않고, 두 갈래로 휘는 곡선(쌍곡선)이다.
            y
          6│●(1,6)
          3│  ●(2,3)
          2│    ● (3,2)
          1│         ● (6,1)
       ─────O──┬──┬──┬──┬──┬──┬──→ x
              1  2  3  4  5  6
     ◇ 핵심 구분: 정비례는 y/x가 일정(=a), 반비례는 xy가 일정(=a).

 〈예제〉
  예제1. y가 x에 정비례하고 x=2일 때 y=10이다. 식을 구하고 x=5일 때 y는?
   풀이: 정비례니 y=ax. x=2,y=10 넣어 10=a×2 → a=5. 식 y=5x. x=5 → y=25.
  예제2. y가 x에 반비례하고 x=3일 때 y=4이다. 식을 구하고 x=6일 때 y는?
   풀이: 반비례니 y=a/x. x=3,y=4 → 4=a/3 → a=12. 식 y=12/x. x=6 → y=12/6=2.
  예제3. y=−2x 의 그래프는 원점을 지나며 어느 방향으로 가나?
   풀이: a=−2<0 → 오른쪽 아래로 내려가는 직선. x=1일 때 y=−2, x=2일 때 y=−4.

 〈연습문제〉
  기초 1. y=3x 에서 x=4일 때 y는?   2. y=4x 에서 x=0일 때 y는?
       3. y=12/x 에서 x=4일 때 y는?   4. y=8/x 에서 x=2일 때 y는?
       5. y=5x 의 그래프는 원점을 지나는가?
  기본 6. y가 x에 정비례, x=3일 때 y=12. 식은?   7. y가 x에 반비례, x=2일 때 y=9. 식은?
       8. y=2x 에서 y=10일 때 x는?
  유형 9. y가 x에 반비례하고 x=5일 때 y=6이다. x=10일 때 y는?
       10. 정비례 y=ax 가 점 (2, −6)을 지난다. a는? 그리고 x=−1일 때 y는?

 〈해설〉
  1. y=3×4=12.
  2. y=4×0=0(정비례 그래프는 원점 지나니 당연).
  3. y=12/4=3.
  4. y=8/2=4.
  5. 정비례 그래프는 항상 원점을 지난다 → 지난다(예).
  6. 12=a×3 → a=4 → y=4x.
  7. 9=a/2 → a=18 → y=18/x.
  8. 10=2x → x=5.
  9. a=xy=5×6=30 → y=30/x. x=10 → y=3.
  10. −6=a×2 → a=−3 → y=−3x. x=−1 → y=−3×(−1)=3.

 〈정답〉 1)12  2)0  3)3  4)4  5)지난다  6)y=4x  7)y=18/x  8)x=5  9)3  10)a=−3, y=3

 〈위로 잇기〉 정비례·반비례는 F05 함수의 가장 단순한 두 모델이다. 일차함수·유리함수·비례 관계 전반으로 자란다.

■ 일차함수 y = ax + b (그래프 · 기울기 · y절편)
 〈왜 배우나〉 정비례 y=ax는 항상 원점을 지난다. 그런데 "기본요금 1000원 + 1km당 500원" 같은 건 출발점이 1000원이라 원점을 안 지난다. 이런 "비례에 출발값을 더한" 관계가 일차함수다.

 〈개념〉 y = ax + b 꼴(a≠0)을 일차함수라 한다. a, b는 정해진 수.
   - a: 기울기. x가 1 늘 때 y가 얼마나 변하는가. a>0이면 오른쪽 위로, a<0이면 오른쪽 아래로.
   - b: y절편. 그래프가 y축과 만나는 점의 y좌표(x=0일 때 y값). 출발 높이라고 보면 된다.

   정비례 y=ax 그래프를 위(또는 아래)로 b만큼 통째로 평행이동한 것이 y=ax+b다.

   예: y = 2x + 1.  x=0 → y=1 (y절편 1). x가 1 늘면 y는 2 늚(기울기 2).
     x: 0, 1, 2 → y: 1, 3, 5.
            y
          5│        ●(2,5)
          3│     ●(1,3)
          1│  ●(0,1)   ← y절편
       ─────O──┬──┬──→ x
              1  2
     기울기 읽기: (1,3)에서 (2,5)로 갈 때 오른쪽 1칸당 위로 2칸 → 기울기 2.

   기울기 = (y의 변화량) ÷ (x의 변화량) = (y증가) / (x증가).
     두 점 (1,3),(2,5)이면 (5−3)/(2−1) = 2/1 = 2.

   그래프 빠르게 그리기: 점 두 개만 찍어 직선으로 잇는다. 보통 y절편 (0, b)와, x를 하나 더 넣은 점을 쓴다.

 〈예제〉
  예제1. y = 3x − 2 의 기울기와 y절편을 말하라.
   풀이: ax+b 꼴에서 a=3, b=−2. 기울기 3, y절편 −2. (x=0이면 y=−2니까.)
  예제2. 일차함수 y = −x + 4 의 그래프를 점 두 개로 나타내라.
   풀이: x=0 → y=4 → (0,4). x=4 → y=0 → (4,0). 이 두 점을 잇는 직선. (a=−1<0이라 내려가는 직선.)
  예제3. 두 점 (0, 1), (2, 7)을 지나는 일차함수의 기울기는?
   풀이: 기울기=(7−1)/(2−0)=6/2=3. y절편은 (0,1)에서 1. 식은 y=3x+1.
   확인: x=2 → 3×2+1=7 참.

 〈연습문제〉
  기초 1. y=4x+3 의 기울기는?   2. y=4x+3 의 y절편은?   3. y=−2x+5 의 기울기는?
       4. y=x−7 의 y절편은?   5. y=2x+1 에서 x=3일 때 y는?
  기본 6. y=−3x+6 에서 y=0일 때 x는?   7. 두 점 (0,2),(1,5)를 지나는 기울기는?
       8. y=5x−4 의 그래프가 지나는 두 점(x=0, x=1)을 구하라.
  유형 9. 기울기 2, y절편 −3인 일차함수의 식은?
       10. 두 점 (1,4),(3,10)을 지나는 일차함수의 식을 구하라.

 〈해설〉
  1. a=4 → 기울기 4.
  2. b=3 → y절편 3.
  3. a=−2 → 기울기 −2.
  4. y=x−7은 y=x+(−7) → b=−7 → y절편 −7.
  5. y=2×3+1=7.
  6. 0=−3x+6 → 3x=6 → x=2.
  7. (5−2)/(1−0)=3/1=3.
  8. x=0 → y=−4 → (0,−4). x=1 → y=1 → (1,1).
  9. y=ax+b에 a=2,b=−3 → y=2x−3.
  10. 기울기=(10−4)/(3−1)=6/2=3. y=3x+b에 (1,4) 넣어 4=3×1+b → b=1 → y=3x+1. 확인: x=3 → 3×3+1=10 참.

 〈정답〉 1)4  2)3  3)−2  4)−7  5)7  6)x=2  7)3  8)(0,−4),(1,1)  9)y=2x−3  10)y=3x+1

 〈위로 잇기〉 일차함수와 기울기·절편은 F05 함수, 미분(기울기의 일반화), 직선의 방정식으로 자란다.

■ 함수의 뜻 (입력 → 출력, 하나의 x에 하나의 y)
 〈왜 배우나〉 자판기에 동전을 넣고 버튼을 누르면 정해진 음료 하나가 나온다. 앞에서 본 정비례·일차함수도 "x를 넣으면 y가 하나 정해지는" 관계였다. 이 관계 전체를 부르는 이름이 함수다.

 〈개념〉 x의 값이 하나 정해지면 그에 따라 y의 값이 오직 하나로 정해질 때, y를 x의 함수라 한다.
   비유: 함수는 기계다.  x(입력) → [ 함수 기계 ] → y(출력).
   규칙이 y=2x라면, 3을 넣으면 6 하나가 나온다. "3을 넣었더니 6도 되고 7도 된다"면 그건 함수가 아니다.

     x=1 ──▶ [ y = 2x ] ──▶ y=2
     x=2 ──▶ [ y = 2x ] ──▶ y=4
     x=3 ──▶ [ y = 2x ] ──▶ y=6

   ★조건★ "하나의 x → 정확히 하나의 y". (서로 다른 x가 같은 y를 줘도 괜찮다. 막히는 건 '하나의 x가 여러 y'인 경우다.)

   함수 표기: y가 x의 함수일 때 y = f(x)로 쓴다. f(x)는 "x를 넣었을 때 나오는 값"이다.
     f(x)=2x 이면 f(3)=2×3=6, f(0)=0, f(−1)=−2.
   ◇ f(3)은 "x에 3을 넣은 출력값"을 뜻하지, f 곱하기 3이 아니다.

   함수가 아닌 예: "x가 1일 때 y는 2도 되고 3도 된다" → 입력 하나에 출력이 둘 → 함수 아님.

 〈예제〉
  예제1. f(x)=3x+1 일 때 f(2)를 구하라.
   풀이: x 자리에 2를 넣는다 → f(2)=3×2+1=7.
  예제2. f(x)=x²−1 일 때 f(0), f(3)을 구하라. (x²은 x를 두 번 곱한 것: 3²=9)
   풀이: f(0)=0²−1=−1. f(3)=3²−1=9−1=8.
  예제3. 다음 대응이 함수인지 판단하라. "x=1 → y=5, x=2 → y=5, x=3 → y=5"
   풀이: 모든 x에 대해 y가 하나씩 정해진다(셋 다 5라도 하나씩이다). 입력 하나에 출력 하나 → 함수 맞음. (서로 다른 x가 같은 y여도 괜찮다.)

 〈연습문제〉
  기초 1. f(x)=2x 일 때 f(4)는?   2. f(x)=x+5 일 때 f(0)은?
       3. f(x)=4x−1 일 때 f(2)는?   4. f(x)=−x 일 때 f(3)은?
       5. f(x)=10−x 일 때 f(10)은?
  기본 6. f(x)=2x+3 에서 f(x)=11이 되는 x는?
       7. f(x)=x² 일 때 f(−2)는?  (제곱은 부호도 곱해진다: (−2)²=4)
       8. f(x)=3x 에서 f(a)=12이면 a는?
  유형 9. "x=1 → y=2, x=1 → y=3" 이 대응은 함수인가? 이유는?
       10. f(x)=2x−1 일 때 f(1)+f(2)를 구하라.

 〈해설〉
  1. f(4)=2×4=8.
  2. f(0)=0+5=5.
  3. f(2)=4×2−1=7.
  4. f(3)=−3.
  5. f(10)=10−10=0.
  6. 2x+3=11 → 2x=8 → x=4.
  7. f(−2)=(−2)²=(−2)×(−2)=4.
  8. 3a=12 → a=4.
  9. x=1 하나에 y가 2와 3 둘이 대응 → 입력 하나에 출력 둘 → 함수 아님.
  10. f(1)=2×1−1=1, f(2)=2×2−1=3 → 합 1+3=4.

 〈정답〉 1)8  2)5  3)7  4)−3  5)0  6)x=4  7)4  8)a=4  9)함수 아님(한 x에 두 y)  10)4

 〈위로 잇기〉 함수의 정의 '하나의 입력 → 하나의 출력'은 F05 함수, 정의역·치역, 합성·역함수, 그리고 수학 전체의 핵심 언어로 자란다.

■ 두 직선의 교점 (연립과 연결)
 〈왜 배우나〉 두 일차함수 그래프가 한 점에서 만나면, 그 점은 두 식을 동시에 만족한다. 이것은 앞에서 배운 연립방정식의 답과 똑같다. 그래프와 식이 한 줄로 이어지는 멋진 자리다.

 〈개념〉 일차함수 y=ax+b의 그래프는 직선이다. 직선 둘을 한 좌표평면에 그리면 보통 한 점에서 만난다. 그 만나는 점을 교점이라 한다.
   교점은 두 직선 위에 동시에 있으므로, 두 식의 y가 같아지는 (x, y)다. 곧 연립방정식
     { y = (첫째 직선)
     { y = (둘째 직선)
   의 해가 교점의 좌표다.

   예: y=x+1 과 y=−x+5 의 교점.
   두 y가 같으니 x+1 = −x+5 → 2x=4 → x=2. y=2+1=3. 교점 (2, 3).

            y
          5│●           직선 y=−x+5 (내려감)
          4│  ＼
          3│    ✕ (2,3) ← 교점
          2│   ／  ＼
          1│ ／  직선 y=x+1 (올라감)
       ─────O──┬──┬──┬──┬──→ x
              1  2  3  4
   ◇ 한 점에서 만나는 두 직선 → 연립의 해 하나. (기울기가 같고 떨어져 있으면 안 만나고, 완전히 겹치면 해가 무수히 많지만, 지금은 한 점에서 만나는 보통의 경우만 다룬다.)

 〈예제〉
  예제1. y=2x 와 y=x+1 의 교점을 구하라.
   풀이: 2x = x+1 → x=1. y=2×1=2. 교점 (1, 2). 검산: y=1+1=2 같음.
  예제2. y=3x−1 과 y=x+3 의 교점을 구하라.
   풀이: 3x−1 = x+3 → 2x=4 → x=2. y=3×2−1=5. 교점 (2, 5). 검산: y=2+3=5 같음.
  예제3. 연립 { y=x+2 , y=2x } 를 풀고, 이것이 두 직선의 교점임을 말하라.
   풀이: x+2 = 2x → x=2 → y=2×2=4. 해 (2,4). 이 점은 두 직선이 만나는 교점과 같다.

 〈연습문제〉
  기초 1. y=x 와 y=4 의 교점은?   2. y=2x 와 y=6 의 교점은?
       3. y=x+1 과 y=3 의 교점은?   4. y=x 와 y=−x+4 의 교점은?
       5. y=2x 와 y=x+2 의 교점은?
  기본 6. y=3x 와 y=x+4 의 교점은?   7. y=−x+5 와 y=x+1 의 교점은?
       8. y=2x−3 과 y=x 의 교점은?
  유형 9. y=4x−2 와 y=2x+4 의 교점은?
       10. 두 직선 y=x+3, y=−2x+9 가 만나는 점의 좌표를 구하라.

 〈해설〉
  1. x=4(y가 4로 같아지는 x). y=4 → 교점 (4,4).
  2. 2x=6 → x=3, y=6 → (3,6).
  3. x+1=3 → x=2, y=3 → (2,3).
  4. x=−x+4 → 2x=4 → x=2, y=2 → (2,2).
  5. 2x=x+2 → x=2, y=4 → (2,4).
  6. 3x=x+4 → 2x=4 → x=2, y=6 → (2,6).
  7. −x+5=x+1 → 4=2x → x=2, y=3 → (2,3).
  8. 2x−3=x → x=3, y=3 → (3,3).
  9. 4x−2=2x+4 → 2x=6 → x=3, y=4×3−2=10 → (3,10). 검산: 2×3+4=10 같음.
  10. x+3=−2x+9 → 3x=6 → x=2, y=2+3=5 → (2,5). 검산: −2×2+9=5 같음.

 〈정답〉 1)(4,4)  2)(3,6)  3)(2,3)  4)(2,2)  5)(2,4)  6)(2,6)  7)(2,3)  8)(3,3)  9)(3,10)  10)(2,5)

 〈위로 잇기〉 "그래프의 교점 = 연립의 해"는 F03·F05에서 방정식·함수·그래프를 하나로 묶는 핵심 다리다. 부등식의 영역, 선형계획법으로도 자란다.

■ 간단한 활용 문제 (속력·거리·시간, 농도)
 〈왜 배우나〉 식을 푸는 기술은 결국 실제 문제를 풀려고 배운다. 속력과 농도는 중2가 가장 많이 만나는 활용 유형이다. "글을 식으로 옮기는 연습"이 핵심이다.

 〈개념〉
   ◇ 속력·거리·시간 ─ 세 양의 관계는 단 하나의 그림에서 다 나온다.
       거리 = 속력 × 시간
     이걸 돌리면:  속력 = 거리 ÷ 시간,  시간 = 거리 ÷ 속력.
     기억법(삼각형):
            ┌─────┐
            │  거리 │
            ├──┬──┤
            │속력│시간│   ← 거리를 가리면 속력×시간, 속력을 가리면 거리÷시간
            └──┴──┘
     단위를 맞추는 게 제일 중요하다. 시간이 '시(h)'면 속력은 'km/h', 거리는 'km'.

   ◇ 농도(소금물) ─ 소금물 안에 소금이 얼마나 진하게 녹아 있나.
       농도(%) = (소금의 양 ÷ 소금물 전체의 양) × 100
     이걸 돌리면:  소금의 양 = 소금물의 양 × 농도 ÷ 100.
     예: 10% 소금물 200g 속 소금 = 200 × 10 ÷ 100 = 20g.
     ★핵심★ 물을 더 붓거나 졸여도 '소금의 양'은 변하지 않는다. 소금의 양을 기준으로 식을 세운다.

   글을 식으로 옮기는 순서: (1) 구하려는 것을 x로 둔다. (2) 위 공식으로 관계식(방정식)을 세운다. (3) 푼다. (4) 단위·말이 되는지 확인.

 〈예제〉
  예제1. 시속 60km로 2시간 달리면 거리는?
   풀이: 거리=속력×시간=60×2=120km.
  예제2. 240km를 4시간에 갔다. 속력은?
   풀이: 속력=거리÷시간=240÷4=60km/h.
  예제3. 8% 소금물 150g에 든 소금의 양은?
   풀이: 소금=소금물×농도÷100=150×8÷100=12g.
  예제4. 소금 30g을 물에 녹여 소금물 200g을 만들었다. 농도는?
   풀이: 농도=(소금÷소금물)×100=(30÷200)×100=15%.

 〈연습문제〉
  기초 1. 시속 50km로 3시간 가면 거리는?
       2. 100km를 시속 25km로 가면 몇 시간?
       3. 180km를 2시간에 갔다. 속력은?
       4. 10% 소금물 300g 속 소금의 양은?
       5. 소금 20g, 소금물 100g. 농도는?
  기본 6. 시속 4km로 걸어 12km를 가는 데 걸리는 시간은?
       7. 5% 소금물 400g 속 소금의 양은?
       8. 소금 40g을 녹여 소금물 250g을 만들면 농도는?
  유형 9. 집에서 학교까지 시속 5km로 가면 30분 걸린다. 거리는 몇 km인가? (힌트: 30분=0.5시간)
       10. 6% 소금물 200g에 물 100g을 더 부으면 농도는 몇 %가 되나? (힌트: 소금의 양은 그대로)

 〈해설〉
  1. 50×3=150km.
  2. 시간=거리÷속력=100÷25=4시간.
  3. 속력=180÷2=90km/h.
  4. 300×10÷100=30g.
  5. (20÷100)×100=20%.
  6. 시간=거리÷속력=12÷4=3시간.
  7. 400×5÷100=20g.
  8. (40÷250)×100=16%.
  9. 거리=속력×시간=5×0.5=2.5km. 흔한 실수: 30분을 30 그대로 넣음(→시간 단위로 0.5).
  10. 처음 소금=200×6÷100=12g. 물 100g 추가 → 소금물 전체 200+100=300g, 소금은 그대로 12g. 농도=(12÷300)×100=4%.

 〈정답〉 1)150km  2)4시간  3)90km/h  4)30g  5)20%  6)3시간  7)20g  8)16%  9)2.5km  10)4%

 〈위로 잇기〉 글을 식으로 옮기고 단위를 다루는 힘은 F03 방정식 활용, F05 함수 모델링, 그리고 과학·경제의 모든 수량 문제로 자란다.
