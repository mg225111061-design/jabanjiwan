여는 의문 (파일 28에서 받은 다리)
================================================================
파일 28(공학 난제)은 양자 컴퓨터를 만들려다 벽에 부딪혀 이렇게 물으며 넘어왔다:
"양자 상태가 환경 때문에 새는 걸 어떻게 막나?"
이건 공학의 질문처럼 보이지만, 그 뿌리는 양자역학 자체의 가장 깊은 상처다.
양자 상태는 절대 외톨이가 아니다 — 늘 주변 공기·빛·열과 손을 잡고 있고, 그 손이 정보를
바깥으로 줄줄 흘린다. 이 누수의 정확한 메커니즘을 잡는 데서부터 양자 전장(戰場)이 열린다.
그래서 우리는 난제 #23부터 시작한다. 아래 8개를 차례로 정복할 "새 도구"를 벼린다.
우리는 풀지 않는다. 도구를 설계 의뢰한다.

◆ 난제 #23  결맞음 어긋남 (Decoherence)  [축: 양자]
================================================================
1) 현상
   양자 상태는 "동시에 여러 가능성이 겹쳐 있는" 특별한 떨림(결맞음, coherence)을 가진다.
   고양이가 "살아있음+죽어있음"을 동시에 품는 그 겹침. 그런데 이 상태를 진공도 아닌
   보통 공기·빛 속에 두면, 눈 깜짝할 새보다 훨씬 빠르게(때론 10⁻²⁰초) 그 "겹침"이 사라진다.
   분명히 안에 있던 정보가 줄줄 새서, 남은 건 그냥 "살았거나 죽었거나" 둘 중 하나처럼 보인다.
   질문: 이 새는 걸 어떻게 식으로 잡고, 어떻게 막나?

2) 동원 무기 ★A 연결★
   · 지구11(양자정보·계산기하)의 밀도행렬(density matrix, ρ)을 동원한다.
     순수 상태 |ψ⟩ 하나로는 "환경과 섞여 정보를 잃은 상태"를 못 적는다. 그래서 ρ=|ψ⟩⟨ψ|로
     올린다. ρ는 격자판(행렬)이고, 그 대각(diagonal) 성분은 "각 경우의 확률", 비대각
     (off-diagonal) 성분은 "경우와 경우 사이의 겹침(결맞음)"을 적는다. 결맞음 어긋남이란
     바로 이 비대각 성분이 0으로 죽는 사건이다. 지구11의 결맞춤 해제(decoherence) 카드를
     "왜 비대각이 죽나"의 메커니즘까지 끌어온다.
   · 지구04(확률통계정보)의 폰노이만 엔트로피(von Neumann entropy, S)를 동원한다.
     S = −tr(ρ ln ρ). 이건 "상태가 얼마나 섞여(불순해) 있나"를 한 수로 잰다. 순수한 겹침은
     S=0, 완전히 새어버린 잡탕은 S가 최대. 누수의 양을 재는 자(尺)로 쓴다.
   · 시간 변화의 무기로 린드블라드 방정식(Lindblad equation)을 여기서 정식 도입한다(아래 해부).

   ▲ 무기를 쓰기 전에 — 이유: 위 무기들은 "새는 걸 적고 재는" 자다. 막는 자가 아니다.
   먼저 새는 메커니즘을 한 글자씩 해부해야, 어디서 막을지가 보인다.

   [해부 — 밀도행렬과 그 비대각]
   2큐비트가 아닌 1큐비트(가장 작은 양자 동전)를 보자. 상태 |ψ⟩ = a|0⟩ + b|1⟩.
   · |0⟩, |1⟩ : 동전의 앞·뒤(기저 상태, basis state). 세로 막대 |·⟩는 "양자 상태"라는 봉투 표시(켓, ket).
   · a, b : 복소수(complex number) 진폭. |a|²=앞 나올 확률, |b|²=뒤 나올 확률, |a|²+|b|²=1.
   밀도행렬:
        ρ = |ψ⟩⟨ψ| = ⎡ |a|²    a b*  ⎤
                        ⎣ a* b   |b|²  ⎦
   · ⟨ψ| : |ψ⟩의 켤레전치(complex conjugate transpose). 가로로 누운 켓, "브라(bra)". 별표 *는 켤레(허수부호 뒤집기).
   · |a|² , |b|² : 대각 성분 = "앞일 확률, 뒤일 확률". 이건 고전 동전도 갖는 평범한 양.
   · a b* , a* b : 비대각 성분 = "앞과 뒤가 *동시에* 겹쳐 떨고 있다"는 양자 고유의 정보. 결맞음.
   결맞음 어긋남 = 시간이 흐르며 이 비대각 ab*, a*b 가 e^(−t/τ) 꼴로 0을 향해 줄어드는 일.
   · t : 시간.  τ(타우) : 결맞음 수명(decoherence time), "겹침이 1/e≈0.37배로 줄 때까지의 시간".
   · e : 자연상수 2.718…, 여기선 "지수적으로(눈덩이처럼 빠르게) 줄어든다"는 곡선 모양을 만든다.

3) 모든 도구의 파탄 + ASCII
   닫힌 양자계(외톨이)는 슈뢰딩거 방정식 iℏ∂ₜ|ψ⟩ = H|ψ⟩ 로 완벽히 풀린다.
   · i : 허수단위(제곱하면 −1).  ℏ : 디랙 상수(plank/2π), "양자 세계의 알갱이 크기".
   · ∂ₜ : 시간에 대한 편미분(시간이 찰나 흐를 때의 변화율).  H : 해밀토니안(에너지 연산자).
   문제: 현실의 양자계는 절대 외톨이가 아니다. 환경(공기·빛·열)과 손잡으면 슈뢰딩거 방정식이
   "계+환경" 전체에는 성립하지만, 우리가 보는 "계만"으로 좁히면(부분추적 tr_env) 식이 깨진다.
   부분추적을 하는 순간 비대각이 새고, 그건 슈뢰딩거 방정식으로는 적을 수 없다(그건 비대각을
   영원히 보존하니까). 벽이 부서지는 그림:

        [닫힌 계: 비대각 영원히 산다]        [환경에 연결: 비대각 줄줄 샌다]
         ρ = ⎡ ●   ◆ ⎤                       ρ(t) = ⎡ ●     ◆·e^(−t/τ) ⎤
             ⎣ ◆   ● ⎦                              ⎣ ◆·e^(−t/τ)   ●   ⎦
            (◆ = 겹침, 안 죽음)                 t 커질수록 →  ⎡ ●  0 ⎤
                                                              ⎣ 0  ● ⎦   ← 겹침 全死
                                                          (고전 잡탕만 남음)

   슈뢰딩거 방정식: 비대각을 죽이는 항이 아예 없다 → 파탄.
   그럼 누수를 적는 식을 따로 만들어야 한다. 그 식이 린드블라드 방정식이다:
        dρ/dt = −(i/ℏ)[H, ρ]  +  Σₖ ( Lₖ ρ Lₖ†  −  ½{ Lₖ†Lₖ, ρ } )
   · [H, ρ] = Hρ − ρH : 교환자(commutator). 닫힌 계의 평범한 떨림(유니타리 회전)을 만드는 항.
   · Σₖ : k에 대해 합(여러 누수 통로를 다 더함).
   · Lₖ : 도약 연산자(jump/Lindblad operator). "환경으로 정보가 한 번 새는 동작"을 적은 행렬.
   · Lₖ† : Lₖ의 켤레전치(단검 † = dagger).  {A,B}=AB+BA : 반교환자(anticommutator).
   · 가운데 ( … ) 통째 = 흩어짐 항(dissipator). 이게 비대각을 e^(−t/τ)로 죽인다.
   파탄의 핵심: 린드블라드는 "환경이 과거를 *기억 못 한다*(마르코프 근사)"를 가정해야 깔끔하다.
   환경이 방금 받은 정보를 도로 계에 되돌려주는(메모리) 진짜 세상에선 이 식조차 새는 걸 정확히는
   못 적는다(→ 그건 난제 #29로 넘어간다). 또한 린드블라드는 누수를 *적기만* 할 뿐, 어떻게 *막을지*는
   한 글자도 알려주지 않는다.

4) 〈도구 설계 의뢰〉 ★궁극 목적★
   네가 만들 것: 비대각(겹침)이 "어느 방향으로 가장 빨리 새는지"와 "그 누수를 거꾸로 메우려면
   계를 어느 부분공간에 숨겨야 하는지"를 한 번에 뱉는 연산자. 가칭 ⟦누수⟧#23(누수나침반, Leak-Compass).
        입력: 상태 ρ + 환경과의 결합 {Lₖ}
        출력: ⟦누수⟧#23[ρ, {Lₖ}] = ( 가장 빨리 새는 방향 단위벡터 d⃗,  그 누수율 γ_max,  안전 부분공간 𝒟 )

        입력                          ⟦누수⟧#23                          출력
        ρ  ─┐                      ┌──────────┐               d⃗  (새는 방향)
            ├──▶  {Lₖ로 누수      │  누수     │──▶ γ_max (속도)
        Lₖ ─┘     속도 텐서 만듦} │  나침반   │──▶ 𝒟 (γ=0인 숨을 곳)
                                   └──────────┘
        ┌─ 안전 부분공간 𝒟의 그림: 누수율 0인 "조용한 골짜기" ─┐
        │   누수율 γ                                            │
        │   ▲                                                   │
        │   │╲        ╱╲          ╱                            │
        │   │ ╲      ╱  ╲        ╱                             │
        │   │  ╲____╱    ╲______╱   ← 골짜기 바닥(γ=0)         │
        │   │   𝒟₁        𝒟₂        여기에 큐비트를 숨긴다     │
        │   └──────────────────────▶ 상태공간 방향              │
        └──────────────────────────────────────────────────────┘

   5대 검문소:
   ① 환원: 환경 결합이 0이면({Lₖ}=∅) γ_max=0, 𝒟=전체공간으로 환원되나? → 닫힌 계의
      "아무것도 안 샌다"와 일치해야 한다. 이건 통과할 만하다(누수 텐서가 0이 되니).
   ② 정의: γ_max와 d⃗의 계산규칙이 모호함 0인가? → 흩어짐 항을 비대각 성분에 대한
      선형사상(Lindbladian 𝓛)으로 보고, 𝓛의 고유값 중 실수부가 가장 음수인 것의 절댓값을 γ_max,
      그 고유모드를 d⃗로 정의하면 규칙은 명확. (지구01 고유값 무기를 여기 끌어온다.)
   ③ 무모순: ⟦누수⟧#23이 뱉는 𝒟가 정말 "결어긋남 없는 부분공간(decoherence-free subspace)"의
      알려진 조건(모든 Lₖ가 𝒟 위에서 같은 상수배로 작용)과 충돌하지 않는가? → 충돌하면 폐기.
   ④ 표적: 정확히 어느 벽? → "린드블라드가 누수를 적기만 하고 *막을 곳*을 안 알려주는" 벽.
      ⟦누수⟧#23은 막을 곳 𝒟를 직접 출력한다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? 진짜 장벽 한 문장 →
      현실의 {Lₖ}는 시간에 따라 변하고(잡음이 떨림), 𝒟도 따라 흔들려서, "고정된 숨을 곳"이
      애초에 존재하지 않을 수 있기 때문이다(시간의존 𝒟의 추적이 미해결).

   막힘 정직: 검문소 ⑤를 완전히는 못 넘었다. {Lₖ}가 시간에 의존하면 ⟦누수⟧#23의 고유모드 분석이
   매 순간 다시 풀려야 하고, 그 "흔들리는 골짜기"를 큐비트가 따라 들어가는 게 물리적으로
   가능한지는 여기서 인류가 모른다.

   [정직 판정] 이 가칭 도구 ⟦누수⟧#23 은 진짜 부분 도구 — 흩어짐 항을 린드블라디안 𝓛로 보고 그 고유모드로 새는 방향 d⃗·γ_max를 *실제로 계산*하며(검문소② 통과), 결어긋남 없는 부분공간 조건과 무모순이다(검문소③). 다만 {Lₖ}가 시간에 따라 흔들리면 고정된 숨을 곳 𝒟가 존재하지 않을 수 있다(검문소⑤). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 시간의존 누수 골짜기를 따라 큐비트를 숨기는 경로가 물리적으로 가능한지 *판정*하는 규칙)이다.

5) 정직한 최전선 + 새 의문
   현재 최선: 특정 대칭이 있을 때의 결어긋남 없는 부분공간, 동적 결합 해제(dynamical
   decoupling), 양자 오류정정 부호까지는 실제로 작동한다(부분적 방어). 그러나 임의의 환경에서
   "최적의 숨을 곳"을 항상 찾는 일반 알고리즘은 없다.
   여기서부터 인류가 모른다: 시간에 따라 흔들리는 누수 골짜기를 따라 큐비트를 영원히 숨길 수 있나?
   새 의문: "그런데 누수를 막기 전에 — 큐비트 *하나*가 아니라 강하게 서로 미는 전자 *수천 개*가
   동시에 겹쳐 있으면, 그 거대한 겹침 상태 자체를 우리는 적을 수나 있나?" → 난제 #24로.

〈발명 아레나 #23〉  결맞음 어긋남
────────────────────────────────────────────────────────────────
1) 현상(중2 한 줄)
   "동시에 둘 다인" 양자 떨림이 공기·빛에 닿자마자 눈 깜짝할 새보다 빨리 "둘 중 하나"로 식어버린다.

2) 네가 이미 푼 것들 ★책 연결★
   · 지구11 밀도행렬 ρ: 순수 상태로 못 적는 "환경과 섞인 상태"를 격자판으로 올려 적었다.
   · 지구11 결맞춤 해제: 비대각 ab*가 e^(−t/T₂) 꼴로 죽는 메커니즘을 손에 넣었다.
   · 지구04 폰노이만 엔트로피 S=−tr(ρ ln ρ): 누수의 *양*을 한 수로 재는 자를 얻었다.
   · 린드블라드 방정식: 흩어짐 항이 비대각을 죽이는 식을 한 글자씩 풀었다.
   ★발명의 씨앗 = 불편함★: 이 도구들은 "새는 걸 *적고 재기*"까지만 깔끔히 통했다. 그런데
   "어디로 가장 빨리 새나, 어디에 숨으면 안 새나"를 물으면 손이 멈춘다. 적는 자(尺)는 막는
   곳을 가리키지 않는다.

3) 무너지는 정확한 지점+ASCII
   e^(−t/T₂)는 *고정된* 결합 {Lₖ}에서만 한 줄로 떨어진다. {Lₖ}가 시간에 따라 떨면 "조용한
   골짜기 𝒟"가 매 순간 자리를 옮겨, 한 번 계산한 숨을 곳이 다음 순간 사라진다.

        [고정 결합: 골짜기 가만히]        [떨리는 결합: 골짜기가 도망친다]
         γ                               γ
         │╲___╱  ← 𝒟 여기 고정            │╲__╱      t₁: 𝒟 여기
         └────────▶ 방향                  │  ╲__╱    t₂: 𝒟 저기로 이동

   ② 정의 — γ_max=린드블라디안 𝓛의 고유값 실수부 최댓값의 절댓값, d⃗=그 고유모드. (통과, 지구01)
   ③ 무모순 — 𝒟가 결어긋남 없는 부분공간 조건과 충돌하면 폐기. (통과 가능)
   ④ 표적 — "린드블라드가 막을 곳을 안 알려주는" 벽을 정확히 친다. (조준 맞음)

◆ 난제 #24  강상관 전자계 (Strongly Correlated Electrons)  [축: 양자]
================================================================
1) 현상
   금속 한 조각 안엔 전자가 어마어마하게 많다. 전자끼리 약하게만 밀면 "각자 따로" 다루는
   근사가 통한다(보통 반도체). 그런데 어떤 물질(고온 초전도체, 모트 절연체)에선 전자들이
   너무 세게 서로 밀어서, 한 전자의 운명이 옆 전자 전부에 매여 버린다. "따로따로"가 무너진다.
   질문: 강하게 미는 전자 수천 개를 어떻게 한꺼번에 푸나?

2) 동원 무기 ★A 연결★
   · 지구16(텐서네트워크·고차원)의 행렬곱 상태(Matrix Product State, MPS)를 동원한다.
     N개 전자의 양자 상태를 곧이곧대로 적으면 2^N개의 숫자가 필요하다(N=300이면 우주의 원자 수보다
     많다). MPS는 이 거대한 숫자 더미를 "작은 행렬들의 사슬"로 압축한다. 핵심은 얽힘이 *국소적*일 때
     2^N을 N×(작은 수)로 줄이는 것.
   · 지구01(선형대수)의 고유값(eigenvalue) 무기를 동원한다. 바닥상태(ground state, 가장 낮은
     에너지)는 해밀토니안 H의 가장 작은 고유값에 딸린 고유벡터다. MPS로 압축한 채로 그 고유벡터를
     찾는 게 목표(밀도행렬 재규격화군 DMRG가 그 방법).

   [해부 — 허바드 모형, 강상관의 최소 무대]
        H = −t Σ⟨i,j⟩,σ ( c†_{iσ} c_{jσ} + c†_{jσ} c_{iσ} )  +  U Σᵢ n_{i↑} n_{i↓}
   · t : 도약 세기(hopping). 전자가 옆 자리로 깡총 뛰는 쉬움 정도. (난제 #23의 τ와 무관, 여기선 hopping.)
   · ⟨i,j⟩ : 이웃한 두 자리 i, j의 쌍.  σ(시그마) : 스핀(↑ 또는 ↓). (여기 σ는 표준편차도 응력도 아님, 스핀.)
   · c†_{iσ} : 생성 연산자(자리 i에 스핀 σ 전자 하나 놓기). c_{jσ} : 소멸 연산자(자리 j에서 하나 빼기).
   · 단검 † : 켤레전치. c†와 c는 짝(놓기/빼기).
   · 첫 항 −t(…) : "전자가 옆으로 뛰어다니며 퍼지려는" 운동에너지. 이것만이면 약상관, 쉽게 풀림.
   · U : 같은 자리 반발(on-site Coulomb). 한 자리에 ↑와 ↓ 두 전자가 같이 있으면 무는 벌점.
   · n_{i↑} = c†_{i↑}c_{i↑} : 자리 i의 ↑ 전자 수(0 또는 1).  n_{i↑}n_{i↓} : 그 자리에 둘 다 있을 때만 1.
   · 둘째 항 U(…) : "같은 자리에 겹치면 비싸다"는 상호작용. U가 t보다 훨씬 크면(U≫t) 강상관.
   통째 의미: "전자는 퍼지고 싶지만(t), 겹치면 벌금(U)이라 서로 눈치 본다." U/t가 크면 전자들이
   서로 자리를 양보하며 *집단으로* 정렬한다 — 이게 따로 못 푸는 강상관의 본질.

3) 모든 도구의 파탄 + ASCII
   몬테카를로(Monte Carlo)는 무작위 표본으로 거대한 합을 근사한다. 페르미온(전자)에 쓰면
   경로의 가중치 e^(−S)가 음수나 복소수가 되어 버린다 — 이게 악명 높은 부호 문제(sign problem).
   · S : 작용(action), 경로의 비용.  e^(−S) : 그 경로가 뽑힐 확률 가중치.
   확률이 음수면 "표본 뽑기"의 의미가 박살난다. 양수와 음수가 거의 상쇄되어, 진짜 답이 거대한
   두 수의 미세한 차이로 묻힌다. 표본을 늘려도 오차가 e^(+N)으로 폭발한다.

        [부호 없을 때: 표본이 답으로 수렴]      [부호 문제: 양수·음수 상쇄로 신호 매몰]
         ████████  진짜 신호                      +██████ −██████  → 차이 ▪ (거의 0)
         ──────── 표본 N 늘리면 오차 ↓             표본 N 늘려도 오차 e^(+N) ↑↑↑
                                                   답 = (큰 +) − (큰 −) = 잡음 속 먼지

   MPS/DMRG는 1차원에선 천하무적이지만, 2차원·3차원에선 얽힘이 면적이 아니라 부피로 자라서
   (얽힘 면적 법칙의 위반) 필요한 행렬 크기가 다시 지수로 폭발한다:

        1D 사슬:  ○─○─○─○─○      얽힘 ∝ 경계점 2개 → 작은 행렬로 OK
        2D 격자:  ○─○─○─○
                  │ │ │ │        얽힘 ∝ 경계 길이 → 행렬 크기 ∝ e^(폭) → 파탄
                  ○─○─○─○

4) 〈도구 설계 의뢰〉 ★궁극 목적★
   네가 만들 것: 2D 강상관 바닥상태를 "부호 문제 없이, 부피가 아닌 면적만큼만" 압축하는
   새 표현. 가칭 ⟦가둠⟧#24(매듭압축, Knot-Compress) — 전자의 음수 가중치를 "꼬임 위상수"로 흡수해
   확률을 다시 음 아닌 수로 바꾸는 연산자.
        입력: 허바드 H (U/t, 격자 모양)
        출력: ⟦가둠⟧#24[H] = ( 압축된 바닥상태 |G⟩,  필요 자원 = 면적∝L,  부호=양수 )

        입력                       ⟦가둠⟧#24                         출력
        2D 격자 H ──▶ ┌───────────────────────┐ ──▶ |G⟩ (바닥상태)
                      │ 음수 가중치를 꼬임수 χ │ ──▶ 자원 ∝ L (면적!)
        U/t  ───────▶ │ 로 옮겨 확률을 +로     │ ──▶ 부호 ≥ 0
                      └───────────────────────┘
        ┌─ 핵심 아이디어 ASCII: 음수를 "꼬임"으로 숨긴다 ─┐
        │   −가중치 경로  ⤳⤳⤳  꼬임 χ=1 로 라벨          │
        │   +가중치 경로  ───   꼬임 χ=0 으로 라벨         │
        │   ⟹ 합산할 땐 |가중치| 만 쓰고, χ는 위상으로 따로 │
        └────────────────────────────────────────────────┘

   5대 검문소:
   ① 환원: U=0(상호작용 끔)이면 ⟦가둠⟧#24가 자유 페르미온의 정확해(슬레이터 행렬식)로 환원되나?
      → 환원돼야 한다. U=0이면 부호 문제도 없으니 χ=0으로 떨어지면 통과.
   ② 정의: "꼬임수 χ"의 계산규칙이 모호함 0인가? → 막힌다(아래 정직 참조).
   ③ 무모순: ⟦가둠⟧#24가 1D로 좁혀지면 MPS의 알려진 정확한 면적 법칙과 일치하나? → 일치해야 한다.
   ④ 표적: 정확히 어느 벽? → "2D 페르미온 부호 문제 + 면적 법칙 위반" 두 벽을 동시에 친다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? →
      부호 문제는 일반적으로 NP-난해(NP-hard)임이 증명되어 있다. 즉 모든 강상관계를 효율적으로
      부호 없이 푸는 ⟦가둠⟧#24은 P=NP가 아닌 한 *존재할 수 없다*. ⟦가둠⟧#24은 잘해야 "어떤 부류"에서만 가능.

   막힘 정직: 검문소 ②와 ⑤에서 막힌다. 음수 가중치를 위상 χ로 깔끔히 분리하는 일반 규칙은
   존재하지 않을 가능성이 크다(부호 문제의 NP-난해성). ⟦가둠⟧#24은 특정 대칭을 가진 격자에서만
   부분적으로 정의될 수 있고, 임의의 U/t·임의의 채움(doping)에서 χ를 어떻게 정의할지는
   여기서부터 인류가 모른다.

   [정직 판정] 이 가칭 도구 ⟦가둠⟧#24 는 재명명에 가까움 — '음수 가중치를 꼬임수 χ로 흡수'는 부호 문제를 다른 말로 옮긴 것이고, χ를 정의하는 규칙이 비어 있다(검문소②·⑤ 막힘). 게다가 부호 문제는 일반적으로 NP-난해라, 모든 강상관계를 푸는 ⟦가둠⟧#24은 P=NP가 아닌 한 *존재할 수 없다*. 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 부호 문제가 다항시간에 풀리는 특정 대칭 격자 부류를 찾아 그 안에서 χ를 실제로 *계산*하는 규칙)이다.

5) 정직한 최전선 + 새 의문
   현재 최선: 절반 채움 등 특수한 경우엔 부호 문제가 사라져 정확히 푼다. 일부 2D는 PEPS
   (투영 얽힘 쌍 상태)로 근사한다. 그러나 일반 도핑된 2D 허바드의 바닥상태는 미해결이고,
   고온 초전도의 메커니즘도 여기에 막혀 있다.
   여기서부터 인류가 모른다: 도핑된 2D 강상관 바닥상태를 효율적으로 적는 표현이 존재하는가.
   새 의문: "수천 전자의 에너지 준위가 빽빽이 모이면 — 그 준위들의 *간격*은 규칙적일까,
   아니면 마치 주사위처럼 랜덤할까? 왜 랜덤을 닮나?" → 난제 #25로.

        1D 사슬:  ○─○─○─○─○   얽힘 ∝ 경계점 2개 → 작은 행렬로 OK
        2D 격자:  ○─○─○─○
                  │ │ │ │      얽힘 ∝ 경계 길이 → 행렬 크기 ∝ e^(폭) → 파탄
                  ○─○─○─○      (여기서 압축이 끝난다)

4) 발명 과녁 (과녁으로만 — 막히는 게 정상)

   음수 가중치를 "꼬임 위상수 χ"로 흡수해 확률을 다시 음 아닌 수로. ★여기서 막히면 그게 정상이다.★

   ② 정의 — "꼬임수 χ"의 계산규칙이 비어 있다. (★막힘★)
   ③ 무모순 — 1D로 좁히면 MPS 면적 법칙과 일치해야. (조건부 통과)
   ④ 표적 — "2D 페르미온 부호 문제 + 면적 법칙 위반" 두 벽을 동시에 친다. (조준 맞음)
   ⑤ 정직 — 부호 문제는 일반적으로 NP-난해. 모든 강상관계를 푸는 ⟦가둠⟧#24은 P=NP가 아닌 한
      *존재할 수 없다*. (★막힘 — 이건 재명명에 가깝다★)

5) 정직한 최전선
   여기서부터 인류가 모른다: 도핑된 2D 강상관 바닥상태를 효율적으로 적는 표현이 존재하는가.
   절반 채움 등 특수한 경우엔 부호 문제가 사라져 정확히 풀고, 일부 2D는 PEPS로 근사한다.
   그러나 일반 도핑된 2D 허바드는 미해결이고, 고온 초전도의 메커니즘도 여기에 막혀 있다.

◆ 난제 #25  양자 카오스 (Quantum Chaos)  [축: 양자]

1) 현상
   복잡한 양자계(무거운 원자핵, 당구대 모양 양자점)의 에너지 준위들을 사다리처럼 줄 세워 보면,
   이웃 준위 사이 간격이 묘하게 "서로 밀어내는" 모양을 띤다. 너무 가까운 간격이 거의 없다.
   놀랍게도 이 간격 분포가, 물리와 아무 상관 없어 보이는 "무작위 행렬(random matrix)"의
   고유값 간격과 똑같다. 질문: 양자 에너지 준위 간격이 왜 랜덤행렬을 닮나?

2) 동원 무기 ★A 연결★
   · 지구01(선형대수)의 고유값(eigenvalue) 무기. 에너지 준위 = 해밀토니안 H의 고유값 Eₙ.
     준위 간격 sₙ = E_{n+1} − Eₙ. 우리가 보는 통계의 주인공이 이 고유값들.
   · 지구08(동역학계·카오스)의 카오스(chaos) 무기. 고전적으로 그 계가 카오스(작은 차이가
     지수로 벌어짐, 리아푸노프 지수 λ>0)일 때만 양자 준위가 랜덤행렬을 닮는다(보흐가스 추측).
   · 지구04(확률통계정보)의 통계 분포·평균·분산. 간격 분포 P(s)를 통계로 다룬다.

   [해부 — 준위 간격 분포와 랜덤행렬]
        P(s) ≈ A·sᵝ·exp(−B·s²)      (윈너 추측, Wigner surmise)
   · s : 이웃 준위 간격(평균이 1이 되게 펴 놓은 값, "unfolded").
   · P(s) : 간격이 s일 확률밀도.  A, B : 정규화 상수(전체 확률 1, 평균 1 맞추는 수).
   · exp(−B·s²) : 간격이 너무 크면 드물다는 꼬리.
   · sᵝ : 핵심! 간격이 0에 가까우면(s→0) P(s)→0. 즉 두 준위가 거의 못 겹친다 = 준위 반발(level repulsion).
   · β(베타) : 대칭에 따라 1, 2, 4. (여기 β는 난제#24의 e^(−S)와 무관, 대칭 지수.)
        β=1 : GOE(직교 앙상블, 시간역전 대칭 있음, 실수 대칭행렬).
        β=2 : GUE(유니타리 앙상블, 시간역전 깨짐, 에르미트 행렬). 자기장 걸린 계.
        β=4 : GSE(심플렉틱 앙상블, 스핀-궤도 + 시간역전).
   · GOE/GUE/GSE의 G : Gaussian(가우시안). 행렬 성분을 정규분포 난수로 채운 무작위 행렬.
   통째 의미: "물리계가 복잡해(카오스) 어떤 특별한 보존량도 안 남으면, 그 에너지 준위는
   *무작위로 채운 행렬의 고유값처럼* 서로 밀어내며 퍼진다." 물리 세부가 아니라 *대칭(β)*만이
   분포 모양을 정한다 — 이게 보편성(universality).

3) 모든 도구의 파탄 + ASCII
   섭동론(perturbation theory)은 "약한 변화"를 차수별로 더해 풀지만, 카오스계에선 준위가
   가까워질 때마다 분모에 (Eₙ−Eₘ)이 들어가 0으로 폭발한다(작은 분모 문제, small denominators).
        보정 ∝ |⟨m|V|n⟩|² / (Eₙ − Eₘ)   ← 두 준위 가까우면 분모→0, 보정→∞
   · V : 섭동(작은 추가 에너지).  ⟨m|V|n⟩ : 준위 m과 n을 잇는 V의 세기.
   준위가 빽빽한 카오스계에선 이 분모가 끝없이 작아져 섭동 급수가 발산한다.

        [규칙적(적분가능)계: 준위 자유로이 겹침]   [카오스계: 준위 서로 밀어냄 + 섭동 발산]
         E ┤ ──                                    E ┤ ──
           ┤ ──  ← 간격 0 흔함(P(0)≠0)               ┤    ── ← 너무 가까운 간격 회피
           ┤ ───                                      ┤ ──     (P(0)=0)
           ┤ ──                                        ┤      ──
              포아송 분포(랜덤·뭉침)                       1/(Eₙ−Eₘ)→∞ 로 섭동 파탄

   그럼 개별 준위를 일일이 푸는 대신, 준위 *전체의 통계*를 직접 다뤄야 한다. 그런데 "왜 통계가
   랜덤행렬과 같은가"를 일반 카오스계에서 처음 원리로부터 증명하는 도구가 없다(보흐가스 추측 미증명).

4) 〈도구 설계 의뢰〉 ★궁극 목적★
   네가 만들 것: 고전계의 카오스 정도(리아푸노프 스펙트럼·주기궤도)를 입력하면 그 양자 준위
   통계가 GOE/GUE/GSE 중 무엇인지, 그리고 보편성에서 *얼마나 벗어나는지*까지 뱉는 다리 연산자.
   가칭 ⟦준위다리⟧#25(혼돈다리, Chaos-Bridge).
        입력: 고전 해밀토니안 H_cl + 그 대칭
        출력: ⟦준위다리⟧#25[H_cl] = ( 앙상블 부류 β,  보편성 이탈도 ε,  이탈을 키우는 보존량 목록 )

        입력                        ⟦준위다리⟧#25                        출력
        H_cl ──▶ ┌──────────────────────────────┐ ──▶ β ∈ {1,2,4}
        대칭 ──▶ │ 주기궤도 합(굿츠빌러 자취공식)│ ──▶ ε (보편성 이탈)
                 │ → 준위 상관함수 → 앙상블 판정 │ ──▶ 숨은 보존량들
                 └──────────────────────────────┘
        ┌─ 출력 ε의 그림: 보편성에서 벗어나는 정도 ─┐
        │  P(s)                                       │
        │   ▲   ╭─╮ ← 순수 GUE(ε=0)                  │
        │   │  ╱   ╲                                  │
        │   │ ╱  ╭╮ ╲  ← 숨은 보존량이 봉우리 둘로    │
        │   │╱  ╱  ╲ ╲    쪼갬(ε>0, 보편성 깨짐)      │
        │   └──────────▶ s                            │
        └─────────────────────────────────────────────┘

   5대 검문소:
   ① 환원: 고전계가 적분가능(보존량 충분히 많음)이면 ⟦준위다리⟧#25이 포아송 분포(반발 없음)를 뱉나?
      → 베리-타보르 추측과 일치해야 한다. 통과 가능성 있음.
   ② 정의: "보편성 이탈도 ε"의 계산규칙이 모호함 0인가? → 준위 간격 분포와 GUE 기준분포 사이의
      거리(예: 콜모고로프 거리)로 정의하면 규칙은 명확.
   ③ 무모순: ⟦준위다리⟧#25이 알려진 굿츠빌러 자취공식(준위 밀도 = 고전 주기궤도들의 합)과 충돌 안 하나?
      → ⟦준위다리⟧#25은 그 공식을 *재료*로 써야 하므로 충돌하면 폐기.
   ④ 표적: 정확히 어느 벽? → "왜 양자 준위 통계가 랜덤행렬과 같은가"의 일반 증명이 없는 벽
      (보흐가스 추측). ⟦준위다리⟧#25은 고전 카오스 → 앙상블 부류의 다리를 명시적으로 놓는다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? →
      주기궤도의 수가 길이에 따라 지수로 폭발해서, 그 합을 통제(수렴)시키는 일이 아직 일반적으론
      안 된다(자취공식의 발산 통제가 미해결).

   막힘 정직: 검문소 ⑤에서 막힌다. 굿츠빌러 합의 발산을 길들이는 일반 방법이 없어, ⟦준위다리⟧#25은 특정
   계(균일 음곡률 면 위의 운동 등)에서만 엄밀히 정의된다. 임의의 카오스계에서 ε를 처음 원리로
   계산하는 건 여기서부터 인류가 모른다.

   [정직 판정] 이 가칭 도구 ⟦준위다리⟧#25 는 진짜 부분 도구 — 굿츠빌러 자취공식을 재료로 준위 통계와 GUE 기준의 거리(콜모고로프 거리)로 이탈도 ε를 명확히 정의하며, 적분가능계에선 포아송으로 환원된다(검문소①·②). 다만 주기궤도 수가 지수로 폭발해 합의 수렴(발산 통제)이 일반적으론 안 된다(검문소⑤). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 임의의 카오스계에서 굿츠빌러 합의 발산을 길들여 ε를 처음 원리로 *계산*하는 규칙)이다.

5) 정직한 최전선 + 새 의문
   현재 최선: 시그마 모형·주기궤도 이론으로 보편성의 강력한 증거가 있고, 일부 계는 엄밀.
   하지만 보흐가스-지아노니-슈미트 추측의 일반 증명은 없다.
   여기서부터 인류가 모른다: 모든 카오스 양자계가 랜덤행렬 통계를 따른다는 것의 일반 증명.
   새 의문: "준위 통계가 보편적이라면 — 입자를 묶는 가장 센 힘(강한 핵력)의 준위·상태는 왜
   *애초에 입자를 영원히 가둬* 절대 혼자 빠져나오지 못하게 하나?" → 난제 #26로.

◆ 난제 #26  QCD 비섭동·색가둠 (Confinement in QCD)  [축: 양자]
================================================================
1) 현상
   양성자·중성자 속엔 쿼크(quark)가 들어 있다. 그런데 쿼크를 하나 떼어내려 아무리 당겨도,
   절대 혼자 빠져나오지 않는다. 당기는 힘이 거리가 멀어져도 *줄지 않고*, 대신 그 에너지로
   새 쿼크 쌍이 펑 튀어나와 다시 묶인다. 자유 쿼크는 자연에 없다(색가둠, confinement).
   질문: 쿼크는 왜 절대 혼자 못 빠져나오나?

2) 동원 무기 ★A 연결★
   · 지구10(수리물리·장론)의 경로적분(path integral)·게이지장(gauge field)을 동원한다.
     양자장의 모든 가능한 역사를 e^(iS/ℏ)로 더하는 경로적분이 출발점. 색가둠은 게이지장이
     쿼크 사이에 만드는 "끈(flux tube)"의 성질이다.
   · 지구02(추상대수)의 군론(group theory). QCD의 게이지 대칭은 SU(3) — 3가지 "색(color)"을
     섞는 회전 군. 이 군이 비가환(non-abelian, 순서가 중요)이라 글루온끼리도 서로 힘을 주고받고,
     그게 가둠의 뿌리다.

   [해부 — 격자 QCD와 윌슨 루프]
   연속 시공간을 작은 격자로 쪼개 경로적분을 유한한 적분으로 만든다(격자 QCD).
        ⟨W(C)⟩ = (1/Z) ∫ 𝒟U  W(C)·e^(−S[U])
   · ⟨·⟩ : 양자 평균(모든 역사에 대한 가중 평균).  Z : 분배함수(전체 가중치 합, 정규화).
   · ∫𝒟U : 모든 게이지장 배열 U에 대한 경로적분.  U : 격자 한 변에 사는 색회전(SU(3) 원소).
   · S[U] : 작용(에너지 비용).  e^(−S) : 그 배열의 가중치(유클리드 시간이라 i 대신 −).
   · W(C) : 윌슨 루프(Wilson loop). 닫힌 고리 C를 따라 색회전 U들을 쭉 곱한 것의 자취(trace).
     "쿼크-반쿼크 쌍을 거리 R만큼 떼었다 시간 T 뒤 도로 붙이는" 가상 실험.
   가둠의 판정식:
        ⟨W(C)⟩ ~ exp(−σ·R·T)      ← 넓이 법칙(area law) = 가둠
   · σ(시그마) : 끈 장력(string tension). 쿼크를 잇는 끈의 단위 길이당 에너지.
     (여기 σ는 표준편차도 파울리도 아님, 끈 장력.)
   · R·T : 윌슨 루프가 감싼 *넓이*.  지수가 넓이에 비례 → 쿼크 떼는 비용 ∝ R(거리) → 무한히 못 뗌.
   대조: 가두지 않는 이론은 둘레 법칙 exp(−c·(R+T))(둘레에 비례) → 멀리 떼는 비용 유한 → 자유 입자.
   통째 의미: 윌슨 루프가 *넓이*만큼 줄면(둘레가 아니라) 쿼크는 영원히 갇힌다.

3) 모든 도구의 파탄 + ASCII
   섭동론은 결합이 약할 때(고에너지, 점근적 자유성)만 통한다. 가둠은 결합이 *센* 저에너지
   현상이라 섭동 급수가 통째로 무의미하다.
        섭동 전개:  결과 = c₁·g² + c₂·g⁴ + c₃·g⁶ + …   ← g가 크면(저에너지) 발산, 무용
   · g : 결합상수(coupling). 저에너지에서 g→큼 → 급수 발산.

            (약한 결합, 섭동 OK)                  └─ flux tube, 장력 σ 일정 ─┘

                                                 q ━━━━━━━━━━━━━━━━ q̄

================================================================
◆ 난제 #27  얽힘의 위상적 분류 (Topological Order & Entanglement)  [축: 양자]
================================================================
1) 현상
   어떤 물질(분수 양자홀, 위상 초전도체)은 겉보기 대칭이 똑같은데도, 양자 상태가 "함부로 못
   풀리는 매듭"처럼 얽혀 있어 서로 다른 종류로 갈린다. 국소적으로 아무리 주물러도 한 종류에서
   다른 종류로 못 바꾼다. 마치 매듭의 종류를 끈을 안 자르고는 못 바꾸듯. 질문: 얽힘에도
   모양(위상)이 있어 분류할 수 있나?

2) 동원 무기 ★A 연결★
   · 지구11(양자정보)의 부분추적(partial trace)·얽힘 엔트로피. 계를 A와 B로 가르고 B를
     추적해 없애면(ρ_A = tr_B ρ), 남은 ρ_A가 얼마나 섞였나로 얽힘을 잰다.
   · 지구12(위상·대수기하첨단)의 베티 수(Betti number)·천 특성류(Chern class). "구멍의 개수"와
     "휘어짐의 총량"을 세는 위상 불변량. 얽힘의 종류를 이 불변량으로 라벨링한다.
   · 지구17(장론·우주론)의 위상적 장론(Topological Quantum Field Theory, TQFT). 위상 질서를
     기술하는 저에너지 유효 이론. 거리·각도가 없고 *연결 방식*만 남은 장론.

   [해부 — 얽힘 엔트로피와 위상 항]
        S(A) = −tr( ρ_A ln ρ_A ) = α·L − γ + …
   · S(A) : 영역 A의 얽힘 엔트로피(A가 나머지와 얼마나 얽혔나).
   · ρ_A = tr_B ρ : A의 환산 밀도행렬(B를 추적해 없앤 것).  tr_B : B에 대한 부분추적.
   · ln : 자연로그.  −tr(ρ_A ln ρ_A) : 폰노이만 엔트로피(난제 #23의 S와 같은 자, 여기선 영역 A에 대해).
   · α·L : 경계 길이 L에 비례하는 평범한 항(면적 법칙). α는 비보편 상수.
   · γ(감마) : 위상 얽힘 엔트로피(topological entanglement entropy). 경계 모양과 무관한 *상수*.
     이게 위상 질서의 지문이다. γ = ln 𝒟, 𝒟는 총 양자 차원(total quantum dimension).
   · 𝒟 : 그 위상상에 사는 "변칙 입자(anyon)"들의 차원 제곱합의 제곱근. 위상의 종류를 정하는 수.
   통째 의미: 얽힘 엔트로피에서 경계에 비례하는 부분을 빼고 *남는 상수 −γ*가, 국소적으로 못
   지우는 "전역 얽힘의 양"이다. γ≠0이면 위상 질서가 있다.
   위상 불변량 무기:
        c₁ = (1/2π) ∫_BZ F        (제1 천 수, first Chern number)
   · c₁ : 정수! 밴드의 "꼬임 총량".  ∫_BZ : 브릴루앙 영역(운동량 공간 전체) 적분.
   · F : 베리 곡률(Berry curvature), 운동량 공간에서 양자 상태가 휘는 정도.
   · 1/2π : 정규화(휘어짐을 정수로 떨어지게 하는 상수).  c₁이 정수라 매끄럽게 못 바꾼다 = 위상 보호.

3) 모든 도구의 파탄 + ASCII
   대칭에 의한 분류(란다우 이론, 질서모수)는 위상 질서 앞에서 통째로 파탄난다. 위상 질서엔
   국소적 질서모수가 *없다* — 어떤 국소량을 봐도 두 위상상이 똑같아 보인다.
        [란다우(대칭깨짐) 그림]              [위상 질서: 국소량으론 구별 불가]
         질서모수 m ≠ 0 ⟹ 상 구별              어느 점을 봐도  ●●●●●  (똑같음)
         ↑↑↑↑↑ (자석)  vs  ↑↓↑↓ (반자석)       그런데 전역 얽힘 패턴이 다름:
         국소적으로 다름 → 쉽게 구별            ╭─╮╭─╮   vs   ╭───╮

◆ 난제 #28  양자-고전 붕괴 경계 (Measurement Problem)  [축: 양자]
================================================================
1) 현상
   양자역학은 측정 전엔 "여러 결과의 겹침"을 키우다가, 측정하는 순간 *딱 하나*로 정해진다.
   슈뢰딩거 방정식엔 이 "하나로 정해짐(붕괴)"이 어디에도 안 적혀 있다 — 방정식은 늘 겹침을
   매끄럽게 키울 뿐이다. 그런데 우리는 한 번도 "살고+죽은" 고양이를 본 적이 없다.
   질문: 양자와 고전의 경계는 정확히 어디서 갈리나? 측정하면 왜 하나가 되나?

2) 동원 무기 ★A 연결★
   · 지구11(양자정보)의 결맞춤 해제(decoherence). 난제 #23의 무기를 다시 끌어온다. 계가 환경과
     얽히면 비대각이 죽어 "겹침이 안 보이는 잡탕"이 된다. 이게 *왜 겹침이 사라져 보이나*는 설명한다.
   · 지구01(선형대수)의 힐베르트 공간(Hilbert space)·정사영(projection). 측정을 사영 연산자
     Pₙ = |n⟩⟨n|로 적는 사영 가설(폰노이만 사영). 측정 = 상태를 한 고유공간으로 사영.

   [해부 — 결맞춤 해제는 "절반의 답"]
        ρ = ⎡ |a|²   ab* ⎤   ──환경 얽힘──▶   ⎡ |a|²   0   ⎤   (대각만 남음)
            ⎣ a*b   |b|² ⎦                     ⎣  0    |b|² ⎦
   · 이 변화는 "겹침(ab*)이 안 보이게 됨"까지만 설명한다. 그러나 남은 대각 ⎡|a|²,|b|²⎤는 여전히
     "확률 |a|²로 0, 확률 |b|²로 1" — 즉 *둘 다 가능성으로 남아 있다*. 실제 한 번의 측정에서
     "하필 0이 나옴" 하나로 *선택*되는 일은 이 식 어디에도 없다.
   · 사영 가설:  |ψ⟩ → Pₙ|ψ⟩ / ‖Pₙ|ψ⟩‖, 확률 ‖Pₙ|ψ⟩‖²(보른 규칙).
   · Pₙ=|n⟩⟨n| : 결과 n으로의 사영(다른 가능성 싹 지움).  ‖·‖ : 노름(벡터 길이).
   · 이건 "하나로 정해짐"을 *손으로 추가한 규칙*이지, 슈뢰딩거 방정식에서 *유도된 게 아니다*.
   통째 의미: 결맞춤 해제는 "왜 겹침이 안 보이나"를 설명하지만 "왜 *이* 결과 하나가 *실제로*
   일어나나(객관적 단일 결과의 출현)"는 설명 못 한다. 이게 측정 문제의 핵.

3) 모든 도구의 파탄 + ASCII
   세 갈래 해석이 다 어딘가에서 파탄난다:
        [코펜하겐]  측정=손으로 붕괴 추가     → "측정"이 뭔지, 경계가 어딘지 정의 안 됨 ✗
        [다세계]    붕괴 없음, 다 일어남       → 단일 결과 출현 안 함, 보른 확률 유도 논쟁 ✗
        [객관붕괴]  방정식에 붕괴 항 추가(GRW) → 새 상수 도입, 에너지 보존 미세 위반 ✗(실험 압박)

        붕괴 경계의 그림: 어디서 "겹침"이 "택일"로 바뀌나?
         원자 ▏겹침──────────────────────────? ──────────────▏ 고양이
              ░░░░░░░░░░░ (양자) ░░░░?░░░ ←경계?→ ▓▓▓ (고전: 택일) ▓▓▓
                          여기 어딘가에서 갈린다는데 — 정확한 선이 없다

   객관붕괴 모형(GRW·CSL)은 슈뢰딩거 방정식에 비선형·확률 항을 더해 큰 물체일수록 빨리 붕괴하게
   만든다:
        d|ψ⟩ = [ −(i/ℏ)H dt  +  (붕괴 항: 위치로 무작위 사영) ] |ψ⟩
   · 붕괴 항은 새 상수 두 개(붕괴율 λ_c, 국소화 길이 r_c)를 손으로 넣는다. (여기 λ_c는
     고유값도 파장도 아님, 붕괴율.) 이 상수들은 이론이 아니라 실험으로만 정해지는데, 아직
     관측 안 됐다(실험이 점점 좁혀 압박 중). 즉 *어느 모형도* 경계를 처음 원리로 안 준다.

4) 〈도구 설계 의뢰〉 ★궁극 목적★
   네가 만들 것: 임의의 물리계에 "이 계는 아직 양자(겹침 유지)인가, 이미 고전(택일)인가, 그
   전이가 어느 척도에서 일어나는가"를 *검증 가능한 예측과 함께* 뱉는 경계 연산자. 가칭
   ⟦붕괴⟧#28(붕괴자, Collapse-Ruler) — 결맞춤 해제율과 (가정한) 객관붕괴율을 한 자에 올려 둘이
   교차하는 척도를 경계로 출력.
        입력: 계의 질량 m, 크기 ℓ, 환경 결합 {Lₖ}
        출력: ⟦붕괴⟧#28[m, ℓ, {Lₖ}] = ( 양자/고전 판정,  전이 척도 ℓ*,  실험으로 가를 예측 )

        입력                          ⟦붕괴⟧#28                        출력
        m, ℓ ──▶ ┌───────────────────────────────┐ ──▶ 양자? 고전?
        {Lₖ} ──▶ │ 결맞춤해제율 Γ_dec(환경) vs    │ ──▶ 전이 척도 ℓ*
                 │ 객관붕괴율 Γ_col(m) 교차점 찾기│ ──▶ 검증 예측(간섭 사라짐)
                 └───────────────────────────────┘
        ┌─ 두 율이 교차하는 곳이 경계 ─┐
        │  율                            │
        │  ▲   Γ_dec╲    ╱Γ_col          │
        │  │        ╲  ╱  ← 교차 = ℓ*    │
        │  │         ╳                   │
        │  │        ╱  ╲                 │
        │  └───────╱────╲──────▶ 척도 ℓ  │
        │      양자│  ℓ* │고전           │
        └────────────────────────────────┘

   5대 검문소:
   ① 환원: 환경 결합 0 + 객관붕괴율 0이면 ⟦붕괴⟧#28이 순수 슈뢰딩거(겹침 영원, 경계 없음)로 환원되나?
      → 환원돼야 한다. 통과 가능.
   ② 정의: "전이 척도 ℓ*"가 모호함 0인가? → 결맞춤 해제율 Γ_dec는 {Lₖ}에서 계산 가능(명확).
      그러나 객관붕괴율 Γ_col은 *아직 검증 안 된 모형 상수*에 의존 → 정의가 모형 선택에 매여 막힌다.
   ③ 무모순: 결맞춤 해제만으로 충분하다는 입장(다세계)과 객관붕괴 입장이 *서로 충돌*한다.
      ⟦붕괴⟧#28이 어느 쪽을 택하든 다른 쪽과 모순. → 이 모순을 실험으로만 가를 수 있다고 정직히 표기.
   ④ 표적: 정확히 어느 벽? → "결맞춤 해제가 단일 결과의 *출현*을 설명 못 하는" 벽.
      ⟦붕괴⟧#28은 그 벽을 "실험으로 검증 가능한 전이 척도"로 바꿔 측정 가능한 질문으로 만든다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? →
      "객관적 단일 결과가 실제로 출현하는가"는 현재 *실험으로 구별 불가능한* 해석 차이라,
      추가 물리(객관붕괴) 없이는 ℓ*가 원리적으로 정의되지 않는다.

   막힘 정직: 검문소 ②③⑤에서 막힌다. ⟦붕괴⟧#28은 "객관붕괴가 실재한다"는 *가정 아래에서만* ℓ*를
   준다. 그 가정이 참인지는 실험으로만 가려지고, 아직 안 갈렸다. 측정 문제의 핵심은 도구의
   문제가 아니라 여기서부터 인류가 모르는 물리의 문제다.

   [정직 판정] 이 가칭 도구 ⟦붕괴⟧#28 은 재명명에 가까움 — '두 율의 교차=경계'에서 결맞춤 해제율 Γ_dec는 계산되지만 객관붕괴율 Γ_col은 아직 검증 안 된 모형 상수에 매여 ℓ*가 가정 위에서만 정의된다(검문소②③⑤ 막힘). 이건 도구의 빈칸이 아니라 물리의 빈칸이다. 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 객관적 단일 결과의 출현 여부를 가르는 새 물리—검증 가능한 붕괴율—을 실험으로 확정하는 것)이다.

5) 정직한 최전선 + 새 의문
   현재 최선: 결맞춤 해제는 정량적으로 완벽히 검증됨(왜 겹침이 안 보이나 설명 끝). 객관붕괴
   모형은 큰 분자 간섭 실험으로 점점 좁혀지지만 아직 발견·배제 안 됨.
   여기서부터 인류가 모른다: 단일 결과가 객관적으로 출현하는지, 양자-고전 경계가 실재하는지.
   새 의문: "결맞춤 해제는 '환경이 과거를 기억 못 한다'고 가정했다. 그런데 진짜 양자 잡음은
   *과거를 기억한다*(되돌아온다). 이 기억하는 잡음을 어떻게 식으로 쓰나?" → 난제 #29로.

================================================================
◆ 난제 #29  비마르코프 양자 동역학 (Non-Markovian Dynamics)  [축: 양자]
================================================================
1) 현상
   난제 #23의 린드블라드 방정식은 "환경이 받은 정보를 곧장 잊는다"(마르코프, Markovian)고
   가정한다. 그러나 진짜 환경(차가운 원자 환경, 구조화된 광자 띠)은 정보를 잠시 품었다가 *도로
   계에 되돌려준다*. 죽었던 결맞음이 *되살아나기도* 한다(정보 역류). 마르코프 식으론 이걸 못
   적는다. 질문: 과거를 기억하는 양자 잡음을 어떻게 식으로 쓰나?

2) 동원 무기 ★A 연결★
   · 지구13(확률과정·거시통계)의 확률과정·상관함수. 환경 잡음을 시간상관 C(t,t′)=⟨B(t)B(t′)⟩를
     가진 확률과정으로 본다. 마르코프는 C가 δ(t−t′)(찰나만 상관)인 특수 경우.
   · 지구11(양자정보)의 밀도행렬 ρ + 린드블라드. 난제 #23의 무기를 비마르코프로 *확장*한다.
     린드블라드의 상수 γ를 시간의존 또는 기억핵으로 바꾸는 게 핵심.

   [해부 — 기억핵을 가진 운동방정식(나카지마-츠완지그)]
        dρ(t)/dt  =  −(i/ℏ)[H, ρ(t)]  +  ∫₀ᵗ K(t−t′) ρ(t′) dt′
   · dρ/dt : 지금 상태의 변화율.  [H,ρ] : 닫힌 떨림 항(난제 #23과 동일).
   · ∫₀ᵗ … dt′ : 0부터 지금 t까지 *과거 전체*에 대한 적분. 마르코프엔 없던 "기억의 누적".
   · K(t−t′) : 기억핵(memory kernel). "t′ 시점의 상태가 지금 t의 변화에 얼마나 영향을 주나"의 무게.
     이게 핵심 발명품. K가 δ(t−t′)에 비례하면(찰나 기억) 린드블라드로 환원된다.
   · ρ(t′) : 과거 t′ 시점의 상태. 지금 변화가 *과거 전체*에 매여 있다 = 비마르코프.
   통째 의미: "지금 상태가 변하는 방식이, 지금만이 아니라 *그동안 겪은 역사 전체*에 달려 있다."
   환경이 기억하는 만큼, K가 길게 끌린다.
   비마르코프성 측도(얼마나 비마르코프인가):
        𝒩 = ∫_{σ>0} σ(t) dt,    σ(t) = d/dt D(ρ₁(t), ρ₂(t))
   · D(ρ₁,ρ₂) : 두 상태를 구별하는 거리(추적 거리, trace distance). 마르코프면 이 거리는 *늘 줄기만* 한다
     (정보가 새기만 함). σ(t)=그 거리의 변화율.
   · 𝒩 : σ>0인 구간(거리가 *되살아나는*, 즉 정보가 *되돌아오는* 구간)만 모은 적분. 𝒩>0이면 비마르코프.
   · (여기 σ는 표준편차도 끈장력도 아님, 추적거리 변화율.)

3) 모든 도구의 파탄 + ASCII
   린드블라드 방정식은 "완전 양성·마르코프 반군(CPTP semigroup)"을 가정해서, 정보가 *오직
   새기만* 하고 절대 안 돌아온다.
        [마르코프(린드블라드): 구별가능성 단조 감소]   [비마르코프: 정보 역류로 되살아남]
         D ┤▔▔▔╲                                       D ┤▔▔╲    ╱▔╲
           ┤    ╲╲                                        ┤   ╲  ╱   ╲╲
           ┤     ╲╲___                                    ┤    ╲╱     ╲╲___
           └──────────▶ t (늘 감소)                       └──────────────▶ t
              σ(t)≤0 항상                                   σ(t)>0 구간 등장 → 𝒩>0

   기억핵 K를 도입하면 식은 맞지만 *계산이 파탄*난다:
   (가) K(t−t′)를 미시 환경에서 정확히 구하는 건 대개 불가능(환경 자유도가 무한).
   (나) K를 근사하면 ρ가 음의 확률(비물리)을 내뱉기 쉽다 — 완전 양성(complete positivity)이 깨진다.
   (다) "얼마나 비마르코프인가"의 측도가 𝒩 말고도 여럿인데(역류·CP-나눔성 등), 서로 일치하지
       않는다 — 비마르코프성의 *유일한 정의 자체가 없다*.

4) 〈도구 설계 의뢰〉 ★궁극 목적★
   네가 만들 것: 미시 환경 상관 C(t,t′)을 입력하면, *완전 양성을 깨지 않으면서* 기억을 적는
   유효 기억핵과 비마르코프 강도를 동시에 뱉는 연산자. 가칭 ⟦기억핵⟧#29(기억핵, Memory-Forge).
        입력: 환경 상관 C(t,t′) (또는 스펙트럼 밀도 J(ω))
        출력: ⟦기억핵⟧#29[C] = ( 유효 기억핵 K_eff,  비마르코프 강도 𝒩,  완전양성 보장 여부 )

        입력                        ⟦기억핵⟧#29                          출력
        C(t,t′) ──▶ ┌────────────────────────────┐ ──▶ K_eff(τ) (기억핵)
                    │ 환경 상관 → 기억핵, 단      │ ──▶ 𝒩 (비마르코프 강도)
        J(ω)  ───▶  │ 완전양성 제약을 강제 사영   │ ──▶ CP보장? (Y/N)
                    └────────────────────────────┘
        ┌─ 핵심: 기억핵의 모양이 곧 기억의 길이 ─┐
        │  K_eff(τ)                              │
        │  ▲                                     │
        │  │█                                    │
        │  │█▆▄▂          마르코프: K≈δ(τ) (뾰족)│
        │  │█  ▔▔▔▔▂▁____ 비마르코프: 길게 끌림  │
        │  └──────────────▶ τ=t−t′ (기억 지연)   │
        └────────────────────────────────────────┘

   5대 검문소:
   ① 환원: 환경 상관이 찰나(C∝δ)면 ⟦기억핵⟧#29이 K_eff∝δ로, 즉 린드블라드(마르코프)로 환원되나?
      → 환원돼야 한다. 𝒩=0으로 떨어지면 통과.
   ② 정의: K_eff와 𝒩의 계산규칙이 모호함 0인가? → K_eff는 나카지마-츠완지그/시간대류 없는
      방정식으로 명확화 가능. 그러나 𝒩의 *정의 선택*(역류 vs CP-나눔성)이 갈려 부분 막힘.
   ③ 무모순: ⟦기억핵⟧#29이 내놓은 ρ(t)가 항상 완전 양성(물리적 상태)인가? → 이게 가장 위험. 근사
      기억핵은 완전 양성을 깨기 쉽다. 강제 사영이 식의 의미를 훼손하지 않는지 검증 필요.
   ④ 표적: 정확히 어느 벽? → "린드블라드가 정보 역류(기억)를 못 적고, 비마르코프성의 정의도
      통일 안 된" 벽. ⟦기억핵⟧#29은 기억핵과 강도를 한 틀에 묶으려 한다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? →
      미시 환경에서 완전 양성을 보장하는 닫힌 기억핵 방정식은 일반적으로 풀 수 없고(환경 자유도
      무한), 비마르코프성의 *서로 다른 측도들이 합의되지 않아* 무엇을 출력해야 정답인지조차 미정.

   막힘 정직: 검문소 ②③⑤에서 막힌다. ⟦기억핵⟧#29은 정확히 풀리는 환경 모형(스핀-보존, 감쇠 진동자)
   에서만 닫힌 K_eff를 준다. 일반 구조화 환경에서 완전 양성을 깨지 않는 기억핵, 그리고
   비마르코프성의 통일된 측도는 여기서부터 인류가 모른다.

   [정직 판정] 이 가칭 도구 ⟦기억핵⟧#29 는 재명명에 가까움 — 기억핵 K_eff는 나카지마-츠완지그로 형식만 적히고, 일반 환경에서 완전 양성을 깨지 않는 닫힌 K_eff가 비어 있으며, 무엇이 정답 출력인지조차 비마르코프성 측도가 통일 안 돼 미정이다(검문소②③⑤ 막힘). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 무한 자유도 환경에서 완전 양성을 보장하며 K_eff를 *계산*하는 닫힌 규칙과, 비마르코프성의 단일 정의)이다.

5) 정직한 최전선 + 색다른 의문
   현재 최선: 정확히 풀리는 모형, 위계 운동방정식(HEOM), 시간대류 없는/있는 마스터 방정식,
   여러 비마르코프성 측도(BLP 역류, RHP CP-나눔성). 그러나 일반론·측도 통일은 미해결.
   여기서부터 인류가 모른다: 임의의 환경에서 완전 양성을 보장하는 일반 기억핵, 그리고
   비마르코프성의 단일 정의.

   전류가 흐른다. 무엇이 이 '속/표면 갈림'을 정하나? 어떤 위상수가?" → 난제 #30으로.

◆ 난제 #30  위상 절연체와 벌크-경계 대응 (Topological Insulators)  [축: 양자]
================================================================
1) 현상
   어떤 물질은 *속(벌크, bulk)은 전기가 안 통하는 절연체*인데, *표면(경계, boundary)에서만*
   전류가 잘 흐른다. 게다가 그 표면 전류는 불순물에도 끊기지 않는다(보호됨). 마치 속의 보이지
   않는 "꼬임"이 표면에 전류를 강제로 만들어 내는 것 같다. 질문: 속은 막혔는데 표면에만 전류가
   흐르는 건 어떤 위상수가 정하나?

2) 동원 무기 ★A 연결★
   · 지구12(위상·대수기하첨단)의 천 특성류(Chern class)·베티 수(Betti number). 밴드 구조의
     "꼬임 총량"을 정수 천 수 C로 센다. 이 정수가 표면 전류 채널의 개수를 *정확히* 정한다.
   · 지구03(기하·시공간)의 위상 절연체·베리 위상(Berry phase). 양자 상태를 운동량 공간에서
     한 바퀴 돌릴 때 따라붙는 기하학적 위상. 그 곡률의 총합이 천 수.

   [해부 — 천 수와 벌크-경계 대응]
        C = (1/2π) ∮_BZ F = (1/2π) ∮_BZ (∂_{k_x} A_y − ∂_{k_y} A_x) d²k
   · C : 천 수(Chern number). *정수*. 밴드의 위상 지문.
   · 1/2π : 정규화(곡률 총합을 정수로 떨어지게).  ∮_BZ : 브릴루앙 영역(닫힌 운동량 공간) 적분.
   · F = ∂_{k_x}A_y − ∂_{k_y}A_x : 베리 곡률(Berry curvature). 운동량 공간에서 상태가 휘는 정도.
   · A = i⟨u_k|∂_k|u_k⟩ : 베리 접속(Berry connection). |u_k⟩는 운동량 k에서의 (주기적) 양자 상태.
   · ∂_{k_x} : 운동량 성분 k_x에 대한 편미분.  d²k : 운동량 공간 면적 요소.
   통째 의미: 운동량 공간 전체에 걸친 상태의 "휘어짐(F)을 다 모으면 *반드시 정수* C가 된다."
   매끄럽게 못 바꾸는 정수라, 작은 교란에 끄떡없다.
   벌크-경계 대응(bulk-boundary correspondence):
        (표면을 가로지르는 보호된 전류 채널 수)  =  ΔC  (양쪽 벌크 천 수의 차)
   · ΔC : 절연체와 진공(또는 다른 위상상)의 천 수 차이. 이 정수만큼 표면에 *끊을 수 없는* 전류
     채널이 강제로 생긴다. 속의 위상수가 표면 물리를 *결정*한다 — 이게 대응의 핵심.

3) 모든 도구의 파탄 + ASCII
   밴드 이론(블로흐 정리)은 "에너지 띠가 차 있나 비었나"로 도체/절연체를 가른다. 그러나 천 수
   C가 다른 두 절연체는 *둘 다 속이 절연체인데도* 종류가 다르다 — 밴드 채움만으론 구별 불가.
        [평범한 밴드 이론]                 [위상으로 갈림: 채움 같아도 C 다름]
         띠 채움 ▓▓▓▓ ⟹ 절연체              속: ▓▓▓▓(C=0)   vs   ▓▓▓▓(C=1)
         띠 비움 ░░░░ ⟹ 도체                 둘 다 절연(채움 동일)인데 표면이 다름!
              채움만 보면 끝                   C=0: 표면 조용  │ C=1: 표면 전류 강제

        벌크-경계 대응의 그림(C가 다르면 경계에 전류):
         ┌──────────────┐
         │ 벌크 C=1     │ ← 속은 절연(전류 0)
         │  ▓▓▓▓▓▓▓▓▓▓  │
         │═════════════→│ ← 표면: 보호된 전류(끊기지 않음), 채널 수 = ΔC = 1
         └──────────────┘
            ▲ 불순물 ✗ 가 있어도 채널이 우회해 끊기지 않음(위상 보호)

   파탄 지점: (가) 상호작용이 강하면(난제 #24의 강상관) 밴드·천 수 정의 자체가 흔들린다 —
   단일 입자 밴드가 없으니 C를 어떻게 정의하나(다체 천 수는 부분적). (나) 무질서·비주기계에선
   브릴루앙 영역 ∮_BZ 적분이 정의 안 된다(주기성 없음). (다) 분류표(주기율표, 10중 대칭류)는
   *비상호작용* 가정에서만 완전하다 — 상호작용이 분류를 무너뜨리거나(붕괴) 새 부류를 만든다.

4) 〈도구 설계 의뢰〉 ★궁극 목적★ (이 파일의 마지막 의뢰)
   네가 만들 것: 상호작용·무질서가 있어 브릴루앙 영역이 없어도 작동하는 *실공간 위상 불변량*,
   그리고 그게 표면 채널 수를 보장하는지까지 뱉는 연산자. 가칭 ⟦실공간천수⟧#30(실공간천수, Real-Chern) —
   운동량 적분 대신 실공간 사영 연산자의 교환자 자취로 천 수를 정의.
        입력: 바닥상태 사영 P (또는 다체 바닥상태 |G⟩)
        출력: ⟦실공간천수⟧#30[P] = ( 실공간 위상수 C_real,  벌크-경계 대응 성립? ,  보호 채널 수 )

        입력                        ⟦실공간천수⟧#30                          출력
        P ──▶ ┌──────────────────────────────────┐ ──▶ C_real (정수?)
              │ C = 2πi·tr( P[ [X,P],[Y,P] ] )    │ ──▶ 벌크-경계 대응 (Y/N)
        |G⟩ ─▶│ (실공간 위치 X,Y의 교환자 자취)  │ ──▶ 보호 채널 수
              └──────────────────────────────────┘
        ┌─ 핵심: 운동량 없이 실공간 좌표 X,Y만으로 ─┐
        │   ∮_BZ F  (운동량, 주기성 필요)            │
        │      ↓ 대체                                │
        │   tr(P[[X,P],[Y,P]])  (실공간, 주기 불필요)│
        │   ⟹ 무질서·비주기에서도 C 정의            │
        └────────────────────────────────────────────┘
   · X, Y : 실공간 위치 연산자.  P : 채워진 상태로의 사영 연산자.  [ , ] : 교환자.
   · tr : 자취(대각합).  2πi : 정규화. 이 조합이 운동량 천 수와 같은 정수를 준다(보트-시 공식).

   5대 검문소:
   ① 환원: 깨끗한 주기계로 좁히면 ⟦실공간천수⟧#30의 C_real이 운동량 천 수 C = (1/2π)∮_BZ F와 정확히 같나?
      → 같아야 한다(보트-시-콜리오 공식이 이를 보장). 통과 가능.
   ② 정의: tr(P[[X,P],[Y,P]])의 계산규칙이 모호함 0인가? → 유한 상관 길이(이동성 간극)일 때
      자취가 수렴해 정수로 떨어지는 게 보장됨(명확). 단 간극이 닫히면 발산(경계 표기).
   ③ 무모순: ⟦실공간천수⟧#30이 깨끗한 계의 알려진 천 수·정수 양자홀 전도도와 충돌 안 하나? → 일치해야 한다.
   ④ 표적: 정확히 어느 벽? → "브릴루앙 영역이 없는(무질서·상호작용) 계에서 천 수를 정의 못
      하고, 강상관에서 분류표가 무너지는" 벽. ⟦실공간천수⟧#30은 실공간으로 그 벽을 우회한다.
   ⑤ 정직: 왜 아직 아무도 못 만들었나? →
      비상호작용 무질서엔 실공간 천 수가 이미 작동하지만, *강상관*에선 단일 사영 P가 없어
      ⟦실공간천수⟧#30을 다체로 올리는 일반화가 미완이다. 상호작용 위상상의 완전 실공간 분류는 미해결.

   막힘 정직: 검문소 ⑤에서 막힌다. ⟦실공간천수⟧#30은 비상호작용 무질서계에선 거의 완성형(이미 작동)이지만,
   강상관 다체계로의 일반화는 부분적이다. 상호작용이 위상 분류를 어떻게 바꾸는지(붕괴·새 부류)
   의 완전한 실공간 사전은 여기서부터 인류가 모른다.

   [정직 판정] 이 가칭 도구 ⟦실공간천수⟧#30 은 진짜 부분 도구 — tr(P[[X,P],[Y,P]])는 운동량 없이 실공간 좌표만으로 천 수를 *실제로 계산*하고(보트-시 공식이 정수성을 보장), 깨끗한 주기계의 천 수와 정확히 일치하며 무질서계에서 작동한다(검문소①②③ 통과). 다만 강상관에선 단일 사영 P가 없어 다체 일반화가 비어 있다(검문소⑤). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 다체 바닥상태에서 실공간 위상수를 정의해 *계산*하고, 상호작용이 분류를 바꾸는 방식을 적는 실공간 사전)이다.

5) 정직한 최전선 + 새 의문
   현재 최선: 비상호작용 위상 절연체·초전도체는 10중 대칭류 주기율표로 완전 분류됐고, 실공간
