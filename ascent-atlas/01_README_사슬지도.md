## 1. 무엇을 만드는가 — 세 권의 책

이 아틀라스는 "어려운 수학·물리를 외우게" 하려는 책이 아니다. 단 하나의 목적이 있다.

> **독자가 인류 미해결 30난제를 정복할 〈새 도구〉를 스스로 발견하게 만든다.**

우리는 증명하지 않는다. 풀지 않는다. **도구를 벼린다.** 대장간에서 칼을 만들 듯, 난제라는 바위를 깰 연장을 독자의 손에 쥐여 준다.

세 권의 책이 있다.

- **문서 A 〈등반 아틀라스〉** (파일 02~24) — 가장 길고 가장 중요하다. 중2 수준의 "0÷0이 왜 안 되지?"에서 시작해, 한 마디도 건너뛰지 않고 최전선까지 **끊김 없는 사슬**로 오른다. 모든 기호(∑, ∂, ⊗, |ψ⟩ …)와 모든 공식을 **한 글자씩** 해부한다. 헷갈릴 곳은 줄이지 않고 더 길게 푼다.
- **문서 B 〈각성서〉** (파일 25) — A를 다 읽은 사람이 C를 "팍" 풀게 만드는 다리. 위대한 도구들(미적분·비유클리드 기하·복소수·집합론·군론)이 어떻게 **태어났는지** 해부해, 도구를 만드는 *방법 자체*를 추출한다. 외치지 않고, 메커니즘만 보여준다.
- **문서 C 〈단련 전장〉** (파일 26~30) — 30개의 난제. 여기는 **푸는 곳이 아니라 도구를 벼리는 곳**이다. 각 난제마다 "기존 도구가 정확히 어디서 부서지는가"를 보이고, "그 자리를 메울 새 연산자를 네가 설계하라"고 의뢰한다.

## 2. 읽는 법

1. **순서대로 읽어라.** 파일 번호가 곧 사슬의 순서다. 02→03(기반 14개)→04~23(무기고 200개)→24(대사전)→25(각성서)→26~29(난제)→30(매트릭스).
   - 여기에 신규 기반 카드 **삼각함수(F04+)**가 더해져, 기반은 사실상 **15개 기반 카드**다(F04 함수와 F05 지수로그 사이에 끼운다).
   - 이 삼각함수(F04+)는 **F02 복소수**(e^(iθ)=cosθ+i·sinθ), **지구06 푸리에**(파동을 sin·cos로 분해), **지구14 구면조화**(공 위의 sin·cos), **지구19 파동**으로 가지를 뻗는다.
2. **각 파일 맨 위 헤더**를 먼저 봐라. `← 직전`은 앞 파일이 남긴 마지막 의문, `→ 다음`은 이 파일이 넘길 의문이다. 이 두 줄이 사슬의 **이음새**다. 어디서 끊겨도 이 줄을 따라가면 다시 이어진다.
3. **모르는 기호가 나오면** 그 자리에서 해부돼 있다. 그래도 막히면 파일 24 〈기호·공식 대사전〉을 펴라.
   - **⋔ 분기 스레드**: 기반 뒷부분(F10 행렬·F11 고유값·F12 확률·F13 미분방정식)부터 사슬이 한 줄에서 여러 줄로 갈라진다. 이 카드들 머리의 `⋔ 분기 스레드:`가 "네 목표(난제)에 맞는 가지"로 가는 유도선이다. 갈림길에서 길을 잃지 않게 도와준다.
4. **R0→R4 표지**를 활용하라. R0(중2의 눈)만 읽어도 직관은 잡힌다. R4(최전선의 칼날)까지 가면 "여기서부터 인류가 모른다"는 절벽 앞에 선다. 그 절벽이 바로 네가 도구를 만들 자리다.

## 3. 발견의 사슬 — 모든 도구는 정확히 이 5마디로 태어난다

이 책의 모든 개념은 예외 없이 다음 다섯 마디를 거친다. 이것이 "도구가 발명되는 보편 문법"이다.

```
① 의문(Question)   중2도 단번에 아는 쉬운 말. "왜 궁금한가 / 뭘 하고 싶은가."
② 벽(Wall)         그 의문 앞에서 기존 도구가 *정확히 어디서* 무너지나(메커니즘). 그림으로.
③ 발명(Invention)  벽을 넘는 새 도구. 기호·규칙·캔버스를 처음부터 정의.
④ 해부(Dissection) R0→R4로 오르며 모든 기호·공식을 한 글자씩. 각 기호 = 무엇·무엇을함·역할·뭘 가능케.
⑤ 새 의문(New Q.)  이 도구가 새로 연 질문 → 다음 마디의 ①로 연결. 닿는 난제 번호 표기.
```

⑤가 다음 마디의 ①이 되기에, **사슬은 파일을 건너뛰어도 끊기지 않는다.** 미분(F06)의 ⑤("변화를 거꾸로 쌓으면?")가 적분(F07)의 ①이 되는 식이다.

## 4. 등반 5단 — 한 마디 안에서 중2부터 최전선까지

```
R0 중2의 눈      직관·그림·비유. ①은 항상 여기서 시작.
R1 고교의 손      기호·정의를 손으로 적는다.
R2 학부의 머리    엄밀한 정의·정리·증명·일반화.
R3 대학원의 시야  "이것은 무엇의 특수경우인가" · 다른 도구와의 연결.
R4 최전선의 칼날  부서지는 지점·열린 질문. ⑤는 항상 여기서.
```
단과 단 사이에는 반드시 `▲ 다음 단으로 — 이유:` 표지가 있어, *왜* 더 깊이 가야 하는지 밝힌다. (기반 파일 02·03은 R5까지 간다.)

## 5. 30난제 의문 지도 — 각 난제를 여는 "쉬운 한 줄 질문"

각 난제는 어려운 이름이 아니라, 중2도 궁금해할 한 줄 질문으로 연다. 이것이 도구를 벼릴 표적이다.

## 6. 사슬 흐름도 — 기반에서 난제까지

```
   F00 논리·집합           "참·거짓·모음을 어떻게 정확히 적나?"
     │
   F01~F05 수·복소수·무한·함수·지수로그   "수를 어디까지 늘릴 수 있나?"
     │  (F04 함수 ──"각도·회전·반복을 함수로 어떻게 적나?"──▶ F04+ 삼각함수 ──▶ F05 지수로그)
     │
   F06 미분 ──⑤"거꾸로 쌓으면?"──▶ F07 적분 ──▶ F08 급수·테일러
     │                                              │
   F09 벡터·내적 ──▶ F10 행렬 ──▶ F11 고유값 ──▶ F12 확률 ──▶ F13 미분방정식
     │                                                            │
  ┌──┴─────────────────────────────────────────────────────────┴──┐
  │            무기고 200 (지구01~20) — 도구를 벼린다                  │
  │  선형대수·대칭성·기하·확률정보·이산CS·함수해석·최적화·카오스 …      │
  └──────────────────────────────┬───────────────────────────────┘
                                 │
                       〈각성서〉 도구를 만드는 법 추출
                                 │
                       〈단련 전장〉 30난제 × 새 연산자 설계
```

각 화살표 위의 따옴표가 그 단계를 여는 의문이다. 이 의문들이 끊기지 않고 30난제까지 흐른다.
