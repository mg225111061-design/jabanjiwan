## 이 전장으로 들어오는 다리 (이음새)

직전 파일 26(수학 난제 #1~#7)은 마지막에 이 의문을 던지며 끝났다.

**"우리는 수(數)와 공간과 군(群)을 길들였다. 그런데 그 도구들을 자연의 가장 흔한 것 — 강물, 바람, 연기 — 에 들이대면, 잔잔하던 흐름이 갑자기 마구 부서진다. 이 흐름이 영원히 매끄러울지, 아니면 어디선가 속도가 무한대로 폭발하는지, 우리는 증명할 수 있을까?"**

이 전장은 그 의문을 정면으로 받는다. 첫 난제 **#8 나비에-스토크스**가 바로 이 질문이다. 여기서부터 우리는 "수학적으로 깔끔한 방정식"이 "실제 자연"과 만나는 경계에서 어떻게 부서지는지를 일곱 번 본다. 흐름(#8) → 계산하면 ∞가 나오는 장(場)(#9) → 그 장과 휘어진 시공간을 합치는 일(#10) → 시공간이 출렁이는 충돌(#11) → 고체도 액체도 아닌 멈춤(#12) → 보이지 않는 질량(#13) → 우주 전체의 치우침(#14). 매 난제에서 우리는 **풀지 않는다.** 가진 무기를 총동원해 정확히 어디서 무너지는지 보고, **그 벽을 넘을 새 도구를 설계 의뢰한다.**

이 문서의 약속(자가 감사 기준): 각 난제는 다섯 마디 — 1)현상 2)동원 무기 3)모든 도구의 파탄+ASCII 4)도구 설계 의뢰 5)정직한 최전선+새 의문. 새로 제안하는 양·연산자는 5대 검문소(환원·정의·무모순·표적·정직)를 전부 통과하거나, 막히면 "여기서부터 인류가 모른다"라고 정직히 적는다.

# ◆ 난제 #8  나비에-스토크스 매끄러운 해의 존재  [축: 물리]

## 1) 현상

수도꼭지를 살살 틀면 물줄기가 유리막대처럼 매끈하게 떨어진다(층류, laminar flow). 더 세게 틀면 물줄기가 갑자기 하얗게 끓듯이 부서진다(난류, turbulence). 굴뚝 연기도 처음엔 곧게 오르다 어느 높이에서 갈래갈래 흐트러진다.

이 흐름 전체를 적는 방정식 — 나비에-스토크스(Navier-Stokes) — 은 1800년대에 이미 완성됐다. 그런데 단순한 질문 하나에 아무도 답하지 못한다. **"매끈한 흐름에서 출발하면, 그 흐름은 영원히 매끈한가? 아니면 어느 순간 어느 점에서 속도가 무한대로 치솟아(폭발, blow-up) 방정식이 의미를 잃는가?"** 3차원에서 이것은 미해결이며, 클레이 수학연구소의 100만 달러 7대 난제 중 하나다.

> 주의: 이 난제는 골드 표본이다. 깊이·길이의 기준점이며, 아래 #9~#14는 이 깊이 이상으로 쓴다.

## 2) 동원 무기 ★A 연결★

- **지구19 나비에-스토크스 방정식** : 흐름의 운동방정식 자체. 무기고에서 통째로 가져온다(아래 해부).
- **지구06 소보레프 공간(Sobolev space)·약한 해(weak solution)** : "함수가 매끈하지 않아도 적분으로는 말이 되는" 넓은 풀밭. 여기까지 가면 해의 *존재*는 보인다.
- **지구06 그린 함수(Green's function)** : 압력항을 풀어내는 적분 도구.
- **F06 미분·F07 적분·F13 미분방정식** : 바닥 연장.
- **지구08 비선형성(nonlinearity)·동역학** : (u·∇)u 항이 어떻게 에너지를 스케일 사이로 몰아넣는지를 보는 눈.

연결의 깊이: 지구06의 약한 해 이론은 **"존재(existence)"라는 벽까지만** 우리를 데려다준다. 그 너머 **"매끄러움(regularity)·유일성(uniqueness)"** 의 벽 앞에서 무기가 멈춘다.

## 3) 모든 도구의 파탄 + ASCII

방정식 원문을 한 글자씩 해부한 뒤, 어디서 부서지는지 본다.

```
   ∂u/∂t + (u·∇)u = −∇p/ρ + ν∇²u + f ,    ∇·u = 0
```

기호 해부(중2 절대 기준):

- **u** : 속도장(velocity field). 공간의 모든 점마다 "지금 거기 물이 어느 방향으로 얼마나 빠르게 가나"를 적은 화살표. 입력은 위치와 시간, 출력은 화살표(벡터).
- **∂u/∂t** : ∂는 "다른 건 고정하고 이것 하나만 살짝 바꿀 때의 변화율"(편미분, partial derivative). ∂는 경계(boundary)를 뜻하기도 하지만 여기선 편미분이다 — 못박는다. ∂u/∂t = "한 점에 가만히 서서 보면 속도가 시간에 따라 얼마나 변하나".
- **(u·∇)u** : ∇는 "나블라(nabla)", 공간 세 방향의 기울기(gradient)를 한 묶음으로 적은 화살표 연산자 ∇=(∂/∂x, ∂/∂y, ∂/∂z). u·∇는 "물 입자를 따라 흘러가며 보는 변화"(이류, advection). 이 항이 **비선형(nonlinear)** — u가 자기 자신을 곱한다. 모든 말썽의 근원.
- **−∇p/ρ** : p는 압력(pressure), ρ는 밀도(density). ρ는 밀도행렬을 뜻하기도 하지만 여기선 질량밀도다 — 못박는다. ∇p는 압력이 높은 데서 낮은 데로 미는 힘.
- **ν∇²u** : ν(뉴, nu)는 점성(kinematic viscosity), "물이 얼마나 끈적한가". ∇²는 라플라시안(Laplacian)=∇·∇, "주변 평균과 얼마나 다른가"를 재는 연산자. ν∇²u = 끈적함이 속도 차이를 문질러 펴는 항(확산, diffusion). 이게 흐름을 매끈하게 *되돌리려는* 유일한 우군.
- **f** : 바깥에서 미는 힘(외력, external force). 중력·펌프 등.
- **∇·u = 0** : ∇·는 발산(divergence), "이 점에서 화살표가 솟아나오나 빨려드나". =0은 "물이 압축되지 않는다"(비압축, incompressible) — 한 곳에 더 채울 수 없다는 보존 조건.
- **통째 의미** : "물 입자의 가속도 = 압력밀기 + 끈적함문지름 + 외력, 단 물은 압축 안 됨." 뉴턴 F=ma를 물에 쓴 것.

파탄의 메커니즘 — **에너지 캐스케이드(energy cascade)**:

```
 비선형항 (u·∇)u 가 에너지를 큰 소용돌이 → 작은 소용돌이로 계단처럼 몰아넣는다.

   큰 소용돌이 ▇▇▇▇  →  ▇▇  →  ▇  →  ▪  →  ·  →  ?
   (스케일 L)     (L/2)   (L/4)  (L/8)        (→0?)
                                              │
        속도 기울기 |∇u| 가 점점 가팔라짐 ──┘──→ ∞ 로 폭발?

   우군 ν∇²u(점성)는 작은 스케일에서 더 세게 문지른다.
   문제: 비선형 몰아넣기 vs 점성 문지름 — 3D에서 누가 이기는지 증명 불가.
```

선형 PDE라면 푼다. 비선형항이 스케일을 무한히 잇기 때문에, 에너지 부등식·소보레프 매장(embedding)으로 **약한 해의 존재(Leray, 1934)** 까지는 가지만 — 그게 *매끄럽고 유일한지* 는 3D에서 증명이 무너진다. 2D에서는 증명됐다(여기서 차원이 갈린다). 3D에서 무너지는 자리: 에너지 추정만으로는 |∇u|의 최댓값을 시간에 대해 *닫지(close)* 못한다. 추정의 사슬이 자기 자신을 물지 못하고 끊긴다.

**파산을 ★수식★으로 (소보레프 노름 붕괴):** 매끄러운 해(smooth solution)가 [0,T)에서 살아있을 조건은 **소보레프 노름 바운드** `sup_{t<T} ‖u(·,t)‖_{Hˢ} < ∞` (s > 5/2 = n/2+1, n=3). 두 노름의 운명이 갈린다 —
- 에너지(L² 노름): `d/dt(½‖u‖²_{L²}) = −ν‖∇u‖²_{L²} ≤ 0` → 시간에 대해 *유계*(안전).
- 고차 노름(Hˢ): 비선형 수송 (u·∇)u가 `d/dt‖u‖²_{Hˢ} ≤ C‖∇u‖_{L^∞}·‖u‖²_{Hˢ}` 를 만들어 — 우변이 좌변을 *되먹임*해(그론월 부등식) 바운드가 **닫히지 않는다**.
- 따라서 어떤 유한시간 `T*`에서 `lim_{t→T*⁻} ‖u(·,t)‖_{Hˢ} = +∞` (노름 폭발 = 특이점 형성)을 *배제하지 못한다*. 이것이 "매끄러운 해 존재"가 미해결인 정확한 수식적 자리다.
- **베일-카토-마즈다(BKM) 판정:** 폭발 ⟺ `∫₀^{T*} ‖ω(·,t)‖_{L^∞} dt = +∞` (ω = ∇×u, 보텍시티). 이 적분이 유한하면 해는 T*를 넘어 매끈히 연장된다. 그 유한/무한을 가르는 양을 잡는 것이 이 난제의 핵심.

쉽게: '총 에너지'는 줄거나 유지돼 안전한데, '기울기의 거칠기(Hˢ 노름)'는 (u·∇)u가 끝없이 키워, 유한한 시간 안에 ∞로 솟을 수 있는지를 못 막는다. 보텍시티 ‖ω‖_∞를 시간에 더한 값이 유한하면 안 깨진다(BKM).

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 비선형 캐스케이드를 "폭발 직전에 가두는" 새 양 또는 캔버스. 모든 스케일에 걸친 에너지 흐름을 한 수로 압축해, 그 수가 유한하면 폭발이 없음을 보장하는 연산자.

가칭 정의 — **스케일가교 연산자 ⟦스케일가교⟧#8(scale-bridge operator)**:

```
   입력:  속도장 u(x,t)
            │
            ▼
   ┌─────────────────────────────────────────────┐
   │  ⟦스케일가교⟧#8[u](t) = ∫_(모든 스케일 k) Φ(k)·E(k,t) dk  │
   │   E(k,t)=스케일 k에서의 에너지,              │
   │   Φ(k)=작은 스케일일수록 무거운 가중치       │
   └─────────────────────────────────────────────┘
            │
            ▼
   출력:  한 개의 수 ⟦스케일가교⟧#8[u](t)
          ⟦스케일가교⟧#8[u](t) < ∞ 가 모든 t에서 유지 ⇒ 폭발 없음(매끄러움 보존)
          ⟦스케일가교⟧#8[u](t) → ∞ 인 순간 t* 가 폭발 시각
```

- **k** : 파수(wavenumber), "스케일의 반대" — k가 크면 작은 소용돌이. 푸리에 분해(Fourier)로 흐름을 스케일별로 쪼갠 좌표.
- **E(k,t)** : 스케일 k에 담긴 에너지(에너지 스펙트럼).
- **Φ(k)** : 가중치 함수. 작은 스케일(큰 k)일수록 폭발에 가까우므로 무겁게 센다.
- 핵심 아이디어: 기존 에너지 ∫E(k)dk는 비선형이 작은 스케일로 옮긴 위험을 *놓친다*. Φ로 작은 스케일을 강조하면, 캐스케이드가 폭발로 가는 길목을 한 수로 감시할 수 있을지 모른다.

**5대 검문소**:

1. **환원(쉬운 경우 기존수학으로 정확 환원?)** : Φ(k)=1이면 ⟦스케일가교⟧#8는 그냥 총 에너지로 환원되어 Leray의 에너지 부등식과 일치해야 한다. 2D나 점성 ν가 큰 흐름에서는 ⟦스케일가교⟧#8가 유한히 유지되어 알려진 매끄러움 결과를 재현해야 한다. — **통과 설계**(Φ=1 환원은 명확).
2. **정의(입출력·규칙 모호함 0?)** : 입력 u, 출력 실수 하나. 단 Φ(k)의 정확한 모양은 *아직 정하지 못했다*. 어떤 Φ가 비선형 몰아넣기를 정확히 상쇄하는지가 미정. — **부분 막힘**(아래 정직).
3. **무모순(증명된 정리와 충돌 안 함?)** : 부분 정칙성 정리(Caffarelli-Kohn-Nirenberg, 특이점 집합의 크기 제한)와 충돌하면 안 된다. ⟦스케일가교⟧#8 유한 ⇒ 특이점 없음은 CKN의 "특이점이 있어도 작다"보다 강하므로 모순 아님(더 강한 주장일 뿐). — **통과**.
4. **표적(정확히 어느 벽?)** : "정칙성 추정의 닫힘(closure of regularity estimate)" 벽. |∇u|의 시간적 제어를 자기 자신으로 닫는 것. — **명중**.
5. **정직(왜 아직 아무도 못 만들었나?)** : **비선형 (u·∇)u 가 스케일을 무한히 잇기 때문이다.** Φ(k)를 어떻게 고르든, 비선형항이 그 가중치를 통과해 더 작은 스케일로 새는 양을 *제어하는 부등식이 자기 자신을 닫지 못한다.* — 검문소 2에서 막힌 그 지점이 바로 여기다.

**막힘 정직** : Φ(k)의 구체적 모양은 여기서부터 인류가 모른다. "임계 노름(critical norm)"이라 불리는, 스케일을 바꿔도 값이 안 변하는 특별한 자(尺)가 후보지만, 임계 노름이 유한해도 폭발을 막는다는 증명은 닫히지 않았다(임계성이 정확히 칼날 위에 있어 점성도 비선형도 같은 무게라 어느 쪽도 못 이긴다).

**[정직 판정]** 이 가칭 도구 ⟦스케일가교⟧#8 은 재명명에 가까움 — Φ(k)의 *구체적 모양*이 비어 있어(검문소2·5 막힘), "유한하면 폭발 없음"이라는 결론을 양에 이름표로 붙였을 뿐이다. 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 비선형 (u·∇)u가 작은 스케일로 새는 양을 자기 자신으로 *닫는* 가중치 Φ와 그 닫힘 부등식)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **Leray 약한 해**(존재 O, 1934), **부분 정칙성**(CKN, 특이점 집합의 1차원 측도 0), 임계 노름 조건부 정칙성(예: 속도가 어떤 임계 노름에서 유한하면 매끄럽다 — 단 그 노름의 유한성 자체는 보장 못 함). **3D 전역 매끄러움은 미해결.** 여기서부터 인류가 모른다.

**새 의문** : "난류의 '무한히 작아지는 사슬'을 끊을 단 하나의 유한한 자(尺)는 무엇인가? 그리고 이 흐름이 *전기를 띤 기체(플라즈마)* 라서 자기장까지 얽히면, 끊어야 할 사슬은 몇 겹이 되나?" → 이 갈래는 #9에서 "장(場) 자체를 계산하면 왜 ∞가 나오나"로 먼저 갈라진다.

# ◆ 난제 #9  양자장론의 무한대 (QFT 무한대·재규격화의 정당성)  [축: 물리]

## 1) 현상

전자 하나의 자기적 성질(자기모멘트)을 양자전기역학(QED)으로 계산하면, **소수점 12자리까지 실험과 맞는다** — 인류 과학사상 가장 정확한 예측이다. 그런데 그 계산 도중, 중간 단계에서 **답이 ∞(무한대)로 튀어나온다.** 전자가 자기 주변의 빛알갱이 구름과 상호작용하는 효과를 다 더하면 적분이 발산한다.

물리학자들은 이 ∞를 **재규격화(renormalization)** 라는 절차로 "빼내고" 유한한 답을 건진다. 답은 기적처럼 맞다. **하지만 질문은 남는다 — 자연은 유한한데, 왜 우리 계산은 ∞를 거치는가? 이 ∞ 빼내기는 수학적으로 정당한가, 아니면 운 좋은 회계 속임수인가?** 4차원에서 상호작용하는 양자장론을 수학적으로 엄밀하게 구성하는 것(예: 양-밀스 질량간극, 클레이 난제)은 미해결이다.

## 2) 동원 무기 ★A 연결★

- **지구10 재규격화(renormalization)** : ∞를 체계적으로 흡수하는 절차. 무기고에서 가져온다.
- **지구10 경로적분(path integral)** : "입자가 갈 수 있는 모든 길을 더한다"는 양자장론의 심장.
- **지구10 파인만 다이어그램(Feynman diagram)** : 모든 일어날 수 있는 일을 선과 점으로 빠짐없이 적는 회계 장부.
- **지구06 함수해석·연산자** : 무한차원 적분을 다룰 그릇.
- **F12 확률·지구04 측도(measure)** : "모든 길의 합"에 무게를 주는 자.

연결의 깊이: 파인만 다이어그램으로 항을 빠짐없이 나열하고, 각 다이어그램의 값을 적분으로 적는 **데까지** 무기가 작동한다. 그 적분을 *실제로 계산*하는 순간 ∞가 나온다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 루프 적분(loop integral)과 베타 함수(beta function):

```
   다이어그램 값 ~ ∫ d⁴k / (k² )(...)  ,     β(g) = μ · dg/dμ
```

기호 해부:

- **∫ d⁴k** : 4차원 운동량 공간 전체에 대한 적분. 루프(loop, 닫힌 고리) 안을 도는 가상입자의 운동량 k를 *모든 값* 에 대해 더한다. ∫는 "잘게 쪼개 다 더하기".
- **k** : 루프 속 가상입자(virtual particle)의 운동량(momentum). 여기서 k는 #8의 파수가 아니라 4차원 운동량이다 — 못박는다.
- **1/k²** : 입자가 운동량 k를 가질 때의 "전파자(propagator)" 크기. k가 클수록(에너지 클수록) 작아지지만, **충분히 빨리 작아지지 않아서** ∫d⁴k = ∫k³dk·(...) 에서 위쪽(k→∞)이 발산한다(자외선 발산, UV divergence).
- **β(g)** : 베타 함수. g는 결합상수(coupling constant), "힘이 얼마나 센가". β는 "우리가 보는 척도(에너지 스케일) μ를 바꾸면 g가 어떻게 변하나"를 적은 것.
- **μ** : 척도(scale), "우리가 얼마나 가까이 들여다보나"의 에너지. μ는 평균·투자율·지표를 뜻하기도 하지만 여기선 재규격화 척도다 — 못박는다.
- **dg/dμ** : 척도를 바꿀 때 결합상수의 변화율.
- **통째 의미** : "가까이 들여다볼수록(μ↑) 힘의 세기 g가 흘러간다(running coupling). 그 흐름의 규칙이 β." 그리고 그 흐름의 출발점에서 ∞가 끼어든다.

파탄의 메커니즘 — **자외선 발산(UV divergence)**:

```
   루프 적분을 에너지 k 의 크기별로 쌓아 보면:

   k:  0 ──── Λ(자른 곳) ──── ∞
       │▁▁▂▂▃▃▅▅▇▇█████████ ...  → 위로 갈수록 기여가 안 줄어듦
                              │
            ∫ 이 끝(k→∞)에서 ████ 무한히 쌓임 = ∞

   재규격화: "Λ에서 잘라(cutoff) 유한하게 만든 뒤,
             실험으로 잰 값으로 상수를 다시 맞추고(되맞춤),
             Λ→∞ 보내도 답이 유한히 남게 한다."
        ┌──────────────────────────────────────┐
        │  (날 계산 = ∞)  −  (상수 되맞춤 = ∞)  │
        │  ───────────────────────────────────  │
        │        = 유한한 답 (실험과 일치)       │
        └──────────────────────────────────────┘
        ∞ − ∞ 를 정해진 절차로 다뤄 유한을 건진다.
```

무기가 멈추는 자리: ∞−∞는 보통 수학에서 *정의되지 않는다.* 재규격화는 "Λ로 자르고, 셈을 끝낸 뒤, Λ를 무한으로 보낸다"는 *극한 절차의 순서*로 이 위험을 우회한다. 섭동(perturbation, 항을 하나씩 더하는) 차수마다 이 우회가 작동함은 보였지만(BPHZ 정리) — **그 무한급수 전체가 진짜 함수로 수렴하는지, 4차원 상호작용 이론이 비섭동적으로 *존재*하는지** 는 증명되지 않았다. 추정의 사슬이 "각 항"까지만 닫히고 "전체"에서 끊긴다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : ∞를 "사후에 빼내는" 대신, 처음부터 ∞가 생기지 않는 *유한한 캔버스* 위에 양자장을 정의하는 양. 척도를 바꿔도 이론이 자기 자신으로 닫히는(자기일관) 한 수.

가칭 정의 — **유한장 측도 ⟦유한장⟧#9(finite-field measure, 산-기호로 표기)**:

```
   입력:  장 설정 φ(모든 점의 장값) + 척도 μ
            │
            ▼
   ┌──────────────────────────────────────────────┐
   │  ⟦유한장⟧#9[φ; μ] = exp(−S[φ]) · J(μ)  를                │
   │   "스케일 껍질(shell)" 단위로만 쌓는 측도       │
   │   각 껍질 μ→μ' 의 기여가 처음부터 유한          │
   └──────────────────────────────────────────────┘
            │
            ▼
   출력:  유한한 분배함수 Z = ∫ ⟦유한장⟧#9[φ;μ] Dφ
          (Λ→∞ 극한이 필요 없음: 껍질마다 이미 유한)

   스케일 껍질 그림:
   μ높음 ▏░░░░▏ 유한
   μ중간 ▏▒▒▒▒▏ 유한   ← 인접 껍질끼리만 정보 주고받음(흐름의 군, RG group)
   μ낮음 ▏▓▓▓▓▏ 유한
```

- **S[φ]** : 작용(action), 그 장 설정의 "값어치(에너지×시간)". exp(−S)는 그 설정이 일어날 무게.
- **J(μ)** : 껍질 옮길 때의 야코비안(Jacobian) 보정 — 정보를 한 척도에서 다음으로 넘길 때의 환율.
- **Dφ** : 모든 장 설정에 대한 경로적분 측도.
- 핵심: 빌슨(Wilson)의 재규격화군(RG)을 "측도로 못박아", ∞를 빼는 게 아니라 *애초에 만들지 않는다.* 각 스케일 껍질이 인접 껍질하고만 유한하게 거래한다.

**5대 검문소**:

1. **환원** : 자유장(상호작용 g=0)에서 ⟦유한장⟧#9는 가우시안 측도로 정확히 환원되어야 한다(이건 수학적으로 잘 정의됨). 2차원·3차원 약결합 이론에서는 이미 엄밀 구성이 존재(구성장론, constructive QFT)하므로 거기서 재현해야 한다. — **통과 설계**.
2. **정의** : 입력 (φ, μ), 출력 측도 한 개. 단 **4차원에서 J(μ)가 비섭동적으로 잘 정의되는지** 가 미정. — **부분 막힘**.
3. **무모순** : 섭동 차수별로 재규격화군 흐름(RG flow)·BPHZ와 일치해야 한다. 가우시안 환원과 RG 일치가 강제되므로 충돌 회피. — **통과**.
4. **표적** : "비섭동적 존재성(non-perturbative existence)" 벽 — 4차원 상호작용 QFT가 수학적 대상으로 정말 있는가. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **4차원에서 척도를 무한히 잘게 쪼개도 정보가 새지 않는 측도가, 비자명한(상호작용 있는) 이론에서 존재하는지를 아무도 구성하지 못했기 때문이다.** φ⁴ 이론은 4차원에서 "자명성(triviality, 결국 자유장으로 붕괴)" 의심까지 있다 — 즉 ⟦유한장⟧#9를 닫으려 하면 상호작용이 사라질 수 있다.

**막힘 정직** : J(μ)의 4차원 비섭동 구성은 여기서부터 인류가 모른다. 양-밀스(Yang-Mills) 게이지 이론에서 질량간극(mass gap)과 함께 이것을 보이는 것이 클레이 난제이며 열려 있다.

**[정직 판정]** 이 가칭 도구 ⟦유한장⟧#9 는 재명명에 가까움 — "껍질마다 이미 유한"은 원하는 결과를 측도의 정의로 선언한 것이고, 4차원에서 J(μ)를 비섭동적으로 *구성*하는 규칙이 비어 있다(검문소2·5 막힘, φ⁴ 자명성 의심까지). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 4D 상호작용 이론에서 스케일을 무한히 쪼개도 정보가 안 새는 측도를 실제로 *짓는* 비섭동 구성)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **섭동적 재규격화 가능성**(QED·표준모형, 차수별 유한), **2·3차원 구성장론**(엄밀 존재), **격자 게이지 이론**(유한 격자에서 수치적으로 다룸). **4차원 상호작용 QFT의 엄밀 구성과 양-밀스 질량간극은 미해결.** 여기서부터 인류가 모른다.

**새 의문** : "장(場)을 휘어지지 않은 평평한 무대 위에서 재규격화하는 것도 이렇게 어려운데 — 그 무대(시공간) 자체가 양자처럼 출렁이면, 즉 *중력까지 양자화* 하면, 우리는 같은 ∞ 빼내기를 쓸 수 있나?" → #10으로 직결.

# ◆ 난제 #10  양자중력 (휘어진 시공간 + 양자도약의 통합)  [축: 물리]

## 1) 현상

세상을 설명하는 두 기둥이 있다. 하나는 **일반상대성이론** — 중력은 힘이 아니라 *시공간이 휘어진 것* 이며, 별·블랙홀이 그 휘어짐을 만든다(아주 큰 것에 잘 맞음). 다른 하나는 **양자역학** — 아주 작은 것은 정해진 위치 없이 확률로 *도약* 한다(아주 작은 것에 잘 맞음).

문제는 **이 둘을 한 언어로 합치면 서로 싸운다.** 시공간이 양자처럼 출렁인다고 가정하고 #9의 ∞ 빼내기를 쓰면, 중력은 재규격화가 안 된다 — ∞를 흡수할 상수가 무한히 많이 필요해서 예측력이 0이 된다. **아주 작으면서 동시에 아주 무거운 것(빅뱅 직후, 블랙홀 중심)** 에서 두 이론이 동시에 필요한데, 합칠 방법을 모른다. 이것이 물리학 최대의 미완성이다.

## 2) 동원 무기 ★A 연결★

- **지구17 아인슈타인 장방정식(Einstein field equation)** : 시공간 휘어짐과 물질의 관계.
- **지구03 리만 곡률(Riemann curvature)** : "공간이 얼마나·어떻게 휘었나"를 재는 텐서.
- **지구01 힐베르트 공간(Hilbert space)** : 양자상태가 사는 무한차원 그릇.
- **지구10 경로적분·재규격화** : #9에서 가져온 양자화 절차.
- **지구03 미분기하·계량(metric)** : 거리를 재는 자.

연결의 깊이: 곡률(지구03)로 휘어짐을 적고, 장방정식(지구17)으로 그 휘어짐의 법칙을 쓰고, 힐베르트 공간(지구01)으로 양자상태를 담는 **데까지** 따로따로는 잘 작동한다. 둘을 *곱하는* 순간 무너진다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 아인슈타인 장방정식과 플랑크 길이:

```
   G_μν = 8πG T_μν ,    ℓ_P = √(ℏG/c³) ≈ 1.6×10⁻³⁵ m
```

기호 해부:

- **G_μν** : 아인슈타인 텐서. 첨자 μ, ν(뮤·뉴)는 시공간의 네 방향(시간 1 + 공간 3)을 가리키는 좌표 이름표, 각각 0,1,2,3을 훑는다. G_μν = "이 점에서 시공간이 어떻게 휘었나"를 리만 곡률에서 추려낸 묶음. (이 G는 결합상수가 아니라 텐서 기호 — 못박는다.)
- **G** (오른쪽) : 뉴턴 중력상수, "중력이 얼마나 센가". 왼쪽 G_μν와 글자만 같고 뜻이 다르다 — 못박는다.
- **T_μν** : 에너지-운동량 텐서. "이 점에 에너지·운동량·압력이 얼마나 있나" = 휘어짐의 *원인*.
- **8π** : 뉴턴 중력과 맞추기 위한 상수(원·구의 기하에서 옴).
- **통째 의미** : "물질(T)이 있으면 시공간(G)이 휜다. 휘어짐이 곧 중력이다." 존 휠러의 말로 "물질은 공간에게 어떻게 휘라 말하고, 공간은 물질에게 어떻게 움직이라 말한다."
- **ℓ_P** : 플랑크 길이(Planck length). ℏ(에이치바, 양자의 기본단위)·G(중력)·c(빛속도)를 섞은, "이보다 작으면 시공간 자체가 양자 거품처럼 출렁여 매끈한 거리 개념이 깨지는" 자. √는 제곱근.

파탄의 메커니즘 — **재규격화 불가능성(non-renormalizability)**:

```
   #9의 ∞ 빼내기를 중력에 적용하면:

   루프 차수:   1차    2차      3차       ...
   필요한 상수: ●      ●●      ●●●●      ... → 차수마다 새 ∞, 새 상수
                 │      │         │
            결합상수 G의 차원이 "음수"라서
            고차 루프일수록 발산이 더 심해짐(↑)

   ┌─────────────────────────────────────────────┐
   │  유한 답을 얻으려면 무한히 많은 상수를        │
   │  실험으로 맞춰야 함 → 예측력 0 (아무 값이나)  │
   └─────────────────────────────────────────────┘

   더 근본적 충돌(시간의 문제):
     양자역학:  시간 t 는 바깥에서 흐르는 절대 시계 ───t───►
     상대성:    시간은 휘어짐의 일부, 절대 시계가 없음  ∿∿∿∿
                       ↑ 둘의 "시간"이 같은 말이 아님
```

무기가 멈추는 자리 둘. (1) **재규격화 불가** : 중력 결합상수(뉴턴 G)는 #9의 무차원 g와 달리 차원을 가져, 고차 루프마다 새로운 ∞를 낳고 그걸 흡수할 상수가 무한히 필요하다 — #9의 ∞ 빼내기 절차가 닫히지 않는다. (2) **시간 문제(problem of time)** : 양자역학은 바깥의 절대 시계로 상태의 변화를 적는데, 상대성에는 그런 시계가 없다(시간이 휘어짐의 일부). 두 이론의 "시간"이라는 단어가 서로 다른 것을 가리켜, 슈뢰딩거 방정식을 시공간 위에 그대로 쓸 수가 없다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 시공간의 휘어짐과 양자 도약을 *한 측도* 위에 올리되, 플랑크 길이 아래에서 ∞가 아니라 *유한한 알갱이* 로 끝나는 양. 그리고 "절대 시계 없이" 변화를 적는 규칙.

가칭 정의 — **공시연산자 ⟦공시⟧#10(geometro-quantum operator, 격자-네모 기호)**:

```
   입력:  시공간 조각 (계량 g_μν 의 양자 중첩) + 물질 상태 |ψ⟩
            │
            ▼
   ┌────────────────────────────────────────────────┐
   │  ⟦공시⟧#10[g,ψ] = "플랑크 알갱이 단위"로만 정의된         │
   │            휘어짐-상태 결합 진폭                  │
   │   ℓ < ℓ_P 인 거리는 입력 자체가 금지(자연 컷오프) │
   └────────────────────────────────────────────────┘
            │
            ▼
   출력:  유한한 진폭(확률폭). ∞ 빼내기 불필요.

   매끈한 시공간 ────────  (큰 스케일: 일반상대성 재현)
                  ╱╲╱╲
   ℓ_P 근처 거품  ◇◇◇◇◇   (작은 스케일: 알갱이, 더 못 쪼갬)
                  └─ 거리의 최소 단위 = ℓ_P, 여기서 ∞가 잘림
```

- **g_μν** : 계량 텐서, 시공간에서 두 점 사이 "진짜 거리"를 재는 자. 양자화하면 g 자체가 중첩(superposition)된다 — 여러 휘어짐이 동시에.
- **|ψ⟩** : 켓(ket), 양자상태를 담은 화살표. ⟨·|·⟩는 두 상태의 겹침(내적).
- 핵심: 플랑크 길이를 *물리적 자연 컷오프* 로 못박아, #9에서 인공으로 넣던 Λ를 자연이 이미 갖고 있다고 본다(고리양자중력·인과적 동적삼각화·끈이론이 각각 다른 방식으로 시도). "시간 문제"는 ⟦공시⟧#10를 외부 시계 없이 *상태들 사이의 상관관계* 로만 정의해 우회 시도.

**5대 검문소**:

1. **환원** : 큰 스케일·약한 중력에서 ⟦공시⟧#10는 고전 아인슈타인 방정식 + 평평한 무대 위 양자장론으로 정확히 환원되어야 한다. — **설계상 요구**(아직 모든 후보 이론이 이 환원을 완전히 보이진 못함).
2. **정의** : 입력이 "계량의 양자 중첩"인데, *어떤 변수로* 시공간을 적느냐(고리·스핀네트워크·끈·삼각형)에 따라 ⟦공시⟧#10의 규칙이 달라진다 — **막힘**.
3. **무모순** : 블랙홀 엔트로피(베켄슈타인-호킹 S=A/4ℓ_P²)를 재현해야 한다. 일부 후보(끈이론의 특정 블랙홀, 고리양자중력의 면적 양자화)는 이를 부분 재현 — **부분 통과**.
4. **표적** : "재규격화 불가능성 + 시간 문제" 벽. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **중력은 시공간 *그 자체* 를 양자화하라고 요구하는데, 양자역학은 양자상태가 그 위에서 살 '고정된 무대'를 전제하기 때문이다.** 무대를 양자화하면 무대가 사라져, 양자역학의 출발 가정이 무너진다. 이 자기참조적 매듭이 핵심 장벽.

**막힘 정직** : 검문소 2에서 막힌다. *옳은 기본 변수* 가 무엇인지를 아무도 모른다. 끈이론·고리양자중력·인과집합 등은 서로 다른 답을 제시하나, 실험으로 가를 에너지(플랑크 에너지)에 도달할 수 없어 판가름이 안 난다. 여기서부터 인류가 모른다.

**[정직 판정]** 이 가칭 도구 ⟦공시⟧#10 은 재명명에 가까움 — "플랑크 알갱이 단위로 정의된 결합 진폭"은 답의 이름일 뿐, *옳은 기본 변수*(끈·스핀네트워크·삼각형 중 무엇)가 미정이라 ⟦공시⟧#10의 규칙 자체가 비어 있다(검문소2 막힘). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 양자화된 무대 위에서 양자상태가 살 수 있게 하는 옳은 변수와 그 위의 동역학 규칙을 실제로 *짓는* 것)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **끈이론**(중력자를 자연히 포함, 일부 블랙홀 엔트로피 재현), **고리양자중력**(면적·부피의 양자화), **점근적 안전성(asymptotic safety)** 가설(중력이 사실은 비섭동적으로 재규격화 가능할 수도), **AdS/CFT 대응**(휘어진 공간의 중력 = 그 경계의 보통 양자장론). **실험으로 검증된 완전한 양자중력 이론은 없다.** 여기서부터 인류가 모른다.

**새 의문** : "시공간이 양자처럼 출렁이는 극한은 못 풀어도, *고전적으로 아주 격렬한 출렁임* — 두 블랙홀이 부딪혀 시공간이 파도치는 일 — 은 정확히 어떻게 계산하나?" → #11로 직결.

# ◆ 난제 #11  블랙홀 충돌과 중력파 파형  [축: 물리]

## 1) 현상

2015년, 두 블랙홀이 13억 광년 밖에서 부딪혔다. 그 충격으로 시공간 자체가 출렁였고(중력파, gravitational wave), 그 파도가 지구를 지나며 검출기(LIGO) 거울 사이 거리를 양성자 지름의 1/1000보다 작게 늘였다 줄였다. 인류는 그 떨림을 들었다.

문제는 **"두 블랙홀이 부딪힐 때 시공간이 정확히 어떻게 출렁이는가" 를 종이와 연필로는 못 푼다.** 아인슈타인 장방정식은 *비선형* 이라(휘어짐이 휘어짐을 더 휘게 한다), 두 블랙홀이 가까워지는 마지막 순간(병합, merger)의 파형(waveform)은 오직 *슈퍼컴퓨터로 시공간을 잘게 쪼개 한 발씩 전진* 시켜야 나온다. 그 계산은 수십 년간 폭발(수치적 발산)했고, 지금도 정밀도·속도·먼 영역의 경계처리에서 최전선이다.

## 2) 동원 무기 ★A 연결★

- **지구17 아인슈타인 장방정식** : 풀어야 할 대상(#10에서 해부한 G_μν=8πG T_μν).
- **지구09 수치해석(numerical analysis)** : 방정식을 격자에서 한 발씩 전진시키는 기술.
- **지구09 룽게-쿠타(Runge-Kutta)** : 시간을 잘게 쪼개 다음 순간을 추정하는 적분기.
- **지구03 미분기하·곡률** : 휘어짐을 좌표에 적는 자.
- **지구06 편미분방정식·경계조건** : 무한히 먼 곳을 유한 격자에서 다루는 처리.

연결의 깊이: 룽게-쿠타(지구09)로 시간 전진, 곡률(지구03)로 휘어짐 기록 — 이 조합은 *선형* 파동방정식이라면 깔끔히 작동한다. 비선형 + 좌표 자유도가 끼면 무너진다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 시간 전진(룽게-쿠타 4차)과 파형:

```
   y_(n+1) = y_n + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)
   h_+(t), h_×(t) = 중력파의 두 편광 파형
```

기호 해부:

- **y_n** : n번째 시각의 "시공간 상태"(계량과 그 변화율을 한 줄에 묶은 것).
- **h** : 시간 걸음 크기(step size), "한 번에 시간을 얼마나 전진하나". 작을수록 정확하나 느리다. (이 h는 중력파 진폭 h와 글자가 같다 — 못박는다: 여기선 시간 걸음.)
- **k₁,k₂,k₃,k₄** : 한 걸음 안에서 기울기를 네 군데서 재 평균낸 추정값(룽게-쿠타의 심장).
- **h_+(t), h_×(t)** : 중력파의 두 편광(polarization). +(플러스)와 ×(크로스)는 시공간을 늘이고 줄이는 두 직각 방향 무늬. 이 h는 진폭 — 못박는다.
- **통째 의미** : "지금 상태에서 기울기를 영리하게 네 번 재 평균내, 다음 순간의 시공간을 추정한다. 이걸 수백만 번 반복해 충돌 전 과정의 파형 h_+·h_×를 뽑는다."

파탄의 메커니즘 — **수치적 불안정과 좌표 특이점**:

```
   ① 비선형 폭발: 휘어짐이 휘어짐을 더 키워,
      작은 격자 오차가 눈덩이처럼 자람

      오차:  ·  →  ▪  →  ▇  →  ████ 발산(코드가 NaN으로 죽음)
             t₀     t₁     t₂      t₃

   ② 좌표 특이점(coordinate singularity):
      블랙홀 중심엔 진짜 ∞(곡률 무한)가 있음.
      격자가 그 ∞를 밟으면 계산이 죽는다.

      격자: ┼─┼─┼─┼─┼─┼─┼
                  ╲   ╱
                   ●●●     ← 블랙홀 중심, 곡률 ∞
                  (밟으면 즉사)

   ③ 게이지(좌표) 자유도:
      같은 시공간을 적는 좌표가 무한히 많아,
      "물리적 출렁임"과 "좌표를 흔든 가짜 출렁임"이 섞임.
      → 어느 게 진짜 파형인지 분리해야 함
```

무기가 멈추는 자리 셋. (1) **비선형 누적 오차** : 룽게-쿠타는 선형계엔 안정적이나, 아인슈타인 방정식의 비선형성에서 1990년대 코드들이 몇 번 전진하면 폭발했다(BSSN 형식 등 방정식을 *다시 쓴* 뒤에야 안정화 — 즉 도구를 고쳐야 했다). (2) **특이점 회피** : 중심의 진짜 ∞를 격자에서 "도려내기(excision)"하거나 "구멍 통과(moving puncture)"로 우회해야 한다. (3) **게이지 분리** : 좌표 흔들림과 진짜 중력파를 가르는 작업이 먼 영역 경계에서 까다롭다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 좌표 자유도와 비선형 폭발에 *면역인* 시간 전진 양. 게이지를 자동으로 골라내고, 격자 없이도 강(强)중력 영역의 파형을 보장 정밀도로 내놓는 연산자.

가칭 정의 — **불변전진 연산자 ⟦불변전진⟧#11(gauge-invariant evolver)**:

```
   입력:  현재 시공간 상태 y_n (단, 게이지-불변량으로만 표현)
            │
            ▼
   ┌──────────────────────────────────────────────┐
   │  ⟦불변전진⟧#11[y_n] = y_(n+1)                               │
   │   곡률 스칼라(좌표 안 타는 양)만으로 전진      │
   │   걸음 h 를 오차에 맞춰 자동 조절(적응적)      │
   │   특이점은 정의역에서 자동 제외               │
   └──────────────────────────────────────────────┘
            │
            ▼
   출력:  다음 순간 상태 + 보장된 오차 막대 ±ε

   적응 격자(작은 오차 영역엔 성기게, 강중력엔 촘촘히):
   먼 곳   ┼───────┼───────┼      (성김)
   충돌부  ┼┼┼┼┼┼┼┼┼┼┼┼┼┼┼      (촘촘)
                  ◇ 특이점은 정의역 밖으로 도려냄
```

- **곡률 스칼라(curvature scalar)** : 리만 곡률을 좌표와 무관한 수 하나로 짜낸 것(예: 크레치만 스칼라). 좌표를 어떻게 흔들어도 안 변하므로 게이지 가짜 출렁임이 안 섞인다.
- **±ε** : 보장 오차 막대. ⟦불변전진⟧#11는 각 걸음의 오차 상한을 함께 내놓아 "이 파형은 ±ε 안에서 참"임을 보장.
- 핵심: 현재 수치상대론은 *방정식을 다시 써서* 안정화하지만 게이지 분리를 사후에 한다. ⟦불변전진⟧#11는 처음부터 게이지-불변량으로만 전진해 그 분리를 없앤다.

**5대 검문소**:

1. **환원** : 약한 중력·먼 영역에서 ⟦불변전진⟧#11는 선형 파동방정식의 룽게-쿠타로 정확히 환원되어야 한다(이미 잘 작동하는 영역 재현). — **통과 설계**.
2. **정의** : 게이지-불변량만으로 *완전한* 시공간 상태를 적을 수 있는가? 4차원에서 좌표 없이 동역학을 닫는 불변량 집합이 *완비(complete)* 인지가 미정. — **부분 막힘**.
3. **무모순** : 이미 검증된 LIGO 파형(수치상대론 + 후-뉴턴 근사로 만든 파형 은행)과 일치해야 한다. — **통과 가능**(검증 가능).
4. **표적** : "강중력 영역의 비선형·게이지 동역학을 보장 정밀도로 전진" 벽. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **아인슈타인 방정식은 '시공간이 어떻게 변하나'와 '그걸 어떤 좌표로 적나'를 깔끔히 분리해주지 않기 때문이다.** 게이지(좌표)는 물리가 아니지만 방정식에 얽혀 있어, 불변량만으로 동역학을 닫으려 하면 식이 매우 비국소(non-local)해져 계산이 폭발한다.

**막힘 정직** : 검문소 2에서 막힌다. 게이지-불변량만으로 동역학을 *국소적으로* 닫는 완비 집합이 알려져 있지 않다. 이건 #10(양자중력)의 게이지 문제와 같은 뿌리다 — 여기서부터(완비·국소 불변량 집합) 인류가 모른다. 다만 이 난제는 #8·#10과 달리 *수치적으로는 답을 낸다*(LIGO 파형은 실제로 계산됨) — 미해결인 것은 "보장 정밀도·게이지 면역"의 수학적 깔끔함이다.

**[정직 판정]** 이 가칭 도구 ⟦불변전진⟧#11 은 진짜 부분 도구 — 현 수치상대론(BSSN·이동 구멍법)은 실제로 LIGO 파형을 *계산해 내고 단계를 줄인다*(이 난제는 #8·#10과 달리 답을 낸다). 다만 게이지-불변량만으로 동역학을 *국소적으로 닫는 완비 집합*은 아직 없다(검문소2 막힘). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 좌표 없이 동역학을 닫으면서도 비국소로 폭발하지 않는 완비 불변량 집합과 그 위의 보장 오차 전진 규칙)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **BSSN/Z4c 형식**(안정한 시간 전진), **이동 구멍법(moving puncture)**(특이점 우회), **적응 격자(AMR)**, **후-뉴턴 + 수치상대론 결합 파형 은행**(LIGO/Virgo 검출에 실제 사용). 충돌 파형은 *계산된다.* **보장 정밀도와 게이지-불변 전진의 수학적 닫힘은 미해결.** 여기서부터 인류가 모른다.

**새 의문** : "격렬하게 출렁이는 시공간도 계산하는데 — 출렁임도 흐름도 없이 그냥 *멈춰버린* 것, 고체도 액체도 아닌 채로 굳은 것(유리)의 그 멈춤은 어떤 방정식으로 적나?" → #12로 직결.

# ◆ 난제 #12  유리 상전이 (유리는 어떻게 멈추나)  [축: 물리]

## 1) 현상

창문 유리는 단단한 고체처럼 보인다. 그런데 원자 배열을 들여다보면 **액체처럼 제멋대로** 다. 결정(crystal)은 원자가 격자에 줄맞춰 서지만, 유리는 액체의 무질서를 그대로 *얼린* 것이다. 뜨거운 유리물을 식히면 어느 온도(유리전이온도, Tg) 근처에서 점성이 수십 자릿수로 치솟아 **거의 흐르지 않게** 된다 — 그런데 *진짜 상전이(끓는점처럼 딱 떨어지는 변화)는 일어나지 않는다.*

문제는 **"이 멈춤이 진짜 상전이인가, 아니면 그냥 너무 느려져 멈춘 척하는 것인가" 를 아무도 모른다.** 끓음·얼음은 자유에너지의 명확한 꺾임으로 설명되는데, 유리의 멈춤에는 그런 꺾임이 안 보인다. 무질서한 채로 멈추는 이 현상의 *질서변수(order parameter)* 가 무엇인지조차 합의가 없다. 응집물질물리학 최대 난제 중 하나다.

## 2) 동원 무기 ★A 연결★

- **지구04 통계역학(statistical mechanics)·분배함수** : 수많은 원자의 평균 행동을 한 함수로.
- **지구04 자유에너지(free energy)·상관함수** : 어떤 상태가 일어날지, 멀리 떨어진 원자가 얼마나 함께 움직이는지.
- **지구08 동역학·완화시간(relaxation time)** : 흐트러진 배열이 풀리는 데 걸리는 시간.
- **지구04 확률분포·엔트로피** : 무질서의 양을 재는 자.

연결의 깊이: 통계역학(지구04)은 끓음·얼음 같은 *질서변수가 분명한* 상전이를 완벽히 설명한다. 자유에너지의 꺾임을 찾으면 된다. 유리에선 *그 질서변수를 못 찾아* 무기가 헛돈다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 자유에너지·상관길이·질서변수:

```
   F = U − T·S ,    ξ = 상관길이 ,    Q = 질서변수(?)
```

기호 해부:

- **F** : 자유에너지(free energy), "그 상태가 일어나려는 경향" — 낮을수록 자연이 좋아함. (F는 힘을 뜻하기도 하나 여기선 자유에너지 — 못박는다.)
- **U** : 내부에너지(원자들의 운동·결합 에너지 총합).
- **T** : 온도(temperature), 무질서를 부추기는 정도.
- **S** : 엔트로피(entropy), 무질서·"가능한 배열의 가짓수"의 로그. T·S는 "온도가 무질서를 통해 깎아주는 에너지".
- **통째 의미** : "자연은 F=U−T·S를 최소로 하는 상태를 고른다. 차면 U가 이겨 질서(낮은 에너지)로, 더우면 T·S가 이겨 무질서로." 보통 상전이는 이 경쟁의 *승자가 바뀌는 꺾임* 이다.
- **ξ(크사이, xi)** : 상관길이(correlation length), "한 원자가 움직이면 몇 칸 떨어진 원자까지 같이 움직이나". 보통 상전이에선 ξ가 전이점에서 발산(∞)한다 — 온 세상이 함께 결정.
- **Q** : 질서변수 — "질서가 얼마나 잡혔나"를 재는 한 수. 결정이면 "격자 줄맞춤 정도", 자석이면 "자화". **유리에선 이 Q가 무엇인지 모른다.**

파탄의 메커니즘 — **숨은 질서변수와 동결**:

```
   보통 상전이(물→얼음): 자유에너지 F 가 온도에서 꺾인다
        F
        │＼          ← 명확한 꺾임 = 상전이
        │ ＼___
        └────────── T,  그리고 ξ → ∞ (질서가 온 세상으로)

   유리: F 는 매끈하다(꺾임 안 보임). 그런데 점성은 폭발한다.
        점성 η
        │              ██
        │           ███
        │        ███         ← 십수 자릿수 폭발
        │   _____             하지만 F·ξ엔 명확한 신호 없음
        └────────── T (Tg 근처)

   원자 그림(유리는 액체 무질서를 "얼린" 것):
     결정:  ● ● ● ●     유리:  ● ●   ●
            ● ● ● ●            ●   ● ●
            ● ● ● ●             ● ●  ●   ← 무질서한 채 멈춤
            (줄맞춤,Q명확)       (Q=???)
```

무기가 멈추는 자리: 통계역학은 *질서변수 Q를 알아야* 자유에너지의 꺾임을 찾는다. 유리는 무질서한 채로 멈추므로, 결정의 "줄맞춤" 같은 단순한 Q가 없다. 후보(겹친 두 복제본의 닮음 = 에드워즈-앤더슨 변수, 또는 동적 불균질성 dynamic heterogeneity)가 제안됐지만, 그 Q가 *진짜 열역학적 상전이* 를 가리키는지 *그냥 동역학적 느려짐* 인지를 가를 실험·이론이 닫히지 않는다. ξ가 발산하는지조차 논쟁이다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 무질서한 채로 멈추는 상태의 *진짜 질서변수* 를 잡는 양. 열역학적 전이와 단순 동결을 가르는 한 수.

가칭 정의 — **동결지표 ⟦동결⟧#12(overlap-order indicator, 모래시계 기호)**:

```
   입력:  같은 유리의 두 독립 복제본 A, B (같은 온도, 다른 시작)
            │
            ▼
   ┌──────────────────────────────────────────────┐
   │  ⟦동결⟧#12(T) = ⟨ A와 B 의 원자 배열이 얼마나 닮았나 ⟩ │
   │   복제본끼리 "포개봤을 때 겹치는 정도"(overlap)│
   │   를 온 부피·긴 시간 평균                       │
   └──────────────────────────────────────────────┘
            │
            ▼
   출력:  한 수 ⟦동결⟧#12(T) ∈ [0,1]
          ⟦동결⟧#12→0: 두 복제본 제각각(액체, 멈춤은 가짜)
          ⟦동결⟧#12>0 로 점프: 같은 골짜기에 갇힘(진짜 열역학 동결)

   복제본 겹침 그림:
     액체(높은 T)         유리(낮은 T)
     A: ●_●__●           A: ●_●_●
     B: __●●_●     vs    B: ●_●_●   ← A,B 가 같은 배열로 갇힘
     겹침≈0               겹침>0 (⟦동결⟧#12 점프)
```

- **복제본(replica)** : 같은 조건의 시스템을 두 벌 독립으로 준비한 것. 스핀유리 이론에서 "복제법(replica method)"의 핵심.
- **overlap(겹침)** : 두 복제본의 원자 위치를 포개 닮은 정도. 액체면 매번 달라 0, 진짜로 갇히면 같은 골짜기라 양수.
- 핵심: 자유에너지에 *안 보이는* 질서를, 두 복제본의 겹침이라는 *숨은 차원* 에서 본다. 메조-프랑스(평균장 유리 이론)에서 ⟦동결⟧#12의 점프가 이론적 전이(콜드 톰슨-아닌센)를 가리키나, 3차원 실제 유리에서 이 점프가 *진짜인지* 가 미정.

**5대 검문소**:

1. **환원** : 평균장(무한차원) 유리에서 ⟦동결⟧#12는 이미 알려진 1단계 복제대칭깨짐(1-RSB) 전이를 재현해야 한다(이건 엄밀히 풀림). — **통과 설계**.
2. **정의** : 입력 두 복제본, 출력 [0,1] 수. 규칙 명확. — **통과**.
3. **무모순** : 실험으로 보이는 점성 폭발·노화(aging)와 충돌하지 않아야 한다. — **통과 가능**.
4. **표적** : "열역학적 상전이 vs 동적 동결을 가르기" 벽. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **3차원 실제 공간에서, 복제본 겹침 ⟦동결⟧#12가 유한 온도에서 진짜로 점프하는지 — 즉 진짜 열역학적 이상적 유리전이가 존재하는지 — 를 아무도 증명·반증 못했기 때문이다.** 평균장에선 점프가 있으나, 실제 3차원에선 "활성화 과정(barrier hopping)"이 점프를 뭉개버릴 수 있어, 전이가 *유한 온도* 가 아니라 *온도 0* 으로 밀려날 가능성을 못 배제한다.

**막힘 정직** : ⟦동결⟧#12의 정의·환원은 통과하나, *3차원에서의 점프 존재* 는 여기서부터 인류가 모른다. 시뮬레이션은 너무 느려져 Tg 아래를 충분히 못 본다(아이러니하게, 멈춤 자체가 검증을 막는다).

**[정직 판정]** 이 가칭 도구 ⟦동결⟧#12 는 진짜 부분 도구 — 두 복제본의 겹침(overlap)은 정의·환원이 통과하고(평균장 1-RSB 전이를 실제로 재현, 검문소1·2), 양인지 0인지를 시뮬레이션으로 *계산*할 수 있다. 다만 3차원 실제 공간에서 그 겹침이 유한 온도에서 진짜 점프하는지가 미해결(검문소5). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 활성화 과정이 점프를 뭉개는지를 가려, 3D에서 이상적 유리전이의 존재를 판정하는 것)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **모드결합이론(MCT)**(동역학적 느려짐을 부분 설명, 단 진짜 멈춤보다 높은 온도에서 가짜 발산), **평균장 유리 이론(RFOT, 복제 1-RSB)**(이상적 유리전이 예측), **동적 불균질성 측정**(원자들이 떼지어 함께 움직임 관찰). **3차원 실제 유리전이가 진짜 열역학 상전이인지는 미해결.** 여기서부터 인류가 모른다.

**새 의문** : "보이지 않는 *질서변수* 도 이렇게 잡기 어려운데 — 아예 보이지 않는 *질량* 그 자체, 은하를 붙잡는 정체불명의 것을 우리는 어떤 식으로 적나?" → #13으로 직결.

# ◆ 난제 #13  암흑물질 (은하를 붙잡는 보이지 않는 것)  [축: 물리]

## 1) 현상

은하는 거대한 회오리처럼 돈다. 가장자리 별이 떨어져 나가지 않으려면, 중심에 충분한 질량의 중력이 있어야 한다. 그런데 **눈에 보이는 별·가스를 다 합쳐도 질량이 한참 모자란다.** 보이는 질량만으로 계산하면 바깥 별들은 너무 빨라서 진작 흩어졌어야 한다. 그런데 안 흩어진다.

은하 회전곡선(별의 속도 v를 중심거리 r에 따라 그린 것)은 바깥에서 *평평* 하다 — 보이는 질량 예측(바깥에서 떨어짐)과 정면으로 어긋난다. 무언가 보이지 않는 것이 질량의 약 5배를 더 보태고 있다(암흑물질, dark matter). **그것이 무엇인지, 그것의 *식* 이 무엇인지 우리는 모른다.** 새 입자인가? 아니면 중력 법칙 자체가 큰 스케일에서 틀린 것인가(MOND)? 우주론 최대 난제다.

## 2) 동원 무기 ★A 연결★

- **지구17 중력(아인슈타인 장방정식·뉴턴 극한)** : 회전 속도와 질량을 잇는 법.
- **지구04 통계역학·분포함수** : 수많은 별·암흑물질 입자의 평균 분포.
- **지구03 곡률** : 빛이 휘는 정도(중력렌즈)로 보이지 않는 질량을 재는 자.
- **F13 미분방정식·F07 적분** : 회전곡선·밀도분포의 바닥 연장.

연결의 깊이: 뉴턴 중력(지구17의 약한 극한)은 태양계에서 완벽하다. 행성 속도를 질량으로 정확히 예측한다. *은하 스케일* 로 키우면 — 같은 법칙이 관측과 어긋난다. 무기가 스케일을 넘으며 깨진다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 회전 속도, ΛCDM, MOND:

```
   v(r) = √(G·M(r)/r)  (뉴턴),    ΛCDM,    MOND: a = √(a_N · a₀)
```

기호 해부:

- **v(r)** : 중심에서 거리 r인 별의 공전 속도. √는 제곱근.
- **G** : 뉴턴 중력상수.
- **M(r)** : 반지름 r 안에 든 총 질량. 보이는 것만 넣으면 바깥에서 늘지 않아 v가 떨어진다.
- **통째 의미(뉴턴)** : "중력이 별을 안으로 당기는 힘 = 원운동에 필요한 힘"에서 나온 식. M(r)이 바깥에서 안 늘면 v∝1/√r 로 *떨어져야* 한다. 관측은 평평 — 모순.
- **Λ(람다, Lambda)** : 우주상수(cosmological constant), 우주를 가속 팽창시키는 암흑에너지. (λ는 고유값·파장도 뜻하나 여기선 우주상수 — 못박는다.)
- **CDM** : 차가운 암흑물질(Cold Dark Matter), "느리게 움직이는 보이지 않는 입자". ΛCDM = 우주를 가장 잘 맞추는 표준 모형(암흑에너지 + 암흑물질).
- **a, a_N, a₀** : MOND의 가속도. a_N은 뉴턴이 예측한 가속도, a₀은 "이보다 작은 가속도에선 중력 법칙이 바뀐다"는 문턱(≈1.2×10⁻¹⁰ m/s²). a=√(a_N·a₀)는 약한 중력에서 수정된 가속.

파탄의 메커니즘 — **보이는 질량으로는 못 맞춤**:

```
   회전곡선:  바깥 별의 속도 v 를 거리 r 로 그리면

   v │   ╭──────────────  ← 관측(평평!)
     │  ╱
     │ ╱  ╲
     │╱     ╲___________  ← 보이는 질량만 쓴 뉴턴 예측(떨어짐)
     └──────────────── r
            ↑ 둘 사이의 간극 = "보이지 않는 질량"이 메워야 함

   두 갈래 처방, 둘 다 흠:
   ┌─────────────────────────┬──────────────────────────┐
   │ ① 새 입자(ΛCDM)         │ ② 중력 수정(MOND)        │
   │  은하 헤일로를 채움      │  a₀ 아래서 법칙 바꿈      │
   │  → 은하 회전 잘 맞음     │  → 은하 회전 잘 맞음      │
   │  ✗ 입자 직접검출 다 실패 │  ✗ 은하단·우주배경엔 실패 │
   │  ✗ 작은 은하 구조 안 맞음│  ✗ 상대론 확장이 추함     │
   └─────────────────────────┴──────────────────────────┘
```

무기가 멈추는 자리: 뉴턴·아인슈타인 중력(지구17)에 *보이는 질량만* 넣으면 회전곡선이 안 맞는다. 두 처방 모두 한쪽을 맞추면 다른 쪽이 깨진다. ΛCDM은 은하단·우주배경복사(CMB)·거대구조를 훌륭히 맞추나 *그 입자를 30년 직접검출에서 한 번도 못 봤고*, 작은 은하의 내부 구조(코어-첨두 문제)가 어긋난다. MOND는 *개별 은하* 회전을 입자 없이 놀랍도록 맞추나(바리온 타리-피셔 관계), 은하단·CMB·중력렌즈에서 무너지고 상대론적 확장(TeVeS 등)이 인위적이다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 작은 스케일(은하)에서 MOND처럼, 큰 스케일(은하단·우주)에서 ΛCDM처럼 *자동으로 갈아타는* 단일 양. 또는 보이지 않는 질량의 분포를 보이는 것에서 유일하게 복원하는 연산자.

가칭 정의 — **스케일전이 중력핵 ⟦스케일중력⟧#13(scale-switching gravity kernel)**:

```
   입력:  보이는 물질 분포 ρ_vis(r) + 가속 스케일 a
            │
            ▼
   ┌────────────────────────────────────────────────┐
   │  ⟦스케일중력⟧#13[ρ_vis](r) = 유효 중력가속도                   │
   │   a ≫ a₀  : 뉴턴/아인슈타인으로 환원(태양계)     │
   │   a ≪ a₀  : 회전곡선 평평(은하 바깥)            │
   │   큰 스케일 : 추가 보이지 않는 성분 자동 포함    │
   │              (은하단·CMB 동시 만족)              │
   └────────────────────────────────────────────────┘
            │
            ▼
   출력:  v(r) 예측 + 중력렌즈 휘는각 동시에

   스케일에 따른 전환:
   a:  큰 ───────── a₀ ───────── 작은
       │뉴턴 정확│  전환  │회전 평평│
       태양계        은하 바깥
       (단 은하단·우주 스케일은 또 다른 거동을 자동으로?)
```

- **a₀** : MOND 가속 문턱. ⟦스케일중력⟧#13는 이 한 상수만으로 두 거동을 잇기를 시도.
- **유효 중력가속도** : 보이는 질량이 만드는 진짜 가속이 아니라, ⟦스케일중력⟧#13이 "이만큼인 것처럼 굴어라"라고 내놓는 값.
- 핵심: 단일 핵 ⟦스케일중력⟧#13으로 스케일별 거동을 자동 전환 — 두 처방을 하나로. 단 *은하단·CMB까지* 동시에 맞추는 ⟦스케일중력⟧#13은 아직 없다.

**5대 검문소**:

1. **환원** : a≫a₀(태양계·고밀도)에서 ⟦스케일중력⟧#13은 뉴턴/아인슈타인으로 정확히 환원되어야 한다(수성 세차·달 거리 검증 통과). — **통과 필수**.
2. **정의** : 입출력 명확하나, "큰 스케일에서 보이지 않는 성분을 자동 포함"하는 규칙의 *구체적 모양* 이 미정. — **막힘**.
3. **무모순** : 우주배경복사(CMB)의 음향 봉우리 비율, 빅뱅 핵합성, 중력렌즈를 *동시에* 만족해야 한다. MOND 계열이 여기서 다 깨졌다 — ⟦스케일중력⟧#13이 이를 어떻게 피할지가 핵심. — **위험**.
4. **표적** : "은하 스케일 회전 + 큰 스케일 우주론을 한 법칙으로" 벽. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **'은하 회전을 입자 없이 맞추는 거동'과 'CMB·은하단을 맞추는 거동'이 서로 다른 물리를 요구하는 것처럼 보이기 때문이다.** 한쪽을 한 상수 a₀로 잡으면 다른 쪽이 어긋난다. 둘을 잇는 단일 법칙이 *존재하는지조차* 불확실하다 — 어쩌면 정말로 새 입자가 답이고, ⟦스케일중력⟧#13은 신기루일 수 있다.

**막힘 정직** : 검문소 2·3에서 막힌다. 큰 스케일 거동의 구체적 형태는 여기서부터 인류가 모른다. 더 정직하게: ⟦스케일중력⟧#13(중력 수정)이 옳은 길인지, 아니면 그냥 *새 입자를 직접 검출* 하는 게 옳은 길인지 — 자연이 어느 쪽인지 우리는 모른다.

**[정직 판정]** 이 가칭 도구 ⟦스케일중력⟧#13 은 재명명에 가까움 — "큰 스케일에서 보이지 않는 성분을 자동 포함"하는 규칙의 구체적 모양이 비어 있고(검문소2 막힘), 그런 단일 법칙이 *존재하는지조차* 불확실하다(신기루일 수 있음). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 은하 회전·은하단·CMB를 한 상수로 동시에 맞추는 거동을 실제로 *계산*하는 핵, 또는 그것이 불가능함의 증명)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **ΛCDM 표준 모형**(CMB·거대구조·은하단을 정밀히 맞춤, 단 입자 미검출 + 소규모 구조 긴장), **MOND/바리온 타리-피셔 관계**(개별 은하 회전을 놀랍게 맞춤, 단 우주론 스케일 실패), **중력렌즈 질량 지도**(총알 은하단 — 보이는 물질과 질량 중심이 어긋나 새 입자 쪽 유리). **암흑물질의 정체는 미해결.** 여기서부터 인류가 모른다.

**새 의문** : "은하 *하나* 의 보이지 않는 질량도 못 잡는데 — 우주에 흩뿌려진 *수십억 은하의 전체 무늬*, 그 미세한 치우침(완벽한 무작위가 아닌 쏠림)은 어떤 통계로 잡나?" → #14로 직결.

# ◆ 난제 #14  비가우시안성 (우주 거대구조의 치우침)  [축: 물리]

## 1) 현상

밤하늘의 은하들은 무작위로 흩뿌려져 있지 않다. 거대한 **거미줄(우주 거대구조, cosmic web)** — 은하들이 실처럼 이어지고, 그 사이는 텅 빈 거품 — 을 이룬다. 이 무늬는 빅뱅 직후의 미세한 밀도 요동이 중력으로 자라난 결과다.

가장 단순한 우주 모형은 그 초기 요동이 *완벽한 종 모양(가우시안, Gaussian) 무작위* 라고 본다. 동전 던지기를 무수히 더한 것처럼 좌우 대칭의 깔끔한 분포. 그런데 **자연이 정말 완벽히 가우시안인지, 아니면 미세하게 한쪽으로 치우쳤는지(비가우시안, non-Gaussian)** 가 우주의 *시작* 에 대한 결정적 단서다. 인플레이션(초기 급팽창)의 어느 모형이 옳은지가 이 치우침의 크기 f_NL 하나에 달렸다. 그 치우침을 *어떤 통계로* 정확히 잡느냐가 현대 우주론의 최전선이다.

## 2) 동원 무기 ★A 연결★

- **지구04 확률분포·가우시안** : 무작위 요동의 기본 종 모양.
- **지구04 중심극한정리(central limit theorem)** : "독립된 무작위를 많이 더하면 가우시안" — 왜 가우시안이 기본인지.
- **지구13 거시통계·확률과정** : 공간에 펼쳐진 무작위장(random field)을 다루는 자.
- **지구04 상관함수·푸리에** : 점들이 얼마나 함께 뭉치는지 스케일별로 재기.

연결의 깊이: 중심극한정리(지구04)는 "왜 자연이 가우시안에 가까운가"를 설명한다 — 수많은 독립 요동의 합. 2점 상관(파워 스펙트럼)까지는 가우시안이 *완전히* 결정한다. 치우침을 보려면 *그 너머* 가 필요해 무기가 부족해진다.

## 3) 모든 도구의 파탄 + ASCII

핵심 식 — 상관함수, 파워 스펙트럼, 비가우시안 변수:

```
   ξ(r) = ⟨δ(x)δ(x+r)⟩ ,   P(k) ,   f_NL (비가우시안 크기)
```

기호 해부:

- **δ(x)** : 밀도 대조(density contrast), "이 점의 밀도가 평균보다 얼마나 높나/낮나"(δ=0이면 평균). (δ는 디랙 델타·변분도 뜻하나 여기선 밀도 대조 — 못박는다.)
- **ξ(r)** : 2점 상관함수(two-point correlation). ⟨·⟩는 온 우주 평균. "거리 r 떨어진 두 점의 밀도 치우침이 얼마나 함께 가나" — 은하가 뭉치는 정도. (ξ는 #12의 상관길이와 같은 글자지만 여기선 상관*함수* — 못박는다.)
- **P(k)** : 파워 스펙트럼(power spectrum), ξ를 푸리에 변환한 것. "스케일 k(파수)마다 요동의 세기가 얼마나". 2점 정보의 전부.
- **f_NL** : 비가우시안성의 크기를 재는 한 수. NL은 nonlinear(비선형). f_NL=0이면 완벽 가우시안, 0이 아니면 치우침. 인플레이션 모형마다 다른 f_NL을 예측 — 그래서 이 한 수가 우주의 시작을 가린다.
- **통째 의미** : "은하가 어떻게 뭉쳤나를 2점(ξ, P(k))으로 적는다. 하지만 *치우침* 은 2점에 안 담긴다 — 3점 이상이 필요하다."

파탄의 메커니즘 — **2점 통계의 맹점**:

```
   가우시안이면: P(k)(2점)만으로 무늬가 완전히 결정됨.
                 3점·4점은 2점에서 자동 계산(새 정보 0).

   비가우시안이면: 2점이 같아도 무늬가 다를 수 있다!
   ┌──────────────────────────┬──────────────────────────┐
   │ 가우시안(대칭)            │ 비가우시안(치우침)        │
   │   ·  · ·  ·  ·            │   ··· 빽빽한 덩이 ·        │
   │  ·  ·  ·  ·  ·            │  ·          텅 빈 곳      │
   │   대칭적 종모양 분포      │   한쪽 꼬리가 두툼함      │
   │   P(k)로 전부 설명        │   P(k) 같아도 3점이 다름   │
   └──────────────────────────┴──────────────────────────┘
                                       │
                 3점 상관(쌍스펙트럼 bispectrum B)이 f_NL 을 잡음
                 B(k₁,k₂,k₃): 세 점이 삼각형을 이루는 모든 모양마다 다름
                              → 측정할 삼각형이 천문학적으로 많음
```

무기가 멈추는 자리: 가우시안 장은 2점(P(k))이 *모든 것* 을 결정한다 — 중심극한정리의 깔끔함. 그러나 치우침은 정의상 2점에 *안 담긴다.* 3점 상관(쌍스펙트럼 bispectrum)부터 비가우시안 정보가 나오는데, (1) 3점은 *세 점이 이루는 삼각형의 모든 모양·크기* 마다 다른 값이라 측정·예측해야 할 양이 폭발하고, (2) 중력이 *자라면서 스스로* 비가우시안을 만들어(비선형 성장), 초기의 진짜 f_NL과 나중에 생긴 가짜 비가우시안을 분리하기가 어렵고, (3) 은하가 암흑물질을 어떻게 따라가는지(편향, bias)가 불확실해 잡음이 낀다.

## 4) 〈도구 설계 의뢰〉 ★궁극 목적★

**의뢰** : 모든 차수의 치우침을 한 캔버스에 압축하되, *초기 비가우시안* f_NL을 *중력이 나중에 만든* 비가우시안에서 깔끔히 분리하는 양.

가칭 정의 — **치우침 분리 연산자 ⟦치우침⟧#14(skew-separator operator, 나비 매듭 기호)**:

```
   입력:  은하 밀도장 δ(x) (관측된 우주 거대구조)
            │
            ▼
   ┌──────────────────────────────────────────────┐
   │  ⟦치우침⟧#14[δ] = (초기 f_NL 성분, 중력성장 성분, 편향성분)│
   │   고차 상관(3점·4점·...)을 한 묶음으로 짜되      │
   │   모양(삼각형 종류)별로 초기/성장 신호를 분리   │
   └──────────────────────────────────────────────┘
            │
            ▼
   출력:  초기 비가우시안 f_NL 하나 + 오차막대

   삼각형 모양으로 신호 가르기:
     찌그러진 삼각형(squeezed)  ◁    ← 초기 f_NL 에 민감(국소형)
     정삼각형(equilateral)     △    ← 다른 인플레이션 모형
     납작한 삼각형(folded)     ▭    ← 또 다른 모형
        ⟦치우침⟧#14 이 모양별 가중치로 초기/성장/편향을 직교 분해
```

- **bispectrum B(k₁,k₂,k₃)** : 3점 상관의 푸리에 짝. 세 파수가 이루는 삼각형마다 값이 다르다.
- **squeezed/equilateral/folded** : 삼각형의 모양. 인플레이션의 종류마다 어느 모양에 신호가 실리는지 다르다 — ⟦치우침⟧#14은 이 모양 의존성을 이용해 분리.
- **직교 분해(orthogonal decomposition)** : 초기·성장·편향 성분이 서로 안 섞이게 가르는 것.
- 핵심: 현재는 특정 모양(템플릿)에 맞춰 f_NL을 따로따로 추정한다. ⟦치우침⟧#14은 모든 모양을 한 번에 직교 분해해, 초기 신호를 성장·편향에서 일관되게 떼어내기를 시도.

**5대 검문소**:

1. **환원** : f_NL=0(완벽 가우시안)이면 ⟦치우침⟧#14의 초기 성분은 0을 내놓고, 모든 정보가 P(k)로 환원되어야 한다(중심극한정리 일치). — **통과 설계**.
2. **정의** : 입력 밀도장, 출력 세 성분. 단 "중력성장 비가우시안"을 *모든 차수에서* 정확히 적는 비섭동 표현이 미정(섭동론은 큰 스케일에서만 닫힘). — **부분 막힘**.
3. **무모순** : 플랑크 위성의 CMB 측정(f_NL^local ≈ 0 ± 5 수준)과 충돌하면 안 된다. — **통과 가능**(검증 가능).
4. **표적** : "초기 비가우시안을 후기 비선형·편향에서 분리" 벽. — **명중**.
5. **정직(왜 아무도 못 만들었나?)** : **중력이 요동을 키우는 과정 자체가 비가우시안을 만들어내, 늦은 시각의 우주에는 '초기의 치우침'과 '중력이 빚은 치우침'이 같은 통계량 안에 섞여 들어가기 때문이다.** 둘을 가르려면 비선형 중력 성장을 *모든 스케일에서* 정확히 알아야 하는데, 작은 스케일에선 섭동론이 닫히지 않고(다시 #8의 비선형 벽과 닿는다), 은하 편향까지 얽혀 직교 분해가 깨진다.

**막힘 정직** : 검문소 2에서 막힌다. 작은 스케일 비선형 중력 성장의 비섭동 표현은 여기서부터 인류가 모른다 — 이는 #8 나비에-스토크스의 비선형 캐스케이드와 같은 종류의 벽이다(중력 N체의 비선형). 큰 스케일에선 ⟦치우침⟧#14가 작동할 여지가 있으나, 작은 스케일 정보를 못 쓰면 f_NL 측정 정밀도가 갇힌다.

**[정직 판정]** 이 가칭 도구 ⟦치우침⟧#14 는 진짜 부분 도구 — 큰 스케일에선 삼각형 모양별 직교 분해로 초기 f_NL을 실제로 *떼어내 측정*한다(검문소1·3 통과, 플랑크 측정이 그 예). 다만 작은 스케일에선 중력 성장 비가우시안의 비섭동 표현이 비어 있다(검문소2 막힘, #8의 비선형 벽과 같은 종). 진짜 새 도구가 되려면 메워야 할 빈칸은 ○○(구체적으로: 모든 스케일에서 비선형 중력 성장을 정확히 적어 초기/성장/편향을 *계산*으로 직교 분해하는 규칙)이다.

## 5) 정직한 최전선 + 새 의문

현재 최선: **플랑크 CMB f_NL 측정**(국소형 f_NL = 0 근처로 강하게 제약 — 가장 단순한 인플레이션과 일치), **은하 쌍스펙트럼·스케일 의존 편향**(큰 스케일에서 f_NL 추가 제약), **차세대 탐사(거대구조 3차원 지도)**가 정밀도를 끌어올리는 중. **초기 비가우시안의 정확한 분리·측정은 미해결 최전선.** 여기서부터 인류가 모른다.
